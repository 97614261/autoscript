# 原生完整流程公开示例

源文件只包含合成数据，不读取私人脚本，不发送按键/点击/滑动。运行 `scripts/build-native-example.py` 生成 `build/native-example/native-workflow.zip`，可导入智构。模板由脚本生成，是1×1像素RGBA(10,20,30,255)。它只用于主机夹具验证，并非有实际业务意义的图像。

流程：截图区域(0,0)-(2,2)→多结果找图→读取数量→AND/NOT复合判断→1–5次循环→计算全局次数→调用worker插件→分别输出运行提示与开发日志→更新界面状态→到时消失的提示。

主机回归分别覆盖找到、未找到、参数越界与界面绑定更新；设备上一般找不到这个合成模板，会执行安全失败分支。项目列表「启动」先配置界面，编辑器「运行」直接使用默认值并跳过界面事件循环。独立Runner按照既有界面事件机制运行，停止由系统浮球控制。没有为了示例强制显示运行中已隐藏的配置窗。

生成的ZIP、冻结资源和独立Runner产物在忽略的build目录中，原稿没有模板二进制或用户素材。备份恢复应保留两个插件、六个变量、界面与提示样式。
