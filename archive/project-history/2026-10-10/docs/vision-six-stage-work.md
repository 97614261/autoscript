# 截图与找图六阶段收口

本批按用户确认的1至6执行，不运行私人脚本，不承诺目标设备固定毫秒数；既有未提交修改保持。

## 工作清单

1. 日志对比：提供真实入口、同记录条件分组、环境检查、样本及百分位变化、导出/复制和不完整警告。旧日志缺少模板内容指纹时明确说明不能确认输入完全一致。
2. Rust精确比较：评估安全批量比较的增量收益，以原路径差分验证预算、取消、评分及顺序；没有收益不合入。
3. 截图读回：核对位图与硬件资源所有权、软件/硬件路径及格式；有等价证据才修改。GPU到CPU复制不能通过复用旧屏消除。
4. 认证传输：按实际SHA运行时选择和已有复制优化复核，保留逐包认证。没有可信收益不更换协议。
5. 可靠性：新增长日志/异常组合回归，运行生命周期和Root会话回归完整执行，目标设备长运行列为待用户实测。
6. 构建交付：开发门禁与MuMu保留数据安装，隔离arm64候选包门禁，集中验收清单。

## 主机合成基准

设备Windows x86_64、Intel Core Ultra9 285H；SHA指令可用；Rust dev热门crate优化，不并发Android构建。模板比较：200×122，RGBA/BGRA，不透明，容差0，900‰，预算10^9，本基准无取消回调（预算/取消一致性另由差分测试覆盖）；每轮100个指定候选连续行段，无ROI遍历、截图或读盘。10轮预热后100轮交替顺序，最近秩P50/P95/P99。

| BGRA比较场景 | 现有 P50/P95/P99 ms | 32位候选 P50/P95/P99 ms |
| --- | --- | --- |
| 全匹配 | 0.3353 / 0.4439 / 0.5141 | 0.3335 / 0.4120 / 0.4447 |
| 每5像素不匹配1个，阈值退出 | 0.1764 / 0.2781 / 0.2987 | 0.1766 / 0.2716 / 0.2939 |
| 每17像素不匹配1个 | 0.3442 / 0.4071 / 0.4879 | 0.3424 / 0.3941 / 0.4888 |

RGBA结果同样没有稳定中位收益；整块相等原型在BGRA全匹配中P50为0.4736ms、现有0.3346ms，在六项场景都更慢，因此没有保留该捷径为生产优化。32位实验默认不运行、只在测试编译中启用；生产调用固定为原路径。

认证仅HMAC数据体计时，每帧720×1280×4=3,686,400字节，没有ROI或模板。每轮5帧，10轮预热后100轮按3种大小轮换顺序，结果按单帧归一化；不含包头、Socket、读回、对端验签和调度，不推断MuMu的11ms可降至本机值。

## 集中设备验收清单

以下仍待用户统一测试，不以单元测试或构建成功冒充设备通过：

1. 新旧两次同脚本日志打开对比，检查样本、P50/P95/P99、输入条件与变化；切换运行/通道和刷新不留下旧红字。
2. 连续运行10至30分钟，找图找到与未找到分别观察；暂停/继续、截图中停止及新运行后没有旧结果或提示复活。
3. 横竖屏切换、屏幕尺寸变化、Root断开/恢复、截图后端失败时给出真实错误，不返回旧画面或半帧；记录实际后端。
4. 编辑器直接运行终止后回编辑；项目列表启动终止后回保留参数的配置界面，主动停止关闭两类运行提示。
5. 手机arm64单独验证上述流程，再导出相同输入的性能记录；手机与MuMu结果不能混合。
