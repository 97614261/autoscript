# 像素找图超时与开发包优化

2026-10-05。用户运行在 `Screen.findImages` 收到 `FRAME_OPERATION_FAILED: Vision(Cancelled)`，表示搜索被中断；原代码将5秒截止和任务取消合并在同一个回调。没有读取私人脚本或声称设备耗时已复现。

## 本批范围

- Cargo dev仅对pixel-vision启用opt-level=3，保留开发调试与溢出检查。Studio、内嵌Runner和手机ABI构建共用此配置，不改ABI/构件缓存目录，不改变Debug签名性质。
- 模板遍历改为安全的逐行切片，消除逐像素的模板位置换算与重复帧行偏移；失败判定以允许不匹配数计数，数学上保持原阈值与最终分数。稀有锚点顺序、逐像素比较数量、透明过滤、方向、步长与预算不变，无跳点、缩放或算法切换。
- 单图、多图首结果与多图结果均使用同一有界控制器，5秒截止保留。记录中断原因，优先任务停止胜过同一检查点超时。错误使用 `VISION_SEARCH_TIMEOUT`、`VISION_SEARCH_CANCELLED`、`VISION_COMPARISON_BUDGET_EXCEEDED`；非中断错误保留原语义，不能转成未找到。
- 找图中收到Stop/任务取消，不再用Lua错误恢复协程；同一drive轮次恢复协程前处理优先取消，仍走任务资源释放。没有增加普通队列轮询或改动Lua线程约束。
- 调试失败提示区分超时、预算与停止，建议缩小ROI、减少模板；不复制用户脚本到提示或文档。
