AutoScript 基础字库与制作工具

用途

ASGLYPH v1用于固定游戏字体和数字等小型离线OCR。制作源用#表示前景、.表示背景；工具会自动裁掉四周空白，再生成运行时字库和独立HTML预览。

制作命令

cargo run --offline -p glyph-maker -- tools/glyph-maker/examples/basic.json dictionaries/main.asglyph glyph-preview.html

为防止误覆盖，输出文件已存在时命令会拒绝写入。

项目声明

"resources": [
  { "kind": "glyphDictionary", "path": "dictionaries/main.asglyph" }
]

Runner启动项目时先按路径稳定排序并注册全部资源，任一资源失败就停止当前会话，不运行部分装载的项目。

运行接口

local frame = Screen.cache(Screen.capture())
local dict = Ocr.loadDictionary("dictionaries/main.asglyph")
local result = Ocr.glyph(frame, dict, 0xffffff, 20, 850, 0, 0, 720, 1280, 3)
Ocr.releaseDictionary(dict)
Screen.release(frame)

结果包含text、coveragePermille和averageScorePermille。
