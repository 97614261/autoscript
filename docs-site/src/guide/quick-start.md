# 第一个自动化项目

先用一条无设备输入的提示验证流程，再加入截图、判断与点击。以下操作不会替你执行脚本；运行始终由你在 App 内确认。

## 创建和编辑

1. 在「项目」页新建可视化项目，选择基准分辨率。
2. 点「编辑」，打开系统悬浮编辑窗。点最小化后才显示编辑吸附球，点球回到编辑窗。
3. 在「调试」中配置一条「弹出提示」，输入文本，选择插入位置并加入积木。
4. 点「运行」。编辑器会先保存、校验并准备运行，编辑窗保留；运行按钮变成停止。

提示需要开启项目提示总开关。提示内容与 App 诊断日志是两个独立通道。

## 加入条件和循环

在「变量」中先声明需要的变量，再加入赋值或计算。判断和循环引用已声明变量；局部变量只属于当前插件，不会因为加入方便而隐式创建变量。

点「循环」直接配置循环体，选择次数、条件或限时模式。跳出循环和结束本次循环应放在循环体中。

## 执行与启动的区别

| 入口 | 行为 |
| --- | --- |
| 编辑器运行 | 直接试运行当前保存后的项目，使用默认配置，不先显示设计界面。 |
| 空闲时单步 | 测试选中的可执行积木及子树，不执行前置流程。 |
| 暂停时单步 | 推进当前已经运行的脚本，不创建另一份运行。 |
| 项目页启动 | 有设计界面时先显示配置，确认后执行；没有界面则直接执行。停止后恢复所属配置界面。 |
