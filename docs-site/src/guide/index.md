# 认识智构

智构是本地优先的 Android 自动化工具。你可以用可视化积木组合输入、图像识别、变量、判断和循环，再在其他 App 上方的悬浮编辑窗里调试。

## 使用前准备

- Android 7.0（API 24）及以上；首发设备架构为 arm64。
- 当前自动化后端需要 Root。Runner 已连接、Root 已就绪与实际输入能力是不同状态，可在「我的」里的权限与运行环境中分别查看。
- 跨 App 编辑、选点和提示需要系统悬浮窗授权。权限由你确认，项目声明不能自动授予系统权限。

## 三个核心概念

| 概念 | 用途 |
| --- | --- |
| 项目 | 一份完整脚本工程，包含插件、变量、图片及设计界面。 |
| 插件 | 项目中的独立流程文件，内部标识仍为 `flowId`；主插件是运行入口。不是 Android 扩展插件。 |
| 积木 | 一项操作或控制结构。参数先成为草稿，校验保存后才作为正式工程使用。 |
