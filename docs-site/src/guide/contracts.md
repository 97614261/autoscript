# 能力与资源约定

API 页不仅列出函数名，也保留执行边界。使用前应同时检查能力、坐标、结果类型和资源所有权。

## 能力声明与系统授权

`project.json.capabilities` 是项目脚本能力声明的唯一来源。新建可视化项目默认勾选当前支持的脚本能力；已有项目保留原选择。声明能力不等于授予悬浮窗权限、获取 Root 或安装可选视觉组件。

API 详情中的「能力声明」是对应契约字段。组合流程还可能需要截图、输入或私有文件能力，不能只根据一项识别 API 推断整段流程需要什么。

## 坐标和区域

输入通常使用设计坐标；图像区域和处理结果以各 API 参数说明为准。矩形常用 `[left, top, right, bottom)` 半开区间，右边和下边不包含在内。

裁剪、旋转、镜像或缩放后得到的图像坐标，不等于原始屏幕坐标。不要把处理图的识别结果未经映射就用于点击。提示窗位置使用真实屏幕像素，`-1` 表示该轴居中，`0` 是真实原点。

## 帧与字库

- `Screen.capture` 返回短生命周期采集编号；需要缓存帧时再传给 `Screen.cache`。
- 缓存帧、加载图片帧和处理结果的持有与释放以契约为准。`Screen.release` 只用于你实际持有的帧。
- 借用帧或帧系列不转移所有权，不因为一次识别结束就重复释放来源。
- 字库通过 `Ocr.loadDictionary` 取得，使用结束后通过 `Ocr.releaseDictionary` 释放。
- 任务句柄不能跨已结束的运行复用；停止和取消后的迟到结果不能当成下一次运行结果。

## 超时与取消

「无匹配」「截图失败」「预算超限」「超时」「取消」不是同一种结果。可空识别结果允许返回 `nil`；失败不能伪装成正常未找到。

契约中的超时是接口边界，不保证宿主或 SDK 工作可被硬实时抢占。循环中应设置真实等待、退出条件与期限，避免无意义地反复截图。

## 文件和隐私

`Files` 操作限定在项目私有数据范围内，不能用于任意系统路径。图片、字库和项目音频应明确登记为资源；普通文本不能用来绕过资源声明或路径校验。

文档站不连接 Runner，不访问项目文件，不记录变量值，也不会执行示例中的设备输入。目录搜索在浏览器本地完成，不使用在线搜索服务。
