# AI 助手

在项目的可视化编辑器右侧点击 **AI**，打开后点 **设置**，填写兼容聊天补全接口地址、密钥和模型名称。接口地址可填到 `/v1`，也可填写完整的 `/chat/completions` 地址。先测试连接，再保存配置。

通常使用默认的 `max_tokens` 参数；接口要求 `max_completion_tokens` 时勾选新模型参数。模型配置仅保存在当前 App 中，不随项目备份导出。

## 四种使用方式

| 方式 | 用法 |
| --- | --- |
| 生成 | 描述步骤，例如“点击指定位置，每次等500毫秒，重复10次”。选择所选前面、后面、分支内或插件末尾作为加入位置。 |
| 修改 | 先选择积木，再要求改参数、增加处理或重新组织所选内容。整段替换需要选择同层连续的积木。 |
| 解释 | 让 AI 说明当前插件或所选积木做什么，可以继续追问。此模式不修改项目。 |
| 排错 | 结合当前插件和最近错误分析，也可以粘贴报错。此模式给出建议，不直接修改项目。 |

模型会收到当前插件、项目中声明的变量、插件参数与资源名称；不会自动收到截图、图片内容或运行变量值。点击发送前可查看面板中的发送范围说明。项目文字会发送到你配置的模型接口，请使用自己信任的服务。

## 先预览，再应用

1. 发送需求，等待函数选择及方案生成。
2. 继续补充要求，或点击 **引用** 指定已有变量和资源。缺少的变量、图片或字库会列出来，补充后重新生成。
3. 点击 **预览修改**，系统校验完整项目。校验失败会显示原因，可以把原因补充给 AI 再调整。
4. 查看新增、删除和改参数量，并切换查看原内容、新内容。
5. 点击 **确认应用**，修改进入当前草稿，可用编辑器的撤销/重做返回。检查后仍需正常保存；不会自动运行。

生成期间切换插件、改变选择、编辑项目或运行脚本，会使原方案失效，需要关闭后重新打开，防止写错位置。

## 取消与重试

生成中可以点击 **停止**，失败可以直接 **重试**，也能保留输入继续调整。新对话会清除本次对话与未应用方案。关闭时若还有未应用方案或未保存配置，会先询问是否丢弃。

较大的插件和需求建议拆分处理。第一版一次最多生成256行、16层积木，使用当前插件上下文及最近四轮对话。模型生成内容需要检查，完整编译校验也不代表它完全符合你的实际业务目标。
