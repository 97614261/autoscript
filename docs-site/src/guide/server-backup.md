# 个人服务器项目备份

此入口要求智构 **0.1.16 或更高版本**，需要先单独部署备份服务；旧版 App 和仅更新网页不会自动出现。

## 手动备份

打开「备份管理 → 服务器 → 设置」，填写个人服务器根地址和独立备份密钥，保存后点刷新。
先保存并关闭编辑/配置窗口、停止脚本，再选择本机项目，确认上传。

上传包含正式脚本、界面和项目资源，不含未保存草稿、运行日志、运行数据。
每份 ZIP 最多 128 MiB，最多保留 32 份、合计 2 GiB；不自动同步或删除旧快照。

## 恢复

刷新列表，选择快照的「恢复为新项目」并确认。
下载会经过签名、大小、摘要、解密验证，再交给原有项目导入流程；恢复不会覆盖或运行原项目。
网络阶段可取消；本机最后导入提交阶段请等待完成。

## 密钥与删除

备份密钥与 APK 发布密钥必须独立，需要用户另行保管，不要发到聊天或日志。
清除 App 数据或换设备后，重新填写相同密钥才能恢复。丢失密钥无法解密，不要直接重新生成。
服务管理员持有同一密钥，因此服务器仍须可信。
HTTP 中的项目和名称已经加密，但传输大小/时间可被观察，仍可能被阻断，不等同于 HTTPS。

每份快照的「删除备份」会要求确认，永久删除对应服务器快照，不影响本机项目。
容量满时需自己选择删除哪些备份，不会自动清理。
