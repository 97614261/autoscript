# App 内更新

智构 **0.1.2 / 版本代码 3** 起支持：打开 App 自动检查 → 发现新版 → 确认后在 App 内下载 → 系统确认安装。没有后台服务，不静默安装，不卸载旧版或清除项目。

## 第一次使用

旧版没有这项功能，网站无法给旧 App 自动增加代码。请先从[下载页](/download)手动安装一次支持更新的版本，之后使用 App 内更新。

在「我的 → 关于智构 → 应用更新」可以关闭自动检查、手动检查或修改更新地址。地址为文档站根地址，不附加 `/download` 或其他路径。更新地址只在本机保存。

自动检查只在 App 前台进行，每六小时最多一次；网络失败不阻止打开 App。手动「检查更新」不受六小时限制。只在站点新包的数值 `versionCode` 大于当前已安装版本时推荐升级，相同版本代码的不同开发构建不作为新版。

## 下载和安装

1. 阅读更新说明、架构和大小，先保存编辑、停止脚本并备份重要项目。
2. 点击「下载并安装」。显示下载进度，可随时取消；离开 App 会取消正在进行的下载，返回后可以重试。
3. 下载完成后检查精确大小、SHA-256、真实 APK 签名、包名、版本及架构；只有与当前智构使用同一签名的新版才会交给安装器。
4. Android 8+ 首次可能要求允许「智构」安装应用。点击「允许安装」，在系统设置中明确允许，返回后点击「安装更新」。不会在启动时申请此权限。
5. Android 安装器仍会询问是否安装。安装是否完成以系统提示和安装后的实际版本为准，打开安装器不等于已完成更新。

安装会重启智构；运行中的脚本需要先停止。一次最多下载 256 MiB、五分钟，失败或取消不会把不完整文件交给安装器。不会自动降级、绕过签名、申请 Root 安装或改变项目数据。

## 没有提示更新？

- **站点与当前版本相同**：正常，同一 `versionCode` 不重复升级。开发构建日期和摘要不同不算新版。
- **站点仍是旧版本**：服务器还没有部署新的站点和真实安装包，或网站被回滚；不会推荐降级。
- **没有适合设备的包**：手机与模拟器架构不同，必须发布相应的当前候选。历史列表中的兼容包不会冒充最新版本。
- **自动检查未完成**：检查网络及更新地址，再手动检查。清单不支持登录跳转、跨站重定向或关闭 HTTPS 校验。
- **下载或校验失败**：可能为网络中断、空间不足、文件不完整、版本/架构不符或签名不同；不会为安装而卸载旧版。

HTTP 连接没有传输加密；安装包仍会核对当前 App 签名，但不能保护版本信息不被屏蔽，也不能代替 HTTPS。建议给站点启用有效 HTTPS。

## 发布侧约定

网站和 App 复用同一份 `/downloads/release.json`。只有当前版本及 `alternatives` 是升级来源，`history` 仅用于网页回溯。不要单独手改清单：使用准备脚本从核对后的实际 APK 生成，保持版本、大小、摘要、架构和文件一致。

发布新版本必须增加 Android `versionCode`；版本代码退回会被发布准备脚本拒绝。网站回滚使用显式回滚工具，不对已安装 App 执行降级。清单使用 `application/json` 和 `Cache-Control: no-cache`，APK 使用带摘要的固定同源地址；站点激活前后均检查。

仅本地构建或打包不会更新线上网站，也不会使已安装 App 发现尚未部署的版本。
