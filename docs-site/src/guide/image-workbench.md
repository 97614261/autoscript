# 图像工作台：蒙版、清理与稳定识别

从截图工具或图片库打开图片工作台。所有操作生成独立处理图，不覆盖原图；保存会另建 PNG。显示放大不改变原像素。处理历史最多8次编辑、合计32MiB，运行流水线最多64步。

## 选择识别图像来源

「图像」菜单可设置新积木默认使用「每次截图」或「共用图像」，每项识别的参数页顶部也能单独选择。每次截图在实际识别时采集并自动释放；共用图像读取所选图像变量，多项识别完成后由脚本统一释放。该默认不改已有积木，不影响工作台测试当前图片或处理流水线读取最终处理图。详见[一帧可以做多次查询](./vision#一帧可以做多次查询)。

图像菜单会记住上次分类，截图取材、图片库、识别测试和制字入口按窗口大小自动排列。识别配置中，带下拉标记的数值标签可点选常用容差、相似度、置信度、频次和数量上限，再按需要手动修改；快捷值不会自动更换算法或其他参数。

普通参数窗在横屏保持紧凑宽度，坐标与操作按钮空间不足时自动换行；内容可上下滚动，复杂工具仍可手动全屏。滤色窗在矮窗口把预览纳入内容滚动，应用和取消保持独立，预览不会绘制到工具按钮上。

截图悬浮条直接显示截图、缩放、微调和确认，点「工具」展开滤色、处理、多边形和制字。滑动/长按时长、多点容差随模式显示。拖动左侧模式图标移动工具条，点击它切换模式。

点「微调」可以输入原图像素坐标：选区使用X/Y/宽/高，滑动和拖动分别设置起终点，多点取色可选中某一点修改或删除。坐标必须在原图内，应用后才生效；颜色点会重新读取相同原图坐标的颜色，修改不会执行触摸。资源和变量选择项显示对应名称，列表较长时可搜索筛选。

## 模板蒙版

1. 点击「蒙版」，放大到需要忽略的文字、数字或动态区域。
2. 用忽略笔或矩形清除区域；恢复笔只恢复本次蒙版编辑的输入像素。
3. 一笔一次撤销，取消手势不提交；可以撤销、重做或清除本次笔画。
4. 对照透明预览后应用，再保存新模板或加入处理积木。

最多64笔、1024点、15,000字节，原图尺寸必须完全一致。全透明模板不能应用；保留区域太少也容易误匹配。透明模板只在忽略透明像素的匹配中有相应语义，不自动更换灰度算法。

## 拖动与多边形选区

矩形框选后，拖内部可以整体移动，拖边缘手柄调整大小；整体移动保持宽高并限制在图像内。切到缩放/拖动模式时拖动的是图片，不是选框。

点击「多边形」，在原图上逐点添加顶点，三个点起自动闭合；可拖顶点、删除选中点、撤销和重做。双指缩放，移动模式拖图。最多128个不同顶点，不能重合或面积为零。

「保留选区」使外部透明，可同时裁到多边形外接矩形；「忽略选区」使内部透明，保留原尺寸。应用进入处理历史，可一次撤销；保存另建模板，也可加入显式蒙版/裁剪处理积木。这里不是多边形找图或OCR搜索范围，识别ROI仍为矩形。

图片工作台的顶部工具和底部操作自动换行；工具区有高度上限，必要时上下滚动。图片库的搜索与工具随列表滚动；清理、蒙版和差异分析在矮窗口把预览与参数一起滚动。画布不覆盖按钮，返回与完成仍可达。

## 固定数字清理

需要把不同颜色视为同一目标时，可在找色配置的「匹配色组」中逐色添加和取色，每色独立容差、任意命中；若需要检查一组颜色的相对位置，请使用多点找色。参见[找色备选色组](./vision#找色支持多个备选颜色)。

选择浅/深前景、灰度阈值，再明确选择小连通块去噪、腐蚀、膨胀、开处理或闭处理。去噪按4/8邻接和最小面积执行；面积1保留小数点等小区域。形态处理半径为1或2像素。

这些操作可能删除小数点、粘连字符或改变笔画。请先对照预览，再重新测试字库；系统不猜阈值、不修补字符、不训练通用OCR。预览和 Rust 执行采用相同整数规则及6400万邻域计算预算。

## 复用完整图像方案

「图像方案」保存处理步骤、来源尺寸、ROI和可选找图/文字识别参数。找图/OCR配置中的「保存为方案」可把识别参数一起带回。

- 支持保存当前、复制、重命名、搜索、确认载入和删除。
- 最多32项、单项32KiB、总计1MiB；随项目备份恢复。
- 不包含截图、帧句柄、输出变量、测试证明或运行结果。
- 载入前复核尺寸和资源，从工作台原图重算，作为一次可撤销处理；不自动测试、保存图片或加入积木。
- 参数、图片或运行会话改变后必须重测；已有积木不随方案修改。

这是图像配置复用，不是延期的插件流程模板库。

## 连续命中与区域等待

在识别配置的「等待与重试」中可选择连续命中、等待区域变化或等待区域稳定。也可直接从「图像 → 处理 → 帧比较 / 区域等待」打开区域等待：只选当前截图变量、固定范围和容差，不必先选模板或配置普通比较输出。选择已声明、互不重名的工作变量，并确认两份截图变量专用于本组合；区域等待不要求无关的前次X/Y变量。

连续命中要求相邻有效新帧均命中，位置偏移不超过指定像素距离；文字需全文相同，字库稳定模式要求完整覆盖。区域稳定比较相邻新帧的变化率，区域变化要求达到变化阈值，可设置连续通过次数及RGB容差。

组合展开为可见的截图、比较、条件、计数、等待和释放积木。总期限使用单调时钟，异常/停止直接终止；单次SDK工作仍不保证硬实时抢占。重复缓存、文件帧或不同屏幕坐标代次不能提供新鲜度证明，不计入连续次数。

底层接口：[`Screen.compareFrames`](/api/generated/screen/compare-frames)。变化率为向下取整的千分比，不等于屏幕语义变化判断。

## 查看失败位置

在工作台找图测试中打开「分析候选位置差异」，指定候选左上位置、容差及实际缩放比例。红色表示该位置不匹配的像素，透明处表示模板忽略区；显示有效像素数、符合率和通道差。

这只分析指定位置，不宣称自动找到了最相似候选。灰度像素差不等于OpenCV相关分数。本地分析耗时不含Root截图或识别引擎，不能当完整识图性能；不会自动保存或记录私人图片。

## 从处理图还原坐标

「坐标还原」预览裁剪、正交旋转、镜像及最近邻缩放的逆采样位置。截图来源显示截图时的原屏位置；文件来源只显示原图位置，没有设备屏幕身份。

运行时用[`Screen.mapPoint`](/api/generated/screen/map-point)，再用「读取识别结果属性」的 `SCREEN_POINT` 总览读取X/Y。来源必须是当前任务拥有的真实截图，最多64步几何链；文件加载及其后续变换会明确拒绝原屏映射。

还原只计算，不点击，不保证画面和屏幕方向仍未变化。处理图识别结果不得直接当作原屏点击坐标。

## 多尺度像素找图

明确选择「多尺度」后设置最小/最大比例和步长，或从函数库加入「多尺度像素找图」。普通像素/灰度找图不自动启用缩放。

范围250–4000‰、最多16档，末端必须整除步长。按距1000‰最近优先、同距较小优先，在每档按指定搜索方向返回首个达标结果；不是全局最高分。最近邻缩放保留透明模板语义，不改原资源、不切OpenCV。

单档模板最多262144像素，累计重采样4194304像素，全部档位共用1亿像素比较预算和5秒合作期限。结果为空或一项，包含实际比例、位置、尺寸和得分。超预算不是未找到。

底层接口：[`Screen.findScaled`](/api/generated/screen/find-scaled)。用「读取识别结果属性」的 `SCALED_IMAGE` 获取数量（序号0）、第一项位置或比例（序号1）。结果位置属于输入帧；不附带点击动作。
