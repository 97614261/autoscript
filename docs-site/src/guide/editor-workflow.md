# 插件、分支与连续编辑

插件是项目中的独立流程文件，主插件是项目入口。一个项目可以有多个插件及虚拟分组；分组不是运行顺序，也不是图片文件夹。

新项目和新插件从空白开始，不自动添加空任务；历史项目已有的空任务保留。空插件自然结束，返回成功。

变量、插件参数和跳转标签支持汉字、英文字母及下划线开头，后续还可用数字，最多64字符。名称作为精确键保存，不自动拼音化；例如 `剩余次数 - 1` 可以直接用于变量计算。项目名、插件文件名和分组原本即可中文命名。自动生成的ID、控件ID及API函数名保持原规则，不改协议身份。

## 变量快捷计算与转换

「变量计算」参数窗分为快捷计算和表达式。快捷模式先选目标变量，再选操作及来源；来源可填写固定值或选择当前插件可见变量。目标按结果类型筛选，整数结果可以写入小数变量；更改操作不会自动修改变量声明。复杂旧表达式保留原编辑方式，切换模式不执行或自动保存。

操作选择按「常用、赋值 / 转换、四则 / 大小、取整 / 余数、文本处理、拆分文本、列表 / 对象」归类，搜索可跨分类查找。每次只展示当前操作需要的输入；来源也能继续转换或计算。

从变量管理中加入计算，先填写公式，再选择加入位置：当前积木上方、下方、列表末尾或指定分支内。取消选位会保留公式和变量草稿，不先保存变量或加入积木。

- 赋值与转换：直接赋值、转整数、转小数、转文本；`+190` 可转为整数 `190`，小数转整数向零截断。可选数字转换失败时的默认值，不会自动把错误改为0。
- 数值计算：加减乘除、两种整除/余数、绝对值、上下取整、四舍五入、较小/较大值，以及目标变量自增/自减。四舍五入遇到一半远离0，例如 `-1.5` 得 `-2`。除零、整数溢出及非有限小数拒绝。
- 文本处理：拼接、去首尾空白、英文大小写、字数、截取、查找和替换；字符索引从1开始，查找失败返回0。截取不会切断中文，英文大小写不进行语言环境转换。
- 拆分与取值：按完整分隔符或多个独立分隔字符拆分，可选去首尾空白、忽略空项。逗号/中文逗号/分号/空格/换行/Tab有快捷按钮；多个分隔字符模式中按钮为追加或取消，完整分隔符模式为替换。结果保存为JSON列表文本。

「取一项」选择列表及整数序号，或对象及文本字段，直接读成文本、整数、小数或JSON子项。列表序号从1开始；对象字段按原名精确读取，不把点或括号解释为路径。嵌套内容先读JSON子项，再继续取值。可选默认值处理缺项、null或数字转换失败；JSON损坏、序号小于1或来源类型错误仍提示，不会吞掉异常。

例如先把 `100,+100,180` 按逗号拆分到文本变量「结果列表」，再选择「取一项 → 整数」，来源「结果列表」、序号2、目标「加成」，即可得到 `100`，无需额外解码或转换积木。

表达式也可使用 `split(文本,分隔符,选项)`、`splitAny(文本,分隔字符,选项)`、`listLen(列表)`、`itemText/itemInt/itemFloat/itemJson(列表或对象,序号或字段[,默认值])`，以及 `intOr(来源,整数默认值)`、`floatOr(来源,数值默认值)`。拆分选项为0至3：1去首尾空白，2忽略空项，3同时启用；省略为0。普通 `split` 的空分隔符按Unicode字符拆分，`splitAny` 的分隔字符不能为空。

仍使用原有受限表达式：最多1024 UTF-8字节、128项、16层；文本来源及结果最多4096字节，拆分最多1024项，编码后也需满足4096字节。列表/对象取值需要Runtime API 1.8，保存及未保存草稿校验会沿原流程提升；普通标量计算保留旧版本兼容。

## 输入参数直接转换和计算

循环次数、限时、等待、循环检查、条件两侧、日志与提示、变量复制、文本/数学/列表/文件等工具的已有标量来源，以及剪贴板文字、浮窗文字、界面赋值、找图范围边界与坐标映射，共用「取值 → 转换 / 计算」。可以直接选变量，也可以生成输入表达式，无需额外加入中间计算积木。

例如次数文本为 `"+3"` 时，循环次数可用 `int(次数文本) + 1`；每次等待可用 `间隔 * 1000`；提示内容可用 `"当前次数：" .. text(次数)`。需要整数的入口，浮点结果须明确转为整数。表达式只能引用当前插件可见的标量变量；不能当成任意 Lua 代码执行。

循环总次数和总限时在进入循环时取一次；等待每执行一次重新取值，循环检查在该检查行取值，条件循环每次判断重新计算，因此能读取循环体更新后的变量。显示预览不会执行表达式。保存重开、变量改名及引用检查保留这些输入，错误继续定位到实际积木行。

输入表达式需要 Runtime API 1.8，保存及未保存草稿校验自动提升。旧的直接选变量方式保持原义。输出目标、循环计数结果、图像句柄与资源选择仍使用原来的变量名或资源身份，不使用输入表达式。

矩形找图的四个边界可分别使用整数输入表达式，留空沿用固定范围；右、下边界不包含。多边形继续使用固定截图坐标，不能同时设置范围变量或表达式。坐标映射的X、Y也可直接计算，映射来源图像与结果接收变量保持原来的选择方式。

## 给成功、失败分支加入操作

1. 先创建被调用插件，在其中写好独立功能。
2. 回到调用方，加入插件调用，并选择被调用插件。
3. 点击调用下面的「成功」或「失败」标题，把该分支选为加入位置。空分支也可以点，不需要先放占位积木。
4. 打开按键、图像、调试或函数配置，填写参数，再加入。普通加入沿用已选分支；若出现位置确认，选择对应真实子区，不要误选调用后的普通下一行。
5. 在另一分支重复操作。两个分支可以分别放日志、提示或其他处理。

示例：主插件调用「检查页面」。它返回成功时执行「点击进入」，返回失败时执行「弹出提示：请先打开目标页面」。调用的后续普通积木位于两个分支之外，不等于成功分支。

## 谁决定成功与失败

在**被调用插件**中使用「返回成功」或「返回失败」。自然运行到末尾默认成功。调用方按实际返回值选择分支；运行异常、用户停止与取消是中止，不应靠失败分支吞掉。

「成功/失败」标题只是加入位置，不是可执行积木。空闲单步、删除或复制时，要选择实际操作行，不能把分支标题当成所属调用行。

## 参数窗何时关闭

| 页面 | 完成后的行为 |
| --- | --- |
| 单项参数窗 | 实际加入草稿后关闭，选中并定位新积木。 |
| 加入位置选择 | 取消会回到原参数，不丢输入，也没有提前加入。 |
| 函数库、图片处理工作台 | 保留，方便继续选其他操作；单项参数仍按上一条处理。 |
| 底部编辑操作窗 | 保持打开，可连续复制、粘贴、修改、撤销等。 |

加入草稿不等于已经保存正式项目；正式运行前仍需保存与校验。切换插件、修改草稿或运行状态变化可能使旧请求失效，此时保留参数，重新选择位置，不会偷偷写入另一个插件。

## 插入与撤销

可以选择本行之前、本行之后、真实子区或列表底部。前插保留原森林顺序与子树；图像组合整体加入后一次撤销，不需要逐行拆除。

底部编辑窗支持多选与折叠子积木，折叠只改变显示。父积木「注释执行」会跳过整棵子树；恢复父级不会清掉子行原本单独设置的禁用状态。显示别名只改变说明，不改变执行参数。

## AI 助手

文字生成、修改所选积木和报错分析见 [AI 助手](./ai-assistant)。AI 方案先预览、整项目校验，再确认应用到草稿，可撤销；不会自动运行。

## 单步没有执行时

先选实际积木行，再检查变量、项目能力及 Root 实际特性。空闲单步不会执行前置赋值，因此需要先准备本行依赖。分支标题不能单步。详情见[调试与运行日志](./debugging)。

空闲单步不显示自动「插件运行/插件返回」提示，显式提示积木仍可预览；完整运行仍按项目设置中各自动提示分类执行，不修改已有选择。
