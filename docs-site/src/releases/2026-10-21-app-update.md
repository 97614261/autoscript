# 2026-10-21 · App 内更新与 Root 诊断

本批 Studio 为 **0.1.2 / 版本代码 3**，包名仍为 `com.zhigou.kaifaban`。这是开发证书签名候选，实际下载包、大小和完整摘要以[下载页](/download)为准。

## App 内更新

- 打开 App 前台自动检查，每六小时一次，可关闭；手动检查不受限频影响。
- 有新版本时先确认，App 内下载并显示进度；完整校验后交给系统确认安装。
- 当前架构从主版本和 `alternatives` 选择，不把历史版本或同版本代码的不同构建当作新版。
- 更早版本需要手动安装一次。不会静默安装、Root 安装、卸载旧版或清除项目。
- 网站发布检查版本代码回退、清单 MIME 和缓存策略，版本与 APK 使用同一份数据。

## Root 与截图

- 优先使用系统安装目录中的 Root 原生程序，减少从应用私有可写目录执行的兼容风险。
- 等待 Root 就绪期间保留工具反馈，实际截图时才隐藏；失败区分连接、启动阶段与截图采集失败。
- 独立 App 诊断在未运行脚本时也可记录，从「我的 → 运行环境 → Root / 截图诊断」查看或复制。

这修复了代码中的兼容风险，不代表用户 ARM 手机的实际原因已经确认。ARM 真机截图仍需可连接设备的实际结果；主机测试、包结构检查、MuMu 与真机验收分别记录。
