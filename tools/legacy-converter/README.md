# 智构 · 独立工程转换工具 v0.3.4

把旧一键玩ZIP工程转换为智构工程。独立离线运行，不需要安装智构、Android SDK、MuMu、Gradle或Cargo。需要Windows系统Python **3.8及以上，安装时保留Tcl/Tk**；便携ZIP不是无Python依赖的EXE。

## 双击使用

1. 解压便携包，双击 `start.cmd`，打开可视化工具。
2. 选择旧工程ZIP，工具分析插件、变量、图片。
3. 选择实际入口插件；选择输出父目录。
4. 点击“开始转换”。可查看阶段进度、运行日志、分类待迁移列表、补全计划，随时取消；双击问题查看原字段与转换节点。
5. 完成后打开详细报告或输出目录。日志自动写入 `tool.log`，也可“保存日志”。

独立页面使用紧凑蓝白布局；表格/日志滚动，窗口可调整大小。普通日志只包含阶段、数量和错误，不包含脚本正文或变量值。详细HTML/JSON报告含私人源字段，不要上传或提交。

## 转换结果

- `original.zip`：原始字节备份，输入不修改。
- `project-draft/`：转换工程，未支持的语义保留结构并用未知节点阻断运行。
- `report.html`：本地可读报告、筛选和原字段查看（最多1000项）。
- `report.json`：完整映射和未支持项。
- `ui-audit.json`：旧界面的原字段、控件、事件及契约缺口；只审计，界面尚未转换。包含私人内容。
- `function-audit.json`：逐函数/调用的参数形状、数量和待确认签名/副作用；静态审计，不执行旧函数，不将同名原生API当作等价。包含私人名称与位置，不能上传。
- `project.asproject`：全部支持且自带Rust编译检查通过时输出，可导入智构。编译通过不等于已进行设备运行验收。
- `candidate.asproject`：没有语义报告阻断，但未带编译检查器时的候选；不能宣称已验证。

有任何未迁移项则状态为“尚有未迁移语义”，不输出假完成的项目备份。取消/出错保留 `.converting-*` 暂存目录供排查；不自动删除用户文件，不覆盖旧输出。

## 当前支持

v0.3.4：新增有界函数参数形状审计和本地报告入口，并更新原生编译检查器。智构增加独立多结果模板匹配、白名单属性读取、复合判断与匹配后动作；这些是原生能力，不证明旧找图/对象/表达式语义等价，旧工程对应阻断不会因同名API存在而消除。

v0.3.3新增：旧弹出提示中的有界字符变量／常量连接转换为原生 `task.message`，不增加临时用户变量。智构可直接配置表达式及弹出提示／运行提示／开发日志三个渠道；数字需要显式 `text` 转换。旧隐式数值转字符、未知函数、非空标题仍不放行。表达式解析成AST而非直接执行原输入，输出上限2048字节。

v0.3.2新增：无限/限时循环映射到原生 `control.cycle`，每轮强制1毫秒可取消让步、不附加假次数上限；限时秒数精确转为毫秒，变量时长保留秒单位，范围受运行契约限制。显式返回成功/失败映射到独立状态节点；结束本次循环已有真实编译实现。插件自然结束的旧Native默认状态仍未知，因此有执行内容的成功/失败分支继续阻断，不猜测迁移。界面v2原生控件数量限制统一为256，但旧布局仍仅审计。

v0.3.1新增：旧字符变量的 `.Length()` / `.字符长度()` 映射到智构原生计算 `byteLen`，按UTF-8字节计数；所带检查器须同批更新。其他字符串成员方法仍需边界与副作用核对，不因新增字节截取/查找就认定旧方法等价。

普通整/浮/字符变量、局部/全局作用域、中文变量稳定别名；同类型变量复制、常量赋值、基础数值加减乘、有界字符串连接和括号；简单变量比较（含常量左值）、相邻如果/否则如果/否则链；常量或整数变量限次循环、等待；手指ID0的点击/按下/弹起/有限直线拖动；标号/跳转/跳出/继续；字面量或单变量提示、注释；无结果分支或仅有两个空标记的插件调用；24/32位BI_RGB图片；插件虚拟分组、真实图片目录及空目录保留。禁用叶步骤作为注释保留，原字段另存，不会重新执行。

仍未完成：旧UI和事件、找图多匹配结果对象及活跃成功/失败分支、复杂表达式/外部函数、位置循环指标及检测标记的旧语义、非0手指、禁用容器。无限循环仍受停止、会话超时、VM和资源配额限制，不保证永久后台执行；让步会影响极短循环的时序，转换通过后仍需人工运行验收。旧字符串按字节及0起点处理，不直接套当前字符函数。外部APK/DEX只保留，不加载或执行；C++除法/余数/函数/成员操作不会直接当成Lua算式。报告的补全计划按阶段、影响项不等于不同功能数量。

## 命令行

在工具目录运行：

```powershell
python -m legacy_converter --gui
python -m legacy_converter "旧工程.zip" --inspect
python -m legacy_converter "旧工程.zip" --output "output/新目录" --entry "main.cj"
```

输出目录必须不存在。默认使用 `bin/validate_project.exe` 的只读编译检查。无检查器也可以独立分析/生成草稿；自备检查器可用 `--validator "可信检查器.exe"`。

退出码：0=分析/候选/已验证转换成功；2=语义阻断；1=工具或输入错误；130=取消。查看汇总status判断是否真正完成。

仓库源码开发测试：`python -m unittest discover -s tests -v`。便携打包：

```powershell
python package.py --output dist/智构工程转换工具.zip --validator "../../rust/target/debug/examples/validate_project.exe"
```

打包白名单仅含工具代码、启动脚本、说明和显式检查器，绝不收集 output、报告、用户ZIP、日志或缓存。

`bundle.json`记录工具版本及文件SHA256，便于比对，不是签名或来源认证。`python -m legacy_converter --version`可查看工具版本。

开发验证包含合成测试、GUI控件/筛选烟测、独立解压后的CLI、当前Rust编译器成功/阻断校验。界面尚待人工视觉验收。真实大型工程仍有未迁移语义，工具可用不代表该工程已100%转换。
