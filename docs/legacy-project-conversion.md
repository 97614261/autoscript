## 当前交付边界

实际实现位于 `tools/legacy-converter/`，独立于 Studio / Runner / Android。提供 Windows Tkinter 可视化页面、CLI、双击启动、便携 ZIP、本地 HTML / JSON 报告。需要 Python 3.8+（含 Tcl/Tk），无需 Android SDK、MuMu、Gradle 或 Cargo；便携包包含已构建的只读 Rust 检查器，不是免 Python 的 EXE。旧 scripts 入口保留薄包装。

GUI 支持选择 ZIP、分析、明确选择入口插件、选择输出目录、开始转换、取消、阶段进度、日志、分类待迁移列表、双击原字段/转换节点对照、补全计划、保存日志、打开报告和目录。后台工作不直接更新控件。普通日志只含可信阶段、数量和错误分类，不输出私有脚本、变量值或异常原文；未知分析字段也不回显。

已参考旧 Java 的 configAnJian、configCycle、configJump、confingVarFuZhi、configPlugin、configTip、confingIfs、variable 和 myTreeCtrl，使用文件层级和字段，而非按截图猜测。

支持：普通整/浮/字符变量声明和作用域；常量赋值、同类型复制、基础加减乘、字符串连接及括号；简单同类型比较（含常量左值）和相邻如果/否则如果/否则链；等待、限次循环（整数常量或变量）；单指ID0点击、按下、弹起、有限直线滑动；跳出/继续、标号/跳转；确认的字面量或单变量提示、注释；无结果动作插件调用（含两个纯空标记）；24/32位BI_RGB BMP到不透明RGB PNG；虚拟分组、图片目录和空目录。明确禁用叶作为注释保留，不会重新执行。

不支持：旧多匹配寻图结果对象、活跃成功/失败树、复杂表达式/自定义函数/属性访问、成功/失败返回值、旧界面的完整布局与事件、禁用容器、不明确的入口和外部APK/DEX库。它们保留原ZIP及逐项原字段报告，并在草稿插入未知节点阻止编译，绝不静默丢掉或替换成可执行空操作。

非0手指、位置循环检测及未确认的旧状态仍待迁移；C++除法、余数、自增自减不直接转成Lua。任一条件无法迁移时保留整个分支链并阻断，不只迁移第一分支。2026-10-03新增的无限/限时循环和显式状态返回支持见文末；上文保留此前交付范围记录。

## 命令

解压 `tools/legacy-converter/dist/智构工程转换工具-0.3.3.zip`，双击 start.cmd。工具目录命令：

```powershell
python -m legacy_converter --gui
python -m legacy_converter "旧工程.zip" --inspect
python -m legacy_converter "旧工程.zip" --output output/新目录 --entry "入口插件.cj"
python -m unittest discover -s tests -v
```

输出目录必须不存在，可以位于仓库之外，默认工具 output 下；仓库验证仍在忽略的 build 目录。未知入口时不猜测业务入口，仅给首个插件临时身份并阻断；明确入口也不能绕过其他缺口。取消/出错保留 .converting-* 暂存，不覆盖或删除用户文件。任务180秒、检查器30秒截止，支持取消；Windows临时文件占用最多重试2秒。

便携包自动使用 bin/validate_project.exe；源码运行可用 --validator 显式指定可信检查器。

- `original.zip`：原始字节备份，原文件不修改。
- `report.json`：变量/图片/插件映射、逐源文件行号、语义缺口和原记录。含私人脚本，不能提交或普通日志打印。
- `project-draft/`：当前清单/JSONL/PNG结构的审阅草稿。
- `report.html`：本地筛选、原字段查看，最多1000项，内容已转义不能执行。
- `tool.log`：GUI自动保存阶段日志，支持手工保存。
- `ui-audit.json`：完整界面原字段及契约缺口，私有内容；审计完成不代表界面转换完成。
- `project.asproject`：无缺口且当前编译器通过才生成；编译通过不等于设备运行验收。
- `candidate.asproject`：无报告阻断但未提供检查器时的候选，不能宣称已验证。

退出码：0=候选生成/检查成功，2=语义未完全迁移或编译阻断，其他非零=工具/输入失败。编译检查只输出类别和数量，不打印原脚本、节点参数、生成Lua或私人名称。
