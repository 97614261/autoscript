# 函数库页面与内容整理（2026-09-29）

## 页面

- 可视化编辑“新增积木”、悬浮编辑“函数”、Lua 调试编辑“函数”共用 `FunctionLibraryDialog.kt`。
- 白底蓝色强调、左侧分类和数量、右侧单行列表。常规高度上限 435dp，短屏按可用高度收缩，不铺满页面。
- 只有分类、列表、详情内容各自滚动；搜索和底部操作保留在外。条目最小高度 40dp，列表仅展示函数名、详情和加入按钮；完整描述、参数、返回值及使用说明集中在详情页。放大系统字体时允许条目增高，长名称截断后可在详情查看。
- 搜索覆盖中文名称、用途、API/kind、参数说明、返回值、使用说明和关键词；支持多个词同时匹配，精确函数名优先。
- 点名称或“详情”查看说明，点列表中的“加入”直接使用原有配置/插入流程，详情页也保留加入按钮。缺少项目 capability 时列表显示“未启用”并禁用加入；详情仍可阅读并列出缺失能力，不将其当作“未实现”。
- 按键、判断、循环、跳转、图像等采用用户语义分类，保留原有 kind 与插入回调协议。

## 内容来源

- 可视化：现有 48 种真实积木目录。参数名称、编辑类型、必填、默认值、可选值、资源和参数关联来自生成的积木契约；补充变量输出、子区、循环上下文、Root 单指触点、帧和资源使用说明。
- Lua：42 个正式 API 全部入库，另有 3 个运行时日志便捷封装及 5 个 Lua 判断/循环模板，共 50 项。此次没有添加新的引擎能力。
- 参数类型、必填、范围说明、返回类型、nil 语义、API 版本和 capability 直接由 `schema/api-schema/functions` 生成 Studio 专用文档，不手工复制另一套签名。
- 新生成文件只进 Studio 的 build 目录，Runner/API 传输不携带编辑文档。Gradle 监测契约输入并生成文档，无新增依赖、持久化或协议变更。
- Lua 示例保留采集、帧、模板、字库、任务和定时器的返回句柄；有外部变量或声明资源前提时明确说明。示例不是无需修改就能独立运行的完整脚本。
- 修复旧 Lua 插入白名单未同步的问题：直接使用生成的真实 API 名单，加上已注册的 `Log.info/warn/error`；仍拒绝未知 API。

## 验证与边界

- Studio 新增 7 项回归：API 完整性、积木提示兼容、文档/能力一致性、搜索、白名单、句柄/输出说明、弹窗高度。
- 文档生成器新增 Kotlin 插值、引号、换行和控制字符转义测试；Rust 格式、Clippy、单元测试验证。
- 执行 Studio 单元测试、Lint、Debug 构建；未安装到设备，未做设备 UI / Root 执行测试。
- 可视化仍通过既有积木配置和插入流程处理参数；Lua 通过“加入示例”写入调试源码后编辑。并未在说明页面另造一套参数执行器。
- 页面仅展示本项目已有能力，不宣称完全覆盖一键玩或易编的全部函数，不加入录制、免 Root、网络/账号等预留功能。
