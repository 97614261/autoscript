# 循环对齐交付（2026-09-29）

## 范围及源码依据

本批主改可视化插件编辑：完整页面和悬浮编辑器共享VisualLoopDialog、结构化命令及节点参数转换，不再让悬浮指标命令退回模糊搜索、误插一个新循环。变量页沿用上一批紧凑卡片、局部/全局维护及计算能力。源码证据保留在variable-page-loop-audit.md；协议决定见ADR 0017。

依据旧一键玩的insertCycle/configCycle和易编rr/w72/qh、service_tk_xh.xml实现可确认的操作。新版反编译缺少rr.onClick，旧版超限的native执行器不可见，因此不声称与不可读实现逐条等价；明确采用“达到阈值退出最近循环”的安全语义。

## 已接通的操作

| 操作 | 页面和运行行为 |
| --- | --- |
| 无限循环 | 主页面直接配置，always=true；保留可配置安全次数上限，达到上限报错，任务取消和资源保护不撤销 |
| 限次循环 | 固定整数或整型变量；真实次数预设和手输；0次合法，最多1000000次 |
| 限时循环 | 固定值或数值变量；真实秒预设；显式毫秒/秒/分钟，范围1ms至24小时，精度至少1ms |
| 获取循环次数 | 独立control.loopmetric积木，执行位置读取最近循环的当前1起始轮次，不修改循环头或新增循环 |
| 获取循环时间 | 独立指标积木，在该位置读取从最近循环开始到当前的单调耗时；默认秒，可选毫秒/分钟；秒/分钟输出要求浮点变量 |
| 空循环/等待 | 同页面“更多循环操作”，复用有取消的task.sleep；固定值0..86400000毫秒，整型变量沿用task.sleep的非负整数等待约束 |
| 循环超次 | 独立control.loopcheck积木；固定值或整型阈值变量；当前轮次达到阈值时退出最近循环 |
| 循环超时 | 同一检查节点；固定/数值阈值变量和显式时间单位；当前位置耗时达到阈值时退出最近循环 |

五项主操作保持紧凑布局，旧版额外三项同页展开，没有增加首级选择弹窗。标题、分段、输入和底部按钮通过居中容器布局，输入/按钮关闭额外字体内边距；面板支持小屏、横屏和键盘后的滚动，不假设固定大空白。

变量选择按整数/数值输出类型过滤，显示局部（含插件参数）和全局作用域；参数/局部优先于同名全局。支持从选择器打开维护，保存后返回原循环草稿继续选取。强制拒绝未选择变量、非法输入、负值、分数次数、非有限数值及越界，不静默默认或截断数值。位置指标和检查只能加入结构循环体，UI和Rust均检查真实祖先，不依据depth猜测归属；调试维护检查也识别指标的输出变量。

## 兼容与边界

- 现有repeat/while v1以及循环头指标字段保留。旧durationVariable缺省毫秒；新增durationUnit只在明确配置后缩放，固定时长仍保存durationMs。不删除或批量重写项目数据。
- 新增loopmetric/loopcheck均为独立v1叶节点，有Schema、积木目录、编译检查和真实Lua生成；生成器升至plugin-v5，使旧冻结产物重新校验/编译。Runner仍只加载冻结Lua，未引入编译器依赖或新增任意宿主接口。
- “无限”仍受安全次数、指令预算和取消保护；默认安全次数10000，最多1000000。超时检查是显式步骤，限时循环也只能在下一轮进入前判断截止；均不会强行中断正在执行的某个宿主动作。需要立即停止时使用任务停止通道。
- 指标/超限检查不跨插件调用或任务隐式寻找外层循环，必须位于本插件的结构循环体。循环结束后的“最后总耗时”不是本批新增操作，原循环头指标也不是最终耗时。
- Lua源码编辑仅为调试用途，本批验收范围是可视化插件，不声称该结构化循环配置可直接作为普通Lua源码运行。

## 用户设备验收

1. 在完整编辑器和悬浮编辑器点“循环”，分别试预设3次、0.5秒、变量次数和变量秒数；退出变量维护后确认草稿保留。
2. 在循环体添加等待100ms、获取时间（浮点变量，秒）、获取次数（整数变量），观察每轮当前位置指标。根层级加入指标应被拒绝，不能误加新循环。
3. 嵌套循环在内层加入超次2/超时0.1秒，确认只退出内层，外层继续。
4. 输入负数、空值、小数次数或超过24小时，确认报错而不是变成默认值；无限循环按停止按钮应沿既有停止通道退出。
5. 旧插件durationVariable=100，未设置durationUnit，仍表示100毫秒；新插件显式选择秒不影响旧文件。
