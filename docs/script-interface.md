# 脚本界面：设计、启动与运行

## 入口与启动顺序

项目的界面设计器采用左侧页面/控件树、中间画布、右侧属性栏。设计器横屏显示，退出后恢复原来的方向。

设计器默认「整页」适配宽度和高度，尽量不滚动画布；使用 +/− 放大缩小后可横向、纵向平移。顶部 32dp 单行工具栏提供「控件」「属性」独立开关和「专注」模式；退出专注恢复之前的面板开关。在不足 560dp 的窄屏只显示一个面板，添加控件后保留控件栏方便连续添加，点击画布控件则显示属性。左侧双列短名称控件按钮、图层列表；右侧布局、样式、交互采用浅底分段标签，颜色输入与色块合并为一行，点击色块弹出色板。常用字段直接改 X/Y、宽高和位置，交互里直接选择变量、插件和页面，不需要手输 ID。顶部内容超宽时可横向滑动，保存/预览不会被截掉。

添加控件按三列寻找页面空位，所有新控件默认高 40px、字号 20px，已有控件尺寸不自动修改；多行、列表、图片和容器可按需在属性里加高。不自动把页面拉长。页面满时明确提示，保留现有布局。可点击「紧凑排版」按三列整理根层控件；空间不足或宽容器可能裁剪子控件时拒绝修改。默认吸附到 8 设计像素网格，可关闭；支持六方向对齐、水平/垂直等距、置顶/置底。容器移动不会重复移动已选子控件，变更父容器尽量保留绝对位置，整组可换页。单选组高度不足以放下纵排选项时采用等宽横排；设计画布和共享运行渲染器使用同一判断，加高后恢复纵排。

画布底部「整理」菜单内的「缩小全部」将所有页面的控件坐标、尺寸、字号按 75% 缩小，保留页面尺寸、ID、变量绑定及事件，尺寸最低 20px、字号最低 8px；支持撤销，保存后生效。「当前页三列排版」对应紧凑排版。不会在读取已有界面时自动缩小，避免重复缩放。设计器按钮最低 22dp、属性行和控件栏按钮为 24dp；共享运行界面的页签和底部操作为 32dp，并移除原生控件额外最小尺寸，单选/复选指示器跟随设计像素比例缩放。编辑画布文字不继承主题的大行高，字号跟随设计像素缩放且不受系统字体缩放再次放大，移除字体额外内边距，避免小控件的居中文字被裁切。

Studio 项目列表的「启动」先显示保存的界面；此时不会执行 Lua。填写后点击界面内「运行」，校验配置，再启动脚本。取消或关闭不启动；未设计界面的项目直接启动。编辑器的「运行」保存草稿后直接执行当前插件，使用界面默认配置，不弹启动配置窗、不进入自动生成的界面事件循环。单步继续走独立检查点路径。独立 Runner 仍先显示启动界面，确认后执行。

项目列表「编辑」直接展开可视化编辑弹窗，背景保留项目列表；不再展示旧全屏程序树/节点 ID/编译诊断页面。最小化才变成吸附球，点击球恢复，关闭退出编辑。编辑控制器、插件保存及工具回调沿用原实现，错误与运行状态在编辑弹窗反馈。编辑期间列表其他项目操作暂时禁用，避免误切换丢失草稿。Lua 调试源码页仍保持独立页面。

Studio 预览、Studio 启动配置窗、运行时悬浮界面、独立 Runner 使用同一个传统 View 渲染器。预览只检查界面，不启动脚本。独立 Runner 只加载冻结发布内容，不依赖设计器或编译器。

## 设计能力

- 输入：单行文本、多行文本、整数、复选框、单选组、下拉框、列表、滑块。
- 展示：标签、图片、进度条；组织：容器、按钮、分页导航。
- 操作：添加、选择、多选、复制、删除、拖动、缩放、左对齐、上对齐、撤销/恢复、预览、保存。
- 属性：稳定 ID、标题、初始值、整数范围、选项、页面、父容器、位置、尺寸、字号、文字/背景色、对齐、可见、可用、必填、绑定与事件。

坐标、尺寸、字号是页面的设计像素，不是屏幕绝对坐标。设计器和运行窗口复用同一套视口算法：默认按宽高中的较小比例整页显示并居中，保持比例、不自动重排控件；标题栏菜单可切换「按宽显示 · 纵向滚动」，长页面保留原有布局并纵向滚动。颜色格式为 `#AARRGGBB`。图片只能使用已声明的项目图片资源。

保存拒绝过期覆盖、失效的绑定和事件引用；旧版四类型表单继续读取，进入设计器保存后才升级 v2，不删除用户数据。

## 值与事件

画布下方固定为一条 28dp 紧凑工具栏，选中控件不再增加操作行或改变画布缩放比例。常用多选、复制、删除、横中、竖中直接点击；「定位」菜单提供靠左/靠右/靠上/靠下、横向居中、纵向居中、正中；「对齐」菜单提供多选同级控件六方向对齐和三项以上的水平/垂直等距。单选按所属页面或容器定位；多选按整体包围框定位，保留内部间距。超出父页面/容器的整组拒绝靠边定位，不自动缩小；不同页面或父容器不能混合对齐。移动容器不会重复移动已选子控件。操作进入撤销历史。属性标签下常驻「文字对齐」左对齐/居中/右对齐，区别于控件位置对齐，沿用已有 alignment 字段并保存到运行界面。

启动时全部控件值进入 `RunnerConfig`，类型为字符串、整数、布尔或选项字符串。

绑定属性可填写 `global:变量名`、`flow:插件ID:变量名`、`param:入口参数名`。全局/插件变量必须已声明；复选框绑定数值变量时使用 1/0，绑定布尔参数时使用 true/false。入口参数是启动配置，不是运行时动态参数。

事件键为 `click`、`longClick`、`change`、`selection`；只有对应控件实际发生的事件才触发。动作支持 `flow:插件ID`、`page:页面ID`、`run`、`close`、`minimize`。运行后的 `run` 不会重复启动脚本。插件事件可接收 `controlId`、`event`（字符串）及 `value`（控件类型）；其他必填参数会阻止保存。

可视化界面读写积木对应以下 API，需要 `ui.control` 能力：

- `UI.getValue(id)`：读取字符串值，未绑定事件的普通控件编辑也会同步。
- `UI.setValue(id, value)`：更新值，不反向触发用户事件。
- `UI.command(id, operation, value)`：操作 `text`、`visible`、`enabled`、`items`、`progress`、`page`、`show`、`hide`、`minimize`；布尔参数为 true/false，`items` 用换行分隔，`page` 的值为页面 ID。
- `UI.waitEvent()`：挂起等待，返回 `控件ID:事件名`；单消费者、可取消，不轮询。可视化编译器自动生成事件分发，通常不需要手写。

函数库「界面 → 读取页面参数」复用 `ui.get` / `UI.getValue`，不新增 API 或改变旧积木 kind。可视化加入前先选已保存页面里的控件（显示页面、标题和稳定 ID），再选字符串结果变量，可直接维护变量；取消不加入默认占位积木。编辑已有积木使用同一个面板。任意页的当前控件值均可读取，不是页面的宽高位置。复选框结果为 `true`/`false` 字符串，整数为数字文本；数值计算可用 `int/float` 转换。`RunnerConfig` 保留启动时的配置，`UI.getValue` 读取运行中的当前值。Lua 调用不存在的 ID 返回空字符串；配置面板拒绝失效 ID。

运行悬浮界面可拖动、最小化为恢复按钮、恢复、关闭停止；页码和控件值在最小化期间保留。停止、失败、服务销毁及新会话替换都会清理窗口；旧窗口不能影响新会话。启动前的最小化恢复按钮仅在应用内显示。

## 自适应小窗

预览、启动配置、独立 Runner、运行悬浮窗共享 32dp 标题栏与 32dp 底部操作栏。菜单包含整页适配、按宽滚动；启动前还可恢复默认值。窗口按当前设计页比例计算自然高度，宽度以设计宽度的半倍 dp 为基准，最低 240dp（小屏受可用空间限制），最大 560dp / 可用宽度的 94%；高度不超过可用高度的 90%。短页面不会被强制拉满屏幕。

屏幕方向、窗口和软键盘可用空间变化会重新计算小窗边界与内容缩放；拖动限制整个窗口在安全区域内。最小化只隐藏或移除窗口挂载，保留 View 树、输入、当前页面和显示方式；旋转不重启脚本或创建新引擎会话。按宽模式保留各页滚动位置（可见空间变化时受新滚动范围限制）。设计器仍横屏，退出后恢复原方向；运行窗口随设备方向适配。

这些规则不修改已保存页面坐标、不新增 runnerUi 字段、不改变 Lua 发布协议。Android 7 的软键盘 Insets 行为及不同设备窗口边界需人工验证。

## 资源与验证边界

最多 16 页、128 控件、8 层容器、64 个选择项、2048 字符文本；撤销最多 100 步。事件队列最多 64 条，界面更新排队最多 128 条，超限停止而不无限积压。无事件等待最长 30 分钟，超时按运行错误处理；可随时停止。图片文件最多 16 MiB、源尺寸最多 4096×4096，显示降采样且单页像素预算有限。

自动检查覆盖模型、旧格式、类型校验、变量绑定、Lua 转义、真实插件事件分发、值同步、队列背压、取消、权限隔离、发布校验及 Android 构建/Lint。实际触摸、软键盘、不同分辨率和 Root 运行仍需要设备人工验收，不能把编译通过当作这些体验已经确认。
