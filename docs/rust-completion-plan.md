## 范围与完成口径

- 以可视化插件实际可用为交付，不以出现按钮、空接口或内核单测通过代替完整链路。
- Root 首发；Lua 5.4；默认 Rust 像素识别/字库 OCR。免 Root、账号、云控、支付不在本计划内。
- 不覆盖现有未提交改动，不删除用户项目。旧 API、节点、插件标识保持兼容；新能力明确门控。
- 不做设备实测。每批做格式、静态检查、单元测试、Debug 构建；设备性能与触摸体验留给用户验收，不能伪造实测结论。
- 状态仅用：未开始 / 进行中 / 代码完成待验证 / 已验证 / 外部阻塞。没有外部后端时不能标完成。

## 检查与风险

本批三个功能已实现：灰度找图、字母数字OCR与独立停止通道，具体结果见native-vision-stop-delivery.md。默认Rust与旧项目行为保留，Studio/Runner继续分离。整个长期计划仍不能宣称完全对齐：参考不透明图像数据协议未知，设备兼容/性能尚未实测。

后续需要用户设备验收灰度/OCR实际样本、长滑动停止/触点释放、API24及16KB页兼容；无优先通道的旧Daemon需更新，不冒称拥有新能力。保留长滑动，不部署设备、不删除用户项目。
