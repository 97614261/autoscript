# 旧工程转换器：剩余实施边界

工具独立放在 tools/legacy-converter/，不嵌入 Studio/Runner。操作、版本和静态结果见[转换说明](../guides/legacy-project-conversion.md)；按未知记录数量推算功能百分比没有意义。

## 已知基线，不是新的复测

2026-10-03的0.3.4静态报告仍有3380条阻断记录、3361未知节点，80个插件均不能编译，尚无最终可运行工程。入口、1张有效原图及5处缺目标插件需确认。
智构已有变量计算、循环、调用状态、提示表达式、多图结果、复合判断、匹配后动作和脚本界面样式等原生能力；同名API存在不等于旧Native语义已确认。

## 后续顺序

| 顺序 | 工作 | 放行条件 |
|---|---|---|
| 1 原稿前置 | 确认入口、有效原图、缺失调用目标 | 由原稿或用户确认，不创建空图片/插件替代 |
| 2 类型与表达式 | 作用域、UTF-8字节索引、负数整除/余数、字符格式、提示标题与内容、禁用容器 | 参数/返回/副作用有源码依据；不把禁用子树自动启用 |
| 3 视觉与结果分支 | 普通/多组/滤色/找色、阈值、方向、优先级、结果数量/属性、成功后动作 | 原算法等价边界明确；失败不点击，成功/失败互斥，取消释放帧 |
| 4 调用与函数 | 调用参数、自然结束默认状态、嵌套/递归、函数与外部库静态签名 | 不用void冒充状态，不执行DEX/APK或任意shell |
| 5 界面和事件 | .pz容器/页签、绑定、事件、Gravity、自动尺寸及SP/PX换算 | 全部活跃控件与事件可迁移；不能只恢复截图外观 |
| 6 交付 | 报告逐行对照、可取消、便携分发、完整编译、备份恢复 | 活跃语义无缺口且编译通过才生成最终工程；设备对照需单独授权 |

旧公开说明、可读Java或经授权的旧版对照样例能补证据；其他项目的OpenCV桥不能证明旧Native语义。缺证据时保留原字段并阻断编译，不以空操作“完成”迁移。

## 跨项目能力要求

必要的通用能力必须同时在智构可视化、函数库、保存/修改、契约和冻结Lua执行链开放；不能只让转换器使用。已有字符/数值语义不因兼容而静默改变。架构和协议变化先写ADR并同步Schema。

## 验证和隐私

合成夹具覆盖中文/引号/逗号、类型和边界、禁用规则、互斥分支、调用隔离、取消/超时及失败清理。
Python保持标准库；检查器真实编译，分发白名单与SHA-256核验。摘要不记录用户源码/变量值，原稿、别名、逐行报告和产物只写忽略的本地目录，不覆盖原件。
当前不重新转换或运行私人脚本，不继续设备测试；历史门禁不代表完整迁移验收。
