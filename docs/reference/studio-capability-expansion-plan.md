## 统一完成标准

每批检查API、函数库、加入/修改、类型化来源与输出、保存/撤销、受限源码、备份、编译、真实运行、取消/超时和停止资源释放。UI不展示无实现操作，错误使用白名单代码，不保存秘密数据或私人脚本。

代码状态、主机执行和设备验收独立记账。特征匹配不能用普通缩放找图验收代替；新OCR不能用模型可加载代替准确率门禁；多指不能用单指命令代替；输入法不能用剪贴板粘贴代替。

生产模型默认替换、任意模型导入、系统静默授权、任意Shell、独立Runner/下载器和账号云功能未获本轮授权。

本表的“已实现”指代码闭环，不等于所有设备或参数100%验收。后续固定provider V2已接通ORB和V5，V1原操作保留、扩展拒绝，不回退或下载；历史同包回归、字符评分及性能见[六项质量交付](../verification/studio-quality-1-6-2026-10-20.md)，新候选评分另见上面的最新六项执行账。宿主原生ARM/API24、任意目标App五指、浏览器业务及跨真实休眠仍与虚拟环境结果分开。

最终APK摘要、40项合成验收、输入法恢复、性能及未认证边界见[2026-10-20交付记录](../verification/studio-capability-expansion-2026-10-20.md)。
