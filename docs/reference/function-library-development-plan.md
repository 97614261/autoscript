# 函数库补强执行计划

当前以[Studio首版总账](studio-first-version-master-plan.md)和[177种积木矩阵](studio-block-coverage.md)为准，160个API；仅开发、源码与测试源码编译/静态检查，实际测试、Lint、APK和安装统一后置。下面五批及日期段落是历史范围和结果，不是新的设备操作授权。

历史范围（2026-10-11用户确认）：基于[逐项核对](function-library-parity-2026-10-11.md)，每批接通可视化配置、声明变量、保存、编译、运行、函数说明、受限源码往返、取消/预算与测试。当时按build.cmd -Verify验证并安装，不执行私人脚本。

历史目录整理：159个API、174种积木。编辑器统一可视化目录；旧Lua函数模板已移除，API仅在函数文档只读展示。完整分类见[函数目录](function-library-inventory-2026-10-12.md)，补强验证见[批次1–5](../verification/function-library-batch-1-5-2026-10-12.md)。下面末尾进展段落按日期保留历史快照，不是当前缺口列表。

## 第一批：基础工具与入口

- [x] 随机整数/字符串、四舍五入、限幅/范围、距离/角度/轮盘计算、RGB通道提取。
- [x] 屏幕尺寸、单调时间、真实Unix时间毫秒的独立积木入口。
- [x] 日期格式/日期运算；明确UTC/固定时区与墙钟/单调时钟不同用途。
- [x] 受控文本粘贴（含中文）、剪贴板、启动/查询App。粘贴键不保证目标App接收；后台限制保留明确错误，不新增或切换输入法。
- [ ] 设备键持续按下/释放评估；保持现有单指与任务触点所有权。

## 第二批：数据与文件

- [x] 文本拆分/拼接/边界处理及有界正则。
- [x] JSON存在性、类型、合法性与子结构读取，不改变既有Data.get标量规则。
- [x] 私有data行操作、追加、存在性、复制/移动、目录管理及持久KV。
- [x] 私有文件元数据、标准Base64及事务ZIP；独立限定文本/二进制/展开预算，不开放任意存储、目标覆盖或批量破坏性删除。帧转PNG使用已有截图保存契约，不宣称通用媒体转码。

## 第三批：运行期界面

- [x] 列表逐项增删改、选择索引与多选索引。
- [x] 占位文字、范围/步长与读回；一次设置范围，严格拒绝越界/不对齐的现值。
- [x] 页面参数导出/恢复；私有Files显式持久保存，密码排除、结构匹配、全部校验后应用。
- [x] 运行期背景图片。
- [x] 主窗/浮球位置查询设置、组内批量操作；不删除用户停止入口。

## 第四批：图像与OCR基础

- [x] 帧裁剪可视化入口。
- [x] 运行期原像素截图保存及有界图片变换。
- [x] 字库OCR逐字结果/指定文本查找及结果读取。
- [x] 批量多点找色、颜色连通块。
- [x] 截图系列的结果/释放配置。
- [x] 保持OpenCV灰度与ONNX单行字母数字范围；其他算法和通用中文OCR暂不纳入。

## 第五批：运行控制

- [x] 脚本主动停止、运行期提示/日志开关。
- [x] 清理后重启。
- [x] 有界脚本录制与回放接口；输入异常及停止确保释放触点。
- [x] 音频基础能力。
- [x] 轻量命名触摸穿透浮窗、声明图片与线段/矩形/圆；独立ui.floating能力及缓存预算，不以运行球冒充。

## 暂不纳入
