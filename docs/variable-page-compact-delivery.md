# 变量页紧凑列表改版（2026-09-29）

用户最新决定：移除类型筛选，压缩每条变量和顶部控件，把可用高度优先留给列表。本次取代上一版两层卡片/双列布局，不改变声明协议、变量类型及运行计算语义。

## 页面结构

- 标题栏40dp：变量管理、未保存状态、新增、关闭。
- 作用域栏36dp：局部/全局数量、当前插件或项目共享说明，合并原来独立的作用域说明行。
- 搜索栏40dp（输入34dp）：仅按名字搜索，完全移除类型筛选状态与过滤参数；四种变量类型仍可创建/编辑，列表左侧类型色标仅用于显示。
- 表头24dp：类型、变量名、条目数量及操作说明，不再另占一行列表标题。
- 单列列表：默认行高40dp加细分隔线，信息和编辑/计算/删除同行；去掉卡片外边框、7dp条目间隔、重复作用域副标题和第二层操作栏。点击行或编辑图标打开编辑；图像不提供标量计算。
- 底栏40dp：取消、保存；维护声明的提示并入标题，未保存关闭确认及删除确认保留。

列表是主面板唯一滚动区域，通过weight直接取得剩余高度，不再包在外层verticalScroll中，也不再有独立300dp高度上限。用户随后要求整体弹窗不要太大：改为按实际条目数自适应，最多预留6行，宽度最多520dp；1条约223dp高、6条及以上约428dp高，空列表约278dp高，错误提示另加最多40dp预留，始终受可用屏幕高度限制。键盘后的可用区域继续重新分配；新增/编辑表单仍另开，不挤占列表。作用域或搜索变化回到列表顶部。页面与悬浮编辑器共用同一实现。

默认字号、可用高度足够且无错误信息时，根据声明布局最多显示约6条完整行，其余只在列表内滚动；变量少时同步缩短整体弹窗，不留大块空白。这是40dp行高的布局估算，不是真机测量或所有分辨率的保证。小屏、键盘和放大字号下会减少可见行数。

## 功能保留

声明校验、同作用域重名限制、其他插件局部隔离、全局遮蔽保护、参数优先、图像计算限制、维护草稿保存与赋值/计算入口均保留。不显示或伪造脚本运行中的变量值。
