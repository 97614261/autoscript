# 按键选点与插入流程交付

日期：2026-09-29。本批补齐此前列出的三个代码缺口；未安装 APK、未操作设备，不能替代设备验收或宣称整个产品已完全对齐。

## 本批已接通

1. **跨应用悬浮选点**：按键面板默认选择悬浮方式，选动作后 Studio 退到目标应用后方。拖动手指标记仅定位，不注入触摸；点击手指打开紧凑动作/时长面板，确认点位后回到原编辑器。
2. **七种动作**：单击、滑动、长按、拖动、独立按下、移动、弹起。缺少 Root 基础输入时全部禁用；后四项及长按需真实持续单指能力。弹起不要求坐标；移动和弹起仅作用于同一运行任务持有的触点。
3. **统一加入位置**：截图和悬浮结果都变成强类型输入积木，经同一个位置弹窗选择上方、下方、内部或列表底部。容器有多个子块时可明确选择分支；不允许将整个复合手势覆盖到一条节点上。
4. **收起与持久化**：确认点位后收起定位工具，再选择加入位置；取消不产生积木。复合手势整批写入，一次撤销移除完整手势。加入后做 Rust 草稿校验和原子保存；失败保留脏草稿，明确标注“尚未保存”，用保存按钮重试，不重复加入。

入口保留“截图选点”替代方式，复用已有画布、十字定位、独立起终点及缩放能力。没有新增录制、多指或免 Root 后端。

## 用户操作

按键 → 选择悬浮/截图方式 → 选动作 → 拖动起点（滑动/拖动另有终点） → 点击手指设置动作和时长 → 确认点位 → 选加入位置 → 确定。

悬浮方式需先授权悬浮窗、连接 Root 后端并停止脚本。时长可直接输入或用 ±100ms 微调，范围 100–5000ms。起点、终点使用各自的窗口参数，拖终点不会带动起点。

按下/移动/弹起不是编辑时执行：加入插件并运行才会触摸目标；无持有租约的移动/弹起由运行时拒绝。仍只支持手指 ID=0。

## 坐标与安全边界

- Runtime 使用标记窗口实际 `getLocationOnScreen` 中心取物理点，坐标从物理屏幕左上角计算；不使用工具面板局部坐标或 dp 直接生成脚本。
- 回调包含一次性请求 ID、动作、屏幕尺寸、物理坐标和时长。Studio 与截图路径共用 `ImageToolCodeGen.DesignMapping`，再转换为项目设计坐标；原持久化节点 kind 与 flowId 不变。
- AIDL v19，服务不导出，另校验同 UID、会话代次、规范项目/插件 ID 和真实输入能力。回调不携带 Lua、文件路径、Root 命令或屏幕缓冲。
- 仅一个活动会话，120 秒截止；取消、编辑器 Binder 死亡、页面离开、插件切换、方向变化、Root 断开、运行停止都会关闭本次会话。请求/代次不匹配的迟到结果不写入插件。
- 插入草稿绑定原项目、插件、源码和选中节点。确认时源码/插件变化则拒绝；悬浮选择期间设计尺寸/缩放变化也拒绝旧结果，不把旧点位写到新插件。
- 部分插入失败或 ID 生成异常都回滚源码、选择与撤销历史，不留下孤立按下节点。
- 输入执行仍使用已有任务身份租约和停止优先通道；选点会话本身不建立触点租约。先建立前台服务，再允许 Studio 退到后台。
