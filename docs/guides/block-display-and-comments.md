# 积木摘要、显示别名与注释执行

## 查看与设置

单击选中一行后，再点该行可展开完整摘要，再点收起；每个列表只展开一行，长内容可在该行内滚动。别名的“只显示别名”仍不暴露参数，长按仍打开编辑。容器折叠时直接显示子积木总数，不额外占一行。

条件的满足/否则若/否则、多图识别及插件调用的成功/失败，统一显示可点击的分支标题，空分支也可选为加入位置，不逐行重复前缀。分支标题不是真实积木，不能单步、复制或删除。加入、粘贴、录制及图像位置选择显示附近积木和落点线；“行后”在整棵子树之后，“里面”在明确子区末尾，多分支须明确选择。

底部编辑窗可先选择起点行，再点“范围”，然后点终点行，一次选中可见顺序的连续积木（含端点，不含分支标题）。超过256项整次拒绝，保留原选择；选中容器的编辑操作仍包含其全部子树。选择状态区同时显示选中行数和含子积木的实际影响行数，父子同时选中不重复计数，折叠的子行也计入。

选中容器或其内部一行，在底部“编辑”中点“聚焦”，可临时只看这个容器，缩进从左侧重新开始；顶部路径可返回父级，点“全部”恢复完整树。不改变源码层级、身份或加入位置，范围外的选择仍保留并明确提醒；全选只追加聚焦范围内的行，清空仍清除完整选择。删除聚焦容器后自动恢复完整树。

手动滚动主积木树会暂停运行跟随，同时禁止执行位置把页面抢到其他插件；点击右上角“回到运行行”恢复最新执行插件、定位与祖先展开，并退出不兼容的聚焦视图，不暂停脚本。底部编辑窗仅在选中行离开视野时定位，不因普通操作把可见行反复顶到最上方。单纯选择、保存标记不重建插件内容投影，内容或插件名变化才更新相关显示。

主积木区和底部编辑列表共用紧凑摘要：显示操作名称和关键参数，长值分项省略，完整内容可打开参数查看。运行提示、弹出提示直接显示内容或绑定变量，不逐行重复持续时间说明；动态提示区分运行、弹出和日志渠道。提示窗的尺寸、位置、颜色及停留时间仍按项目提示样式设置，不伪造积木独立参数。

循环体不逐行重复“循环体”前缀，层级仍用缩进和辅助线表示；已有独立标题的其他分支也不再逐行重复短标识。调用、异步及定时插件显示当前插件名称，不显示内部ID，缺失引用显示“插件不存在”。找图行优先显示图片、阈值及命中动作，不铺开四边坐标；这不改变选区或识别参数。

选中一行，打开底部“编辑”（也可长按该行），直接点击“别名”：

- 别名＋参数：用自定义名称替换操作标题，保留关键参数摘要。
- 只显示别名：列表只显示自定义名称，参数仍在参数面板和源码中完整保留。
- 恢复默认或清空别名：恢复原操作名称与摘要。

别名最多80个Unicode码点，不允许换行、控制字符或非法Unicode；插件仍受1MiB源码预算约束。别名不改变量名、执行参数、运行提示内容或能力声明。未应用修改关闭时要求确认；运行期间禁止应用，切换上下文后拒绝迟到应用。

别名随积木保存、复制、备份恢复；支持撤销重做。完整摘要和参数仍参与搜索与无障碍描述，行内精简不修改原参数或身份。整插件受限源码的 `--@node` 元数据保存显示信息，省略 `display` 保留原信息，明确 `display:null` 清除。本行源码只修改参数，不修改显示信息。

## 注释执行与添加说明

编辑窗不再分组，19个操作直接平铺为小文字按钮，包括本行源码、插件源码、上移、下移、缩进、本积木随机策略及批量参数。标题12sp，选择状态10sp、路径9sp；全选、清空24dp起，操作按钮26dp起、文字10sp，间距3dp。约315dp可用宽度时为5列4排；窄窗或大字体自动减少列数，操作区有界滚动，保留中部积木列表。其他弹窗标题尺寸不受此项影响。

右上角方框按钮支持最大化全屏与还原；切换仅改变窗口布局，不改选中行、多选或编辑草稿。全屏使用可用屏幕空间，操作仍无分组，右上角关闭保留。

插件源码、本行源码、查找替换、变量管理及检查等长内容窗口也支持同样的全屏/还原图标；放大不会自动校验、保存或执行，原未保存关闭确认保留。函数库/详情、插件列表、图像配置和识别/OCR测试同样按需提供；加入位置、别名、改名及确认等短表单保持小窗。

- 添加说明：新增说明积木，不改变其他积木的执行。
- 注释执行：跳过所选积木。判断、循环等容器被注释时，其全部子节点也不执行，不会把循环体单独执行一次。
- 恢复执行：恢复所选根节点；不清除子节点原本单独设置的注释。

自身注释显示“已注释”；仅因祖先注释而无法执行的子节点显示“随父级禁用”。选中父级和其子节点时只处理父级一次。注释和恢复均可撤销重做；单步不能绕过禁用。

此批验证涵盖源数据往返、复制与备份、父子禁用、生成Lua执行，以及别名不影响执行参数。设备视觉效果与用户脚本运行不由单元测试替代。
