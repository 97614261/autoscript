# 项目随机化

## 入口

编辑器左上角设置 → 运行设置 →「随机化 · 触摸 / 图像 / 等待」。普通触摸、图像命中动作、普通等待独立配置，默认全部关闭。明确应用后保存到项目；备份携带配置，独立 Runner 的冻结脚本采用相同策略。

选中单个支持的积木 → 底部编辑 →「随机」，可跟随项目、关闭本积木或自定义。移动和弹起继承本手势按下时的偏移，不允许在半个手势中重新抽样。元数据参与保存、撤销重做、复制和受限源码往返；本行源码只改参数。

## 规则

- 位置 X/Y 各配置 ±0～4096 **实际屏幕 px**，先由宿主映射设计坐标，再从不会越出屏幕的合法偏移交集中均匀抽取。普通触摸和识图命中动作不叠加。识图结果变量与积木原始坐标不被修改。
- 滑动两个端点共用一次偏移；同一单指按下、移动、弹起共用一次偏移。编译器只对同一子区内不中断的固定坐标手势预求路径边界，不跨插件调用或条件分支猜测路径。
- 动态分步手势的新点无法容纳既有偏移时，报 `RANDOMIZATION_GESTURE_OUT_OF_BOUNDS` 并使用既有任务清理释放触点；不夹边、不重新抽样。映射快照变化时拒绝继续随机手势。
- 普通等待的增减范围支持毫秒（±60000）或百分比（±100）。例如1000ms、增减-10%～10%，得到900～1100ms。负结果最低为0；随机后的等待超过24小时明确拒绝。
- 零等待仍为0。按下期间、生成的长按/拖动/录制内部等待、勾选「保持精确时长」的等待不浮动。启动延迟、识图轮询、超时、调度让步不受影响；不添加每行随机停顿。

配置只作用于可视化编译生成的相关积木，不重写公开 Input/Task 函数的默认语义。不提供运行中修改项目策略的隐式全局开关。

## 兼容

旧项目缺少配置时保持原行为，不增加坐标解析调用。保存项目随机化或节点随机策略后，运行 API 要求提升到1.8，不降低既有更高版本。编译器明确拒绝低版本声明的随机项目；独立 Runner 支持1.8。

宿主接口 `Input.resolvePoint` 只读返回映射后的像素、屏幕尺寸和快照身份，不发送触摸，不代表截图或输入实测成功。屏幕像素移动/滑动继续使用真实 Root 输入、任务租约、取消和清理，不新增后端。

随机输入传递解析时的 `snapshotId`，宿主准备输入时再次复核。像素 API 省略该可选参数时保留旧语义；参数属于API1.8，不保证设备实际发送与物理屏幕旋转原子化。

相关决策：[ADR 0064](../adr/0064-project-randomization.md)。单元测试使用固定种子验证合法范围与一致性；实际运行不固定种子，不记录抽样坐标或用户变量。设备效果仍需实际屏幕验收。
