# 截图保存弹窗优化

2026-10-25同名保存更新：截图模板、处理图、字库和图片/字库/音频导入，同名时提供“覆盖保存 / 编号另存 / 取消”。覆盖保留资源路径和积木引用；确认后若新旧文件内容变化则拒绝，失败保留旧文件和表单输入。取消只返回保存配置，不丢预览。图片工作台默认带入原图名称与目录，处理图仍编码为PNG，其他格式不伪装原格式。覆盖后刷新缩略图、模板范围与识别测试；正在执行的冻结资源不变，下次运行使用新内容。图像/滤色方案采用同样的同名选择，不自动修改已加入的积木。项目/插件改名、备份恢复及脚本文件API仍使用各自规则，见[ADR0160](../adr/0160-confirmed-resource-overwrite.md)。

2026-10-25补充：从编辑器直接截图并保存的PNG模板，会记住当时框选的原屏范围和截图尺寸。新建找图配置选择该模板时，使用这个范围作为默认搜索区域；可继续框选或手动修改，也可点“模板范围”重新采用。多模板只在全部都有记录且原屏尺寸一致时取范围并集。旧模板/普通导入图没有记录时保留原有范围；处理后另存的图片不继承原屏坐标，不按图片宽高猜位置。只是配置默认值，不缩放像素、不证明当前屏幕尺寸相同、不改变既有积木。

2026-10-05。适用于可视化图像工具截图裁剪、项目整屏截图保存、图片目录选择及旧共享调用；不改工程格式和原像素保存链。

- 名称放在顶部，首次编辑可直接替换建议名称，目录切换及重绘不重置名字；PNG后缀自动补齐。名称在提交前验证，不以后台清洗静默改变用户输入。
- 目录按当前层级展示，提供图片根目录、上一级和当前位置；只显示直接子目录，包含已存在空目录，避免平铺全部路径。底部显示最终目标路径。
- 新建文件夹就地展开单行输入，支持键盘确认；后台创建真实目录，完成后立即进入。名称重复、越界、超过四层或120字符路径预算会明确报错。
- 新建是即时工程操作，取消保存不会删除已创建目录；空目录沿用既有备份恢复。创建期间禁止关闭/保存或重复创建，失败保留输入以便修正。
- 保存通过既有裁剪与正式资源导入链，不改变像素；同名按顶部最新规则显式选择，保存结果展示实际资源路径。
- 2026-10-14历史补强：曾仅提供编号保存或返回改名，现已被顶部同名保存规则替代。处理和识别加入见[Studio图片工作台](studio-image-workbench.md)，历史批次结果不代表本轮设备验收。
- 2026-10-15：所有截图/处理图保存入口展示实际裁剪尺寸px，继续原像素、超预算拒绝；改过名称、位置或未完成新文件夹输入后关闭需确认。取消不保存新图片、不改原图、不删除已创建目录。截图取材返回保留识别测试的未加入配置，但旧测试证明失效，需重新测试。
- 紧凑白底、蓝色标题、居中操作，列表有界滚动，横屏/键盘情况下正文可滚动且底栏保留。新建未结束时禁用保存，避免误将截图存到父目录。
