# 截图保存弹窗优化

2026-10-05。适用于可视化图像工具截图裁剪、项目整屏截图保存、图片目录选择及旧共享调用；不改工程格式和原像素保存链。

- 名称放在顶部，首次编辑可直接替换建议名称，目录切换及重绘不重置名字；PNG后缀自动补齐。名称在提交前验证，不以后台清洗静默改变用户输入。
- 目录按当前层级展示，提供图片根目录、上一级和当前位置；只显示直接子目录，包含已存在空目录，避免平铺全部路径。底部显示最终目标路径。
- 新建文件夹就地展开单行输入，支持键盘确认；后台创建真实目录，完成后立即进入。名称重复、越界、超过四层或120字符路径预算会明确报错。
- 新建是即时工程操作，取消保存不会删除已创建目录；空目录沿用既有备份恢复。创建期间禁止关闭/保存或重复创建，失败保留输入以便修正。
- 保存通过既有裁剪与正式资源导入链，不改变像素、不覆盖同名文件；同名沿用Store自动编号，保存结果展示实际资源路径。
- 2026-10-14补强：同名提交前明确确认编号保存或返回改名；工作台保存结果显示实际资源路径，处理和识别加入见[Studio图片工作台](studio-image-workbench.md)。本轮测试执行与安装按用户决定后置，不沿用下文历史批次结果作为本轮验收。
- 2026-10-15：所有截图/处理图保存入口展示实际裁剪尺寸px，继续原像素、超预算拒绝；改过名称、位置或未完成新文件夹输入后关闭需确认。取消不保存新图片、不改原图、不删除已创建目录。截图取材返回保留识别测试的未加入配置，但旧测试证明失效，需重新测试。
- 紧凑白底、蓝色标题、居中操作，列表有界滚动，横屏/键盘情况下正文可滚动且底栏保留。新建未结束时禁用保存，避免误将截图存到父目录。

主机测试覆盖子目录过滤、空目录、相对创建、重复、非法路径、预算、PNG后缀及名称保持。实际触摸、软键盘、横竖屏与截图效果由用户统一验收，不以主机测试冒充设备验收。
