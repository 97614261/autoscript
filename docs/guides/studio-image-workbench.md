## 操作流程

图片库或截图工具进入工作台 → 处理预览 → 保存图片（新建或确认覆盖同名），或测试找图/取字 → 选择已声明输出变量 → 选择加入位置 → 整批校验并加入插件。加入不执行脚本，也不生成点击动作。

- 处理支持灰度、阈值二值化、旋转、镜像、最近邻缩放、半开区间裁剪。二值化先按既有 Rust 权重取灰度，大于等于阈值为白，否则为黑；阈值为 0–255，默认 128，保留 Alpha。预览和积木复用既有 `screen.transform` 契约。
- 处理预览不改写原文件，只有保存并明确确认覆盖同名时才替换资源。最多保留 8 次位图编辑、含原图 32 MiB；存活预览的处理步骤独立保留，最多 64 步。撤销/重做不丢失重现当前预览所需的步骤。
- 每边最多 4096 像素，总量不超过 4,194,304 像素；超过预算明确拒绝，不静默缩小。处理有取消检查和 5 秒期限。
- 保存可改名、选目录、就地新建真实文件夹；保留原像素。同名时可覆盖保存、编号另存或取消，覆盖保留路径及引用，结果展示实际保存路径；确认期间内容变更则拒绝。取消保留预览和名称/位置；后台操作使用独立图片副本，关闭或切换上下文后不回填迟到结果。字库和资源导入也支持该选择，详见[截图保存](image-save-redesign.md)。

## 测试与加入

- 找图明确选择像素/灰度算法，OCR 明确选择已声明字库或字母数字后端，不自动换算法。
- 已保存图片测试支持原图X/Y/宽/高和像素五方向，测试及回填共用同一不可变配置；范围在原图内且右/下不包含，不截断非法输入。图片/范围标记共用Fit留白坐标。灰度仍单模板最高分，不使用方向或颜色容差。测试仅单模板，目录/多结果、频次及动作不在此验收，需正式配置。
- 截图取材时暂隐而非丢弃测试配置，返回后仍保留选择和输入；资源或来源变化清空证明并取消所属工作，必须重测。处理尾部的加入范围不得与已测试范围不同。
- 测试绑定当前位图、算法、完整参数、模板/字库及运行服务会话；更改参数需要重测。保存图片测试的解码位图在替换/关闭时释放，取消与失败均释放忙状态和所属临时文件。
- “处理 + 找图/取字”的有效性检查保留到加入位置选择及编译后的最终提交；测试失效即拒绝加入，不以旧测试冒充当前会话成功。
- 选择运行时截图或项目原图，以及两个不同的已声明图像变量；处理中间帧交替输出并释放。识别读取最终处理帧，不再截图；结果变量要求匹配类型、互不冲突。默认识别后释放最终帧，也可明确保留给后续步骤。
- 提供本行之前、本行之后、真实子区、列表底部。整批组合校验、复核正式项目/全部草稿/选择/运行身份之后一次可撤销加入；失败保留原草稿。处理坐标不是原屏坐标，不能直接作为点击位置。

## 识图1–6批补强 · 2026-10-14

右侧图像按找图、颜色、文字、处理分组。新增的是现有能力的可视化入口，不是更换算法：多点批量颜色、连通块、逐字字库结果、指定文字定位、加载/裁剪/变换/保存、帧系列均可配置。详情和源码仍使用同一生成契约。

- 图像来源可明确选择运行截图或已有图像。自身支持autoCapture的积木使用内部临时帧；其他识别展开为截图→识别→释放，需要选择专用图像变量并明确覆盖原值。已有图像不截图、不自动释放；结果读取不额外申请截图能力。
- 模板顺序、范围、采样点、取字配置及识别类型草稿有未保存关闭保护；选点/维护变量/取消加入位置后保留当前配置。
- 像素/灰度找图可选择等待出现、等待消失、限次重试、连续未命中计时。选择已声明整数工作变量及整数是否找到结果（1/0），展开为普通可编辑积木。最后判断的“如果”为完成，“否则”为超时/次数耗尽；异常/主动停止直接中止。每次读取新屏幕，去掉内嵌动作，轮询等待保持精确时长。成功分支动作由用户明确添加。
- 等待总超时1–600000ms、轮询间隔1–60000ms、重试1–10000次。每次识别前后检查期限，剩余等待不超过余量；首次未命中后才开始连续未命中计时，命中重置。宿主/SDK调用仍按既有期限退出，不承诺硬实时抢占。
- 找图、OCR总览/逐字/指定文字、颜色及连通块统一用“读取识别结果属性”配置。生成一个vision.readresult，不需要临时变量；源结果不覆盖，接收变量必须类型匹配且与来源不同。独立64KiB浅层结构预算，字库最多2048项、颜色/连通块256项、找图64项；缺字段/形状错误/越界明确拒绝，recognized为整数1/0。旧Data组合保留原语义，不自动迁移。
- 配置和三个测试入口显示运行服务及可选组件状态。已校验未加载不冒充识别成功；开始测试前后台检查缓存状态。缺组件、加载失败、忙、取消、超时、未找到分开显示，错误只传固定白名单代码，不显示SDK异常或私有路径。保存图像测试不强求Root截图。
- OCR保持ASGLYPH字库和ONNX单行A–Z/a–z/0–9；范围、字库颜色/容差、空格间距、相似度/逐字置信度可配置，结果文本可选择复制。逐字位置和分数由真实glyphdetails结果读取，不用文本推测位置；置信度不是正确率保证。

以上整批加入复用完整项目/全部编辑草稿校验，并复核正式数据、选择、能力与运行身份；成功一次撤销，失败不改草稿。不自动创建变量，不执行、不生成处理图坐标点击。见[ADR0109](../adr/0109-studio-recognition-workflow.md)与[本批记录](../verification/studio-recognition-completion-2026-10-14.md)。

## 当前识图收口 · 2026-10-14

- 颜色/多点颜色、字库/字母数字同样支持四种等待。条件状态不能占用原输出、分数、覆盖率或工作变量；选择器排除冲突，提交再次校验。字库覆盖率与得分也必须不同。
- 字库等待留空目标须至少一个有效字符（覆盖率>0）；完全一致须覆盖率1000‰并比较完整文字。包含非空目标改用同帧真实逐字结果和既有文字定位：目标外允许未知字，目标内部未知/跨行不通过，空白目标不支持且最多256字节；真正已识别问号与未知占位符区分。一次截图和OCR后读回原文字、得分、覆盖率；另选两个互不冲突的已声明字符变量接逐字及目标集合，不覆盖原输出，不隐藏建变量。旧已保存组合不迁移，见[ADR0112](../adr/0112-studio-coverage-and-recognition-workflows.md)。
- 等待窗常用时限及条件紧凑显示，映射按需展开；快速分配保留有效已有选择、排除原识别引用，列出映射后确认才应用。变量不足时返回维护，不自动创建，回来保留草稿。
- 完成状态1=条件完成，0=总期限或次数耗尽；异常/停止直接终止。尝试次数和耗时是实际值；期限在识别前后检查，到期后的命中不采纳，正在进行的调用不保证硬实时抢占。
- 字库详细预览可点字框或列表联动选中；快捷配置所选序号读取，不带入坐标、不生成点击。须另选运行时“字库逐字结果”的字符来源变量及接收变量，本次预览不能作为变量内容，下一帧序号不代表固定字符身份。
- 结果读取复用最多一份任务所属的已校验解析结果，精确绑定来源字节/类型/任务代次，取消和结束清理；不是复用旧屏。选择器说明对应生产积木，普通OCR文本/单点1/0不能当集合，逐字也可读数量；字符类型不证明内容形状，运行时严格校验。动作先校验全部所选坐标；来源、类型、偏移、锚点、首项/逐项、动作、数量及时长变化都需重新确认原屏来源。
- 色点错误直接指出第几项及字段；输入不静默转换成其他数值。完整说明见[ADR0111](../adr/0111-recognition-wait-safety-and-result-cache.md)。设备交互、效果、速度和内存仍待集中验收。
