# 可视化悬浮编辑器标题栏

`EditorDock.kt` 的 `EditorDockPanel` 是可视化悬浮编辑弹窗主页面，完整可视化编辑器和项目列表页的悬浮编辑入口共用它。标题点击的插件文件管理实现位于 `PluginFileManagerDialog.kt`。

标题栏左侧为设置，中央为当前插件标题，右侧依次为最小化、最大化/还原、保存关闭。标题在可用区域居中；点击选择插件，非按钮区域过拖动阈值后移动窗口，不误开文件选择。设置打开现有项目设置，沿用插件已保存和运行状态安全检查。

设置使用齿轮图标，最小化使用横线图标。可选择插件时标题使用浅蓝圆角入口和下拉箭头；不可选择时不显示下拉提示。插件选择页提供新建插件/分组、搜索与多选维护。底部按钮使用容器居中，不用固定文字上下边距。

最小化显示灵动环并保留插件、草稿、窗口位置及最大化模式；编辑球无论运行与否都只恢复编辑窗，不展开正式运行控制。编辑运行保留窗口，运行按钮变停止，并提供暂停/继续和单步。保存关闭成功后编辑窗与编辑球一起关闭；关闭仍在运行的编辑会话时才交还正式运行控制。

最大化避开系统状态栏、导航栏及刘海，不承诺隐藏系统栏；只改变编辑窗口工作区，不修改脚本屏幕坐标、界面设计稿或原小窗几何。还原回原小窗，最大化拖动先还原再移动。Android30+读取系统WindowMetrics，旧系统使用保守的显示可用边界，具体设备布局仍需验收。

编辑器直接运行保持原有窗口行为，不自动收起。项目列表启动先显示设计界面，界面参数校验成功后，第二次点击运行立即隐藏设计弹窗，再提交启动请求；同步提交失败恢复弹窗。保存、编译、Root 就绪检查及配置的运行延迟仍正常执行，隐藏界面不等同于引擎已经开始执行。

运行服务在启动时只激活界面能力，不自动重开一份运行界面，避免“关闭—闪现—再次关闭”。需要在脚本运行期间显示时使用显式 `UI.command("window", "show", "")`；隐藏期间更新控件值仍被保留。

## 脚本存储

Studio 的项目根目录为 Android 应用私有目录 `/data/user/0/com.zhigou.kaifaban/files/projects/<projectId>/`。可视化插件保存在 `visual/flows/*.jsonl`（默认 `main.jsonl`）；Lua 入口是项目根目录的 `main.lua`，其他 Lua 文件在 `lua/`。插件分组为 `.studio/source-groups.json` 中的虚拟分组，不移动实际插件文件。电脑的仓库目录是应用源码，不是模拟器里正在编辑的脚本目录。
