# 可视化积木编辑

底部「编辑」和积木长按共用操作窗。主列表与操作窗共享子积木折叠状态，保留紧凑行高和真实结构缩进；折叠只影响显示，不改变源码、执行或保存层级。

## 选择与定位

- 点一行单选，左侧勾选框多选；全选最多256行，包含折叠隐藏行。选择父积木已包含其子树，复制、移动、删除与注释执行不会重复处理子节点。
- 全选和清空使用一次批量选择，不逐行反复解析插件；不记录撤销历史、不修改插件内容。
- 操作窗提供「展开全部 / 折叠全部」。切到源码选择的隐藏子行或新的运行位置时展开需要的祖先，其他折叠分支保持不变。
- 两个列表按窗口宽度和真实缩进计算横向空间；深层积木可以横向滚动，不使用固定960dp画布。

## 连续操作

19个操作保留紧凑平铺布局。复制、粘贴、撤销、重做、删除、移动、缩进等操作不会关闭操作窗；保存/校验时暂时禁用操作，结束后继续操作。参数、源码、别名等详情在上层弹出，关闭后回原列表；明确关闭或开始运行时才收起编辑操作窗。

粘贴提供「本行之前 / 本行之后 / 真实子区」。前插保持复制森林顺序，复制重新分配节点和子区身份，保留引用、别名及独立禁用状态；没有选中行时加入根列表底部。整批改动只占一次撤销。

增加缩进只接受连续同级选中根，目标是其上一行真实容器。多分支容器先选分支，确认时再次复核项目、插件、完整源码、主选中行、多选集合、真实分支与运行状态；陈旧选择明确拒绝，不操作后来选中的行。

## 函数收藏与最近使用

函数库上方可切换「全部 / 收藏 / 最近使用」，点函数旁的星形收藏或取消收藏。最多收藏64项；最近使用保留24种函数，按实际成功加入的顺序排列，打开参数或取消加入不算使用。切换这三个页签会清除分类过滤，搜索仍可继续缩小范围。

这两项只记录当前App的函数类型，不包含参数或项目内容，不随项目备份。函数文档的API契约仍为只读，不能加入积木。

## 全项目查找

从「更多 → 查找替换 → 搜整个项目」进入。可按函数、变量、图片或全部参数检索所有插件的当前草稿，包括尚未保存的修改；多个关键词以空格分隔，必须同时匹配。显示插件名称、真实源码行及摘要，点结果退出局部聚焦、暂停运行跟随并定位真实积木，不保存或执行脚本。

结果按插件分组，可收起单组，显示实际命中的参数。展开筛选可以限定当前插件/全部插件、启用行/已注释行；父级注释导致不执行的子行也算已注释。「上一条 / 下一条」定位但保留查找面板，点结果定位并关闭。关键词、过滤条件、分组折叠、当前结果和滚动位置在本次编辑会话内保留。

查找使用打开时的草稿快照。若结果对应的插件内容已经改变，点「刷新」明确重读，不会猜测新位置。最多检索16MiB、20000行，单插件最多1MiB；只读、结构无效及超限的插件会明确提示未完整检索。结果独立滚动，不再只显示前200行。

## 整项目预览替换

从全项目查找底部点「替换」。文字替换区分大小写，支持内容、标题、文本参数及设置变量的文字常量；不替换变量身份、表达式、任意JSON、目录或内部ID。图片替换必须明确选择项目中已声明的原图和新图，只改真实图片参数及图片列表引用，不删除或重命名文件；文件夹来源不参与。

可限定当前/全部插件及启用/注释行。先生成预览，再逐项勾选，显示插件、行、函数、参数及新旧值；确认后对全部当前草稿组合编译，复核正式清单、所有源码、选择、编辑器身份和运行状态后才一次应用。预览最多256行、512项参数、32个插件，整批原文与候选合计最多32MiB；超限明确拒绝，不静默替换部分内容。

替换仅修改未保存草稿，不运行脚本。跨插件替换在任一参与插件执行撤销/重做时整批处理，保留各插件原有历史；如果其他参与插件还有后续修改或记录已失效，整批拒绝，先处理后续修改后再撤销，不只回退其中一部分。明确关闭未应用输入时需确认，取消校验不应用迟到结果。

## 批量参数

明确勾选2至256行同一种函数后，在底部「编辑 → 批量参数」勾选一个或多个要统一的参数，输入后预览确认。支持延时、相似度、容差、超时、循环次数等公共整数，以及自动截图、精确延时、部分采集、禁止窗外关闭、运行提示/日志开关和查找方向、日志级别等明确选项；不开放找到后自动点击等动作枚举。绑定变量的参数不允许覆盖，图片路径、变量名、结果变量和身份不参与批改。没有共同可改字段的选择明确拒绝。

只改勾选的真实行，不自动改父积木包含的其他子行。先校验全部插件草稿，再复核项目、所有草稿、选择和运行状态，通过后一次应用为未保存草稿，可一次撤销；取消、校验失败或上下文变化时不修改任何行。正式保存仍走原保存入口。

## 报错定位

已知编译、结构及运行错误先显示直白说明和建议，可展开、选择或复制原始详情（最多64Ki字符）。编译诊断能准确对应当前插件和积木时，提供「定位积木 / 打开参数」；源码已经改变、身份不明确或积木已删除时不猜位置。不从自由文本推测参数字段；当前诊断没有结构化字段路径时只打开该积木原有参数页，不假装已定位到某个输入框。运行日志的详情也补充已知错误说明，但不从Lua文本猜积木身份。

## 保存与恢复

运行前保存全部脏插件时，冻结清单、所有正式插件基线及编辑草稿，组合编译通过后再次复核，以同一个有界回滚事务提交；任一插件或清单冲突则整批拒绝，不逐个保存造成部分提交。单插件保存只提交该插件，不顺带保存其他草稿；若另有未保存插件，同时核对本次提交的正式结果与全部打开草稿，不能依赖尚未保存的其他修改让正式工程通过。旧内容回滚总预算仍为32MiB，超限明确拒绝而不丢弃原稿。

取消启动若发生在磁盘提交前，不开始保存；已开始的有界事务及编辑器保存回执一起完成后再响应取消，仍不继续启动脚本。保存期间后来产生的新编辑保持未保存状态。

编辑草稿恢复可以「保留并关闭」，正式项目不变；待处理记录保留期间暂停自动检查点，重新打开项目可继续处理。校验恢复仍需完整项目和全部候选组合校验，恢复可撤销，不自动正式保存或运行。

自动恢复记录在停止编辑300ms后冻结文本，哈希和写盘在后台完成；持续输入不反复对大插件计算摘要。明确丢弃记录也核对所属会话和修订，旧窗口的迟到任务不能删除新窗口的恢复记录。

## 显示与执行

别名与参数摘要见[积木显示](block-display-and-comments.md)。添加说明和注释执行互相独立；父积木注释跳过全部子树，恢复父级不清除子节点独立禁用状态。

运行位置与编辑选择分离，执行高亮不依赖日志开关。暂停标记下一步；运行终止清除高亮，不伪造已执行行。空闲单步隔离编译选中积木及子树，不执行前置节点；暂停单步复用已认证的调试会话。编辑运行保留主编辑窗，收起编辑操作、保留停止及暂停/继续。

持续触点启动预检从摘要已验证的source-map实际输出身份推导，不因禁用子树或单步范围外的按下/移动/弹起误阻断。整项目仍保守计入所有已输出插件定义，不保证分支可达性；历史缺失位置记录的产物保持保守检查，不视为无需求。项目能力声明和运行服务的最终设备校验不变。
