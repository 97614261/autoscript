# Root 全局动作录制（阶段 1–3）

录制入口只在可视化插件编辑器提供。它读取其他应用的真实 `/dev/input/eventN` 事件，不监听编辑器点击，也不使用无障碍。开始前必须 Root READY、认证后端支持 INPUT_RECORDING、悬浮窗权限已授予、项目 `project.json.capabilities` 显式声明 `input.basic`，并且脚本/选点/另一录制均未占用输入。缺项明确失败，不修改项目能力。

开始成功后编辑窗口和录制 Dialog 隐藏，Activity 退到后台；独立灵动环 REC 控制窗提供停止、取消。运行灵动环原有暂停/继续/停止语义不变。停止点击未完成触摸会被丢弃，控制窗真实屏幕范围内的触摸从结果中过滤；取消不保留可提交动作。协议25通过单次完成事件自动恢复当前悬浮编辑工作区并显示结果，App内录制则回智构查看；也可从通知恢复后主动停止并预览。不用固定周期轮询。当前录制身份、服务和非零有符号会话代次必须一致；关闭、切插件及重复完成不能重新开窗。结果仍需检查并选择加入位置，不自动保存或运行。旧主动获取接口的浮窗收尾结果最多缓存一份、120秒；关闭工作区发送结构化取消。

Root 协议固定 32 字节开始配置、16 字节停止配置，均带正数随机录制 token；认证通道自带随机会话与序列重放保护。开始也受输入请求 ID 栅栏约束，停止走独立优先通道。evdev 线程只打开固定目录下的字符设备，不接受文件路径、shell 或命令字符串。最多16个设备、32个 MT slot、8192事件默认预算（范围128–16384）、60秒、512个动作/跳过手势。必须有一个支持协议 B 的空闲触屏；不支持协议 A、多触屏、无有效轴、不能设 CLOCK_MONOTONIC 等设备明确拒绝。SYN_DROPPED、错误事件、多指、溢出、方向变化拒绝整批。

用户明确开始新录制时，Root工作线程先等待上一次优先停止的认证清理回执，再恢复输入栅栏；清理失败不得放行。等待前后复核当前录制token，等待中取消或更换会话不得迟到启动录制；不把普通Runner连接当作这项清理已经完成。

支持单指点击、500–5000ms 长按、50–5000ms 近直线滑动，以及 Home/Back/音量+/音量-/Enter/Menu 白名单按键。不读取文本键盘字符。超过5秒、过短移动、明显弯曲/闭合轨迹不伪装为直线，单独跳过并在预览报告数量；之前的可记录动作保留。事件错误与多指不是“跳过”，仍整体拒绝。轨迹最大1024点，直线允许12原屏像素偏差，点击抖动容差8原屏像素。

动作记录为32字节小端 `kind/startMs/durationMs/x1/y1/x2/y2/keyCode`，原始逻辑屏幕像素；JNI结果24字节头为 `token/u64,count/u32,elapsed/u32,status/u32,skipped/u32`。IPC结果为 `RecordingReply`，携带 generation/宽高/方向，最多16384字节动作。JNI/AIDL/客户端均验证严格长度、身份和动作时序，失败不能携带动作。

预览按项目冻结的 design/scaleMode 映射为现有 input.tap/input.swipe/input.keyevent/task.sleep 积木，长按使用同点 swipe。letterbox 黑边明确拒绝，不夹到设计边缘；可删除不需要的动作、选择保留动作之间等待。一次最多256积木，超限要求删动作/分段录制，不截断。确认后仅一次编辑器插入，可撤销，不自动执行。项目、插件、源或设计已变化时宿主拒绝回填。

已添加主机协议、解码、优先停止、JNI结果、Android结果、控制窗过滤与草稿转换测试。主机测试和编译不等于设备验收：MuMu/真机仍需实际采点校验自然触屏轴与逻辑方向，跨应用录制/浮窗停止/取消/多指/旋转/超时/断连及单次撤销。未通过设备采点前不能把所有 Android Root 设备宣称为支持。
