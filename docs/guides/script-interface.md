## 入口与启动顺序

项目的界面设计器采用左侧控件/图层、中间画布、右侧属性栏。页面切换下拉和「+ 页」位于画布顶部，收起左侧控件栏或进入专注模式后仍可使用；切页清空控件选择并恢复整页缩放。左侧不再显示控件数量或页操作，控件列表可用高度相应增加。设计器横屏显示，退出后恢复原来的方向。

底部不再常驻说明、选择摘要或反馈文字；三栏工作区占满顶栏以下的可用区域。必要的保存、恢复、校验反馈在顶部短时浮层显示，不挤占画布；可以关闭，消失后点顶部「提示」重新查看，校验问题保留「定位」动作。原页面设计像素、控件布局及等比整页适配不改变，不把画布拉伸到不同宽高比。

设计器默认「整页」适配宽度和高度，尽量不滚动画布；使用 +/− 放大缩小后可横向、纵向平移。顶部 32dp 单行工具栏提供「控件」「属性」独立开关和「专注」模式；退出专注恢复之前的面板开关。在不足 560dp 的窄屏只显示一个面板，添加控件后保留控件栏方便连续添加，点击画布控件则显示属性。左侧双列短名称控件按钮、图层列表；右侧布局、样式、交互采用浅底分段标签，颜色输入与色块合并为一行，点击色块弹出色板。常用字段直接改 X/Y、宽高和位置，交互里直接选择变量、插件和页面，不需要手输 ID。顶部内容超宽时可横向滑动，保存/预览不会被截掉。

添加控件按三列寻找页面空位，所有新控件默认高 40px、字号 20px，已有控件尺寸不自动修改；多行、列表、图片和容器可按需在属性里加高。不自动把页面拉长。页面满时明确提示，保留现有布局。可点击「紧凑排版」按三列整理根层控件；空间不足或宽容器可能裁剪子控件时拒绝修改。默认吸附到 8 设计像素网格，可关闭；支持六方向对齐、水平/垂直等距、置顶/置底。容器移动不会重复移动已选子控件，变更父容器尽量保留绝对位置，整组可换页。单选组高度不足以放下纵排选项时采用等宽横排；设计画布和共享运行渲染器使用同一判断，加高后恢复纵排。

画布底部「整理」保留当前页三列排版、所选排列、统一尺寸、网格吸附和尺寸预设，不再提供「缩小全部75%」入口；读取已有界面也不会自动缩放原稿。设计器按钮最低 22dp、属性行和控件栏按钮为 24dp；共享运行界面的页签和底部操作为 32dp，并移除原生控件额外最小尺寸，单选/复选指示器跟随设计像素比例缩放。编辑画布文字不继承主题的大行高，字号跟随设计像素缩放且不受系统字体缩放再次放大，移除字体额外内边距，避免小控件的居中文字被裁切。

Studio 项目列表的「启动」先显示保存的界面；此时不会执行 Lua。填写后点击界面内「运行」，校验配置，再启动脚本。取消或关闭不启动；未设计界面的项目直接启动。编辑器的「运行」保存草稿后直接执行当前插件，使用界面默认配置，不弹启动配置窗、不进入自动生成的界面事件循环。单步继续走独立检查点路径。独立 Runner 仍先显示启动界面，确认后执行。

项目列表「编辑」直接展开可视化编辑弹窗，背景保留项目列表；不再展示旧全屏程序树/节点 ID/编译诊断页面。最小化才变成吸附球，点击球恢复，关闭退出编辑。编辑控制器、插件保存及工具回调沿用原实现，错误与运行状态在编辑弹窗反馈。编辑期间列表其他项目操作暂时禁用，避免误切换丢失草稿。独立Lua编辑页已退休，历史项目仍可完整备份。

Studio 预览、Studio 启动配置窗、运行时悬浮界面、独立 Runner 使用同一个传统 View 渲染器。预览只检查界面，不启动脚本。独立 Runner 只加载冻结发布内容，不依赖设计器或编译器。

设计画布按页面和全部祖先容器的交集裁剪控件内容，仍保留选中轮廓和拖动操作，便于将超界控件移回；不改写已保存坐标或尺寸。运行下拉框和列表明确保留无选中状态，清空或删除当前选项后不以第一项冒充当前值；脚本读取选中序号为0。Android下拉框用仅展示的「未选择」承载空状态，该行不能选中、不列入弹出选项，也不进入正式选项、脚本数量/索引或项目数据；列表仍为无勾选状态。

## 设计能力

- 输入：单行文本、多行文本、整数、复选框、单选组、下拉框、列表、滑块。
- 展示：标签、图片、进度条；组织：容器、按钮、分页导航。
- 操作：添加、选择、多选、复制、删除、拖动、缩放、左对齐、上对齐、撤销/恢复、预览、保存。
- 属性：稳定 ID、标题、初始值、整数范围、选项、页面、父容器、位置、尺寸、字号、文字/背景色、对齐、可见、可用、必填、绑定与事件。

坐标、尺寸、字号是页面的设计像素，不是屏幕绝对坐标。设计器和运行窗口复用同一套视口算法：默认按宽高中的较小比例整页显示并居中，保持比例、不自动重排控件；标题栏菜单可切换「按宽显示 · 纵向滚动」，长页面保留原有布局并纵向滚动。颜色格式为 `#AARRGGBB`。图片只能使用已声明的项目图片资源。

保存拒绝过期覆盖、失效的绑定和事件引用；旧版四类型表单继续读取，进入设计器保存后才升级 v2，不删除用户数据。

## 值与事件

选择项在设计器按条目添加、修改、删除，不以逗号拆分已保存数据；逗号、引号和前后空格会原样回显。删除当前默认项时选择剩余首项作为默认，空项或重复项仍由保存校验拒绝。

函数库「设置控件值」「界面操作」使用专用配置面板：选择已保存的控件、操作、固定值或来源变量；读取属性时选择已声明的字符结果变量，切页时选择页面。窗口显示/隐藏/最小化自动使用window，不需要手输ID。失效控件、非选择控件的items和非进度条的progress在加入前拒绝。旧积木kind及参数格式不变；运行时仍校验动态值。

画布下方固定为一条 28dp 紧凑工具栏，选中控件不再增加操作行或改变画布缩放比例。常用多选、复制、删除、横中、竖中直接点击；「定位」菜单提供靠左/靠右/靠上/靠下、横向居中、纵向居中、正中；「对齐」菜单提供多选同级控件六方向对齐和三项以上的水平/垂直等距。单选按所属页面或容器定位；多选按整体包围框定位，保留内部间距。超出父页面/容器的整组拒绝靠边定位，不自动缩小；不同页面或父容器不能混合对齐。移动容器不会重复移动已选子控件。操作进入撤销历史。「样式」标签提供「文字对齐」左对齐/居中/右对齐，不跨标签常驻，区别于控件位置对齐，沿用已有 alignment 字段并保存到运行界面。

「定位」「对齐」「整理」采用与按钮相连的统一紧凑菜单：白底、细边框、圆角，逐项分隔；菜单宽152–232dp、高不超过248dp，且按按钮上下实际可用空间限制高度，超高内部滚动。弹出层直接按按钮边界定位，不使用默认菜单的影子/空白区域作为可见菜单锚点；优先向上展开、间隔3dp，顶部空间不足时向下，左右避开8dp屏幕边缘。条目最小32dp，大字体可以换行；箭头为独立绘制的图形，与文字在同一行垂直居中，不依赖文字字符的基线。菜单禁用后自动关闭，点击外部或返回关闭，不改变已有整理、对齐功能及撤销行为。

启动时全部控件值进入 `RunnerConfig`，类型为字符串、整数、布尔或选项字符串。

绑定属性可填写 `global:变量名`、`flow:插件ID:变量名`、`param:入口参数名`。全局/插件变量必须已声明；复选框绑定数值变量时使用 1/0，绑定布尔参数时使用 true/false。入口参数是启动配置，不是运行时动态参数。

事件键为 `click`、`longClick`、`change`、`selection`；只有对应控件实际发生的事件才触发。动作支持 `flow:插件ID`、`page:页面ID`、`run`、`close`、`minimize`。运行后的 `run` 不会重复启动脚本。插件事件可接收 `controlId`、`event`（字符串）及 `value`（控件类型）；其他必填参数会阻止保存。

可视化界面读写积木对应以下 API，需要 `ui.control` 能力：

- `UI.getValue(id)`：读取字符串值，未绑定事件的普通控件编辑也会同步。
- `UI.setValue(id, value)`：更新值，不反向触发用户事件。
- `UI.command(id, operation, value)`：操作 `text`、`visible`、`enabled`、`items`、`progress`、`page`、`show`、`hide`、`minimize`；布尔参数为 true/false，`items` 用换行分隔，`page` 的值为页面 ID。
- `UI.waitEvent()`：挂起等待，返回 `控件ID:事件名`；单消费者、可取消，不轮询。可视化编译器自动生成事件分发，通常不需要手写。

运行时布局和样式仍通过 `UI.command` 的白名单读写：`x`、`y`、`width`、`height`、`fontPx`、`textColor`、`background`、`alignment`。坐标相对所属页面或容器，数值为设计像素；X 0–4096、Y 0–8192、宽 20–4096、高 20–8192、字号 8–160。颜色严格使用 `#AARRGGBB`，对齐仅 `left`/`center`/`right`；原有控件值及布尔写法保持兼容。

`UI.command("label", "get:x", "")` 返回当前位置的数字字符串，`UI.command("label", "get:textColor", "")` 返回精确颜色字符串；也可读取 `y`、`width`、`height`、`fontPx`、`background`、`alignment`、`value`、`text`、`visible`、`enabled`、`items`、`progress`。读取的第三参数必须为空，属性不存在、类型不适用或 ID 不存在报错。`visible`/`enabled` 读取控件自身保存的开关；父容器仍可以阻止子控件显示和交互。旧 v1 表单没有设计像素与样式属性，不虚构坐标。写操作不返回值。

新属性写入与读取等待主线程宿主完成，读取前按顺序应用已发出的旧界面命令；Lua 挂起而不轮询。宿主适配最多等待 2 秒，调度超时 3 秒，可取消。隐藏或非当前页的布局和样式覆盖保留到恢复渲染，读取无需挂载控件；运行属性不改写项目清单，恢复默认值清除覆盖。

单选组的子选项、列表条目现在分别触发已配置的 `click`/`longClick`，下拉框打开触发 `click`、选择改变触发 `selection`，滑块用户松手触发已配置的 `click`；不增加 runnerUi 事件键，也不由程序写值合成事件。

函数库「界面 → 读取页面参数」复用 `ui.get` / `UI.getValue`，不新增 API 或改变旧积木 kind。可视化加入前先选已保存页面里的控件（显示页面、标题和稳定 ID），再选字符串结果变量，可直接维护变量；取消不加入默认占位积木。编辑已有积木使用同一个面板。任意页的当前控件值均可读取，不是页面的宽高位置。复选框结果为 `true`/`false` 字符串，整数为数字文本；数值计算可用 `int/float` 转换。`RunnerConfig` 保留启动时的配置，`UI.getValue` 读取运行中的当前值。Lua 调用不存在的 ID 返回空字符串；配置面板拒绝失效 ID。

读取参数窗有未应用的控件/结果变量选择时，返回、窗外、标题关闭和取消均先确认，不静默丢弃或加入。变量名超过契约长度明确报错，不截取成另一名称。

编辑器的原生界面预览归同一编辑会话管理，与参数窗共享16个子窗口上限；截图和系统选择期间暂隐，结束后恢复同一View树，关闭会话清理且迟到请求不能重开。运行变量观察窗仍是独立非模态窗口，不占此子窗口名额。预览最小化/提交隐藏状态不因旋转自动展开。

运行悬浮界面可拖动、最小化为恢复按钮、恢复、关闭停止；页码和控件值在最小化期间保留。停止、失败、服务销毁及新会话替换都会清理窗口；旧窗口不能影响新会话。启动前的最小化恢复按钮仅在应用内显示。

## 脚本对话框

函数库「调试 → 对话框」及右侧「调试 → 对话框」提供「确认对话框」「布局对话框」「关闭对话框」，都要求项目声明 `ui.control`。加入确认框、布局框先配置，不插入未经确认的默认积木；修改复用同一面板，插件源码往返保留参数。页面参数和控件操作仍归「界面」，`ui.*`稳定标识及运行协议不变。

- 确认框：填写标题、内容、两个按钮文字、等待期限和字符结果变量。运行返回 `confirm` / `cancel` / `dismiss` / `timeout`；判断积木明确比较 `confirm`，返回、窗外或到期不能算确定。无需先设计页面。
- 布局框：选择界面设计器**已保存**的页面 ID，可禁止点击窗外关闭，返回键仍可关闭。布局内的 `close` 动作和底部关闭仅关框，结果为 `close`；返回/窗外为 `dismiss`，到期为 `timeout`。结果变量可省略，控件填写值保留，用读取页面参数获取。原主窗口暂时隐藏，框结束恢复原显示状态；停止不恢复。
- 关闭框：关闭当前交互框，不停止脚本，不关主窗口。确认框被脚本关闭时结果为 `dismiss`。没有交互框时无操作。

等待默认60000ms，可设1000～1800000ms；Lua协程挂起、不轮询，Root工作线程不被用户等待占住；停止取消等待并移除窗口。同一运行不允许重复叠交互框。期间旧异步控件更新可用，额外属性宿主读写可能明确报 `UI_QUEUE_FULL`，不要在另一个任务持续查询弹窗属性。编辑器直接运行保持既有「跳过自动界面事件循环」规则：使用页面自身关闭动作结束弹窗，插件按钮不会因此额外启动事件循环。

对应 API：`UI.confirm(title,message,confirmText,cancelText,timeoutMs)`、`UI.showDialogAndWait(pageId,blockOutside,timeoutMs)`、`UI.closeDialog()`。标题最多192、内容4096、按钮文字各96 UTF-8字节；内容可换行。布局按保存尺寸及现有小窗适配显示，不新建布局文件或修改原稿。此类交互独立于运行提示总开关。

## 自适应小窗

预览、启动配置、独立 Runner、运行悬浮窗共享 32dp 标题栏与 32dp 底部操作栏。菜单包含整页适配、按宽滚动；启动前还可恢复默认值。窗口按当前设计页比例计算自然高度，宽度以设计宽度的半倍 dp 为基准，最低 240dp（小屏受可用空间限制），最大 560dp / 可用宽度的 94%；高度不超过可用高度的 90%。短页面不会被强制拉满屏幕。

屏幕方向、窗口和软键盘可用空间变化会重新计算小窗边界与内容缩放；拖动限制整个窗口在安全区域内。最小化只隐藏或移除窗口挂载，保留 View 树、输入、当前页面和显示方式；旋转不重启脚本或创建新引擎会话。按宽模式保留各页滚动位置（可见空间变化时受新滚动范围限制）。设计器仍横屏，退出后恢复原方向；运行窗口随设备方向适配。

这些规则不修改已保存页面坐标、不新增 runnerUi 字段、不改变 Lua 发布协议。Android 7 的软键盘 Insets 行为及不同设备窗口边界需人工验证。

## 资源与验证边界

控件布局属性提供「智能尺寸」和「适应内容」：当前会话默认在显示文字、选项或字号改变时增大宽高，可关闭以保持手工尺寸；旧界面加载不调整。增大不移动邻居，受页面/容器和同级控件限制，空间不足会提示，调整与内容编辑作为一次可撤销草稿保存。单选横排需所有选项实际宽度能容纳；不足时换行、纵排并在真实预览/运行界面内部滚动，列表、多选、下拉条目同样换行。画布仍可拖动，超出选项用滚动轨道提示，完整交互请点预览。动态items不改变保存矩形或项目。见[ADR0065](../adr/0065-content-aware-script-ui-controls.md)。

新增开关（SWITCH）沿用布尔值 true/false，可绑定既有布尔参数或数值变量；密码输入（PASSWORD）沿用文本读写、必填和绑定规则，运行 View 与画布使用掩码。掩码不是加密：不要在设计默认值中保存真实密码，脚本也不要输出密码值。开关与密码是独立真实控件，不改变旧复选框及单行输入的行为。

小数输入（DECIMAL）使用number，值有限且在正负十亿内，支持负值、小数与科学计数法，不接受NaN/Infinity或十六进制。范围边界暂沿用整数格式；绑定只允许NUMBER变量或number参数。初始化Lua传递真实数值，不截断为整数。

通用 `UI.getValue` / `get:value` 仍返回文字，读取积木结果使用已声明的字符变量；读取小数后可通过既有计算转换成数值。配置初始化和绑定保持number类型，不为新控件改变旧API签名。

多选列表（MULTISELECT）默认值正式保存为字符串数组，最多64选项、所选JSON文本最多2048字符；必填至少一项。设计器和固定值操作提供逐项勾选。脚本 `UI.getValue`、`UI.setValue`、事件value和STRING变量绑定均使用JSON数组文本，例如 `["a,b","带引号\""]`，不按逗号拆分。`items`更新保留仍存在的选择；必填无剩余项时选首项。不新增隐式数组变量。这两类要求v2设计界面，旧v1类型及摘要不变。

设计器支持显式框选模式（矩形相交选择当前页控件，容器按绝对位置计算）；中心参考线辅助定位。点击画布取得焦点后，方向键移动1设计像素，Shift+方向键移动8像素，不抢属性输入焦点。选择后的定位/对齐继续进入撤销历史。保存校验失败可点「定位问题」选择对应控件和属性栏；引用失败使用保存层返回的真实控件ID。

界面设计恢复按ADR0061独立保存在私有ui-designer-drafts，最多16项目、每记录1MiB，300ms防抖。恢复需明确确认且正式清单和当前编辑上下文不变；恢复可撤销、不保存、不运行。当前已有新修改时不覆盖。正常退出或明确丢弃清理所属记录；进程被杀前最后尚未落盘的输入不保证保留。

恢复弹窗的「保留并关闭」只关闭提示，保留待处理记录；顶部「恢复草稿」可重新打开。待处理期间暂停自动草稿记录，退出也保留该记录。无法读取、正式清单已变化或当前已有修改时不显示不可用的恢复按钮；「丢弃记录」仅删除恢复记录，不改正式界面。恢复或丢弃失败在弹窗内显示原因，成功后关闭提示。

2026-10-10修复：运行配置值数量复用256控件上限（128仍是界面命令队列上限，不是控件上限）；`hide`移除窗口及恢复按钮，保留控件状态，`minimize`才显示恢复按钮，后续`show`恢复同一界面。脚本窗口标题按整个标题栏居中。设计器保存固定提交时的草稿，迟到手势不得在保存期间修改草稿。

最多 16 页、256 控件（v1 仍为 32）、8 层容器、64 个选择项、2048 字符文本；撤销最多 100 步。事件队列最多 64 条，界面更新排队最多 128 条，超限停止而不无限积压。无事件等待最长 30 分钟，超时按运行错误处理；可随时停止。图片文件最多 16 MiB、源尺寸最多 4096×4096，显示降采样且单页像素预算有限。
