# Studio变量、流程与函数库

## 声明与计算

变量管理保留局部/全局作用域和名称搜索，不增加类型筛选。列表采用32dp最小行高，小窗按内容显示最多六行，支持全屏；大字体可以增高。不为查看变量读取或记录运行值，运行值仍由独立观察窗负责。

声明类型为整数、浮点、字符、图像，项目合计最多512个。局部变量只属于当前插件；同名插件参数优先于局部，局部优先于全局。集合/对象使用JSON字符变量，不新增独立持久化类型。图像保存任务内句柄，不参与标量计算。

计算支持固定值、变量引用、运算符、整数/浮点/字符转换、字符与字节处理和自增/自减；仍由Rust白名单表达式编译器校验，不执行任意Lua。来源选择优先打开实际有候选的作用域，参数单独标识。计算窗提供全屏/还原，未应用表达式不会因放大保存或执行。

变量声明保存和计算加入仍是不同动作。保存中禁用再次保存、新增、编辑和删除；宿主重新检查最新忙状态和运行状态。变量类型变更、删除或新增会使旧编译产物失效，后续必须重新编译，不将声明保存成功冒充所有引用已有效。改名继续使用既有多文件回滚事务，保留界面绑定和积木引用。

## 判断与循环

条件支持单比较和与/或/非树，否则如果保留真实独立子区。条件预算仍为64项/8层/8192字节，编译器做类型和引用检查；不靠界面把非法参数钳成合法值。

循环使用已有契约：限次`control.repeat`、条件`control.while`、可取消无限/限时`control.cycle`。循环指标和阈值退出是独立积木，作用于最近循环；跳出和跳过只能放入循环体。

专用循环面板现在可选择/清空序号与耗时输出，并保留已有配置：限次写入`indexVariable`，其他循环写入`iterationVariable`；耗时写入`elapsedVariable`，单位为毫秒。序号只接受已声明整数变量，耗时接受整数/浮点，不把插件参数作为输出。输入次数与时长仍可以来自符合类型的参数。

旧`control.while`的无限/限时配置保留次数上限，不自动变成`control.cycle`。修改旧节点可切换无限/限时模式，不改变积木类型或子树；新节点默认可取消循环，每轮让步，无额外次数上限。

## JSON列表与对象遍历

当前通过真实积木组合完成遍历，**没有新增单独的foreach积木，也不是延期的插件模板库**。

1. 声明字符变量`items`、整数变量`total`和`index`、字符变量`key`和`item`，将列表JSON放入`items`。
2. 「集合 / 对象长度」使用`jsonVariable=items`，结果写入`total`。
3. 「限次循环」使用次数变量`total`，序号输出选择`index`（从1开始）。
4. 循环体先计算`key = text(index)`，再「读取JSON子结构」使用`jsonVariable=items`、`keyVariable=key`，结果写入`item`，之后编排业务积木。

`item`为JSON编码文本；字符串需要「解码JSON字符串」，数值可按类型计算转换。不要在遍历中无意修改来源列表长度。对象可先用「获取对象键列表」得到JSON键数组，再按相同方式遍历键并读取原对象；不开放无界集合或任意Lua迭代。

## 跳转、调用与函数库

标记和跳转只能位于当前插件根层级；调用插件支持类型化参数、返回参数及成功/失败子区。调用编辑统一走真实参数表，即使原调用参数为空，切换目标后也能填写目标参数；不会把只有目标选择的紧凑页当完整调用配置。

跳转页等待毫秒只接受整数，变量类型按参数/局部/全局真实优先级解析；不能因同名全局整数而误选被浮点参数遮蔽的变量。

函数库继续来自生成积木目录，列表仅显示名称和详情/加入，小行高、分类紧凑。变量、集合、循环、插件调用参数与返回分别分节。确认/布局/关闭对话框归调试，控件操作归界面。`Screen.loadImage`的参考明确对应图片加载，不再关联找图；API文档仍只读，四种旧工程兼容积木不作为无用页面删除。
