# Studio 调试、提示与日志

2026-10-14，第六阶段开发收口。按用户决定，设备测试和安装统一后置，独立 Runner、下载器及 provider 验收不在本批范围内。

## 入口归属

- 右侧调试提供运行提示、短时弹出提示、脚本日志输出、添加说明、确认/布局/关闭对话框及弹窗样式。对话框继续按用户已确认的 ADR0066 归调试，不因简化导航移走。
- 启动延迟、提示总开关、自动提示类别和随机策略仍在项目设置；调试不重复展示运行环境或权限设置。
- 弹窗样式的预览固定在顶部，输入区单独滚动。宽高、坐标、字号和圆角为设备像素；时长为毫秒。X/Y=-1 分轴居中，0为屏幕原点，预览缩小不改变保存数据。
- 背景与文字仍用 #AARRGGBB，新增 0/25/50/75/100% 不透明度快捷设置，只改 Alpha，不改 RGB；不完整颜色不能用快捷键静默修复。
- 修改已有提示积木复用调试的完整窗口，包括全屏和未保存确认。系统返回、点外部、标题关闭与底部关闭都经过同一个草稿关闭判断。修改日志记录开关不会清掉尚未保存的样式文本。
- 固定文字/变量日志支持信息、警告、错误级别；修改会保留所选级别。动态表达式的 console 通道沿用已有 info 契约，不新增字段或冒充可设置严重度。

## 输出与执行显示

运行提示面向脚本使用者；Log 输出是脚本主动写入的调试记录；连接/Root/运行状态属于诊断。三者不能相互代替，不自动把提示文本、变量值、识别文字或积木源码写入诊断。

“添加说明”不执行，也不禁用其他积木；禁用本行/子树仍使用编辑窗的“注释执行”。显示别名与参数摘要继续属于积木显示配置，不能混入执行参数；动态提示文本通过已有字符表达式和声明变量明确配置。

运行高亮沿用独立执行位置事件与有界最近节点队列，不读取日志记录开关。暂停保留下一步位置，终止及会话切换清除旧显示；不为了显示动态提示节点延迟脚本。

## 日志查看

- 日志仍是独立弹窗，固定右上角全屏/还原，保留历史运行、统计、记录设置、对比、截图总览和导出入口。
- 实时日志按不可变快照筛选，避免可变列表的缓存键导致新增记录不刷新。支持全部/脚本输出/运行诊断/其他，按已有通道前缀分类；未知旧格式保留在其他，不根据消息正文猜通道。
- “仅错误”识别真实脚本 ERROR 级别，信息级消息中的 ERROR 字样不改变级别；同时保留既有结构化失败筛选。
- 列表最多显示两行摘要，点击打开原文详情；详情可全屏、滚动、选择和有界复制。摘要省略不修改原始记录、筛选结果或导出内容。
- 历史脚本输出、运行诊断、追踪/指标继续分文件。清理仍需明确确认，只清理当前项目可删除记录，运行中/待写完/未知结构保留，不删除项目资源。
- 日志记录设置仍为独立紧凑小窗，只保存追踪和识图统计，保留最新提示/延迟/样式设置。导出保持本地文件选择，不上传；内容可能包含脚本主动输出的私密信息。
- 记录设置保存不立即关闭小窗，忙状态不移除窗口或草稿；以最新项目里的两个实际开关确认“已保存”。失败仍保留输入可重试，关闭只比较当前已保存开关，已经提交的保存不因关闭而撤销。

## 提示生命周期

主动停止、失败、重启和销毁清除提示窗口、操作对话框、计时器及失效显示票据。失败终止现在明确清理短时提示，不再沿用正常结束的到期保留。正常结束只关闭持续提示，最后一条短时提示仍可显示到到期。既有会话票据拒绝旧运行的显示、关闭与到期回调，不允许迟到提示重开。
