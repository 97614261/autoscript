# 运行期界面、帧资源与脚本控制

## 界面

函数库的界面命令提供背景图片、容器组和窗口位置配置。背景只选择项目已声明的图片，空字符清除；用于显示的解码缓存有预算，不修改原图片。容器组操作包含嵌套子控件，不影响组外控件；重置值先校验全部默认值，不重置运行期样式。

主窗与脚本界面浮球使用设备像素位置；超出可用屏幕的窗口会限制在可见范围内。隐藏时设置位置不会自动显示窗口。这里的浮球是脚本界面的最小化入口，不是运行服务的暂停/停止球。

## 帧与连续截图

先声明图像变量接收截图，裁剪使用源帧原像素半开矩形：包含左上、不包含右下。源与输出使用不同图像变量，裁剪失败不会替换源帧。

连续截图输出字符变量中的 JSON，包含 frames、timestampNanos、droppedFrames、partial。最多120帧、60秒、120FPS；实际请求仍受帧池预算限制，不能保证所有配置都可采集。使用“读取系列帧”把指定序号的句柄借用到图像变量，再用于识别或裁剪。

读取系列帧不复制图片。不要对借用句柄先单独释放，再释放同一系列；裁剪产生的新帧则需独立释放。系列释放后输出字符清空，曾借用的图像变量不再可使用。任务结束/失败/停止仍会清理任务持有的资源。句柄不可持久化或跨任务传递，不等于保存图片文件。

## 控制

- 停止脚本：停止整个本次运行及子任务，清理待显示提示和持有资源，后续语句不再执行。
- 脚本日志开关：只影响后续脚本日志，不删除已有输出，也不关闭运行诊断或识图统计。
- 脚本提示开关：关闭时清理已有提示，开启不重放旧提示，不绕过项目提示总开关。

上述状态不写回项目。重新运行脚本使用本次冻结脚本和已确认界面初值，先停止与认证清理，再创建新VM；每次外部启动最多10次，主动停止、Root失效或会话变化撤销重启，不中途弹回编辑器。每段运行日志独立，前段标记restarted。

原像素PNG保存、图片变换和结构化字库识别已接通对应固定契约，不自动截图或缩放源帧；PNG仅保存项目私有data。

## 脚本录制与回放

函数库的脚本录制接收1000–60000ms时长及128–512事件预算，结果写入声明的字符变量。到期正常完成，只返回完整动作；停止、取消或异常不返回半成结果。录制期间禁止其他脚本触摸和设备键，等待不占用Root工作线程。

回放读取字符变量中的完整录制JSON，先校验全部动作和当前屏幕尺寸、方向，再使用原像素坐标执行。无效数据不会产生输入动作。屏幕变化拒绝继续；内部等待、长按和拖动不套用项目随机化。录制不是录屏，不采集音频或麦克风。

## 音频

提供播放、停止、读取和设置音乐流音量四种积木。播放页可导入wav/mp3/ogg/flac/m4a到本项目私有data/audio；单文件最多20MiB，二进制运行数据共用64MiB预算，单播放器最长播放60秒。文件头校验不代表解码一定成功，设备解码失败会明确返回错误。

音频运行数据不随项目备份或独立Runner包复制，换设备须重新导入。音量为0–100的音乐流相对值，不自动调大，也不在停止后自动恢复；仅用户显式的设置积木改变系统音乐音量。结束、失败、主动停止及重启都会释放播放器。
