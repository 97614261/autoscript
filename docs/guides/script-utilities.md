# 脚本基础工具

入口：可视化编辑器 → 函数库 →「计算」或「系统」。每个工具先配置参数和结果变量，再加入积木；修改使用同一紧凑面板。

项目设置 → 脚本能力：数值工具声明core.math（数值与随机工具），屏幕尺寸声明device.display（设备显示尺寸），时间读取声明core.task（任务与提示）。不会自动授予Android权限或静默修改项目声明。

## 配置与执行规则

- 数值参数可选择固定值或来源变量；整数参数只接受已声明整数变量，浮点参数接受整数或浮点来源。输出严格选择声明的整/浮/字变量，不静默把浮点截断到整数。维护变量入口可直接打开原变量管理页。
- 普通数值输入范围±1,000,000,000,000，必须有限；随机整数范围±9,007,199,254,740,991，两端包含。随机源是会话内非密码学PRNG，不能生成密钥、Token或其他安全凭据。
- 随机字符串长度1～1024；模式1小写、2大写、3大小写、4大小写加数字、5小写加数字。每个字符采用有界无偏采样。
- 四舍五入的半值远离零，3.5→4、-3.5→-4。限制范围和范围判断要求下限不大于上限；范围判断端点包含，结果为1/0。
- 角度按屏幕Y向下计算：向右0°、向下90°。两点相同没有方向，明确报错；翻转模式1上下、2左右。轮盘坐标返回浮点数，不自动点击，也不自动换坐标系；半径0～1,000,000,000。
- RGB输入限0xRRGGBB整数（0～16777215）；各通道返回0～255。颜色合成仍用既有RGB合成积木，不加入重复功能。
- 屏幕尺寸来自既有宿主显示快照，两个输出变量必须不同。设计画布尺寸与设备屏幕尺寸不是同一回事。
- 单调时间适合计算耗时，Unix时间是墙钟毫秒，只用于日期基准/时间戳；不要用Unix时间控制超时、性能或循环截止。读取不改变系统时间。
- 未保存参数关闭会要求确认；不会因打开配置、切分类或关闭窗口执行函数。工具结果与参数参与保存、撤销、备份和受限源码往返。
- 调用失败显示固定错误类别，不把非法数值、缺变量或取消伪装为结果0。

## 本批边界

当前新增的是基础工具和三项系统读取入口。日期格式/日期运算、文本/中文输入、剪贴板、App操作、文件增强、扩展界面、更多图像与运行控制仍按[执行计划](../reference/function-library-development-plan.md)继续，不把这一批称为老版函数库全部对齐。

全部工具有真实运行实现和编译器检查；测试中已冻结16个积木并通过真实RuntimeExecutor执行。构建/单元测试不是界面触摸、键盘和真实设备效果全部验收。

# 文本、JSON与日期扩展

Text 的位置与长度按 Unicode 字符而不是 UTF-8 字节，位置从1开始；未找到为0。
基础输入/输出最多64KiB，拆分结果最多1024项。拆分/拼接使用JSON字符数组，拒绝自动把数字转成字符。
取左/右/中间、插入、删除、替换、取标记前后、去空白、大小写、查找、次数均提供独立积木。
重复文本的API为 Text.repeatText，避免Lua保留字repeat。

正则为受限有限自动机实现：输入4096字节，模式128字节，编译上限1MiB，
全部提取最多64个完整匹配，不支持反向引用或环视；超过预算报错，不隐式截断。
单个匹配与判断没有“64匹配”的限制，全部提取才有结果个数上限。
使用固定regex 1.12.3，MIT/Apache2双许可证，最低Rust1.65；
纯Rust，不引入额外Android系统API；不以未测量数字声称安装包增量。

Data.valid/type/has/getJson分别检查合法性、读取类型、键存在性及读取JSON子结构。
has能区别缺失与null，getJson允许对象/数组，旧Data.get仍只读取标量。
大小、深度16、总项数1024的限制保持一致。

Date.format使用Unix毫秒和明确的固定时区偏移（UTC0、北京时间480），格式为date/time/datetime。
Date.addDays每一天精确86400000毫秒，不模拟本地夏令时；
Date.daysBetween返回有符号浮点天数。日期不改变系统时间，不用于运行超时。

## 私有数据文件

Files.append、exists/isDir、mkdir、copy/move、rmdir和行读写均限制在当前项目私有data目录。
复制和改名不覆盖目标，rmdir仅删除空目录，不提供递归删除。
行号从1起；兼容LF/CRLF，空文件0行，末尾换行不另计一行；写行统一LF并保留可表示的空行。
追加/行修改保持单文件64KiB、总512KiB/256项限制；保存原子提交，取消或过期上下文不会覆盖正式数据。

Files.kvSet/Get/Remove/Keys/Add用JSON对象文件维护持久键值，get返回JSON文本，
字符串可再用Data.text解码；缺失get为null，keys按键排序。
kvAdd缺失按0，已有值必须64位整数，累加溢出拒绝，不将小数截断。
不开放任意存储、源码/图片目录、私有回收目录或项目身份参数。

## 运行期列表

界面操作积木支持追加、插入、修改、删除和清空选项。插入/修改分别填写索引和文字，
单选索引从1起，0仅用于取消非必选项；多选索引用JSON整数数组，例如[1,3]。
索引与选项文字值分开，修改所选项的文字保留选择；删除后按必选规则处理。
选项最多64项，文字1～128字符、不得包含控制字符或重复；必选控件不能清空。
读取选项数量/索引和普通读取页面参数都读取更新后的运行状态，不改设计稿、不触发插件事件。

## 输入提示、范围与步长

界面操作支持hint占位提示，minimum/maximum整数范围边界，以及滑块step步长；
get:hint/minimum/maximum/step可读回当前值。range一次设置上下界（滑块可同时填步长）。
运行修改不改变设计稿，隐藏/跨页仍保留。
修改前当前值必须在新范围内；滑块跨度须被步长整除且当前值对齐，最多一百万档。
不自动截断或取整。先设置合法值，再修改范围，或使用一次设置范围。

## 保存与恢复页面参数

在“界面操作”选择整个窗口：

1. 导出页面参数（get:config），结果接已声明的字符变量config。
2. 用“写数据文件”把config写入settings/ui.json，项目需另启用storage.data。
3. 用“读取数据文件”把该文件读到config。
4. 恢复页面参数（restoreConfig），值来源选择config。

快照仅包含可输入控件，不含密码、静态标签、布局或事件；密码保持当前运行值。
最多8192 UTF-8字节，超出拒绝，不保存不完整配置。
控件ID/类型/必选、选项、范围和步长不同则拒绝；仅修改颜色、标题或位置仍可恢复。
所有值全部校验成功才应用，不触发插件事件、不改变窗口显隐、不启动脚本。
导出本身不写文件，恢复本身不读任意路径，不隐式申请存储。
