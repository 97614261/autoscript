# 单步与运行行高亮（2026-10-12）

决策见 [ADR 0082](../adr/0082-selected-node-test-and-live-position.md)。

## 行为

- 空闲时底部单步测试选中节点及其子树，不执行前置或后置兄弟节点。变量/界面使用初始默认配置；外层上下文依赖不自动补造。
- 暂停中的单步仍推进当前暂停会话，继续仍退出步进模式。
- 普通运行高亮独立使用真实插件/节点身份，和手动编辑选择分离；显示“执行中”，暂停检查点显示“下一步”。只展开目标祖先，不展开无关折叠；目标不在可见范围时直接滚动。
- 执行位置不依赖日志/提示开关，不读取变量或源码。服务最多20Hz单槽合并，客户端主线程消息也只保留一个待投递槽；旧代次、已结束运行和暂停状态拒绝运行位置回调。
- 保留既有运行时隐藏编辑窗的行为；高亮不主动重新展开窗口，不影响脚本操作目标App。

## 产物与兼容

完整原项目先校验，再从结构化节点生成独立测试流程。正式插件和 generated 不改变，测试写入 generated-node-test；原清单、全部正式插件摘要及目标身份在启动前复核。运行协议升级23，Studio和内嵌Runner一起重建，旧Runner明确拒绝版本不兼容。

## 回归覆盖

- Rust真实运行：选中日志仅输出本行，前后行不执行；循环保留子树，叶节点可独立提取；单独跳出外层循环被拒绝；父级注释阻止子节点测试。
- 测试编译不覆盖正式源码/生成物；不存在的节点拒绝。
- 运行位置在关闭追踪/识图统计时仍可读取，保留Unicode插件身份，最新覆盖旧节点；停止后不可读取。
- Android测试：测试产物摘要及目标检查、原清单/插件变化拒绝启动；客户端拒绝旧运行、旧服务代次、暂停/停止/断开消息。

验证口径为本地单元测试、Clippy、Lint、Debug构建与MuMu更新安装；未进行设备点击或脚本实测。快速节点可被合并，不保证屏幕逐行绘制，也未进行性能基准。
