# 函数库数据与运行期列表补强

本次范围不是五批全部完成。基础工具上一批不重复计数；
新增文本25、JSON4、日期3、私有文件17，共49个API和49种积木。
累计127个API、138种积木，数量不作为产品完成百分比。
运行期界面通过原有UI.command提供10项列表写入/读取命令。

## 接通内容

- 新积木均有类型化配置，固定值/声明变量来源，严格字符/整数/浮点结果。
- 新的契约、函数说明、受限源码往返、能力声明、保存、编译与运行同时接通。
- 文本索引按Unicode字符从1起；JSON子结构不改变旧Data.get标量语义。
- 日期为真实Unix毫秒、明确固定时区；每一天精确24小时，不模拟夏令时。
- 私有文件追加、行读写、存在判断、目录、复制改名和持久KV均真实操作；
  目标不覆盖、目录仅删除空目录、配额与取消保护继续生效。
- 列表按选项值和索引区分：增删改/清空、单选/多选索引；
  更新隐藏页面状态，不写设计稿、不触发插件事件。
- 列表后普通读取页面参数转宿主读取，避免只读引擎初始缓存；
  确认中的事件快照保持原有语义。
- JSON解析前限制嵌套，拒绝无效Unicode选项；
  未通过验证的操作不得部分修改状态。

## 依赖

regex固定1.12.3，regex-automata0.4.14、regex-syntax0.8.10由锁文件固定；
MIT/Apache2，纯Rust，最低Rust1.65，不新增Android系统API要求。
有限自动机、不支持环视/反向引用，输入4KiB、模式128字节、编译1MiB、
最多64完整结果，超预算明确失败。依赖说明见[官方文档](https://docs.rs/regex/1.12.3/regex/)。
