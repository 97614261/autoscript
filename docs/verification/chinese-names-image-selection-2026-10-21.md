# 中文命名、空插件及图像选区完善

日期：2026-10-21。范围见[ADR0138](../adr/0138-chinese-names-and-image-selection.md)。
本批开发和主机检查与设备验收分开记录；不扩大默认OCR模型、Root授权或输入安全边界。

## 本批实现

| 项目 | 实现及边界 |
| --- | --- |
| 中文命名 | 变量、插件参数和跳转标签接受汉字、ASCII字母、下划线及后续数字，最多64字符。变量计算、引用改名、界面绑定及运行变量读取同步支持；生成ID、控件ID、API名和协议身份不变。 |
| 安全编译 | UTF-8表达式扫描仍输出带引号的类型化表键；中文跳转标签编码为ASCII Lua标签，不执行用户源码或创建隐藏变量。64汉字的运行快照预算为192个UTF-8字节。 |
| 空插件 | 新建主插件和普通插件保存空JSONL。首次加入、撤销回空、复制和备份恢复均支持；旧工程已有noop不删除。 |
| 矩形选区 | 内部拖动整体移动，手柄优先调整边缘；保持原像素宽高、限制在图像内，取消和双指手势不提交半次修改。 |
| 多边形 | 3–128个不同顶点，点加、拖顶点、删点、撤销/重做、双指缩放及移动图片。保留区外透明或忽略区内，保留选区可另裁外接框；不将搜索/OCR的矩形ROI变成多边形搜索。 |
| 处理一致性 | 既有v1蒙版增加polygon笔画，Kotlin和Rust以像素中心、奇偶规则填充；保留字节、点数、像素、工作量及取消预算。蒙版加裁剪作为一次处理历史，可另存及加入显式处理积木。 |
| 窄横屏 | 画布裁在自己的视口；工具条可横滚，返回/完成固定可达。工作台顶部有界滚动，底部仅说明滚动，操作行固定并可横滚。 |
| Root诊断 | 我的/运行环境始终显示Root与截图诊断入口；截图失败按请求传递固定细码，不依赖全局last-error或输出原始进程内容。清理失败继续禁输入，作废旧连接后走既有有界重连，不重放失败操作。 |
| 单步提示 | 选中积木单步不额外自动显示插件开始/返回提示；显式提示积木及正式运行的项目提示设置保留。App诊断与脚本提示继续分通道。 |
