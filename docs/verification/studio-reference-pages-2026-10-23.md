# Studio 页面参考复刻

日期：2026-10-23。设计边界见 [ADR0145](../adr/0145-studio-reference-page-design.md)。

## 实现范围

- 项目页：浅紫背景、原生绘制文件夹装饰、数量、四个真实工具入口、搜索及排序；项目卡片常规四列两行，窄屏/大字体按内容预算降至两列或一列。保留默认展开首项目、同时只展开一个、完整 ID 查看/复制、单独编辑恢复权限和删除确认。
- 我的页：原 Logo、实际包版本、三个分区、六个真实入口及实际运行摘要；短视口压紧留白，内容仍可滚动，不加账号/云功能。
- 底部导航：三个既有目的地、浅紫胶囊选中态、圆角白底；按文字内容增长，不固定高度裁字。
- 启动：Android 原生起始背景，API31+遵循系统 Splash；首个真实内容布局后做约320ms退出光效，不阻塞点击、不等待 Root、不加最低加载时长。渐变线是装饰，不是虚构的加载百分比；原 Logo 未变形或重画。
- UI 热路径：日期字符串按时间戳及当前 Locale 记忆，不在每次运行状态重组时重复创建日期格式器；列表装饰静态绘制，不增加持续动画时钟。

## 仍可评估的性能方向

当前不是“没有优化空间”。区域截图读回/传输、采集传输流水线仍未实现，须先定义显式区域来源、坐标代次、认证片段及完整帧发布，不改变现有全屏 capture 的语义。已有同帧批量模板准备不重复计作新优化。长时间 PSS 增长归因及 OCR 歧义评估另行记账；本次页面改版没有宣称识图提速。
