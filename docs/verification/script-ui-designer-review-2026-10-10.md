# 右侧界面设计器审查与修复

用户所指为编辑器右侧「界面」进入的设计器，不仅是运行悬浮窗。本轮不运行私人脚本、不安装、不执行设备测试。

## 源码核对

后续1–5：操作按控件类型筛选，显式选择控件/属性时带出设计默认值；布尔与选项直接选择，颜色用色板，固定值与变量来源分开，位置尺寸给范围。画布增加框选、中心参考线、取得焦点后的方向键1px/Shift8px。局部属性预校验与保存层引用异常携带控件身份，提供定位。ADR0061独立恢复记录、确认/上下文复核、会话票据和原子提交；新增几何、操作默认值及恢复边界回归。

控件库存仍为14类。开关、密码/小数专用输入、数字步进、多选列表、日期时间、文件选择、独立颜色选择等不是现有运行控件；属性色板不是脚本颜色控件。没有占位加入或把标签模拟算作新控件。WebView、图表、树、音视频等复杂控件也不在首版现有能力中。

- 14类控件：单行、多行、整数、复选、单选、下拉、列表、滑块、进度、标签、按钮、图片、容器、分页导航。
- 页面：新建、选择、空页删除、尺寸、背景、说明；最多16页、256控件。新控件40设计像素高，按三列寻找空位，满页拒绝，不自动拉长画布。
- 编辑：多选、复制、删除、拖动、缩放、网格吸附、六向定位/对齐、等距、图层、换页/容器、紧凑排版、整体缩小、100步撤销重做。
- 属性：标题、默认值、范围、选项、位置尺寸、可见/可用/必填、字体与文字对齐、颜色、边框、圆角。
- 交互：从声明变量/入口参数选择绑定；点击、长按、变化、选择动作；运行、关闭/停止、最小化、切页和插件调用。保存核查引用与类型，不以任意动作配置保证每类控件都会产生该事件。
- 保存/预览：共享模型和View渲染器；过期版本拒绝覆盖，预览不执行脚本。
