## 本批完成

- Python 3.9+ 标准库服务，固定仅监听 `127.0.0.1`，私有 Token、SSH 隧道、非 root systemd 单元和 Nginx 持久下载映射。
- Windows `publish-apk.cmd`：冻结 APK 副本，实际验签并复核固定开发证书、包身份、版本、minSdk、ABI 和完整视觉库存；通过修订前置条件串行上传并读取确认，不自动重试。
- 服务端复核元数据、真实大小、SHA-256 和有界 ZIP 库存；本地验签与服务端校验分开，不宣称服务器独立验证了签名或二进制清单身份。
- 私有暂存、不可变 APK/校验文件先发布，清单最后原子替换；提交前回滚仅限本请求文件，提交后错误不得删除已引用资源。
- 拒绝降版、错误架构选项、未知文件、并发占用、超时、旧修订及超预算；同包重复提交不重复历史，不自动删除数据。
- 下载页实时复核清单；核对期间标记构建快照并禁用下载，失败清空旧候选并提供重试。静态 HTML 仍保留可核对快照。
- 文档更新显式支持持久下载目录，持有发布进程锁；需临时停止发布服务，不停止 Nginx。静态站回滚不回滚持久 APK。
- 合并本批重复加入的打包复制段、CI 步骤和说明段；增加最后一次读取跨越上传期限的回归测试。

## 尚未实际验收的边界

- 没有建立真实 SSH 上传隧道，也未验证实际服务器的 Python、密钥登录、systemd 或 Nginx 新映射。
- POSIX 文件锁、目录 fsync 和权限隔离未在本轮 Linux 设备执行；不能用 Windows 测试代替。
- 一次性服务器配置、Token 私密传递及本机配置仍由管理员执行；没有生成或持久化真实凭据。
- 公网下载、范围请求、缓存、HTTPS 和完整公网 SHA-256 须在部署后单独检查。私有 API 成功不等于公网下载可用。
- HTTP 合成 APK 用于事务与边界测试，不是已签名 App 或设备验收；真实 APK 验签通过也不代表新包设备回归通过。
- 同版本代码替换网站下载不触发 App 升级；自动更新需要递增 `versionCode`，仍由用户确认下载和系统安装。
- 超预算/未知文件/崩溃暂存必须保留现场并人工处理；本版无自动归档、自动删除、任意文件上传或公网管理入口。
