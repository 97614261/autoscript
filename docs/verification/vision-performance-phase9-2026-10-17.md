# Vision/runtime performance phase 9 · 2026-10-17

## 范围

第八阶段已经收口像素候选点门禁；本阶段转向运行时常用函数，确认前序文本、
JSON 和数学路径没有因为识图链路改动而回退。测试使用固定合成输入和 release
Rust，计时不包含 Lua 调度、JNI、Android、Root 截图、文件系统或设备输入。

## 执行

```text
cargo test -p runtime-executor --release -- benchmark_common_function_matrix --ignored --nocapture
```

固定输入每项 100 个热样本，10 个预热批次；表中是每次调用的批内摊销微秒：

| 场景 | P50 | P95 | P99 |
| --- | ---: | ---: | ---: |
| 64KiB ASCII 文本头部切片 | 2.637 | 3.072 | 3.634 |
| Unicode 文本头部切片 | 13.423 | 14.746 | 16.920 |
| 64KiB ASCII 文本尾部切片 | 18.887 | 20.335 | 30.209 |
| 4KiB 数字正则 | 27.850 | 35.380 | 46.145 |
| 512 项 JSON 读取 | 9.105 | 12.065 | 14.990 |
| 整数范围计算 | 0.0118 | 0.0130 | 0.0137 |

每个结果在计时前均经过正确性断言，测试结果为 1 passed、0 failed。与前序固定
矩阵相比，当前值处于同一量级；主机调度会影响尾分位，不把单次变化写成提速
或回退。

## 结论

- 第九阶段的运行时函数基线完成，未发现需要立即修改生产代码的稳定回退。
- 本阶段不改变 Lua/API 语义、变量类型、预算、取消、日志或识图算法。
- 像素候选游标仍按第八阶段结论拒绝合入；阶段 5 行偏移快路径和已验证的帧/截图
  所有权优化保持不变。
- MuMu 当前智构主界面处于前台，设备 QA 脚本未强停用户会话；因此本记录不宣称
  第九阶段完成 Android 端到端采样。设备测试需在用户保存并停止当前运行后再执行。

## 后续边界

真实设备端仍应使用同一 ABI、屏幕、ROI、模板和 provider 记录截图、传输、帧入池
和匹配分段；主机函数矩阵不能替代该验收，也不能据此承诺完整脚本低于 100ms。
