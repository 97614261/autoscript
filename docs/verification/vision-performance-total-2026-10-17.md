# 智构识图与运行性能阶段总报告 · 2026-10-17

## 总结

阶段 1–10 已完成代码、主机基准和 MuMu 合成验收。生产改动只保留有稳定正确性或
所有权收益的路径；没有把单次主机基准、局部 P50 或评估模型结果写成端到端承诺。

当前结论：

- 灰度找图、截图/传输/帧所有权、编辑运行链路和基础 UI/沙箱验收通过。
- 运行时常用函数没有发现稳定回退。
- 增量候选游标、直接字节锚点等不稳定候选均拒绝进入生产。
- 唯一明确的识别失败是等宽字体小写 `l/1` 混淆；生产模型没有替换。
- 真实手机 ARM64、Android 7/API24、所有输入法和完整系统生命周期仍不是本报告的已验收范围。

## 关键性能数据

### MuMu 视觉链路

- 灰度找图热样本：P50/P95/P99 = `0.094/0.267/0.375ms`，96x64 帧、8x8 模板。
- ONNX 大写字母：P50/P95/P99 = `169.910/178.530/178.530ms`。
- ONNX 数字：P50/P95/P99 = `85.973/89.950/89.950ms`。
- ONNX 混合字母数字：P50/P95/P99 = `76.558/86.912/86.912ms`。
- ONNX 小写等宽字母：10 次均无法实现完整精确匹配，`l` 被识别成 `1`。

这些数值是独立合成识别或匹配阶段，不包含完整脚本循环的所有 Lua/JNI/输入成本；
截图、桥接、帧入池、匹配分位也不能相加当作单次端到端百分位。

### 运行时函数主机矩阵

- 64KiB ASCII 头部切片：P50 `2.637us`
- Unicode 头部切片：P50 `13.423us`
- 64KiB ASCII 尾部切片：P50 `18.887us`
- 4KiB 数字正则：P50 `27.850us`
- 512 项 JSON：P50 `9.105us`
- 整数范围计算：P50 `0.0118us`

2. 所有真实输入法的遮挡、权限撤销、系统回收和横竖屏组合。
3. OCR 等宽字体 `l/1` 的模型或策略修复；当前仅允许评估，未授权替换生产模型。
4. OpenCV/ONNX 瘦身组件的正式按需下载与 Runner 分发；当前仅保留验证/组件能力，下载器仍延期。
5. 独立 Runner、账号/云、流程模板库等用户明确延期范围，不计 Studio 首版缺口。

## 放行口径

本报告不是“所有设备、所有模型、所有积木参数 100% 通过”的声明。当前可放行的是：
默认 full 配置下的 Studio 可视化编辑/运行、已验证 Root 设备链路、灰度找图和已有
安全边界。涉及小写等宽文本识别时，应在脚本中使用可区分字体/目标或显式处理失败，
不能假设 `l` 与 `1` 已经可靠区分。
