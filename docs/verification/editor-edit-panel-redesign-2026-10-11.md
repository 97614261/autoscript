# 编辑操作窗改版 · 2026-10-11

仅调整底部“编辑”及长按积木共用的操作窗，不改变脚本数据格式、运行入口或命令语义。初版曾使用分组；按用户最新要求，现已取消全部操作分组，以下为当前布局。

- 标题统一“编辑积木”，上方仅保留已选/总行数、全选、清空和单行路径。
- 17个操作无分组直接平铺：参数、别名、复制、粘贴、撤销、重做、剪切、删除、添加说明、注释执行/恢复执行、以此为模板、上移、下移、减少缩进、增加缩进、本行源码、插件源码。
- 标题12sp、标题栏32dp起；选择状态10sp、路径9sp，减少上下留白，仅此编辑窗使用小标题，不全局缩小其他弹窗。
- 去掉按钮图标，居中文字10sp，按钮26dp起、间距3dp。约315dp可用宽度为5列4排，不必切换分组；参数强调色、删除警示色及禁用状态保留。窄窗/大字体减少列数，有界操作区滚动，保留中部列表。
- 移除重复底部关闭栏，仍由右上角关闭及返回关闭。选择自动定位、256项上限、父子注释规则、删除确认与原命令回调保留。
- 提取独立EditorEditToolbar组件，移除无调用的旧图标上下堆叠按钮组件。

初版验证：`build.cmd -Verify`成功（2m22s），Studio及共享模块单元测试、Lint、Debug构建成功；MuMu 0更新安装成功，保留应用数据。此结果对应被替换的分组版，不冒充本次无分组版验证。

本次测试改为覆盖17个工具在2至6列中无遗漏、原顺序保留、说明/注释名称区分，以及窄窗/大字体列数；测试包含常见360dp屏幕弹窗内约315dp可用宽度。

无分组版验证：`build.cmd -Verify`成功（2m15s），Studio及共享模块单元测试、Lint、Debug构建通过；目录与文档检查通过（121个本地链接），MuMu 0更新安装成功，原应用数据保留。

## 全屏与记录设置后续修改

- 编辑操作窗和运行日志共用固定右上角全屏/还原图标，关闭图标独立，不参与其他操作的横向滚动。编辑窗全屏不再受430dp内容高度限制；保持选择、草稿和列表状态。
- 日志标题改为紧凑小字号，对比、截图总览/详情和导出移到内容工具条，移除重复关闭底栏，日志数据、导出、清理保护规则不变。
- 记录设置从通用调试大面板拆为独立紧凑小窗，区分可选追踪/统计与自动脚本输出/诊断，显式保存及未保存关闭确认保留。保存仅合并两个日志字段，其他最新项目配置不回退。
- 新增固定标题操作宽度回归与2项日志草稿测试。

## 其他弹窗全屏选择

按内容空间补充，不给每个小窗机械加按钮：

- 插件源码、本行源码：扩大文本区，预览/参考列表同步放宽；仍按实际可用高度约束，键盘和横屏不强制保留旧最小高度。
- 查找替换、变量管理、变量检查/运行变量：扩大结果或数据区域，搜索与当前选择保留。
- 函数库/文档及函数详情、插件文件列表：扩展列表和说明空间，不改搜索、分组、声明或插入语义。
- 图像配置、已保存图片识别测试、OCR配置测试：扩展表单/原图预览，放大不启动识别、不取消既有任务；关闭仍使用原取消流程。
- 日志同条件对比、调试主窗及运行提示筛选配置：长内容可全屏；日志对比数据不因切换重新读取。
- 界面设计器和图片库已经全页；确认、改名、变量声明编辑、加入位置、短选择、运行延迟及日志记录设置保留小窗。

新增视口高度回归：全屏取消旧文本区高度上限，但可用空间变小时不超出键盘后边界。
