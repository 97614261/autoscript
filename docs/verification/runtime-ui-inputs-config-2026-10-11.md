# 运行期输入属性与页面参数配置

本批继续函数库第三批，不代表五批全部完成。

## 已接通

- 界面操作新增占位提示、整数上下界、滑块步长及对应读回。
- 一次设置范围同时应用上下界/步长；当前值越界、不对齐或跨度无效时拒绝，
  不截断或取整，不修改正式设计稿；旧表单输入也保留正确范围语义。
- 隐藏及跨页保留运行属性；实际View使用新范围和步长生成滑块档位。
- 整个窗口可导出输入参数JSON到字符变量、从字符变量恢复；
  文件持久保存/读取复用既有私有Files，需单独storage.data能力。
- 最多8192字节，结构摘要核对控件ID/类型/必选、选项、范围及步长；
  恢复所有值先校验再一次应用，不触发插件事件或改变显隐。
- 密码不导出、不恢复；布局、事件和非输入控件不属于参数快照。
- 恢复后的普通页面参数读取转宿主获取当前值，不读旧缓存；既有事件快照语义保留。
- 可视化参数入口、字段适用范围、函数库说明、编译和受限源码契约同步接通。
