# 调试面板重新分组

按用户决定，环境归属设置。项目设置已有「软件权限 / Root 环境」真实入口，继续复用 SoftwarePermissions，不添加另一套固定状态页。

## 本次实现

- 调试主面板使用公共有界窗口、独立关闭按钮、横向等宽四页导航，移除占宽的左侧栏和「开发环境」入口。
- 输出积木：运行提示、短时弹窗、开发日志、注释；保留文字、变量及受限表达式配置。加入输出不保存调试配置。
- 提示行为：唯一提示总开关、自动提示分类及变量筛选。
- 提示外观：保留现有像素尺寸、坐标、字号、圆角、时长、文字对齐、颜色和默认样式。
- 运行诊断：运行延迟、积木追踪、识图耗时统计。日志仍走编辑器底部独立入口；暂停、停止不混入此配置页面。
- 配置页底部明确为「保存配置」。关闭未加入输出或未保存配置前确认，外部关闭和标题栏关闭共用保护。

## 边界

不修改持久化字段、输出协议、运行后端及日志隐私规则。不自动申请权限、不启动脚本，不添加未接通的断点或后端切换开关。

实际位置预览、短时试显、变量回填窗口整体改版尚不在本次实现范围；现有样式预览仍是居中样式示意，不是 X/Y 位置模拟。

验证结果以本次任务最终报告为准；不将编译成功作为设备端视觉验收。
