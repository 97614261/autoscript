# 插件选择与维护页收口 · 2026-10-20

## 问题与改动

- 旧选择底栏强制 40dp，却同时显示图标和标签，导致底部文字裁切；改为 28dp 最小高度的同行小按钮，整项自然换行。列表使用 38dp 最小行高和较小图标，字号增大允许内容增高。
- 复用共享小标题面板、固定关闭和全屏/还原；搜索和排序就近展示，新建插件、新建分组、管理、刷新直接可用。普通窗口按首次内容预算确定高度，不随选择/筛选跳动。
- 单击文件打开，勾选/长按管理；底栏明确打开所选插件和插入调用，不再使用容易混淆的“选择”按钮。插入调用复用原宿主命令，不增加执行入口或自动运行。
- 多选、全选可见、取消选择按真实文件/分组身份处理，筛选不会清除隐藏选择；批量操作使用完整选择，移出分组只提交确实属于分组的文件。
- 主插件删除置灰，切换主插件增加确认；删除保持确认和 Store 引用保护，解散分组不删除成员。删/设入口确认均冻结目标身份并在提交前复核。
- 新建插件和分组分开；加入分组能选择已有分组或输入新名称，不再只显示前四项。改名/另存目标冻结，不随当前选择变化；错误显示在输入窗内，同名改名为无操作，改名/另存后保留有效选择。
- 新 UI 辅助控件和纯选择/命名策略按职责拆出，移除原固定高度图标底栏及旧命名布局。不改项目数据/Flow/API/Rust 格式，不实现延期模板库。
