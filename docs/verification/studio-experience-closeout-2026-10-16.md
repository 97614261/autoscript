# Studio 首版六项体验收尾验收

2026-10-16。前五项开发及同包MuMu回归完成；第六项已生成arm64候选，真机及Android 7实际验收仍缺设备。范围为首页互动空间、真实执行高亮、公共页面密度、异常清理、同包MuMu回归及手机候选交付。遵循[ADR0117](../adr/0117-studio-first-release-experience-closeout.md)，不增加Runner、下载器或云功能，不改变项目和Logo几何。

## 代码变化

1. 首页主题由导航宿主保存，切页返回保留，Activity恢复使用可保存主题名。小竖屏、大字体及横向短视口按实际内容分配区域；三行演示和有界滚动避免操作被裁掉，垂直背景手势交给滚动。明确小字行高和完整标题内边距预算，防止主题栏挤入演示区。动画时钟仅影响绘制和演示子区；生命周期、动画比例及省电限制继续生效。
2. 真实积木沿用原项目、插件、节点及运行代次校验，执行中为紫色、刚经过为灰蓝色、暂停下一步为暖色；仅执行入场有220ms有限强调，不给脚本添加延时。选择与执行身份保持独立，不复用首页演示时间线。
3. 公共面板和确认框使用实际Compose字体比例，原生窗口根显式保留调用方Density，不在新窗口重置字体。空列表及搜索无结果共享紧凑布局、内容高度和真实操作；保留禁用状态与危险操作确认。我的页移除“连接 已连接”重复措辞。
4. 会话所属观察窗重复注册不关闭当前窗口，迟到注销不重复释放；子窗口按对象身份管理。显示失败准确返回失败，窗口配置异常进入原有故障回调，同会话只报告一次。清理先撤销所有权，允许关闭回调重入而不重复关闭。未自动撤销系统权限、清用户草稿或杀系统进程。

## 本轮发现和修复

- 首次抽取空状态组件时访问文件私有样式，编译拒绝；改为直接复用共享配色/图标。高亮接线测试仍匹配旧内联文案，改为验证实际映射接线，并增加独立状态映射及真实行控件回归。

## 手机与交付边界

当前连接仅MuMu 0/API32；`emulator-5554`为同一模拟器的ADB别名，不是独立真机。ARM真机及API24/25未连接，不能用arm64构建或MuMu结果代替实际验收。

手机候选使用`build-mobile.cmd -Verify`隔离输出，仍为Debug签名；正式签名、上架及安装到未指定设备不在本次自动操作范围。真机仍需确认悬浮授权、Root就绪、截图/输入、编辑器与运行状态、键盘和方向适配；API24/25还需复核旧窗口类型及对应软键盘/系统栏分支。

已有OCR字母数字歧义、其他输入法/ROM、全积木参数组合和系统强制回收矩阵保留原边界。生产模型、默认full及运行语义没有替换。
