# 调试入口职责分离

用户确认运行提示保留在右侧调试，其他项目级配置迁往对应入口。

| 功能 | 入口 |
| --- | --- |
| 加入运行提示、短时弹窗、日志输出、既有注释快捷操作 | 右侧调试 |
| 提示总开关、自动提示分类与变量筛选 | 项目设置 → 提示设置 |
| 像素样式 | 右侧调试 → 弹窗样式 |
| 启动前延迟 | 右侧调试 → 运行设置 |
| 积木执行追踪、识图统计 | 底部日志 → 记录设置 |
| 系统权限、Root、输入能力 | 设置 → 软件权限 / Root 环境 |

保留原 project.json.debugSettings 字段与协议，不迁移或删除用户配置。设置保存使用既有期望版本复核；冲突不覆盖。日志记录设置复用宿主保存回调，运行中不可修改编辑设置时不显示入口。新的设置页与旧输出页复用配置控件，避免复制两套逻辑。

当前日志开关影响后续运行，不重写历史记录；关闭提示不会关闭独立诊断日志。样式仍为示意预览，未添加位置模拟或试显。安装不卸载、不清数据。验证结果以任务最终报告为准。
