# MuMu 截图与找图设备验收记录

本轮按用户“你帮我测吧”执行实际设备测试，不修改生产代码、不运行私人项目。Windows Computer Use 的 Node 助手两次启动失败，因此通过 Android ADB、UIAutomator、实际屏幕截图和运行文件日志验证。

## 环境与隔离

- MuMu 0，ADB `127.0.0.1:16384`，x86_64，Android API 32，720×1280，设备报告 HUAWEI DCO-AL00。
- 测试现有安装版本 0.1.0，设备报告最后更新时间 2026-10-10 10:53:07；本轮没有重新安装或构建。
- 新建独立可视化项目 `QA_20261010`；通过 run-as 只向已核验名称和身份的该新项目装入测试清单、积木和本轮桌面截图裁剪模板。现有私人项目未运行、未改参数和源码。
- 脚本只有日志、持续提示、短时提示、有限循环、自动截图找图和等待，没有输入动作。模板保留 200×122 原像素；ROI 为 [149,407,546,879]，900‰，容差0，方向0，首结果，无成功点击。
- 实际采集后端为 root-surfacecontrol，传输为 authenticated-stream，匹配为 rust-rgba-first。
- 本地截图、XML、测试夹具、原始日志与汇总保存在忽略目录 `build/device-acceptance/`。QA 项目保留供复查。

## 实际通过项

1. 项目列表点击编辑直接显示编辑窗，不退到桌面；最小化只显示灵动环球，点球恢复同一编辑窗。主动返回桌面后编辑窗仍可操作。
2. 编辑器运行一次点击启动，不先显示配置界面；运行球点击展开暂停/继续和停止，没有相机入口混入。
3. 暂停后脚本日志连续两次读取均为48行，继续后重新增长；运行诊断真实记录运行中、已暂停、运行中。
4. 切到设置应用，识图返回0；回桌面后重新返回1，没有继续报告离开前的成功结果。
5. 编辑器运行主动停止后回编辑，持续提示和运行控制窗清理，无 Vision(Cancelled) 错误弹窗。两次停止诊断从 stop_requested 到已停止分别6ms与10ms；这是服务记录的状态间隔，不是鼠标点击到屏幕呈现的端到端延迟。
6. 项目列表启动先显示配置小窗，参数从 QA-A 改为 QA-A_B；点击底部运行执行，停止后恢复配置和修改过的参数。设计按钮 RUN 也一次点击执行，未要求重复点击。
7. 提示使用260×40px、X=0、Y=1000、字体18px，实际位置和尺寸符合配置。短时提示在3000ms后消失，持续提示在运行期间保留、停止/正常结束后消失。两类提示同时指定同一位置时，前3秒文本会重叠，本测试未将其判为取消或寿命失败。
8. 连续运行620380ms（10分20秒），600次截图和600次找到，失败、未找到、取消、丢弃、截断和引擎丢弃均0。正常结束恢复配置小窗与QA-A_B参数，Root仍认证。
9. 日志全屏/还原、截图总览、历史切换、刷新、对比入口正常。600次主指标一屏可见；UI百分位与停止后的原始日志计算一致。没有旧红色不可读取错误残留。
10. 对比页面对47与600样本明确提示少于100样本；未找到行没有相同结果的对照时跳过13行，不混入找到指标。点击复制报告未出现界面错误，但没有独立读取系统剪贴板核验内容。
11. 从日志实际导出，保存后回原日志窗；共享文件夹生成 `智构运行-8658d010.txt`，162358字节，元数据为本测试项目、ended、600次，与原日志一致。
