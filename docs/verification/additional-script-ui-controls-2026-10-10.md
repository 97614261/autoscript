# 新增脚本界面控件

## 已实现

开关 SWITCH、密码输入 PASSWORD 接通设计器新增/属性/画布、保存回显、共享传统 View、脚本值读写、初始化 Lua、Rust 发布校验与 schema。保留既有类型和枚举默认映射；不扩大资源预算，不引入依赖。密码画布显示掩码，Android 7 兼容分支不调用 API 26 的自动填充属性；掩码不代表加密。

## 第二批完成

小数DECIMAL/number与多选MULTISELECT/multiChoice接通设计器、正式保存、回显、共享View、脚本读写、变量/参数及事件绑定、独立Runner配置和发布摘要。总共18类真实控件。小数有限且不截断，仅绑定number；范围边界仍是整数格式。多选正式默认值为字符串数组，运行与STRING绑定为JSON文本，最多64项、2048字符。固定值支持勾选，不改变旧单选；非法、重复、未知和必填空选择明确拒绝。动态选项更新保留有效选择，必填无剩余项选首项。超预算回退原勾选并提示，不截断、不创建隐式数组变量。

普通读取API仍返回字符结果，不擅自改变旧API签名。数值初始化和事件保持number，多选事件保留逗号和引号。扩展类型仅v2，v1四种值类型不变；Runner小数摘要使用规范数值位模式，避免平台科学计数法格式不同。
