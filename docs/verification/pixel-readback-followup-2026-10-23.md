## 实现及等价边界

四角遍历用增量行列替换逐候选除法/余数，中心向外逻辑不改。模板的有效像素数、允许失配数、锚点相对字节偏移和排序孔位在一次搜索开始前准备，绑定当前不可变图像的行跨度；不加入跨帧缓存。RGBA/BGRA、透明、容差、原点、行padding、首命中、多个命中、预算余量及取消检查保持参考等价。

新增生产遍历对旧除法参考的五方向/单轴/步长/极限坐标测试，以及比较准备对原参考的预算及取消检查点测试。旧显式微基准的“IncrementalSearchPoints”副本实际上仍用除法，现已删除副本、直接调用生产SearchPoints；不以此前的误名分支证明本轮提速，不改写旧测量日志。

## 像素读回实验与取舍

独立QA只创建公开软件Bitmap，不截图、触摸、运行脚本或切输入法。三组为16K/32行、32K/64行、64K/128行；实际按宽度取整，所有字节先与原默认输出比较，再轮换配置顺序，10次预热后各100次。计时含getPixels/编码/计数sink，不含真实Root桥/Socket/系统采集；不能将软件Bitmap约2ms读回冒充真实截图中约13ms的getPixels。

初轮完整写出P95：竖屏2.541 / 2.457 / 2.407ms，横屏2.554 / 2.485 / 2.438ms。64K组仅减少约0.12–0.13ms，IntArray+ByteArray工作区从约120–124KiB增加到约510–512KiB。不能仅按微小合成收益改变生产默认，也不能据此排除真实Root软件位图上的收益；额外构建独立64K中间候选测真实桥，结果决定采用或恢复。参数不是用户脚本设置。

加入透明、几何变化及末块的最终软件Bitmap夹具七项全部通过（实际getPixels颜色对整图单次读回，不比较创建Bitmap前尚未量化的半透明输入）。第二轮完整写出P95为竖屏2.549 / 2.477 / 2.415ms、横屏2.544 / 2.466 / 2.424ms；证据为`readback-arm-final.log`，测试包SHA256为`178873dd222be71ccc107ed873e441b9c2ca0513435e1d02d8ef145a1cae7ab7`。

真实Root补测使用独立中间候选，仅将Root桥工作区改为64K/128行，同一公开性能工程六项通过。五场景的pixelRead P95为14.617 / 14.380 / 14.879 / 14.095 / 13.713ms，完整流程P95为57 / 106 / 101 / 64 / 134ms；与16K候选的完整67 / 101 / 101 / 70 / 132ms没有一致方向，读回本身没有可靠下降。故撤销生产64K设置，保留16K/32行，不能把整链路抖动当作更大缓冲的收益。原始日志`arm-readback64-performance.log`及精确中间APK单独保留，不把它算最终包。

## 其余方向审计

- `FramePool.register_template`已按规范内容摘要共享PreparedTemplate；注册同内容仍需构建候选及摘要，但不在每次找图重建。注册任务外再加缓存不是同帧识别收益。
- `find_named_template_batch_observed`已一次解析帧租约和图像视图，按调用者顺序共享预算、模板准备、取消检查；没有二次截图或像素复制。原始像素找图直接读RGBA/BGRA，不先构造整帧灰度。本轮不再加没有测量依据的重复缓存。
- 当前Root桥读回并传输完整画面；ROI仅限制后续匹配，先全屏再裁剪不能算区域传输。新区域路径至少要显式携带原屏尺寸、旋转/坐标代次、区域原点及像素尺寸，打通Root请求、认证元数据、帧来源和结果逆映射，并覆盖停止、旋转及降级；旧Screen.capture仍须返回全屏。
- RootDaemon当前先接收完整像素及40字节阶段尾部，才发布含最终采集耗时的认证元数据。真正边采边发必须新协商开始/片段/最终摘要，失败或取消作废未完成帧，并保持总期限和停止优先级；不能提前把部分帧交给脚本，也不能删去HMAC或最终验证。这部分未实现，不计为已完成优化。
