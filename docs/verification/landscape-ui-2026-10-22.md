# 横屏与短视口布局适配

## 本批范围

- 共享参数弹窗按实际剩余高度选择紧凑标题与底部确认栏；不只依赖横竖屏方向，键盘和小悬浮窗同样适用。
  不自动最大化、不关闭表单、不修改草稿或加入规则。
- 图像工作台在宽且矮的视口采用左侧预览、右侧工具与操作；工具按完整按钮换行并可滚动，返回固定在标题栏，
  保存、找图、取字、制字及加入处理积木保持原入口。窄视口保留上下结构和有界滚动，预览独立裁切。
  变换、选区、历史、资源预算和识别证明语义不变。
- 函数库使用键盘之后的实际约束高度，短视口减少标题和搜索留白、移除常驻底部操作说明，保留分类、搜索、
  详情、加入与全屏切换。编辑操作窗合并短视口展开/折叠按钮，宽窗操作区最多九列，连续操作不关闭。
- 设计器返回、预览、保存固定在顶部，中间工具独立横向滚动；页面条和底部快速操作允许按文字实际高度增长，
  属性标题、输入、选择、工具项及下拉选项不再以固定行高裁切大字体，页签按实际字号适配。
  不修改保存的画布和控件像素。提示样式预览保持顶部固定，高度最多为实际内容区的 24%，上限 72dp。
- 截图保存按实际视口与键盘边界约束高度，短视口缩减标题、表单间距及操作栏，表单独立滚动，保存和取消固定。

## 验证口径

- 增加短视口、工具侧栏宽度及大字体下保留预览空间的几何回归；更新宽窗操作列数断言。
- 扩展自有图像选择设备夹具：横屏工作台普通/大字体、函数库搜索与全屏、共享弹窗确认与全屏保留、
  截图保存操作、设计器固定按钮和大字体属性行不重叠；原矩形拖动、取消、多边形及空插件断言继续保留。
- 只使用 MuMu 0 和本轮创建的公开 QA 项目，不连接或安装手机，不更改系统字号、输入法及持久方向设置；
  Activity 临时方向在结束时恢复。原生手机及 ARM/API25 仍单独验收。
- 本批不是运行性能优化，不改变 Root、截图后端、匹配算法、默认 full 或 OCR 模型。

## 本轮结果

### 初次失败和修复

- 首轮在 Activity 横屏切换期间遇到 MuMu 系统输入冻结（`DispatchFrozen=true`），界面树已经变化而截图
  仍停留旧帧，工作台返回点击超时；该轮不计通过。按既有授权只重启 MuMu 0，不清数据；测试增加实际显示方向、
  可访问布局及公开哨兵像素三者一致后再操作的检查，不以布局回调代替画面已呈现。
- 第二轮工作台普通/大字体通过，函数库测试未识别仅具有点击动作标签的关闭按钮；补充读取已有的
  `ACTION_CLICK` 标签后重测，不修改或放宽布局断言。第三轮 14 项通过、`cleanup=true`。
- 随后逐张复核截图，发现设计器大字体属性标题和输入标签仍受旧固定行高影响；补齐共用控件的行高/行距适配，
  并新增属性行不重叠的设备断言。最终构建及设备结果单独记录，不把第三轮旧包通过当作最终包通过。

### 最终结果

- `build.cmd -Verify` 通过：九个执行模块共 1331 项单测，1329 通过、2 项既有跳过，0 失败和错误。
  Lint 为 0 错误、38 警告、12 提示；APK 的 ABI、固定模型及布局门禁通过，默认 full 保持不变。
  仓库布局检查通过，671 个本地链接、0 个本地专用引用、22 个包含在 Rust 根下的成员。
- 最终生产包为双架构 Debug，104914836 字节；保留数据安装到 MuMu 0（API32 / x86_64）。
  SHA-256：`c9887a0c80bafbf6c46f866262f915e487b1e9824f238bb39841f679f790e9ac`。
- 最终 QA 包单独重新构建，SHA-256：
  `6b889bfdaf966319510a9b71c8d84fd8e7edbcbbb600a86eea955abbefe0f974`。
  最终 `imageSelectionOnly` 为 14/14，完成码 -1、`pass=true/cleanup=true`；
  包含最后新增的大字体属性行不重叠检查，不复用旧结果。
- 测试结束恢复 Activity 原方向，输入状态为 `DispatchEnabled=true/DispatchFrozen=false`。
  最终工作台普通/1.6 倍字体、函数库、共享弹窗、截图保存及设计器截图已取回；
  对比复核确认设计器属性标题、名称和宽高行不再互相覆盖。
