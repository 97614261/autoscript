# Studio 多组滤色实现与验证

日期：2026-10-19。范围见 [ADR0129](../adr/0129-project-color-filter-workflow.md)，操作见[滤色找图与字库取材](../../docs-site/src/guide/image-filters.md)。不声称与旧 Native 的不可见算法完全等价，不改既有找图、字库格式或生产模型。

## 实现

- 绝对 RGB 通道容差、通道差相对滤色、自定义逐条方式；多颜色保留取并集，排除优先，支持反选。
- 黑白输出保留 Alpha；透明保留保留原 RGBA、清除其他区域。原图不修改，尺寸和坐标不变。
- 截图工具直达滤色，图片工作台同一入口；固定预览、原图/处理图对照、原像素取色、紧凑规则与方案区、全屏切换、非法输入阻断及关闭确认。
- 项目方案原子冲突校验、同名副本、确认删除、损坏文件保护及备份恢复。规则复制进积木，不在执行时读取可变方案。
- 处理历史、保存新模板、制作字库、既有真实识别测试与完整处理/识别积木链路复用；不自动运行、点击或创建隐藏变量。
- Rust `Screen.transform` 与可视化 `screen.transform` 使用同一版本化规则。Kotlin 预览使用跨语言黄金向量；旧模式拒绝滤色参数，结构、编译与 UI 校验均覆盖。
- 每次最多32规则、8192字节、4,194,304像素和6400万像素规则比较；每256像素检查取消，保留既有期限与帧释放。
