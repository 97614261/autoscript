# 智构六批代码补强（2026-10-10）

用户要求：先继续开发代码，暂停模拟器和真机实测。本轮不启动设备、不安装 APK、不运行任何私人脚本。以下是代码实现范围，不代表设备验收或整个项目达到 100%。

## 1. 运行错误与积木定位

- 历史页提供最近失败位置，识图统计条件提供“定位”。只使用结构化 task/vision 事件的插件/积木身份；压缩条件记录通过既有解码器恢复，最多保留 16 个失败位置。
- 主动取消、未找到不算失败位置。脚本打印的文本及 Lua 堆栈不会被推断为可导航身份，匿名化身份不可反向定位。
- 当前项目身份、插件和积木存在性均复核；成功定位清除折叠并选中当前草稿的积木，不保存、不运行、不覆盖草稿。提醒当前草稿可能与历史运行不同。
- 真正的 ROOT_STOP_CLEANUP_FAILED 单独解释，不当作正常停止。既有诊断文件白名单继续保留，不扩大原始脚本日志范围。

## 2. 编辑和保存一致性

- 变量表保存、保存并加入计算、调试设置保存统一使用编辑操作的异常/取消/收尾处理；取消不冒充失败，失败不丢草稿，忙状态必定释放。
- 加入计算只在成功插入后触发下一次保存，失败明确区分“变量表保存”和“积木加入”。
- 源码应用在验证前后复核目标插件、项目清单、各插件草稿和实时运行状态。继续复用已有受限 Lua→IR 校验与单次可撤销替换，不直接执行文本。
- 保存/参数编辑期间拒绝日志切换插件。已有存储层插件删除引用保护、变量重命名多文件事务保持；变量改名后不恢复可能含旧名称的撤销历史。

## 3. 图像与模板身份

- 延续现有单张/列表/目录互斥、截图回填保留草稿、原像素模板和半开范围规则，不更换识别算法或扩大 OCR 范围。
- 找图日志加入有序 templateFingerprints 与 sha256-rgba-v1 口径，复用注册模板时已经生成的宽高+规范 RGBA SHA-256。路径、编码文件元数据和行填充不影响身份；搜索不再次哈希像素。
- 单图、多模板和灰度宿主请求可读取缓存身份；动态帧模板未预处理时不伪造指纹。
- 新旧日志均可展示。缺少完整指纹的找图指标不计算跨运行变化；尺寸相同但内容不同的模板不混合。截图仍按环境、后端、传输和结果比较。屏幕内容没有核验，不据此自动声称提速。
- 统计摘要显示“指纹已记录/内容未核验”，详情提供中文指纹口径。

## 4. 输入和调试状态

- 输入能力缓存绑定连接代次、Root 就绪和手动刷新代次，旧缓存不能启用新会话控件；启动选点/录制再次检查实际能力、输入声明和运行状态。
- 悬浮选点使用请求所有的临时隐藏，不再主动修改用户的最小化状态。准备失败/取消恢复展开状态；请求票据拒绝关闭、切换插件和下一次请求后的迟到回调。
- 截图选点启动被拒绝时，不继续切入图像工具状态。
- 运行变量读取异常释放“读取中”；取消正常传播，陈旧读取不能覆盖新读取。编译器变量校验异常显示可重试信息，不让异常退出 UI。
- 优先停止通道、认证清理、单步检查点和已有运行入口返回策略均保持，不做输入降级绕过。

## 5. 日志 UI 和复制

- 保留既有紧凑/全屏/分页截图总览，增加“仅错误”和有界定位操作，不替换程序树。
- 错误筛选包含结构化失败、截图/匹配超时与预算超限；取消和未找到不显示为错误。
- 普通日志复制也进行 128 KiB UTF-8 上限检查和完整回读。超限明确要求筛选或导出，不静默截断；生成在后台、关闭窗口取消、系统剪贴板限制及异常可见。
- 未进行新的小屏、键盘或横竖屏人工视觉验收，不能仅以本地编译宣称这些设备效果全部合格。

## 6. 独立 Runner 打包

- 生成 APK 总大小及原生库各 ABI、ONNX 模型、冻结项目资源、Android 代码、其他资源的组成报告。条目大小不含签名/对齐开销，不公开用户图片路径。
- 冻结完成后再次核对源码和资源的有界内容摘要，不仅检查文件长度/清单；同尺寸替换也阻断打包。检查可取消且受既有打包期限约束。
- 取消只针对控制器自己持有的工作；取消后和后续任务之间的迟到进度不串入日志，保留既有失败清理和成功产物导出流程。
- 固定包名/版本/设备私有签名限制仍需明确展示；本轮不引入自定义 Runner 品牌、外部签名密钥、在线更新或账号功能。Debug 候选不冒充正式发布包。
