# 界面设计恢复弹窗修正 · 2026-10-11

范围：用户截图中的「恢复界面设计」弹窗。原实现把两个按钮放入公共取消按钮槽，与独立右侧恢复按钮错层；本批不调整设计画布、不修改正式界面或恢复记录格式。

## 实现

- 公共确认窗新增可选独立操作列表，旧调用继续使用原双槽布局。恢复窗采用小字号和紧凑留白，每个按钮独立等宽居中；窄屏或大字体放不下全部操作时整体切为有界可滚动单列。
- 区分记录无法读取、正式清单变化、当前设计已有修改及可恢复四种状态。仅可恢复时展示「恢复草稿」；其他状态只显示「保留并关闭」「丢弃记录」，不展示死灰恢复按钮。
- 保留关闭不删记录，顶部恢复入口可重新打开；明确丢弃只清理所属恢复记录，不改正式界面。恢复或丢弃成功关闭提示，失败在弹窗内反馈并保留记录。
- 保留正式清单摘要及上下文检查；异步恢复同时复核最新已保存设计，恢复仍为可撤销草稿，不保存、不运行。未读取用户私人项目，不判断截图中具体是哪项清单变化。
