# 私有运行数据提交复核

2026-10-12，本地验证，不安装或启动MuMu，不运行私人脚本。

## 修复范围

原有恢复在提交前检查目标与配额，但提交时没有再次检查；期间出现同名新文件可能被原子rename覆盖。恢复现在在项目共享配额锁内重新解析路径、拒绝已有目标、复核回收载荷和文件上限，并重新计算当前数据配额后才发布。

移至回收区、新建目录与移动文件也使用同一提交锁；提交时复核当前配额和源文件约束，避免把提交前的结果当成提交时真相。文件移动重新执行有界UTF-8读取，不扩大为二进制或目录移动。失败保留源文件及回收载荷，不删除新目标或其他项目数据。

新增三项回归：恢复前出现同名文件不得覆盖；恢复提交前文本配额被占满不得超配额；移动提交前源文件变大不得越过文件上限。测试使用可控提交回调模拟两阶段间的变化，不冒充Android跨进程设备实测。

这不是ZIP/通用二进制交付，不新增API、积木或能力。契约仍为143个API、158种积木；既有Android7兼容配额锁复用，不增加依赖。

运行服务单元测试92项，失败0、错误0、跳过1；新增三项全部通过。构建使用原始Gradle，未运行会自动安装MuMu的build.cmd。
