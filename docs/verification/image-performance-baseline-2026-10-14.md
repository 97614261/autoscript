# Rust 图像性能基线 · 2026-10-14

## 范围

这是 Windows 主机上的 Rust `pixel-vision` release 合成基线，用于建立
条件分离的 P50/P95/P99 参考。输入为固定 720x1280 RGBA 帧、200x122 模板、
相似度 1000、容差 0、方向 0，每个场景 100 次；不包含 Root 截图、Binder、
JNI、OpenCV/ONNX、OCR、输入注入或脚本调度。

命令：

```text
cargo test -p pixel-vision --release --offline benchmark_fixed_search_matrix -- --ignored --nocapture
```
