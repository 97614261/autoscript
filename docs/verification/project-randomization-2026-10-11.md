# 项目随机化实现与验证 · 2026-10-11

## 已实现

- 项目运行设置：普通触摸、识别命中动作、普通等待三项独立策略，默认关闭。
- 单积木：跟随项目、关闭、自定义；不支持半手势重新随机，移动/弹起沿用按下偏移。
- 元数据：严格字段/整数/范围校验，保存、撤销重做、复制、备份恢复、插件源码往返；本行源码只改参数且保留随机策略。
- 执行：宿主映射之后使用实际屏幕px，合法交集取样，同一手势偏移一致，识图结果不变；固定路径预求边界，未知动态路径越界明确失败。
- 等待：毫秒或百分比增减，零等待不变；触点持有期间、生成的长按/拖动/录制内部等待及显式精确等待不浮动。启动、轮询、超时和调度让步不修改。
- API1.8：只读坐标解析、像素移动/滑动；可选快照身份在宿主准备输入时复核。旧像素调用省略身份仍保持原语义。
- Runner：保存随机配置后提升版本要求，编译器拒绝低版本随机项目；冻结脚本与嵌入Runner支持1.8。未增加Android编辑器依赖。

## 边界

- 没有执行用户私人脚本或设备触摸验收；构建安装不等于横竖屏、真实输入及视觉效果全部验收。
- 不保证设备实际发送与物理屏幕旋转原子化；校验的是准备请求时已知的宿主快照。
- 不增加随机轨迹、每行停顿、运行中全局策略修改或用户固定种子配置。
- 旧录制中的独立未标记间隔无法可靠猜测来源；本次新生成的录制间隔带精确标记，已有持续触点期间等待也受到保护。
- 原始按键/找图参数保留；识图积木已有偏移先决定动作基础点，项目随机再作用于最终动作，普通触摸默认不叠加在识别动作上。

操作见[项目随机化](../guides/project-randomization.md)，决策见[ADR0064](../adr/0064-project-randomization.md)。
