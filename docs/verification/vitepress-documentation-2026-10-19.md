# 智构 VitePress 文档站

2026-10-19。将现有 docs-site 扩展为独立文档站，不改变 Android/Rust 运行代码、项目数据或 API 契约。设计与边界见 [ADR0127](../adr/0127-generated-vitepress-documentation.md)，运行命令见 [文档站说明](../../docs-site/README.md)。

## 已实现

- VitePress 1.6.4、Vue 3.5.44、`@vue/theme` 2.4.0，三个直接开发依赖；Vite 安全补丁固定到 6.4.4，实际依赖由 npm 锁文件固定。
- 智构品牌首页、六篇使用指南、19 个 API 分类、本地关键词和分类筛选、每个 API 的独立页面及官方主题深浅色切换。
- 160 个 API 全部来自既有 JSON 契约，生成前逐项核对 Rust 快照。包含参数顺序、必填、返回类型/可空、能力、取消、超时、副作用、资源所有权、兼容名称、Opcode 和可展开原始契约。
- API 新增或变化后在 dev/build 前重新生成，目录/侧栏不另维护接口清单。生成器拒绝重复身份、未知策略、越界路径、符号链接及改写手写页面，只清理明确所属的过时生成页。
- 复用现有品牌 PNG，复制前后 SHA-256 均为 `e2f58b096895802c8b54b109bda72265b03d3b2b3bc0a29db8f3905774e6820f`，没有修改 Logo。
- Node 文档 CI 与 Android/Rust 编译独立。未新增后端、登录、分析统计、云搜索、下载器或部署流程。
