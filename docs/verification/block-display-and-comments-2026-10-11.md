# 积木显示与注释执行 · 2026-10-11

本批实现完成；范围为积木参数摘要、逐行显示别名、执行注释及其数据往返，不代表整个项目所有能力完成。

## 实现

- 运行提示显示文字或绑定变量及持续状态；弹出提示显示文字或变量及到期状态。
- 编辑/长按选中一行→显示别名，支持别名＋参数、只显示别名、恢复默认；别名独立于执行参数。
- 注释普通行不执行，注释判断/循环跳过整个子树；恢复父级保留子节点独立禁用。列表区分自身注释与随父级禁用，多选父子仅处理根一次。
- 编辑、调试及参数面板区分添加说明与注释执行。
- 显示元数据支持正式保存、撤销重做、复制、备份、整插件受限源码与本行参数源码往返。读取非法字段拒绝编辑，迟到应用拒绝，应用超出1MiB预算不改变原稿。
- 列表投影一次解析积木文档，不逐行反复解析；未宣称实测性能收益。
