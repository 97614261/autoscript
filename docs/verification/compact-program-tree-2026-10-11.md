# 紧凑积木指令树

参考一键玩树形编辑与易编 item_tree_list、q22 的紧凑行设计。
主树与多选编辑窗共用短摘要：操作名称、关键坐标/赋值/条件/次数/模板。
通用契约回退只展示两个原始标量字段；不会把摘要当源码或修改正式参数。
变量来源优先于未使用的固定值，复合判断不显示无效旧比较；字符串与数字有区分。
长文本有省略标记并清除控制字符，详细参数继续在编辑弹窗维护。

保留现有树形层级、折叠、横向滚动、选中与单步定位。
普通行无复选框；多选窗保留选择操作。
默认最小行高35dp，字体放大允许增高；展开图标扩大触摸范围。
项目协议、编译与运行语义不变。验证采用 build.cmd -Verify，不运行私人脚本。

第二轮视觉设计：操作名称与参数使用同一行的不同字重/颜色，分支前缀单独弱化。
树层级增加浅色引导线，选中与执行位置使用窄侧标识和不同浅背景。
折叠显示状态文字，禁用行降灰；多选窗复用同一套文字分层。
行高与现有横向滚动不变，无新增类别大图标或参数卡片。
