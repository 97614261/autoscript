# 运行变量观察窗验证

日期：2026-10-13。决策：[ADR 0092](../adr/0092-runtime-variable-observer-window.md)。

## 实现范围

- 独立的紧凑非模态观察窗，普通 App 内使用 App 窗口，悬浮编辑使用同会话系统窗口；窗口外放行触摸，不铺全屏拦截层。
- 标题拖动、收起/展开、放大/还原、关闭；再次从更多进入展开原窗，不创建重复窗口。默认260×320dp，按屏幕及字体限制尺寸，旋转复核边界。
- 全局/局部/变动标签、紧凑类型/名称/当前值列表、搜索变量名、锁定插件、所选采样详情及显式复制。
- 窗口独立于参数弹窗，不阻止编辑器运行、最小化或保存关闭；最小化继续可见，选点/截图/系统选择随会话暂隐，关闭会话清理。收起停止刷新，展开重新读取。
- 运行中每次完成后至少等待500ms再读；暂停/停止/失败只读一次，也可手动刷新。客户端单槽门闩保持到同步Binder真正返回，UI取消不能制造重叠请求。
- 周期刷新保留上一份列表，读取中/忙明确标注旧采样；连接断开、会话不匹配、启动空闲/停止中清掉旧值。UI请求票据、连接/状态修订及真实运行修订复核迟到结果。
- 按实际类型/值/截断状态比较样本，首次或新运行建立基线；全局可跨插件比较，局部只比较同插件相邻样本。变动集合裁到当前128变量内，不假称每次赋值都已捕获。
- 修正快照Parcelable对负数连接代次的错误拒绝：仍为不透明有符号身份，不改Parcel布局或执行协议。
- 无运行值写回、自动剪贴板输出、变量日志或新Runner依赖。

## 测试与限制

新增测试覆盖基线/累计变化、作用域隔离、锁定/搜索、新运行/负代次/旧修订、截断与类型变化、缺失值及重复键、窗口几何、保留刷新列表、单槽读取背压及异常释放、观察窗单实例/非模态/暂隐/关闭生命周期。

本批最终 `build-mobile.cmd -Verify` 成功：Studio 625项、RuntimeClient 24项测试均0失败/错误；共享模块测试、Lint、ARM64 Debug构建、原生打包及仓库布局检查通过。无设备验收结论。

首次打包校验发现增量APK有约34.6MB布局空洞，已有3个旧包备份，未删除旧备份或绕过预算。将该候选单独保留到忽略的 `build/apk-output-backups/observer-20261013-*` 后重新生成；最终候选115,490,852字节，ZIP布局/签名/填充3,745,796字节，低于16MiB上限。

未安装手机/MuMu，未操作或运行私人项目。仍需设备核验跨App窗口外触摸、首次开窗、拖动/旋转/大字体、编辑器最小化、授权撤销，以及暂停/停止的最后样本。

观察窗和编辑窗可能进入屏幕截图，应移开识别区域或关闭观察窗；未静默隐藏运行中的观察窗来改变识图输入。采样可能漏掉短暂变化；截断前缀相同不能证明完整值相同。
