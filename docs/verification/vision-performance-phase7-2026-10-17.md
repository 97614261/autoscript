# Vision performance phase 7 · 2026-10-17

## 候选评估

本阶段评估了精确匹配锚点的直接 RGBA/BGRA 字节比较，目标是绕过每个锚点的
`Color` 解码和通道比较。候选保留了原有预算、取消和结果检查，先以固定矩阵
和全量像素回归验证。

## 门禁结论

候选在一次交错矩阵中没有稳定优于当前路径，长 ROI 未命中和多模板条件出现
明显尾部波动；随后主机负载变化也会使 P50/P95 发生较大漂移。由于没有得到
可重复的收益，本阶段不把直接字节路径合入生产，已撤回候选代码。当前生产仍
使用已验证的 `read_pixel` 锚点语义与第五阶段行偏移快路径。

## 验证

- `cargo fmt --all -- --check`：通过。
- `cargo test -p pixel-vision`：35 通过，8 个既有性能测试跳过。
- 固定矩阵基准命令：通过；结果仅用于候选门禁，不作为设备性能声明。
- 已保留第六阶段的顺序、透明像素、预算、取消和 ROI 回归。

本阶段没有改变生产 API、Lua 语义、算法选择、Root 截图或传输协议，也没有
安装 APK、连接 MuMu 或运行私人脚本。后续如要继续优化，应先设计同一进程内
交错的 A/B 基准，避免主机调度噪声把候选误判为提速。
