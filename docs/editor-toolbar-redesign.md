# 编辑器底栏与积木操作

## 2026-10-04 最新决定

底栏为运行、单步、编辑、日志、更多；编辑直接使用原整理多选窗，旧分组操作菜单删除。更多不再重复整理、多选、撤销、重做、单步。日志独立弹窗。源码入口、变量工具、缩放柄和统一确认框见 `editor-panels-unification.md` 与 ADR 0038。下文保留上一批历史记录，不作为当前入口说明。

## 2026-10-03 历史实现

- 按用户最新决定，底栏仅展示运行、单步、编辑、更多。撤销、重做与原第二排复制、粘贴、删除、上移、下移、多选统一收进编辑弹窗。按钮图标 20dp，每排 44dp，均匀排列、真实布局居中；292dp 和 232dp 宽窗均为一排四列，极窄窗口自动换行。运行中仅保留暂停/继续、单步、停止、更多，不能将停止收到更多里。
- 编辑：打开紧凑分组操作弹窗（宽窗三列、窄窗两列），和长按积木共享；无选择也可打开，撤销、重做、粘贴和多选按实际历史、剪贴板与宿主能力启用，依赖选中节点的操作禁用。只读或运行中不提供编辑入口。整理/多选使用有界小窗、全选/清除选择与四列命令网格，详见 `editor-input-image-permissions.md`。
- 编辑弹窗与长按积木：编辑参数、以此为模板、撤销、重做、复制、粘贴、删除、上移、下移、多选、剪切、缩进、禁用/恢复执行、添加注释。单选编辑参数，多选进入整理面板。沿用现有强类型编辑命令、子树操作、保存与撤销，不另造数据通路。
- 以此为模板：选择加入位置后，回填原积木参数；不再提供修改原积木位置，原积木修改统一由编辑入口完成。内部加入仍要求明确分支，原有源版本检查保留。整理面板的单选标题栏也提供模板入口。
- 更多：整理、撤销、重做、单步、界面预览、录制、变量检查、查找替换、运行变量。无 Root 录制能力的入口继续禁用，不伪装成功。
- 日志：列表上方的固定入口控制下方日志区域，展开后保留程序树；生命周期失败/诊断标记提示查阅。运行提示仍独立展示，不把用户提示合并成开发日志。
- 主面板多选高亮与实际选择集合一致。窄/矮窗口右侧入口可滚动，不丢失 AI 等末尾按钮。新默认宽高 292×378dp，既有尺寸不强制重置。

## 验证和范围

纯逻辑测试覆盖底栏四个入口、编辑操作聚合、窄窗换行不丢操作、运行/暂停时停止始终可访问、空选择/只读/历史/剪贴板可用性、没有命令实现的宿主不启用批量按钮以及日志诊断标记。既有参数反显测试继续验证保留容器/子树、模板加入/撤销、过期参数拒绝和内部加入分支。

本批不修改项目清单、节点协议、Root 后端、脚本启动或运行提示语义，不添加依赖。主可视化编辑器和项目列表浮窗复用 EditorDock；Lua 调试分支保留，未提供真实历史/批量命令的宿主不会启用相关操作。

设备视觉、长按手感、参数保存、批量复制和拖动缩放由用户手测，不自动运行私有脚本或操作目标应用。
