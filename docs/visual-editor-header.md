# 可视化悬浮编辑器标题栏

`EditorDock.kt` 的 `EditorDockPanel` 是可视化悬浮编辑弹窗主页面，完整可视化编辑器和项目列表页的悬浮编辑入口共用它。标题点击的插件文件管理实现位于 `PluginFileManagerDialog.kt`。

标题栏左侧为设置，中央为当前插件标题，右侧依次为最小化、关闭。标题按窗口中心对齐；点击继续选择插件，拖动继续移动编辑窗口。设置打开宿主现有项目设置，沿用插件已保存、项目空闲和停止运行的条件；项目列表页的设置变更也同步到当前悬浮编辑项目快照。

设置使用齿轮图标，最小化使用横线图标。可选择插件时标题使用浅蓝圆角入口和下拉箭头，两侧对称留白保证标题居中；不可选择时不显示下拉提示。插件选择页改为居中紧凑弹窗，搜索默认展开，提供直接新建入口（可创建插件或分组），点击插件立即打开；长按或勾选进入原有多选维护功能。底部按钮使用容器居中，不用固定文字上下边距。

最小化将展开状态切为收起，显示灵动环吸附球，保留当前插件和窗口位置；小球支持拖动及松手贴边，空闲时点小球恢复窗口，运行时点小球展开暂停/继续、停止控制，不直接停止。关闭隐藏整个悬浮编辑器及小球，并执行原有关闭回调。

编辑器直接运行保持原有窗口行为，不自动收起。项目列表启动先显示设计界面，界面参数校验成功后，第二次点击运行立即隐藏设计弹窗，再提交启动请求；同步提交失败恢复弹窗。保存、编译、Root 就绪检查及配置的运行延迟仍正常执行，隐藏界面不等同于引擎已经开始执行。

运行服务在启动时只激活界面能力，不自动重开一份运行界面，避免“关闭—闪现—再次关闭”。需要在脚本运行期间显示时使用显式 `UI.command("window", "show", "")`；隐藏期间更新控件值仍被保留。

## 脚本存储

Studio 的项目根目录为 Android 应用私有目录 `/data/user/0/com.autoscript.studio/files/projects/<projectId>/`。可视化插件保存在 `visual/flows/*.jsonl`（默认 `main.jsonl`）；Lua 入口是项目根目录的 `main.lua`，其他 Lua 文件在 `lua/`。插件分组为 `.studio/source-groups.json` 中的虚拟分组，不移动实际插件文件。电脑的仓库目录是应用源码，不是模拟器里正在编辑的脚本目录。
