# ADR 0032：有界动态提示表达式

状态：采纳。日期：2026-10-03。

新增 `task.message` v1：`expression` 为1..1024字节的现有强类型标量计算语法，结果必须为字符；`channel` 为popup/output/console。复用Prompt.toast、Prompt.show及Log.info，不新增宿主API或权限，不把提示转成应用诊断日志。弹出渠道复用项目样式及自动消失，持续提示和开发日志仍独立。

表达式解析成AST后渲染，绝不把输入原文直接当Lua执行。变量必须为当前插件可见声明或类型一致参数；数字仅通过显式text转换拼接，图像、布尔、未知来源、未知函数、超长结果继续拒绝。运行时求值一次，不生成临时用户变量；沿用表达式1024字节、128项、16层及中间字符值4096字节限制，另在宿主调用前检查提示结果为合法UTF-8且不超过2048字节。三个渠道统一要求runtimeApi至少1.6。沿用会话停止、超时和背压。

智构调试面板新增文字／变量／表达式入口并保留修改回显，函数库可检索/加入。现有task.prompt/runprompt/log保持v1语义，编辑旧节点不静默改类型。Lua调试分支不从此入口直译计算DSL；新增能力用于原生可视化和冻结脚本。

旧configTip保存表达式内容；转换器仅迁移经过既有字符拼接白名单的表达式，数值隐式转字符、任意函数、标题、文件日志仍阻断。原稿/报告不变。生成器升级版本并更新fixture，工具同步检查器后再发布；每项以合成编译和真实PUC Lua执行验证，不执行私人脚本。
