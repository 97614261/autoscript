# ADR 0061：界面设计器独立草稿恢复

状态：接受，2026-10-10。

设计草稿独立保存在App私有ui-designer-drafts，不进入项目备份或Runner。最多16个项目记录、每记录1MiB；项目身份使用摘要文件名，原子替换并保留上次已提交记录，不读取tmp。进程内会话票据拒绝迟到写入。用户确认恢复前复核完整正式清单摘要和当前草稿；恢复作为一次可撤销编辑，不写正式项目、不编译运行。结构、数量、身份、引用和大小受限，未通过数值/选项业务校验的编辑草稿可以恢复后修正，正式保存仍执行原校验。

300ms有界防抖不是逐键持久化保证；未提交到控件模型的输入不保证恢复。正常明确丢弃会清除所属恢复记录；写盘失败提示主动保存，不能静默删除项目。

2026-10-11交互修正：恢复弹窗按记录无效、正式清单变化、当前草稿已修改和可恢复四种状态分别说明。只有可恢复状态展示恢复动作；其余状态提供保留关闭与明确丢弃，关闭不清理记录。每个操作独立占一格，不在公共取消按钮槽内堆叠多个按钮；窄屏或大字体不足以并排时整组改为有界可滚动单列。摘要和恢复上下文检查不放宽，失败保留记录并在弹窗内反馈。
