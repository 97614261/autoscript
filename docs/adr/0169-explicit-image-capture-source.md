# ADR 0169：图像识别显式选择截图来源

日期：2026-10-27

## 决定

图像工具提供「每次截图」和「共用图像」两个明确选项，统一放在识别配置前部，不再把自动截图藏在高级参数中。图像菜单可记住本机新积木默认值，缺省仍为每次截图；修改默认值不重写已有积木，不影响处理工作台或结果读取。

每次截图沿用原 `autoCapture` 或可见的截图、识别、释放组合，不增加运行协议、隐式变量或另一套帧管理。共用图像仅借用已声明的图像变量，不截图或释放；连续识别后由调用方显式释放，改变画面后须重新采集。截图暂存变量仍须确认覆盖及释放，完整加入校验、身份分配和一次撤销保持不变。

取色、找色、多点找色、找图和识字入口共用同一选择；补齐特征匹配和 V5 候选识字的原截图组合入口，不改变算法或模型。编辑已有 `autoCapture` 积木使用其原参数，旧共帧叶节点仍显示其真实来源，不伪造单节点截图能力或删除相邻截图、释放积木。读取结果和图像处理不受默认来源影响，处理图识别不隐式重截屏。

来源选择、图像变量及覆盖确认随内容滚动，保留矮横屏标题与提交固定、参数草稿和取消确认。没有所谓「零内存截图」模式：每次截图仍短暂持有像素，识别后释放所属帧，不承诺清空底层复用缓冲。

## 验证边界

定向主机检查覆盖默认值回退、创建和编辑隔离、17类识别的两种来源、截图释放配对、参数不变性及结果读取/处理图不截图。生产与测试 Kotlin 编译单独记录。

本批不升 App 版本、不生成 Studio 安装包、安装、发布或连接设备，不把主机检查当作手机界面或识别效果验收。

实际收尾：44 项主机检查通过，分别为来源策略 5、识别流程 12、识别参数 14、原子加入 4、识别收尾 7 和能力流程 2。Studio Release 生产及测试 Kotlin 编译、Release Lint 和 diff 空白检查通过。主机测试的既有依赖重建了独立 Runner 模板，没有生成本轮 Studio 安装包或操作设备。
