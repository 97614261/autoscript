# ADR 0005: 可视化循环使用受限的运行时契约

## 决定

可视化 Flow 的循环不是编辑器拼接 Lua 文本，而是由受版本控制的控制节点表达。循环节点只接受
固定值或已声明变量；编译器生成带迭代上限的 Lua，并通过运行时单调时间读取实现限时循环。

循环次数和已耗时间只能写入显式选择的变量，且只在循环体作用域内可读取。停止请求仍由任务
调度器处理，循环本身不引入轮询线程或 UI 计时器。

## 后果

- 固定次数、变量次数、无限、限时以及循环指标都能被静态验证并冻结到生成物。
- 需要为单调时间增加一个窄的只读 HostRequest；UI 与 Flow 编译器不会依赖 JNI 或 Root 实现。
- 旧悬浮编辑面板继续作为输入界面，但只发送结构化循环配置给可视化编辑器。
