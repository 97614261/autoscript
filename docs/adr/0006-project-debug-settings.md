# ADR 0006: 项目调试设置冻结到启动计划

## 决定

调试设置属于项目，不属于 Studio 设备偏好。项目清单保存一个严格、版本内兼容的
`debugSettings` 对象；启动前由 Studio 将其应用到冻结后的运行计划。

本批次先实现 `runDelayMs`：Studio 用一个闭包包装冻结 Lua 入口，使其在任务调度器内
执行 `Task.sleep` 后再调用原入口。这样延迟可取消、不会阻塞 Binder 或 UI 线程，也不需要
把延迟实现泄露给 RootDaemon。

## 后果

- Lua 和可视化 Flow 获得相同、项目级的运行延迟语义。
- 生成物的完整性仍在包装前校验；运行时拿到的仍是单个冻结 Lua 模块。
- 其它易编精灵调试项只有在 Runtime 有对应强类型能力时才可启用。首发 Root 范围不提供
  系统录屏、无障碍按键或无障碍音量停止。
