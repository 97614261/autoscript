# ADR 0193: 运行日志显示可读的积木位置

日期：2026-10-29

用户要求运行日志能看懂，不再只显示内部节点编号。

- 复用编译器已经写入真实检查点的插件显示名、规范积木行号及函数目录名称。Rust 在真实进入及任务终止事件中追加可选 `visualLocation`，不重新读项目、不根据高亮猜测，也不从后续草稿解析历史位置。
- 实时及历史共用投影，显示“插件 放技能 · 第 12 行 · 点击”；失败追加“执行失败”。行号包含禁用节点，不受折叠和生成 Lua 行号影响。原事件身份、项目归属及结构化错误定位保持不变，其他任务的上下文不得借用。
- 编号仅在列表正文隐藏，点开详情/复制原文及导出仍保留原身份。新事件沿用原有界队列、单条大小和轮转预算；名称长度、单行文字及行号完整校验，列表长名称省略以保留定位身份及失败标记，完整名称仍在原始事件。
- 旧事件缺少显示信息或信息不合法时，保留原身份及错误，列表明确提示“此记录未保存名称和行号”，不凭当前源码补造历史。脚本主动输出的文字不改写，搜索兼容名称与内部编号。
- 追踪开关、执行/输入安全、项目和日志格式版本不变；仅给已允许记录的位置增加三项显示元数据，不新增源码、变量值或模板路径。

仅必要定向主机检查和原x86_64候选/保数据MuMu0有限查看；不运行私人脚本、不连接真机、不升版或上线。实际检查与安装结果另记。
