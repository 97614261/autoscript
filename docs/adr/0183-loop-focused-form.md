# ADR 0183: 聚焦当前参数的循环弹窗

日期：2026-10-28

用户继续否定三行单选布局，要求重新设计。循环弹窗改为顶部三段选择、当前参数正文与轻量固定底栏，减少非当前参数、重复导航和大面积确认按钮。

- 顶部仅保留无限、限次、限时三段切换，正文仅显示当前操作参数，切换前清除输入焦点。
- 次数和时长用横向对齐的字段配置，常用次数/秒数直接填入；完整预设仍可从更多打开。选择变量成功才切换来源，取消保留原数值，可返回数值输入。
- 五种辅助操作合并到“其他循环操作”同窗选择区，打开时暂时收起参数，选择或返回后恢复，保留未提交数值；不叠加整份表单，以免横屏底行被固定底栏挤出。编辑旧积木仍遵守类型锁定，不以新类型替换。
- 输出与高级设置沿用折叠及已有配置自动展开，时间单位仍同窗展开，短窗口和大字号保留有界滚动/上下布局回退。
- 底部显示当前操作摘要及取消/加入两个小按钮，保留自定义确认文字。移除三行单选及其辅助分组下拉布局。

本轮只改布局与快捷填入，原解析、参数构建、校验、变量类型/作用域、草稿和执行语义不变。仅必要Release生产编译和原x86_64优化构建、压实/必要包检查后，保数据安装MuMu 0供查看；不重跑整套模型检查、不提交积木或运行项目、不连接真机、不升版或发布线上。实际结果另记。
