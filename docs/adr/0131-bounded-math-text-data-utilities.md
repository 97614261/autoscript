# ADR 0131 有界数学文本与数据工具

日期：2026-10-19

状态：已采纳

## 决定

对照简单玩 API 后，先补高频纯计算能力：数学单值及双值运算、保留小数、数字格式化、正则替换、字符过滤、文本反转、JSON 编码和数组排序。新增九个固定契约，复用现有工具积木参数窗、显式声明变量、编译器及受限源码往返；不扩展任意表达式执行，也不改变旧积木。

数学输入与结果限制为有限数、绝对值不超过 10^12；三角函数明确使用弧度。小数处理以实际二进制浮点值为准，半值远离零，不承诺十进制精确运算。JSON 编码区分文本转义和已有 JSON 规范化，不将 Lua 表或代码作为数据。数组排序只接受同类型标量数组，不隐式转换或按本地语言排序。

沿用文本 64KiB、JSON 16 层与 1024 项预算。正则替换复用有限自动机限制，原文及替换文各 4096 字节、表达式 128 字节、最多 1024 个匹配；替换串按字面值处理，不解释捕获引用。所有输出长度在追加前核对，不通过大结果分配后再拒绝。

## 范围

不涉及平台权限、网络、任意路径、下载器、通用 OCR、模型替换或独立 Runner 扩展。后续图像便捷操作、平台只读查询及文件格式工具仍单独推进。API 比较是能力语义对照，不承诺兼容旧产品函数名或全部参数。

## 验证

覆盖定义域、非有限数、UTF-8、输出膨胀、混合类型、预算、能力拒绝、真实 Lua 调用、积木编译及源码往返。代码验证、安装与设备实际验收分别记录。
