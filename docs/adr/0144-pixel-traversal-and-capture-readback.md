# ADR0144：候选遍历与像素读回续优

日期：2026-10-23。状态：同语义扫描优化及读回实验/取舍完成，两配置Verify与精确包两端回归通过；区域传输和流水线未实现。

## 目标与边界

用户授权继续优化，不以100ms作为终点。本轮先减少同语义热路径工作量，再评估需要新契约的区域传输与流水线。默认full/V4、Root鉴权/重放/期限、停止优先级及旧帧新鲜度不变；不得用缩放、跳采或旧画面降低耗时。

## 顺序

1. 大范围候选遍历去掉逐点除法，评估提前准备不变模板比较信息与安全批量比较。参考实现复核五方向、步长、边缘、透明、容差、得分、首个/多个命中及预算/取消边界；没有收益的实验不进入生产。
2. Bitmap像素读回在有界工作缓冲内对比分块；原像素/通道/Alpha保持一致，不能直接把预乘原生字节当作getPixels颜色。几何变化及末块不得泄露旧尾部。
3. 同帧多模板和重复预处理核对现有所有权、缓存及准备路径，不新增隐藏帧或跨输入复用旧结果；只有明确绑定同一不可变帧及完整参数才能共享。
4. 区域读回/传输与流水线分别核对协议、帧来源、原屏坐标和中途失败；不把小ROI匹配冒充区域采集。若无法在本轮保持边界并完整验证，明确记录尚未实现，不静默切换现有Screen.capture语义。
5. 保留前轮精确APK/QA作为基线；CPU微基准、完整设备流程、有限长测与准确率分开。记录P50/P95/P99、模板/ROI、设备、计时内外间隔及失败，不以P95相加或不同包历史结果证明当前通过。

线上仍由用户发布，不读发布密钥、不改下载清单。只使用自有公开QA工程，不切输入法或运行私人脚本。实现、实验取舍及证据统一记于[续优执行账](../verification/pixel-readback-followup-2026-10-23.md)。

## 本轮结果

采用增量四角遍历及每搜索固定模板比较准备，保留五方向、相似度、预算及取消等价。软件Bitmap与真实Root均测过64K分块，真实pixelRead未可靠下降，故撤销实验并保留16K/32行。恢复构建与已通过性能/主线的16K候选摘要完全一致。

同帧批量识别已有帧及模板准备共享，不重复实现/计数。真正区域读回需新的原屏来源及坐标/协议契约，真正流水线需协商和最终摘要发布规则；两项仅审计，不能作为已完成交付。
