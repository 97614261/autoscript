# ADR 0173：多选删除与全区域颜色计数

日期：2026-10-27

## 决定

可视化积木多选后，在选区摘要和编辑窗工具栏提供「删除所选」；多选的删除格标为「批量删除」。复用原有绑定源码、选区和树的确认，不允许陈旧确认删除新内容。删除先去除重复子树根，一次解析文档、收集所属子块并一次提交，整批只占一次撤销，保留未选中的相邻节点。

颜色计数与坐标列表分开：计数默认 `limit=0`，统计有限ROI内全部匹配像素，不受坐标列表容量限制；UI只有勾选「提前停止」才显示阈值，正数1–6400万保留达到即停的语义。旧正数参数不被默认值覆盖。比较次数、图像尺寸、取消和超时约束仍有效，预算耗尽不得返回伪造的完整计数。

全部找色的坐标列表扩为1–2048，Rust宿主、Lua参数、编译器、节点契约、编辑回显与COLORS结果读取同步。2048个固定 `{x,y}` 项仍在64KiB结果文本预算内；其他形状保留原容量，批量多点找色和颜色连通块仍为256项。声明为文本的可视化输出编码为COLORS JSON，兼容未声明的旧Lua表输出及插件参数遮蔽。Lua API直接调用仍返回原坐标表。

扩展计数参数（0或大于256）及大于256的坐标列表要求runtimeApi 1.8，并检查 `Screen.colorLimitsVersion == 1`，防止旧运行时误解新参数。复用既有JNI草稿和ProjectStore事务提升机制，不降低编译器版本门禁，不修改旧节点身份。

六类基础颜色操作（取色、找色、比色、多点找色、颜色计数、全部找色）可用 `autoCapture` 在编译器局部管理临时帧。每次执行重新截图、缓存、查询并释放；普通错误同样释放，取消沿执行器所属资源清理。不会隐式声明或覆盖项目图像变量。旧节点缺省false，仍使用原图像变量；「共用图像」必须选择已声明IMAGE变量，并由脚本显式赋值和释放。其他仍需可见截图组合的算法保留原暂存声明及覆盖确认。

本批不升版、生成Studio安装包、连接/安装设备或发布线上，不改服务器配置、密钥或项目备份；线上仍为0.1.25/versionCode26。主机检查不能代替实际手机界面及输入效果验收。
