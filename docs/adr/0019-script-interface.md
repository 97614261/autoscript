# ADR 0019：可设计脚本界面及两阶段启动

状态：已实现，2026-10-01，界面计划 1–6 的代码与自动验证已接通；设备触摸、软键盘和 Root 场景仍待人工验收。使用与限制见 [脚本界面说明](../script-interface.md)。

- 最初普通运行统一先打开已设计界面；此入口约定现由 [ADR 0020](0020-studio-launch-and-editor-entry.md) 替代：Studio 列表启动先配置，编辑器运行直接执行。独立 Runner 仍先配置，单步独立。
- Studio 设计器使用 Compose；Studio 预览、启动界面、运行悬浮窗和独立 Runner 共用 script-ui 模块的传统 View 渲染器。该模块不得依赖引擎或项目列表。
- runnerUi v2 保留旧 fields 的类型和初始值，增加页面及控件布局、样式、绑定、事件扩展。旧表单按 v1 读取，不删除数据；新增字段同步 Kotlin、Rust 和发布摘要。
- 事件使用有界队列，在 Lua 所属线程执行插件。等待事件挂起协程，由事件唤醒；不固定周期轮询。停止独立抢占，旧窗口事件不得进入新会话。
- 控件操作是强类型、白名单 UI 请求，不允许任意 View、Context、Javascript 或 Android 对象穿过脚本边界。运行窗口支持显示、隐藏、最小化、恢复及关闭停止。
- 页面及控件 ID 稳定，保存拒绝过期覆盖。资源图片必须属于项目已声明资源；绑定变量必须属于项目声明。
- 每阶段必须真实接通保存、解析、预览和运行，不把预留按钮视为完成。

## 自适应小窗补全（2026-10-01）

沿用现有 script-ui 边界，增加共享的窗口尺寸/视口算法和传统 View 小窗外壳，Studio、Runner、运行悬浮窗不再分别写尺寸与标题栏。设计器使用同一等比适配算法。默认整页适配，可在窗口菜单切换按宽纵向滚动；窗口大小受可用屏幕、安全边距及键盘约束，配置变化只更新窗口与视口，不重启引擎。输入、当前页、显示模式和滚动状态在最小化及尺寸变化中保留。此补全不增加持久化字段，不改变 runnerUi v2、设计坐标、Lua 或冻结发布协议。
