# ADR 0055：首版恢复边界与仓库归档

日期：2026-10-10。用户授权继续六批代码收口，并清理无用文件、集中保留历史文件；设备测试仍暂停。

## 决定

- 项目列表只读，不删除清单事务文件。清单解析前检查文件预算。
- 可视化插件文件缺失时，只自动恢复 `.previous` 中的已提交旧副本，且先检查 UTF-8、大小与根身份；没有该副本时明确失败。未提交 `.tmp`、历史 `.bak`、损坏的现有文件不能被静默替换。恢复前撤销生成代次，恢复保留来源副本，打开后的编译校验仍必需。
- 插件保存涉及最低运行 API 提升时，共用既有清单/插件回滚日志，避免清单已变但插件未提交。未知或损坏恢复日志拒绝写入。
- 活跃源码按职责拆分，并在同一com.autoscript.studio包下按九个职责子目录组织；仅文件位置改变，不改变包名、数据身份、协议或入口。历史阶段文档集中至 `archive/project-history/2026-10-10/`，保留目录映射并更新本地 Markdown 链接；ADR、操作手册和当前状态留在 docs。
- 本地截图证据也集中归档，不删用户截图、竞品资料、私有工程或已导出文件。删除仅限经逐项确认的可再生临时文件；不删除整个构建缓存或工作区。
- 清理不进入 Android sourceSets，仓库检查应验证本地文档链接与活跃源码引用。无设备安装/测试，本地主机门禁与设备验收分开记录。

## 限制

2026-10-10后续决定：用户明确要求删除无用文件及文档，不再保留全部阶段计划和退休UI副本。按[清理记录](../verification/repository-cleanup-2026-10-10.md)删除经核对的82个文件，先制作校验过的本地恢复ZIP；有测量价值的历史性能证据继续保留。docs按guides/reference/verification/adr分类，引用随迁移更新。这次扩大的是已确认退休文件的清理范围，不授权删除用户数据、整个构建缓存或活跃兼容路径。

`.previous` 恢复不代替 Rust 完整项目校验，也不承诺恢复进程死亡时尚未持久化的内存草稿。历史 Lua 数据和兼容路径继续保留。重构不得把仍活跃的 Legacy 命名函数误判为废弃文件。
