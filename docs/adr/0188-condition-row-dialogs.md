# ADR 0188: 条件行式弹窗

日期：2026-10-29

用户要求重新设计条件，点击弹窗选择，参考当前已接受的循环样式。

- 条件入口由无标题三项小菜单改为与循环一致的紧凑行式弹窗：如果、否则如果、否则先选择，固定底栏继续配置或选择分支积木。保留原宿主控制命令、选中节点约束及分支事务，不直接拼接 Lua。
- 条件参数窗横屏限宽 320dp，左侧变量、比较方式、右侧值同排标签与短输入；变量按钮 36dp，输入最低 30dp。比较方式、变量、判断模式与复合关系均点击弹窗选择，取消不更改原字段，长变量列表支持搜索。
- 固定值与变量共用右侧一行，选择变量后才切换，可返回固定值；无可选变量时保留手动输入入口。固定 JSON 标量和变量优先的原语义不变。
- 复合条件的与/或/非、递归子项、有效性检查、64项/8层/8192字节限制和否则如果编辑保留；错误固定在底栏上方，正文按实际剩余高度滚动。窄窗及大字号可上下排，不自动聚焦搜索。
- 删除旧三项菜单及参数页宽大分组/来源切换栏，不改变积木数据、编译运行、加入位置、保存或一次撤销。

仅必要条件/插入定向检查与原 x86_64 优化构建，保数据更新 MuMu0 查看；不加入积木、运行项目、连接真机、升版或发布。实际结果另记。

实际结果：14 项定向检查通过（复合条件 2、配置后插入 9、既有条件/分支/反射事务 3），Release 生产及测试编译通过。初候选在 MuMu0 当前 720×1280 竖屏查看三项入口、短行参数、六种比较方式、无自动键盘的变量搜索、选择已有变量后返回原固定值以及复合条件；均为未提交预览，最后取消。发现两处重复说明后合并为一处，返回字面量按钮改为“固定”，入口底栏改为“下一步”。

最终仅增量编译及原 x86_64 优化构建、packageRelease 压实和必要包检查，不重跑未改的逻辑测试。候选保持 0.1.30/versionCode31，51824010 字节，SHA256 `989811743a57294e10e18a3e7d420bcd734a2e2562b7b88db0f6237d756c7d6e`；原函数保数据覆盖 MuMu0，冷启动 Status ok/495ms、进程4519。最终查看三项入口及“下一步”文案，停留条件窗。未添加或运行积木、改变项目、旋转设备、连接真机、升版或发布；有限竖屏查看不冒充横屏/真实键盘/全部复合树设备验收。日志与截图保存在忽略的 `build/adr0188-*`。
