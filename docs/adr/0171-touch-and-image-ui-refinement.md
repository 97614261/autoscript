# ADR 0171：触控与图像操作界面整理

日期：2026-10-27

## 决定

在ADR0170紧凑窗口基础上，触控入口区分常用动作和持续触点，缩小动作卡片并随窗口/字号选择列数；本机记住悬浮准星或截图选点方式。原七种动作、能力读取、权限入口及录制入口保留，显示和点击仍各自校验后端能力。参数使用受控输入、布尔选择和自适应网格，时长可快捷填入，未提交关闭需确认；切换坐标类型不自动换算数值，原完整参数校验不变。

截图悬浮条保留原点击/拖动手势状态机和真实尺寸限界，常用截图、缩放、像素微调、提交与关闭直接可见；处理、滤色、多边形及制字在可展开工具区。时长和多点容差随对应模式显示，不要求横向寻找隐藏按钮。增加原图像素微调：矩形X/Y/宽/高、触点、起终点及颜色点，输入非法或越界整次拒绝；显式应用时才更新选取，颜色点从同一原图重新采样。不改变视图变换、设计坐标、截图时隐藏浮层、生成积木和一次撤销边界。

原生悬浮准星面板的设置正文按真实屏高扣除标题、操作条及边距后滚动，确认与取消不在滚动区；坐标随准星移动刷新。只改变窗口呈现，不执行触摸或改变Root、选点回执、屏幕代次检查及窗口会话归属。

图像专用表单统一受控输入、可换行勾选及显示中文标签的选择器；较长的资源/变量列表支持筛选，不自动聚焦。等待/结果读取/结果动作/帧操作保留类型、覆盖释放及原屏来源的明确确认，次要说明按需展开。坐标、色点及制字操作适配窄窗和大字号，色点不再把四个输入及删除挤在同一行。图片库和方案列表将工具与搜索纳入正文滚动；短视口的清理、蒙版及差异预览随表单滚动，画布显式裁剪，提交仍固定。

不改变识别算法、帧来源策略、资源格式、保存/删除/引用查询、测试证明、项目身份和候选事务。仅做定向主机检查及Kotlin编译/Lint；不升版、不生成Studio安装包、不安装、发布或连接设备。主机检查不代表手机视觉效果已验收。

## 验证

103项定向主机检查通过：像素编辑6、触控入口5、点位编辑9、图像视口29、制字像素6、识别后续14、图像工作流12、识别参数15、原生面板几何4、取点协议3。新增检查覆盖手输原像素边界、批次整次拒绝、非法/溢出输入、顺序及原色点预算，以及短屏面板固定操作区的高度预算。

Studio和Runtime服务Release生产/测试Kotlin编译及Studio Release Lint通过；关闭微调保护和模式名称收尾后增量编译/Lint再次通过。diff空白检查通过。首条命令误用物理目录名`:modules:runtime-service`，Gradle在执行任务前拒绝；改为工程原逻辑身份`:android:runtime-service`后通过，失败日志保留。集中检查日志为`build/touch-image-ui-checks-compile.log`，最终增量日志为`build/touch-image-ui-checks-final.log`。

Runtime共享代码变化触发既有独立Runner模板构建依赖；没有生成本轮Studio安装包、升版本、连接设备、安装或发布。手机横竖屏、实际键盘及窗口可见效果未在本轮设备验证。
