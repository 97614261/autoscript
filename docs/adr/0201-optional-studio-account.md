# ADR 0201: App账号可选，本机功能免登录

日期：2026-10-31

用户明确App不强制登录，服务器部署稍后，继续App端开发。本批把账号边界落实到现有界面：

- 保持启动直接进入App，项目创建、编辑、运行和本地备份不依赖Studio账号或账号服务器；
  账号页仅在用户点击“我的”账号卡片或云备份入口时打开。
- “我的”未登录卡片说明可选登录用于云备份，状态显示“本机使用”，页尾说明本机编辑与运行免登录。
- 登录和注册共用的固定底栏增加“暂不登录”，沿调用方原返回动作离开，不创建会话、不清项目；
  请求中保留取消，不让返回动作绕过正在进行的写入。登录页说明只有云备份需要账号。
- 会话过期/退出仍只影响云备份与账号页，不触发主导航或编辑器拦截。旧个人密钥备份和本地备份路径保留。

本批为入口文案和既有返回动作接线，不新增收费、套餐或脚本授权，不修改后台和服务器，
不自动迁移旧备份、不升版或发布。仅进行增量生产编译，不重复前批协议及MuMu整套验收。

修正参数数组后通过，原失败日志保留。diff --check通过。仅源代码开发，未生成或安装新APK、运行项目脚本、
操作MuMu/真机、部署后台或发布线上，也未提交Git。
