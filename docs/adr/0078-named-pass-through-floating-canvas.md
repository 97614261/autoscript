# ADR 0078：命名轻量浮窗与像素绘图

2026-10-12用户要求执行独立浮窗与绘图。与主配置界面、交互对话框、提示和控制球分离，新增ui.floating能力；提供显示/更新、隐藏、关闭、读取实际边界。最多8个窗口，按设备原像素定位，X/Y=-1分轴居中，限制到屏幕可见范围；不可抢焦点，全部窗口区域穿透触摸，交互按钮仍使用已设计脚本界面。

显示接受名称、像素位置/尺寸、文字、字号/颜色/背景、已声明图片及有界基础图形JSON。图形最多32项，仅线段、实心矩形/圆；固定字段，不执行绘图代码。窗口最多2048x2048、全窗口总面积8Mi像素，字号8–96px、文字4096UTF-8字节、绘图8192字节。图片按contain适配显示，不改资源像素；仅当前冻结声明资源，单图4Mi像素，RGBA源缓存64MiB、绘图图片缓存32MiB，超预算明确失败，不冒充显示成功。

调用等待走独立工具工作线程，主线程只管理View/WindowManager。先完整校验、准备资源，再一次显示/更新。取消、主动停止、结束、失败、重启及服务销毁清除窗口；隐藏保留内容，显示/更新只修改本名称。迟到回调使用运行世代/工具epoch拒绝。未授权悬浮窗明确失败，不退回App内显示。

准备阶段仅声明ui.floating的运行注册绘图图片；不增加普通找图脚本的副本缓存。新准备清理旧冻结资源，重启复用原资源。浮窗可进入系统截图，需识图的脚本可显式隐藏，不能自动改变识图算法或冒充底层画面。

这是基础非交互绘图，不提供任意WebView、Java、Shell、用户代码Canvas或无限动画；不替代主窗/暂停停止入口。Studio提供紧凑配置和基础图形快捷示例，全部参数可保存、编译、受限源码往返。
