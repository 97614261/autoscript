# ADR 0063：积木显示别名

2026-10-11，按用户确认实施。

积木 envelope 增加可选 display 对象：alias（最多80个Unicode码点，无控制字符）和 showParameters（布尔）。
它属于显示元数据，不进入 args，不改变节点 kind、身份、版本、能力或运行逻辑。
没有 display 的旧项目保持原显示。清空别名移除 display；别名不写入普通运行日志。
原始插件数据参与正式保存、复制及备份，编辑事务支持撤销重做。
受限源码 @node 元数据可携带 display；缺省时保留当前身份已有显示信息，明确 null 清除。
整插件源码支持校验修改；本行源码只改参数，显示元数据由显示设置维护。

禁用沿用既有 disabled：普通行不执行，容器及其子树不执行；子树的独立禁用标记不被覆盖。
区分“添加说明”与“注释执行”，不提供绕过判断或将循环体执行一次的模式。
旧客户端不认识新元数据会拒绝加载，不能静默丢弃；本版保持旧项目与协议兼容。
