# ADR 0011：可视化编辑第二批功能闭环

## 范围

本批接通图像测试/标注库、节点多选批量操作、静态变量检查/运行变量/数据回填/节点单步，以及输入后端能力检测。只支持现有 Root、像素视觉与字库能力；不新增无障碍、录制、ONNX、账号或云服务。

## 决定

- 多选操作以去除已选祖先后的子树根为单位，整体事务和单次撤销；参数编辑仍只针对一个节点。注释继续是说明节点，不冒充停用代码。
- 调试检查点由编译器生成，只有 Studio 开发运行开启。单步按积木边界暂停，不使用睡眠轮询。停止保留现有优先控制通道；继续关闭步进模式。
- 变量快照只在 Lua 所属线程读取，经有界调试响应传回编辑器，不能通过普通日志传递变量值；回填只通过现有节点事务，不执行任意 Lua。
- 图像测试使用 runtime-api 新增的有界模板预览请求，经低频显式文件描述符传入已保存的截屏/模板，runtime-service 解码后调用脚本相同的 Rust 像素匹配器。Studio 不直接依赖 JNI 或视觉实现。脚本已运行时拒绝测试，预览不访问脚本 VM 或脚本帧句柄；不通过普通日志返回匹配数据。协议升至18。
- 模板测试仅承诺模板找图，找色/字库 OCR 测试不冒充已实现。变量维护检查是保守警告，参数/类型校验仍由真实 Flow 编译器负责，不声称静态证明所有分支已赋值。
- 输入入口按后端实际能力启用；不能把获得 Root 等同于支持所有触点原语。

## 验证

本批只做主机静态检查、单元测试与 Debug 构建，不宣称设备实测或参考产品所有功能均已对齐。

- 2026-09-28：Studio 单元测试141项通过；引擎、JNI、编译器、执行器、调度器、Root 客户端与打包器的 Rust 测试通过。
- `cargo fmt --all -- --check`、`git diff --check`、相关 crate 的 Clippy 通过；Clippy 仍有现存警告，不声称警告清零。
- Studio `lintDebug` 无错误（仍有23项警告、20项建议），修复图片预览及项目文件路径检查的 Android 7/API 24 兼容性。
- Studio 与 Runner 模板 `assembleDebug` 通过，两种 ABI 均可构建。

## 手动验收入口与边界

1. 在可视化悬浮编辑器或页面编辑器点击“工具”：标注截屏沿用原有相机入口，标注库打开现有图像库；测试识别选择已保存的截屏和模板，显示真实匹配坐标/相似度，可一次加入截屏、找图、释放帧三个积木。
2. 点击底部“修改”：勾选多个节点，复制/剪切/粘贴、移动、缩进/减少缩进、删除按子树批量执行；失败全部回滚，一次撤销恢复整个批次。参数修改与说明仍要求单选。
3. 空闲时点击底部“单步”启动开发会话，在积木执行前暂停；再次单步执行到下一积木边界。继续运行关闭步进，停止优先取消会话。睡眠或宿主请求结束前不会伪造下一积木完成。
4. “调试”中的变量信息显式刷新最近检查点的局部/全局标量，最多128项，每个字符串最多1024字节；超长值显示截断，不能回填。变量检查展示保守维护警告，并可调用真实编译器检查参数/类型。
5. 底部“数据回填”：单选目标积木、选择运行变量与兼容的标量参数，再停止运行并确认；编译器检查通过后才写入，支持撤销。资源句柄、图片路径、流程ID和截断值不得回填。
6. 按键动作按 Root 后端已协商的能力启用。Android 7 仍可使用基本点击/滑动；不支持独立触点操作时禁用依赖该能力的长按/拖动入口，运行时也拒绝相关插件而不是静默失败。

模板测试不包含找色与字库 OCR 测试，也不代表实时连续识别。变量维护警告不替代全路径数据流分析。单步按积木边界而非 Lua 源码行执行；Runner 冻结产物不启用 Studio 调试快照。
