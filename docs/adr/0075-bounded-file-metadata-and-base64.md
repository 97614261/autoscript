# ADR 0075：私有文件元数据与Base64

2026-10-12用户要求执行文件工具补齐。新增文件大小、扩展名、递归目录统计及文件Base64转换固定契约，只接受项目私有data规范相对路径，单独声明storage.data。

大小返回真实字节整数，扩展名为不含点的末尾扩展名，不存在文件明确失败；目录统计返回files/directories/bytes的JSON，不导出绝对路径。递归复用16层、256条目和现有配额，取消和有界宿主期限不变。

Base64采用规范RFC4648标准字母表与必需填充，无空白、URL变体或非规范尾位；编码输入最多49152字节，解码输入最多65536字符。解码写入为单文件原子不覆盖，允许二进制，不改变Files.read/write的严格UTF-8语义。媒体头文件计入二进制总预算，非媒体文件仍计入现有512KiB普通数据预算，不因扩展名放宽配额。备份不包含私有运行data。

ZIP目录事务、平台工具、命名浮窗另行实现和验证，不以此批宣称第一批全部完成。
