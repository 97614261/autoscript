# ADR 0012：识别完善、资源与运行任务

状态：实施中。日期：2026-09-29。

## 背景

现代找图固定搜索方向，矩形只接受字面量；多模板、图像结果、频次、成功动作和周期任务尚未完整接通。既有 Root 与像素引擎可复用，但不能通过伪 API 或隐藏条件改变旧插件行为。

## 决策

1. 保留现有 API 的 opcode 与默认语义。新增参数仅允许尾部可选且有明确默认值；新操作用独立 opcode，不能修改旧返回布局。
2. 新识别节点语义使用独立节点版本，兼容读旧节点，不删除旧字段或用户数据。变量范围仅允许整数或显式变量引用，不接受任意源码表达式。
3. 新增能力明确 runtimeApi 门控；manifest.capabilities 为唯一授权来源，输入动作额外要求 input.basic。
4. 多模板只能来自项目声明资源，确定性顺序、有限模板数与共享比较预算。结果图像使用 FramePool 租约和任务资源登记，不高频转图片文件/ByteArray。
5. 识别频次表示插件本轮运行内的节点访问计数；第一次执行识别，此后每 N 次访问识别一次。跳过时清除本次输出，不复用陈旧坐标输入。
6. 成功后输入动作生成结构化调用，坐标转换一次，输入状态由原仲裁器拥有；取消/异常清理不由 UI 猜测。
7. 周期回调保留在同一 Lua VM，timerId 与回调轮次关联，回调完成必须通知 scheduler；不重入，错过的 tick 合并，不固定周期轮询。
8. OpenCV/ONNX 仅窄适配接入，不替换默认 Rust 像素/字库 OCR；必须先做依赖与模型授权评估，未集成后端不宣称完成。
9. 找图的是否找到结果：旧未声明变量继续返回 boolean；显式整型/数值声明（含插件参数）返回1/0，使变量维护页的四种声明类型可用，字符串/图像结果声明拒绝。坐标仍为整数或nil，不通过开放任意类型转换掩盖错误。

## 验证

逐批验证旧项目兼容、生成 Lua 与 executor 实际执行、预算/取消/释放；每批格式/静态检查/单元测试/Debug 构建。用户设备验收与性能测量不在主机验证范围。
