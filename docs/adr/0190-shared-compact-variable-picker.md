# ADR 0190: 统一紧凑变量选择与管理

日期：2026-10-29

用户要求变量管理和其他选择变量的 UI 参考当前循环里的选择窗口。

## 实现

- 抽出循环同款变量选择器：横屏默认280dp、正文最多220dp，作用域和搜索同排，窄窗或大字号上下排，30dp起的变量行包含名称和类型。当前值标记、点选返回、取消保留原值；选项不自动聚焦搜索框。
- 循环、计算、条件及复合条件、输出、流程参数、通用积木、图像识别及流水线、识别结果、图像扩展、文本工具、运行工具、浮窗和界面参数/变量绑定复用同一选择器。资源、操作方式和类型等非变量选项保留自己的选项语义。
- 变量管理窗口收为320dp，筛选和搜索同排；类型、名称及编辑/计算/删除同一行，内容少时缩短窗口、最多六行后滚动。新增/编辑改为紧凑名称和类型字段，保留新增、编辑、改名引用、计算、删除、保存、繁忙和未保存关闭保护。
- 元数据只注释调用方提供的候选，不扩大类型或作用域权限。沿用参数/局部遮蔽全局的真实解析规则、原固定值/清空/不接收选项和禁用值；不改变变量声明、表达式、项目保存或积木加入事务。

仅必要定向主机检查、Release编译和原x86_64优化候选及MuMu0有限查看。不升版、不上线、不连接真机、不旋转设备或运行私人脚本，实际结果另记。
