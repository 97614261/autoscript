# ADR 0199: 账号入口与后台账号、备份管理

日期：2026-10-31

用户要求执行后续计划1—3：完善App账号入口、后台账号管理、后台备份管理。沿ADR0198与后台
`codex/zhigou-admin` 开发，不部署线上，不改收费或独立Runner。

- “我的”顶部显示登录/注册或当前账号，进入账号页、修改密码及云备份；项目备份继续共用生产账号偏好和Keystore。
  新增会话变更通知让账号卡片刷新，QA命名空间不触发生产通知。密码只存页面内存，取消/提交后清理；
  修改成功后清除本机旧会话、所有设备重新登录，备份密钥与原备份保留。忘记密码由后台管理员重置。
- 后台新增嵌入式独立管理页 `/studio-admin/`，保持若依Vue参考源码不变；复用原管理员验证码登录及JWT，
  App令牌不能访问管理API，管理员令牌也不能访问App备份。管理API具备独立权限、分页上限100及统一响应。
  账号显示状态、注册/最近登录、备份数/字节，支持启用/停用、改配额、重置密码、强制下线。
- 显式SQL003仅修改新增Studio账号表，增加会话版本、登录时间与配额；旧会话缺省版本0兼容。
  改密、后台重置、停用/启用或强制下线推进版本，不扫描Redis。账号锁串行保护配额更新及备份写入，拒绝低于已用配额。
- 按账号查看解密的备份名称、大小、时间，管理员不获得响应中的密钥或存储引用；不新增解密脚本下载。
  删除确认与原摘要CAS保护、管理操作记录和密码脱敏沿原若依机制。单文件检查大小/摘要；离线只读工具报告
  缺失、损坏及未引用文件，限定清单预算与超时，不自动删除或修复。
- 本地初始化仅给独立开发库补迁移，空用户表可创建独立管理员；密码写入忽略目录，不打印，不复制原管理员。
  三个缺失策略参数使用本地新默认值，保留原库、已有账号/参数及源配置。初始化密码长度首次不符及缺失参数
  导致的两次实际管理员验证失败保留；最终修复未放宽原管理员登录规则。
