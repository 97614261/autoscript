# ADR 0117 Studio首版体验与异常路径收尾

2026-10-16，已接受。对应用户授权执行六项收尾：首页、真实执行视觉、公共页面、异常路径、同包回归、真机及交付。

## 决定

- 首页主题状态提升到Studio导航宿主的可保存状态，跨页和Activity恢复保留；只保存主题名，不写项目或脚本配置。小视口按字号预算分配标题、Logo、演示和主题区；空间不足时缩为三行演示，极小视口允许滚动而不裁掉操作。
- 首页时钟状态仅在绘制和演示子组件读取，不让整个页面随帧重组；监听系统动画比例和省电变化，暂停及离页停止推进。固定资源、Logo几何和无业务访问边界不变。
- 真实积木高亮仍只消费既有经过/当前位置和暂停快照；用不同颜色区分执行、刚经过、暂停下一步，入场动效有限，不新增轮询、运行延时或保证绘制每个高速节点。编辑选择、日志和执行身份仍分开。
- 公共面板按实际Compose字号计算顶部/底部高度，原生窗口边界显式保留调用方Density，不重置自定义字体比例；空项目与无匹配状态使用相同紧凑排版及明确操作，不为装饰添加入口。
- 编辑观察窗按对象身份幂等注册/注销，迟到注销不得重复关闭已转交或已清理窗口；窗口故障按会话合并一次报告，注册失败准确返回失败并清理所属窗口。悬浮授权失败不绕过授权，不清用户草稿。
- 第5项仅在明确MuMu实例上使用自有合成工程，最终同一候选包集中复验，旧结果不替代新结果。临时QA键盘仅在已有用户授权及finally恢复机制下使用。
- 第6项隔离构建arm64候选。没有明确连接的真机/API24设备时保留未验收，不能以模拟器或构建成功代替；正式签名及发布仍需另行确认。

## 不变范围

项目格式、包名、协议、生产模型、默认full、Runner及下载器延期、用户数据和Logo轮廓均不变。不运行私人脚本或自动撤销系统权限，不为验收主动杀系统进程。

## 验证

主机测试分别覆盖首页布局/主题恢复、执行样式映射及窗口幂等/故障合并；页面和完整工作流分别记录实际结果，测试中断明确保留原始失败。手机候选与开发包输出和Gradle缓存隔离，交付说明保留OCR歧义和未覆盖设备边界。

## 2026年10月20日提示层级补充

编辑错误与确认提示使用同一悬浮会话的优先显示规则。相同类型的原生窗口按首次附着排序，Compose的zIndex不能调整不同窗口；因此提示存在时，后来注册的普通窗口暂候，关闭最后一个提示后按注册顺序显示。已经显示的背景窗保持附着，不dismiss/recreate，不改参数及草稿。提示自身的子选择窗继承提示身份；借用确认外观的找图测试、处理流水线和尺寸等配置明确作为普通窗口，不阻断其维护变量或后续配置入口。

原生预览与Compose弹窗共用这项会话规则，运行变量观察窗在提示期间暂隐。系统选择仍优先隐藏整个编辑会话，返回后恢复原顺序；会话关闭清理待显示窗口并拒绝迟到回调。积木参数窗不得绕过共享宿主，编辑根错误在工具与参数窗之后声明。本次不更改脚本运行提示的位置、时长和停止清理，也不申请更高窗口权限、覆盖系统安全窗口或引入周期置顶任务。

## 2026年10月21日加入完成策略（替代通用连续加入反馈）

按用户接受的判断，不强迫所有参数面板连续加入。调试、循环、跳转等参数窗在真正加入草稿后关闭，复用现有节点选择与滚动定位；选位置、取消或校验失败不提前关闭，不清空输入。请求携带原表单完成票据，只有实际提交路径触发一次；销毁表单撤销票据，迟到完成不能关闭重新打开的表单。

函数库保持列表、搜索与分类，供继续挑选；各单项配置成功后关闭。图片处理工作台保留原处理预览及状态，加入流水线配置在位置选择期间仅隐藏原生窗口，不销毁参数，取消可原样返回。底部编辑操作窗继续支持重复复制、粘贴、移动、撤销，不随单次操作关闭。

删除上一轮专用“加入成功”TextView浮层及其计时/宿主接线，不再增加通用成功弹窗。既有状态栏和工作台整批状态仍只表示草稿操作，不冒充磁盘保存。共享错误/确认优先级、系统选择暂隐、脚本运行提示和运行变量观察窗均不变；不改数据格式、能力或运行协议。

### 编辑、图像与异常三项复验补强

普通参数配置及位置选择也绑定原插件、完整草稿和选择集合；提交前复核当前运行/编辑状态与所需能力，不因切插件、后台状态变化或变量重命名将旧请求加入新位置。拒绝时不改变草稿、选择或撤销栈，保留表单供用户检查并返回重开。维护变量仅新增声明且未改变原草稿时仍可正常继续。普通单块前插与定位作为一次既有批量插入事务，不留下需要两次撤销的中间位置。图像整批编译、来源及取消约束继续保持，不修改协议或默认模型。

图像加入只在有界子任务内准备/编译，成功回到仍活动的所属协程后复核上下文并一次提交；子任务超时返回失败，不能与实时草稿提交竞态。真正的所属任务取消仍向上传播，不转换为普通超时。成功选中组合第一行以复用现有定位，不增加运行延时或日志。变量维护中的计算表单不在异步保存受理时销毁，失败保留公式；计算另加不丢弃其他尚未提交的父参数窗。

终止状态先完成所属运行的日志队列封口、冻结身份及前台状态清理，再向监听者发布；监听者收到终止后立即准备新运行，不得被上一轮通知尾部清空。仅调整既有通知顺序，不等待磁盘写完、不让停止控制进入普通队列，也不改协议或放宽日志背压预算。

### 2026年10月22日旧版 Android 键盘与短视口补充

远程 ARM/API25 实测中，原生窗口在键盘显示时可能保持完整高度，只更新窗口局部底部 inset。
共享弹窗在 API24–29 使用 resize 策略，并从本窗口的实际内容位置计算仍被遮挡的部分，
只收缩内容并消费对应 inset，避免已经缩小的窗口再次扣减。布局监听随所属视图注册和清理，
不靠关闭键盘、轮询置顶或修改系统输入法来修复。API30 及以上保留原有窗口策略。

字库制作在短视口将名称和说明纳入内容滚动，返回、保存及其他操作保留单行可横向滚动底栏；
变量管理将作用域、搜索和列头纳入同一虚拟化列表，避免固定工具区挤掉列表及保存/取消。
图像识别配置同样按实际剩余高度约束；短视口把来源、分类及等待快捷入口纳入内容滚动，
仅标题和确认/取消固定，避免截图返回后键盘挤掉全部参数。常规高度仍保留固定分类，
切换布局不重建参数、分类或滚动状态，不以隐藏键盘代替可操作性。
数据、草稿、全屏切换、能力、模型和运行协议不变。键盘验收必须实际输入及点击，
按钮仅处于屏幕范围内不等于没有被键盘遮挡；临时 QA 键盘在 finally 恢复原输入法并停用。
