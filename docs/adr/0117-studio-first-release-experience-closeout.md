# ADR 0117 Studio首版体验与异常路径收尾

2026-10-16，已接受。对应用户授权执行六项收尾：首页、真实执行视觉、公共页面、异常路径、同包回归、真机及交付。

## 决定

- 首页主题状态提升到Studio导航宿主的可保存状态，跨页和Activity恢复保留；只保存主题名，不写项目或脚本配置。小视口按字号预算分配标题、Logo、演示和主题区；空间不足时缩为三行演示，极小视口允许滚动而不裁掉操作。
- 首页时钟状态仅在绘制和演示子组件读取，不让整个页面随帧重组；监听系统动画比例和省电变化，暂停及离页停止推进。固定资源、Logo几何和无业务访问边界不变。
- 真实积木高亮仍只消费既有经过/当前位置和暂停快照；用不同颜色区分执行、刚经过、暂停下一步，入场动效有限，不新增轮询、运行延时或保证绘制每个高速节点。编辑选择、日志和执行身份仍分开。
- 公共面板按实际Compose字号计算顶部/底部高度，原生窗口边界显式保留调用方Density，不重置自定义字体比例；空项目与无匹配状态使用相同紧凑排版及明确操作，不为装饰添加入口。
- 编辑观察窗按对象身份幂等注册/注销，迟到注销不得重复关闭已转交或已清理窗口；窗口故障按会话合并一次报告，注册失败准确返回失败并清理所属窗口。悬浮授权失败不绕过授权，不清用户草稿。
- 第5项仅在明确MuMu实例上使用自有合成工程，最终同一候选包集中复验，旧结果不替代新结果。临时QA键盘仅在已有用户授权及finally恢复机制下使用。
- 第6项隔离构建arm64候选。没有明确连接的真机/API24设备时保留未验收，不能以模拟器或构建成功代替；正式签名及发布仍需另行确认。

## 不变范围

项目格式、包名、协议、生产模型、默认full、Runner及下载器延期、用户数据和Logo轮廓均不变。不运行私人脚本或自动撤销系统权限，不为验收主动杀系统进程。

## 验证

主机测试分别覆盖首页布局/主题恢复、执行样式映射及窗口幂等/故障合并；页面和完整工作流分别记录实际结果，测试中断明确保留原始失败。手机候选与开发包输出和Gradle缓存隔离，交付说明保留OCR歧义和未覆盖设备边界。
