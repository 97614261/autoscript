# ADR0142：常驻点击、固定输入诊断与虚拟系统收尾

日期：2026-10-22。状态：已实施，有限验收及残余边界见[执行账](../verification/studio-input-memory-closeout-2026-10-22.md)。

## 决定

用户要求执行后续1、2、3、4、6，第5项以现有ARM虚拟系统验收即可。本批不再以宿主原生/API24验收作为完成前提，但不得把API25虚拟Android记录为原生/API24通过。

普通Tap在常驻ASI2桥已存在且无活动触点时复用该桥，严格顺序发送DOWN和UP。开始前记录不确定触点，只有UP获确认才清除。取消在两个事件前检查；失败不重放、不转Shell补点，优先停止/断线清理仍负责释放不确定触点，清理失败继续禁输入。桥在操作开始前不可用时才使用原有有界系统input路径；不扩大输入命令白名单。

协议3新增可协商的INPUT_FAILURE_DETAILS位，失败载荷只含固定u32原因；旧客户端仍接收空载荷。诊断不包含坐标、命令、进程原始输出或项目内容。客户端只在协商后接受原因，JNI映射稳定代码而非格式化任意传输错误。

截图热路径仅调整有界复用缓冲中的BGRA编码，不直接传Bitmap原始存储（避免步幅、预乘Alpha及字节序改变语义），不复用旧屏冒充新采集。性能比较须包含实际输入导致的缓存失效。

内存按任务/帧/缓冲/队列所有权及长跑样本查证；PSS增长本身既不是泄漏证明，也不是无泄漏证明。增加有界内容无关计数和重复长跑，不通过强制GC、清数据或定期重启掩盖增长。

检查发现定时器的惰性堆项可在反复取消长定时器时积累。新增/取消时，当堆超过活动定时器两倍加64项时从实际记录压实；不改变活动截止时间、暂停及回调语义。截图短缓存只查询最新一帧，容量缩为1；任务持有帧/系列仍由原FramePool及租约管理。此两项不被当作上一轮PSS增长的已证实根因。

固定字库完善数字/大小写覆盖及显式校对流程；ASGLYPH v1、256样本/2MiB、13状态/8MiB历史预算不变。期望文字只评分、不参与识别；不更换默认full/V4或暗改生产识别策略。

交付冻结实际候选摘要、验签及设备结果；不自动发布线上、不自动删除下载历史。失败、复测、虚拟系统及不可得内存指标单独披露。

## 验证要求

- Tap顺序、DOWN/UP失败、两处取消、无失败重放；协议新旧协商及非法载荷拒绝。
- BGRA编码逐字节等价（含透明及非整块末尾）、缓冲预算与复用。
- 字库覆盖/显式标注、缺字/歧义与待标注数据保留。
- 当前ARM虚拟系统和MuMu自有QA，长跑、停止清理与新帧性能；不操作私人脚本或更换默认输入法。
