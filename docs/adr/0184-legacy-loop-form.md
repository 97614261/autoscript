# ADR 0184: 参考老版的循环表单

日期：2026-10-29

用户要求参考老版。核对易编的`service_tk_xh.xml`默认及v22布局、对应字符串，和旧一键玩`guagua_insert_cycle.xml`、`insertCycle.java`及`configCycle.java`。易编采用固定值/变量来源切换、左侧单选与右侧字段常驻五行、30dp控件和等分取消/加入；一键玩的八行同时包含等待和超次/超时。仅参考可见布局与交互，不推断未反编译的Native执行行为。

- 常用五行直接展示无限、限次、限时、读取次数及读取耗时，右侧参数持续可见，不再用类型分页切换正文、重复摘要或一排常用值按钮。
- 顶部只切固定值/变量，使用既有来源标记，切换保留数值和变量名；变量仍需选取已声明且类型/作用域正确的项。点击字段的常用/变量选择或编辑数值时对应行被选中，锁定编辑的其他类型只读。
- 30dp输入与单位同排，左列统一对齐，不铺满选中背景；窄窗/大字号改上下排列并保留有界滚动。单位选择仍在同窗展开，避免原生Popup层级穿透。
- 等待、到次跳出、到时跳出保留同窗选择入口。选择区打开时收起原参数但不清草稿，确认栏变为返回以防误加入；附加操作可回到常用循环。
- 输出、让步及旧安全次数配置保留高级入口和已配置自动展开。底部参考老版用两个等分文字按钮与分隔线。

删除本批已弃用的类型分页、数值快捷按钮排及重复输入控件。原解析、参数构建、变量类型/作用域、草稿、插入和执行语义保持。仅必要Release编译及原x86_64优化候选构建、压实/必要包检查后保数据安装MuMu 0；不重跑整套测试、不提交积木或运行项目、不连接真机、不升版或发布。实际结果另记。

Release生产编译、原x86_64优化构建、packageRelease压实和必要包检查通过，未重跑未改的模型测试。候选仍0.1.30/versionCode31、51831566字节、SHA256 `67c362478202ab8be3e48462a3f21b8a2421973474b41db70f9fb26603b8f096`。原函数保数据覆盖MuMu 0、首次安装时间保留，冷启动Status ok/402ms、进程8190。1280×720横屏确认固定值/变量模式的五行及底栏完整，切回固定值时原次数与时长仍为3；附加三项同窗完整，返回保留原配置，最终留常用表单。

证据在忽略的`build/adr0184-*`构建/安装日志和界面截图，最终预览仅保留弹窗。未提交积木、运行项目脚本、连真机、升版或上线；有限查看不代表全部变量选择、真实键盘、大字号或其他设备验收。
