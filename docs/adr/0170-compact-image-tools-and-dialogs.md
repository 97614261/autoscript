# ADR 0170：图像便捷操作与横屏紧凑弹窗

日期：2026-10-27

## 决定

普通弹窗以实际可用窗口宽度为边界，不按横屏比例拉伸。共享表单默认400dp，确认框360dp；简单触控及图片保存采用360–380dp，复杂图像、变量及项目设置采用400–420dp，双栏函数库保留520dp。窄窗口留出边距并自然收缩，显式全屏仍使用全部可用视口。修正流程配置先填满宽度再限宽导致上限无效的问题。

流程配置、图片识别测试及函数详情补齐实际可用高度与键盘约束。延续ADR0117的原生宿主、窗口层级、输入焦点和局部IME避让，不改变草稿、关闭确认、保存回执、加入位置或会话所有权。确认框在短视口使用更紧凑的标题及操作区；内容滚动，提交仍独立。

图像菜单记住本机上次分类；四个常用入口、功能卡片和坐标输入按实际宽度及字号选择列数。图像工作台上下工具条、制字类别及操作条、多色颜色块、找图算法和取字方式可换行，不要求手动拉宽。长工具区有高度预算并允许纵向滚动，画布及固定返回仍保留。替代ADR0117中制字底栏必须单行横向滚动的旧排版决定，不改变其动作及数据语义。

识别参数的容差、相似度、最低置信度、频次和数量上限提供点击标签选择常用数值，仍可手输，沿原完整校验提交；不自动选择阈值、不修改其他参数、不更换识别算法。处理图找图及OCR使用受控紧凑输入，修改参数仍作废测试证明。

滤色窗按可用高度缩小预览；短视口将预览及说明纳入内容滚动，保留应用/取消。滤色预览显式裁剪到自身画布，不能绘制到按钮区域。所有识别来源、颜色组、删除与引用查询、方案操作继续保留；像素数据、资源事务、预算、截图/释放和项目协议不变。

## 验证边界

50项定向主机检查通过：面板几何11、键盘8、层级4、识别参数15、图片保存8及色组4。几何覆盖横屏不伸宽、窄窗口边距和大字体换行，数值快捷测试通过原参数解析并检查模板及范围未变。Studio Release生产/测试Kotlin编译、Release Lint及diff空白检查通过。

首轮三处Compose嵌套作用域高度读取编译失败，外层捕获预算后修正；第二轮新增测试误将资源列表传到插件列表参数，修正后原定检查通过。失败日志保留，最终日志为`build/compact-image-dialog-checks-complete.log`。

本批不升版本、不生成Studio安装包、不安装、发布或连接设备；既有独立Runner构建依赖为UP-TO-DATE。主机布局规则检查不代表手机上所有窗口及输入法的视觉验收。
