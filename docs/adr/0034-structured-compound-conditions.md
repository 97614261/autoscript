# ADR0034：有界复合判断

日期：2026-10-03。接受。用户确认补全原生判断能力。

control.if v1继续原有单比较；v2可附加condition树（compare/all/any/not），有condition时使用树而不是兼容的单比较字段。否则如果同样支持树，首个成立分支独占执行。旧节点无树的无损升级保持行为。

每棵树最多64节点、8层、8192字节；all/any非空。叶子只能比较变量与JSON标量或变量，名字、运算符、字段白名单校验；未知结构拒绝。Lua只由编译器生成，and/or短路；主判断求值一次后同时用于调试事件及分支。编辑器使用树形操作而非要求用户填写表达式/JSON。新增能力不证明旧Native解释器的未知表达式等价；转换器只有确认的结构才迁移。
