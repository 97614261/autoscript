# ADR 0197: AI 助手第一版

日期：2026-10-30

用户确认第一版完整范围：兼容模型配置、文字生成、选中修改、解释和排错、预览确认与撤销、取消超时重试及紧凑布局。实现归 Studio，不扩展 Runner 或 Rust 运行能力。

- 从正式可视化编辑器右侧 AI 打开，冻结当前插件、所有草稿、选择、分支、项目清单与资源版本、运行会话及执行修订。执行修订在客户端发布前记录连接/会话/引擎变化，防止快速运行后返回空闲被StateFlow合并漏掉；普通Root/诊断刷新不作废方案。异步请求和校验完成后均复核；确认时再核对正式项目，不覆盖后续修改，不自动保存或执行。
- 模型仅返回受限 JSON 方案。目录选择和生成分两步，只有当前已声明能力允许的现行函数可选；函数参数源于既有生成目录，不另建 API 真相。图片/字库仅发送声明路径，不上传像素；上下文不带运行变量值、截图或任意文件。发送按钮明确说明数据范围。
- 生成支持选前/选后/指定分支/插件末尾；改参限定所选子树，整段替换限定同层连续根。生成节点经原剪贴板重映射与项目全局数字高水位分配，预览只改隔离草稿；最终使用原完整编译校验和草稿事务，单次可撤销。解释/排错模式拒绝任何修改，缺少资源时阻止应用。
- 配置包含接口地址、密钥、模型名及两种输出上限字段。使用系统 HTTPS 和证书校验，HTTP 仅限本机回环调试；拒绝内嵌账号、查询参数与跳转，不把密钥发送到新地址。配置用 Android Keystore AES-GCM 加密保存在 App 私有偏好，不进入项目导出、普通日志或 Android 备份，不内置任何模型密钥。
- 兼容非流式聊天补全协议。单次网络90秒、两步生成150秒，连接12秒；最多2条清理中连接，无排队堆积；取消主动断开连接。请求384KiB、响应512KiB、方案128KiB、当前插件96KiB、最近四轮历史96KiB、256积木/16层；JSON先做深度、字段重复与严格语法检查。HTTP错误只展示分类信息，不显示服务端原始错误或认证内容。
- UI复用紧凑面板、固定底栏与滚动正文，生成不自动聚焦搜索框。配置、引用、插入分支、前后预览、取消、关闭确认和失败重试均有实际入口。

官方 API 文档在本机访问受到403/传输中断限制；本版按兼容聊天补全协议实现，以本地独立服务验证请求/响应与取消，不将其当真实付费模型质量验收。用户尚未提供模型服务配置，不自动读取其他工具凭据或发送项目到第三方。
