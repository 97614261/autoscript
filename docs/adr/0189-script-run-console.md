# ADR 0189: 脚本运行日志

日期：2026-10-29

用户指出日志偏向 App 状态，要求正常执行和错误都能看到，并参考老版简化界面。

## 对照与范围

对照易编精灵的 FloatSuspension、ConsoleLogRecyclerView、hv 和 bv：老版将带时间的文字放进有界队列，批量刷新列表，使用较小字号/间距，支持跟随、滚动和查看原文。该代码不能证明老版自动记录了每一条积木。

现有 Studio 的实时记录主要是 Runner、Root 和引擎状态，主动脚本输出走另一个前缀；真实逐积木观测原先只进 events.jsonl。只改变筛选不足以补齐运行记录。

## 实现

- 接受运行后记录开始，实际状态变化记录暂停、继续、停止、完成和失败；未运行或单独 Root 状态变化不产生虚构脚本事件。短单步再次回到暂停仍记录单步完成。终止时先排空输出/观测，再追加结束记录并封口，保留原停止和发布顺序。
- 生命周期复用 script.log，有界实时列表同时显示。错误文件记录仅写既有白名单错误码；完整临时诊断仍沿原诊断来源查看，不自动记录源码、变量值或模板路径。
- 可选逐积木追踪开启后，把真实结构化进入事件投影到实时列表；失败任务和真实丢失计数同样投影。沿用原追踪开关，不根据高亮采样补造历史。格式不符及不合规身份不用于生成记录。
- 历史脚本视图将脚本文件和原事件文件中的追踪/失败/丢失记录按实际接收时间合并，重复输出保留；观测原文和性能统计仍独立可达。没有追踪的旧日志不补造积木过程。
- 默认只保留实时/历史及全部、输出、错误筛选；内部诊断、观测原文、性能统计和记录设置放更多。列表收紧为时间、类型、正文，点行查看/复制原文。保留手动暂停跟随、搜索、导出、确认清理、真实身份定位及原项目归属保护。

本轮不升版、不发布线上，不连接真机或运行私人项目。必要定向检查及有限 MuMu 查看结果另记。
