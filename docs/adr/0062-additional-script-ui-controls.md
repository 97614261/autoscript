# ADR 0062：扩展脚本界面控件

## 决定

新增开关、密码、小数、多选列表四类真实控件，接通设计、持久化、共享 View 渲染、脚本读写及独立 Runner 校验，不用标签模拟控件。

开关沿用 boolean，密码沿用 text。密码仅提供输入掩码，不是加密存储；默认值不得填写真实密码，运行值不得进入普通日志。旧控件和值语义保持不变。

小数需使用有限数值及 number 绑定，不能静默转换为整数或文本。多选需使用有界字符串数组，保留选项标点，不用逗号切分；新增类型须同步 Android、Rust、schema 和运行事件边界后才能交付。

小数使用v2的number/DECIMAL，值为有限浮点数，范围不超过正负十亿，沿用整数范围边界字段；范围边界暂不支持小数。仅允许number变量、number入口/事件参数。多选使用v2的multiChoice/MULTISELECT，正式默认值为JSON字符串数组，最多64项，选项唯一且来自声明列表；必填至少一项。运行读写、事件和STRING变量绑定使用该数组的JSON文本，最多2048字符；不新增隐式数组变量，不改变旧单选。更新选项保留仍存在的选择，必填无剩余项时选择首项。超过预算拒绝而不截断。

独立Runner解析、配置记忆、Lua初始化和发布摘要同步支持新类型；新增number摘要使用规范IEEE754位模式的16位十六进制（正负零统一），multiChoice摘要使用规范JSON数组文本，避免小数打印格式或转义差异。旧发布摘要路径不变。

## 实施边界

先接通沿用既有值类型的开关和密码；小数、多选在跨语言契约回归完成前不开放占位入口。无新依赖，控件、事件及资源预算不扩大。密码画布只显示掩码。
