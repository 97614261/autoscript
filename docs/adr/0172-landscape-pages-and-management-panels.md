# ADR 0172：横屏主页面与管理面板

日期：2026-10-27

## 决定

在ADR0170/0171触控及图像紧凑界面的基础上，整理其余常用页面。宽且短的横屏主窗口把三个导航入口移至64dp侧栏，竖屏、窄窗及大字号仍使用原底栏；导航身份、启动遮罩、全屏编辑隐藏导航和返回行为保持不变。项目页空间足够时合并工具与搜索排序，其他窗口仍自动分行；项目展开和操作顺序不变。我的设置分区在足够宽的短窗口中并排，保留原入口。

项目设置缩小固定标题、标签及操作条，重新读取移至标题区；资源导入/筛选、能力批量操作和运行界面预览与对应列表共同滚动。长状态提示独立限高滚动，不挤占全部配置区。能力选项根据字号选择一或两列，行高允许随文字增长。运行设置的选择项复用图像选择器提取出的通用控件，长列表可搜索，存储键值和确认流程不变，不自动聚焦。

日志及插件文件窗口按共享面板实际剩余高度约束正文，不使用键盘出现前的高度强撑窗口。多段工具区共用高度预算，工具自动换行并在本区域内滚动；列表、全文详情、全屏及原来的记录/清理/导出操作保留。运行变量的筛选及工具有界滚动，表格仍读取原会话和采样状态，保留拖动标题与关闭。插件管理自动选择一或两列，禁止的模板入口及一次提交限制不变。

源码窗口换行展示小操作按钮，说明按需展开；快速选择行的搜索与列表共用可用空间。共用搜索框允许大字号增加行高，不使用填满正文的装饰层。本地备份说明随槽位列表滚动，压缩进度条和卡片空白；运行错误详情改为一层正文滚动，复制和关闭不随错误文本滚走。

不改变项目数据、草稿、身份、资源和保存事务、撤销、Root/input安全、运行提示生命周期或备份加密。只做定向主机检查、Kotlin编译与Lint；不升版、生成Studio安装包、连接或安装设备、发布线上。主机检查不代表横屏或真实键盘视觉效果已经设备验收。

## 验证

64项定向主机检查通过：窗口几何13、键盘边界8、导航4、入口模型11、项目设置草稿9、插件管理3、运行变量观察9、日志过滤4、记录设置草稿3。覆盖宽短窗口/大字号切换、无效尺寸拒绝、多个工具区的总预算，以及已有导航、草稿、变量和日志规则。

Studio Debug/Release生产Kotlin编译、Release测试Kotlin编译及Release Lint通过，Lint保留已有警告，不宣称零警告。首轮集中编译发现设置正文缺少实验布局注解，以及运行变量嵌套Compose作用域隐式读取高度的问题；修正后同组通过，保留首轮失败日志`build/landscape-ui-checks.log`及成功日志`build/landscape-ui-checks-final.log`。收尾的状态提示预算和顶栏宽度调整完成增量Debug/Release编译及Release Lint，日志为`build/landscape-ui-checks-incremental.log`；diff空白检查通过。

检查中的原Runner Release模板构建依赖为UP-TO-DATE；未生成本轮Studio安装包或升版，线上仍0.1.24。未连接/安装设备、操作私人脚本或发布服务器。
