# ADR 0065：控件内容适配

状态：接受，2026-10-11。

设计器提供当前会话的智能尺寸开关及显式适应内容。只在显示文字、选项或字号改变时增大控件，不在加载旧设计时改布局；与内容编辑一并撤销，正式保存复用原校验。不新增协议字段。增大受页面、容器与同级控件限制，不移动邻居、不自动修复已有重叠。

单选横排同时检查高度与实测文字宽度。空间不足转为多行纵排及内部滚动；列表、多选与下拉条目换行。动态选项不扩大保存矩形或修改项目，保持选择与事件语义。

控件默认宽高与字号由共享设计像素尺寸表提供（208×40、20px字）。开关轨道28×16、滑块12、选择标记18、滑条/进度轨道8、滑条手柄16，随画布等比缩放，不继承Android主题的dp尺寸。传统View渲染与设计器预览使用相同尺寸；列表去除系统分隔及额外留白，内容适配采用对应预留宽度。此规则只修改绘制与新增默认值，不批量调整已保存矩形，不修改控件值、事件或旧版表单。
