# ADR 0072：有界图像变换、保存与结构化识别结果

2026-10-11，用户要求补完函数库第四、第五批，暂不安装MuMu。

图像变换仅对任务已持有的不可变帧进行90/180/270度旋转、横纵镜像、灰度和最近邻缩放，输出独立任务帧；单图最多4194304像素，逐行检查取消，源帧不变，仍受帧池总预算约束。不把缩放后的图片冒充原像素截图。

显式PNG保存读取已持有帧，使用设备原像素，不自动截图或缩放。PNG编码采用有界safe Rust实现，宿主仅将编码内容原子保存到当前项目私有data；需要storage.data，拒绝覆盖目标，单文件最多20MiB、项目总量64MiB，原文本读取/写入仍保持64KiB上限。PNG保存不进入高频取帧路径，不向脚本暴露任意路径。

文本文件及文本回收记录保持既有512KiB配额，PNG另受64MiB总预算约束；按内容签名识别二进制，不以扩展名放宽文本配额。

字库详细结果包括逐字文字、半开矩形、分数和是否识别；文本查找只读取已有结构化结果，不重复OCR、不要求无关截图能力、不跨行或跨未识别字形拼接命中。命中边界包含全部中间字形，不仅首尾。结果最多65536字节，超出明确失败。

批量多点找色保持相对色点语义，返回有界坐标JSON；连通块支持4/8邻接，返回面积及半开矩形，不把像素计数当色块。ROI最多4194304像素、最多256结果、比较预算与取消均显式执行。OpenCV继续只做灰度、ONNX继续只做单行字母数字，不扩大算法或中文OCR范围。

宿主文件写入继续使用会话票据、取消检查及提交锁，不让迟到结果污染新运行；可视化入口、受限源码、契约及函数说明必须同时接通，不能只供旧工程转换器使用。
