# ADR 0195: 分支独立折叠

日期：2026-10-29

用户要求满足/失败等分支支持折叠。

- 满足、否则如果、否则、成功、失败标题前增加独立展开箭头，折叠后显示所含真实积木数量。标题仍选择加入位置；空分支保留原入口，不提供无效折叠。
- 以插件内父节点与分支槽标识保存视图状态，主树和多选窗共用，嵌套分支互不影响。父节点收起再展开仍保留各分支状态，展开全部同时清除两类折叠。
- 手动折叠内含当前选择的分支，将主选择移到该分支锚点；运行时手动折叠退出跟随。恢复跟随、显式定位和搜索只沿原入口展开所需层级，过期分支状态随真实程序更新清理。
- 只过滤展示投影，不更改节点/源码/执行顺序、保存/撤销或选位事务；保持ADR0194的单条最近分组细线。

仅必要定向检查、原x86_64优化候选及MuMu0保数据有限查看，不运行脚本、不连真机、不升版上线。实际结果另记。
