# ADR 0030：兼容能力同时面向智构原生编辑

状态：采纳。日期：2026-10-03。

用户明确：补能力，并且智构也能原生使用。能力通过正常可视化配置、函数库说明、版本兼容的节点、编译器和冻结Lua交付；独立转换器只消费这些能力，不成为运行依赖。

第一批复用 `variable.calculate` v1 的有界表达式契约，新增白名单 `byteLen(string)`、`byteFind(string,string,integer)`、`byteSub(string,integer,integer)`、`idiv(integer,integer)`、`irem(integer,integer)`。函数名和参数经过解析/类型检查，不把用户表达式直接拼成可执行Lua。无新依赖、宿主请求或权限，不新增JNI接口；生成的纯Lua辅助实现随冻结脚本供Studio与Runner共用。旧编译器遇到新增函数应拒绝，不静默降级。

`byteLen` 返回UTF-8字节数；`byteFind` 第三参数从0开始，按字节作字面查找，未找到返回-1，空查找串返回有效起点，起点超字符串尾返回-1。起点限0..4096。`byteSub` 起点0..字节长度，长度0..4096，末尾自动截短；结果必须是完整UTF-8，否则报错，不制造损坏文本。各字符串最多4096字节。

`idiv` 向零截断整数除法；`irem` 余数与被除数同号。使用64位整数，不经过浮点转换。除零及最小整数除以/取余-1拒绝，避免溢出。既有 `/` 浮点除法、`//` 向下整除、`%` 余数，以及 `len/sub/find` 的字符数、1起点、未找到0的语义不变。

变量计算弹窗提供字符/字节处理及整数运算选项；函数库的真实变量计算条目提供签名、示例和边界说明；继续复用同一加入与修改面板、变量作用域和改名保护，不增加无实现的Lua API。

旧源码的 `.Length()`/`.字符长度()` 可按公开的UTF-8字节长度契约降低成 `byteLen`。旧Mid/Find等未确认边界或副作用的行为不自动等价迁移；尤其不能因新增安全字节截取而宣称支持旧任意二进制截取。其他循环、调用、视觉和界面阶段仍需逐批实现和验证。
