# ADR 0018：可视化编辑器底部操作与执行禁用

状态：接受（2026-09-30，用户要求完成底部操作对齐 1–5）。

## 决策

- 两个可视化入口共享底部按钮与操作状态；运行、暂停、停止过程中不允许修改程序树。
- 参数反显恢复所选积木参数，不读取运行变量快照。支持修改原节点或复用新增；修改保留节点身份和子树。运行变量回填继续保留在调试检查页。
- 删除需要确认选中根节点及其子树，确认期间程序或选择变化则取消。
- 节点信封增加可选 `disabled: boolean`，省略等同 false。保持 kind、nodeId、flowId 和原参数不变。禁用容器包括整个子树；编译时排除有效禁用节点，仍校验文档结构。文字说明独立保留。
- 单步使用现有 Lua 检查点。2026-09-30 单步修订：首次点击从插件入口正常执行到所选节点，并执行该节点，停在下一个实际到达的检查点；后续一次点击推进至下一个检查点。前置操作和初始化不会被跳过，因此显示“前置步骤会执行”。保留不执行目标的运行至检查点模式用于测试，不以字符串裁剪 Lua 跳过上下文。容器的一步是进入循环/判断后的下一个检查点，不宣称一次运行整棵子树。最后一步正常结束；未到达所选节点则正常结束。
- 暂停位置独立于编辑选择，显示“下一步”高亮并滚动到可见位置；使用状态事件序号按暂停事件读取一次有界调试快照，禁止定时轮询。快速步骤也必须发布运行→暂停反馈，连续点击和跨项目会话不能推进错误任务。继续取消单步，停止保留优先控制通道。
- Runner 不引入 Flow 编译器依赖；上述调试设置仅修改 Studio 已校验冻结 Lua 的运行副本，不改磁盘生成物。
- “显示界面”接入项目界面预览；不存在界面时明确提示，不冒充最小化。变量检查、查找替换和变量信息保留真实入口；运行中仍可只读检查。录制缺少 Runtime 事件流，明确标为未接入并禁用，不以预览控制冒充真实录制。

## 兼容性与验证

旧文档缺少 disabled 时行为不变，新文档不删除任何节点；复制、撤销、恢复和保存保留该标记。旧严格解析器不会理解新字段，因此发布需同步 Studio/编译器，Runner 只读取冻结 Lua。验证禁用子树、标签引用、撤销、反显写回与选中检查点；使用 build.cmd -Verify 验证并安装 MuMu。
