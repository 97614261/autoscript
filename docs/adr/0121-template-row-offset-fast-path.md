# ADR 0121：模板匹配行偏移快路径

状态：接受（2026-10-17，识图性能第五阶段）。

## 决定

在精确模板比较的行跨度路径中，候选起点的第一行偏移只计算一次，后续行按已
校验的 `row_stride` 递增。该变化不改变候选顺序、透明像素、容差、相似度、
预算消耗或取消检查点。

同时保留 32 像素整数比较作为测试候选，不接入生产：固定主机样本的 P95/P99
没有稳定优于现有字节比较，且部分场景更慢。

## 原因

找图失败或靠后命中时，行偏移计算会在大量候选上重复执行。把乘法移到候选
开始处是低风险的确定性优化；使用已经通过图像几何校验的行跨度，不需要额外
帧副本或不安全代码。

## 限制

- 这只是 Rust CPU 匹配微优化，不包含 Root 截图、JNI、Bitmap 或传输时间。
- 固定主机矩阵没有证明端到端设备延迟下降，设备收益仍需单独测量。
- 任何新的字节/整数比较替代都必须先有交错基准和完整预算/取消等价回归。
