# ADR 0203: 多边形搜索范围

日期：2026-11-04

用户要求框选、找色和找图支持多边形。本批只开发并做主机检查，不安装设备、升版、发布或提交 Git。

## 范围与交互

- 接入区域找色、颜色计数、全部找色、多点找色、普通找图和多结果找图。矩形保持默认；灰度、多尺度、特征匹配和 OCR 暂不接入多边形搜索。
- 复用原顶点编辑器，明确区分搜索范围与图像处理蒙版。支持添加、拖动、删除顶点，整体移动、视图缩放、撤销重做、清空、确认与放弃保护。识别表单显示顶点数，可重新调整或改回矩形。
- 选区保留截图原坐标，随积木参数保存并可回填；选区返回不重置阈值和输出变量，也不被模板默认范围覆盖。切换为固定矩形清除多边形，屏幕选区清除动态范围变量。旧选区超出当前截图时明确提示重新选择，不静默缩放。
- 拾取状态聚合为项目级记忆对象，维持原表单草稿生命期；图像弹窗放入独立组合组，解决编辑器 Compose 方法超过 JVM 64 KiB 上限，插入事务仍由父级编辑会话持有。

## 协议与执行

- 六类积木新增可选 `polygon` 文本，内容为 `[[x,y],...]` JSON；空值维持原调用。Lua 七个相关接口在末尾增加可选参数；找色、计数、全部找色仍保留其前一个备选色组位置。
- 3–128 个不同整数顶点，坐标 0–4096，必须在矩形 ROI 内；拒绝自交、非相邻边相接、重叠、零面积及不覆盖任何像素的选区。允许凹形与反向顶点顺序，像素中心的半开填充规则与原多边形蒙版一致。
- 找色仅比较内部像素，同一像素不因备选色组重复计数；多点找色检查全部偏移点；找图要求模板全部像素的矩形范围可被选区容纳，凹形缺口不能跨越。范围过滤先于结果数量限制，保持原搜索方向和多模板次序。
- 多边形按原扩展能力流程使用 runtimeApi 1.8；正式保存和未保存草稿都可提升，草稿校验不写项目。生成 Lua 检查 `Screen.polygonRegionVersion == 1`，旧组件明确拒绝，不静默退化成矩形。
- Runtime 仅缓存最多 8 份有界几何扫描行，不缓存图像。模板可落入的位置以扫描行交集预先计算，避免每个候选位置重复遍历整个模板高度；保留共享工作预算、取消、帧归属和越界找色警告。截图方式仍由原每次截图/共用图像配置决定。
