# ADR 0029：分阶段、有证据的旧工程转换

日期：2026-10-02。状态：实施。

用户要求详细核对并补全。保持ADR0027/0028的独立工具和失效封闭原则；按 docs/legacy-converter-completion-plan.md 分阶段落实，不能因旧Native反编译缺失而自行猜测功能。

将已确认的旧插件分组转换到现有 .studio/source-groups.json，图片目录转换到 .studio/image-directories.json，不把虚拟分组变成真实插件路径。原名字如不符合当前契约则稳定别名并保留报告，不能静默改写。重复归属/缺失插件应阻断，不能抢占第一条。

旧编辑器明确“运行跳过注释行”。仅无子节点且明确为代码解释的禁用记录转换成 task.comment，并在报告保存原字段；有子节点的禁用容器仍阻断，因为不能确认子树是否全部禁用。这不是将未知活跃操作转成空操作。

新增规则仅使用已存在的IR：字符串同类型连接映射为variable.calculate的连接运算；简单变量运行提示用valueVariable；变量限次用timesVariable。无限循环不得用现有固定上限伪装等价；限时、找图和返回状态必须明确旧行为再落地。

报告采用稳定类别，GUI支持按类别筛选及本地原始/转换节点对照。私人记录仅本地显示或私有报告，不进入常规日志。最终状态同时受未迁移项、编译和输入缺陷约束。

补充规则：`configPlugin.createPluginFile` 固定生成的两个空结果标记只有 `_显示` 且没有子步骤时，可转换为普通调用并在报告保留标记；有额外字段或执行子树仍阻断。循环尾也只剥离无附加动作的末尾标记。

字符串连接允许有界括号；比较的常量左值可在相同类型下交换两侧并反转关系运算符。复合逻辑和隐式强制转换不因此开放。

界面审计只读取并诊断，不代表迁移完成。根据 `myView`/`myUI` 记录旧控件、事件和当前UI契约缺口；完整原字段仅保存本地 `ui-audit.json`，日志仅使用固定特征键和数量。旧字符串 Length/Mid/Find 的字节及0起点语义与当前字符函数不同，不能按同名直接映射。
