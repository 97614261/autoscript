# ADR 0092：Studio 运行变量观察窗

日期：2026-10-13。状态：接受。用户要求完善老版运行变量观察体验。

## 决策

- 运行变量为 Studio 编辑会话所属的独立有界观察窗，不作为参数弹窗、不阻止编辑/运行/最小化；系统悬浮编辑使用同会话授权的非模态窗口，普通 App 内编辑使用 App 窗口，不额外申请悬浮权限。
- 每编辑会话最多一个观察窗；标题拖动、收起/展开、放大/还原、关闭。关闭编辑会话同时清理窗口和读取任务。选点、截图、系统选择时随所属会话隐藏，恢复后重新读取；最小化编辑器不隐藏观察窗。
- 全局/局部/变动筛选、变量名搜索、类型/名称/值紧凑表格及详情复制。局部默认跟随真实运行插件；可锁定插件，但执行进入其他插件时明确无法读取锁定插件当前局部值，不以初始值或旧值冒充。
- 运行中可见窗口最多每 500ms 发起一次串行快照读取；暂停/终止时读取一次并冻结，手动刷新明确发起新读取。收起或系统隐藏停止自动刷新，再展开立即读取。刷新不执行脚本、不写回初始值、变量值不进入普通日志。
- 沿用强类型快照、最多128变量/每值1024字符。UI 请求票据、项目、连接代次、状态修订及运行修订拒绝迟到结果。客户端加入单槽读取门闩，即使协程取消而 Binder 尚未返回也不得叠加读取。
- 变动表示观察期间相邻有效样本实际读到的类型/值/截断状态变化，不是每次赋值追踪。首次读取建立基线；全局跨插件比较，局部仅比较同插件相邻样本。新运行清空基线；保留当前可见变量的有界变动集合。截断内容相同不能证明完整值未变化。
- 不复制老版字符串消息解析、公共文件或50ms高频轮询，不修改 Runner、执行协议或 Lua 单线程模型；详细数据不可通过剪贴板自动输出，复制仅由用户明确点击。

## 后果

观察采样可能错过短暂值变化，界面必须说明采样及截断限制。关闭/隐藏观察不影响运行高亮、日志、脚本提示或脚本执行。真实跨 App 触摸、授权撤销和旋转需设备验收，不以本地测试代替。
