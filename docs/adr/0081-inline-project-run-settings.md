# ADR 0081：项目运行设置同页编辑与能力默认选择

2026-10-12，按用户最新决定，新建 Studio 可视化项目默认声明当前积木契约所需全部能力。由生成的 BlockCatalog 收集，不把 Root 就绪、系统授权或输入实测视为已完成；不自动启用随机化。已有项目不自动增加能力，设置保留其声明及未知能力，提供全选和清空，显式保存。

项目设置的运行页直接编辑启动延迟、用户提示总开关与自动分类、触摸/图像/等待随机化、提示弹窗样式，不再打开第二层配置窗。允许滚动，未完成数值输入保留为字符串；底部统一保存能力与运行设置，先完整校验和复核预期配置，再一次清单原子写入。关闭未保存内容需确认。资源和界面配置仍独立即时保存；日志追踪和识图统计仍归日志记录设置，右侧调试继续保留既有样式及延迟快捷入口。

删除已无引用的旧项目二级配置入口、静态调试环境布局及无入口的旧调试标题/开关。仍被积木参数编辑和日志调用的共享页面不得删除。旧项目及备份数据不迁移或清理。
