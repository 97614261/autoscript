# ADR 0071：帧/截图系列积木和脚本主动控制

2026-10-11，继续函数库第四、第五批。

裁剪复用 Screen.crop，源和输出均为已声明图像变量且不得同名。半开矩形采用源帧原像素，不使用设计坐标缩放；失败不替换源帧，任务资源预算、取消和结束清理沿用现有帧池。

连续截图复用 Screen.captureSeries，最多120帧、60秒、120FPS，帧池可提前拒绝超出最坏情况预算的请求。结果为有界JSON字符变量，保存帧句柄、纳秒时间戳、丢帧数和partial；提供取指定帧和显式释放全部帧积木。句柄只在采集任务内有效，不可当持久图片或跨任务使用；取帧是借用同一句柄，不能把系列和取出的帧各释放一次。停止/失败由任务资源清理兜底。

Task.stop 无返回，用既有调度优先停止机制结束整个运行，而非仅return当前插件；不得借普通业务队列绕过触点及认证清理。Log.setEnabled 只控制后续脚本Log输出，不影响诊断或识图统计；Prompt.setEnabled控制本次运行持续/短时提示，关闭清除当前提示和迟到显示，开启不重放旧提示、不覆盖冻结的项目总开关。开关不写回项目，不关闭UI对话框或运行控制球。

本记录不声称已完成清理后重启、脚本录制、音频、PNG持久保存、图片变换、逐字OCR或颜色连通块；这些继续按执行计划实现，不能以本批入口补强代替。
