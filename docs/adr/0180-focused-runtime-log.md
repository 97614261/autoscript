# ADR 0180: 精简编辑器运行日志

日期：2026-10-28

用户要求底部日志精简内容、整理样式并删除冗余代码。本轮仅改变日志呈现和筛选，不删除现有记录或改变脚本执行、日志采集与文件格式。

## 实现

- 当前页默认显示脚本输出、真实错误以及无法识别来源的旧格式内容；普通Runner、Root和引擎状态切换到全部记录或运行诊断查看。脚本原文中的错误字样不再被当作系统错误，Root及截图等已知错误码仍保留。
- 日志列表时间与正文分列，去掉已知的重复传输/渠道前缀，错误行浅红显示。长内容点击查看完整原文，搜索和复制始终使用原始记录，不合并重复的脚本输出。
- 顶部仅保留当前、历史、统计；刷新、定位、记录设置、导出、清理和统计辅助功能集中到更多。搜索按需展开，历史记录选择去掉多余前后按钮，常规元数据说明按需展开。
- 手动拖动列表暂停跟随，点击跟随恢复；新增日志使用直接滚动，避免高频输出反复启动滚动动画。历史筛选仍后台执行并响应取消，实时可变列表仍取不可变快照。
- 将独立的日志列表及原文详情拆出主窗口文件，删除旧的常驻多行筛选工具、重复导出底栏、清理菜单状态、重复时间前缀规则及失效的源码字串测试；日志导出、清理确认、项目归属和积木定位保护保留。

不升版、不发布线上，不连接真机或运行用户项目脚本。必要定向检查后沿原优化构建安装MuMu 0，保留应用数据。
