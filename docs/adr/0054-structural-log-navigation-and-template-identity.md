# ADR 0054：日志定位与冻结模板内容身份

日期：2026-10-10

## 决定

- 日志定位只使用已记录事件的 flowId/nodeId，不从用户脚本输出、Lua 行号或错误文本猜测。定位只选中当前草稿，明确它可能与历史运行不同；插件/节点不存在时拒绝定位。匿名化身份不可反向定位。
- 模板指纹复用像素模板注册时已有的 SHA-256（宽高小端编码 + 按行规范 RGBA），版本为 `sha256-rgba-v1`。路径、编码文件元数据、行填充和采集时间不属于内容身份。每次搜索只读取固定大小的缓存摘要，不再次遍历像素。
- 观测中的 `templateFingerprints` 保留搜索顺序，与 `templateCount/templateSizes` 配对。动态帧模板没有缓存摘要时不补造。旧日志照常展示，但没有完整指纹的匹配指标不能计算跨运行变化；截图指标仍按既有后端/环境口径比较。
- 内容指纹仅证明模板内容相同，不证明屏幕内容、Root 会话或因果收益相同，不记录屏幕摘要，也不改变搜索与停止语义。

## 边界

不引入新依赖、协议能力或用户资源路径日志；现有紧凑条件表自动保存新可选字段。无模板的 OCR 仍不被当作带指纹的找图指标。
