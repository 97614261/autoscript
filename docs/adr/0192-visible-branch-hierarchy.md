# ADR 0192: 可视化分支层级更清楚

日期：2026-10-29

用户要求去掉随父级禁用的重复文案，并让满足分支及内部积木的缩进更清楚。

- 继承禁用的子积木保留灰显和状态元数据，去掉每行前缀；直接被注释的节点仍显示已注释。
- 展示缩进步长从8dp增至12dp，满足/否则/否则如果及成功/失败分支独占一层，内部积木再进一层；循环体仍沿原单层呈现。
- 分支行加入短连接线，正文层级线加深。主列表、编辑多选窗及加入位置预览采用同一展示层级；编辑窗分支标题补齐复选框所占空间，避免标题比父节点靠左。
- 只调整视图层级，不改执行节点的实际深度、顺序、标识、禁用状态、选中/折叠/撤销和保存。深层内容仍可横向滚动。

仅必要定向主机检查、Release编译与原x86_64优化本地候选和MuMu0有限查看，不运行私人脚本、不连接真机、不升版或上线。实际结果另记。

34项定向检查完成：首轮33项通过，唯一失败为旧测试仍按8dp计算深层内容宽度；同步12dp期望后只复查该项并通过，失败日志保留。涵盖禁用显示、真实/展示深度分离、嵌套分支、选位边界及原编辑几何/身份；Release生产/测试编译通过。

原x86_64优化构建、压实及必要包检查通过，仍为0.1.30/versionCode31，本地候选51832814字节、SHA256 0d64b674887115bd38c9b02f3252d76f481a15abbfd246db3a8704ebc416a0ee。原函数保数据覆盖MuMu0，冷启动Status ok/438ms、进程7208、首次安装时间保留。720×1280竖屏实际对照同一插件：继承禁用子行无重复文案，满足/否则的短连接及正文再缩进完整；编辑多选窗分支标签在父级之后，内部复选框/正文继续缩进。未选中/修改/保存/运行积木，查看后关闭多选窗并留主编辑器；未旋转、改输入法、连真机、升版或上线，不以有限竖屏查看冒充横屏/执行设备验收。
