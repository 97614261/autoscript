# ADR 0133 Studio检查性能与固定视觉组件升级

日期：2026-10-20。状态：采纳。

## 范围

本批按六项计划完善Studio：批量变量检查、编辑器职责拆分、离线视觉组件、固定字符准确率比较、同包回归和性能分位数、交付记录。默认full和V4不变，不打独立ARM候选，不扩展下载器或独立Runner产品。

## 决策

- 变量检查从冻结源码生成一次只读投影，在后台批量检查，按源码身份发布；保留注释子树和分支保守语义，不缓存可修改编辑文档。
- 编辑窗口生命周期仍由原宿主持有。独立提取树显示、操作和工作流辅助代码，不改持久化格式或窗口交互。
- 固定provider升级为组件版本2与SPI版本2，OpenCV增加ORB，ONNX携带固定摘要的V4和V5。V1继续只支持原操作；扩展操作明确拒绝，不能降级算法。V2模型集合有固定白名单、长度和摘要，不接受外部模型路径。
- 所有组件仍须发行签名、实际清单和冻结快照校验；进程钉住、租约、取消及配额保持。导入不自动选择，full不加载外置组件，设备测试仅使用自有QA存储。
- 准确率使用公开合成字样与真实识别输出比较；预期文字只用于评分。首次和热身后的性能分开，端到端分位数独立计算，不相加各阶段分位数。
- 性能交叉检查发现Android的System.elapsedRealtimeMillis读取调度批次旧时间，漏计批次内同步匹配。改为直接读取CLOCK_BOOTTIME，失败明确报错；调度器虚拟时钟、截图缓存及API格式不变。测量增加逐样本的阶段总耗时下界校验；日志采样间隔只放计时区外并明确披露，不扩大生产队列或忽略丢记录。

## 验收

代码测试、设备回归和性能样本分别记录。所有设备结果须关联同一候选APK摘要；构建成功不能代替识别准确率或设备通过。交付记录列出样本条件、未通过项和保留限制。
