# ADR 0050：运行健康总览、帧所有权与传输分段

状态：接受（2026-10-09，用户确认执行后续计划1至4）。

## 决定

运行日志记录单调时钟的已观测运行时长及终止时长，Root时长从实际认证完成起算。运行中Root会话更换须明确标记，不把重连后的时间拼成一个连续旧会话。旧日志缺项显示未知，不由样本数量推断运行时长；健康计数只取主操作事件，不能重复计入阶段行。记录丢弃/限额/无效计数始终可见，总览保持紧凑，新增传输细分可独立续页，原指标不删除。

帧池新增私有不可变共享像素容器，兼容已有Arc切片，同时允许安全移动Vec到Arc<Vec>，避免Vec转Arc切片的整帧复制。仅暴露只读切片，不允许借助唯一引用重新取得可变Vec；真实Vec容量计入内存预算。保留单帧、帧序列、租约、取消和资源上限语义，不缓存旧屏，不采用unsafe。模板注册的已有接口保持兼容。

新增可协商的截图传输观测能力：新端在认证像素包之后发送固定有界认证结束摘要，仅包含数据包编码、写出/背压耗时及包数；未协商的旧端没有摘要。客户端验证请求身份、顺序、包数及数字范围，摘要缺失/损坏与半帧同样关闭连接；不要把它当作可忽略的非认证旁路。客户端独立累计接收读取、验签/协议校验、像素追加耗时，各百分位仍不可相加。

控制通道失效通过另一个可选协商能力传递固定白名单失败原因；旧端沿用空的BackendFailure，不收到它无法理解的新枚举。采集后端失败与控制会话不可用明确区分，不降低鉴权、不自动重试半帧。发送分段用于定位，只有有可信对照收益的优化才交付；软件位图读回保持原颜色语义。

## 验证

单调计时/Root会话更换/旧日志、计数去重、页内主指标保留；Vec原地址保持、容量预算、租约跨任务/释放、帧序列；新旧协议、摘要截断/重复/关联/鉴权/包数/超限及控制错误协商；长时间活动、暂停/真实空闲、停止/恢复和新会话旧包拒绝。使用合成数据与推进时钟，不运行私人脚本。完成格式、静态检查、单元测试和build.cmd -Verify后保留数据安装MuMu。
