# 0038 编辑与日志入口统一

2026-10-04，按用户最新决定实施。

底栏编辑直接打开原多选整理窗，旧独立操作菜单移除，长按复用同一入口。“更多”保留界面预览、录制、变量检查、查找替换、运行变量，不重复编辑和单步。日志独立小窗展示，不改变程序树高度；允许筛选、显式复制与切换跟随最新。

源码编辑是插件 JSONL 编辑，不是任意 Lua 和积木的双向转换。可视化持久化格式及编译器仍为唯一依据；提交有 1 MiB 上限，后台编译校验成功后再次检查运行状态和原始草稿身份，结构检查成功后写入可撤销历史，不直接标记已保存。不增加手写 Lua 节点或绕过 capabilities。

确认弹窗共用 StudioConfirmDialog 外壳，保留每个调用方的删除验证、无效状态禁用与恢复语义。脚本运行提示不是开发日志，不受此次日志显示调整影响。
