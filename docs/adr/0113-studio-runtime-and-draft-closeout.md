# ADR0113: Studio运行及草稿收口

2026-10-15。用户授权总计划第4–6阶段；仅开发、源码编译和静态检查，集中回归、APK及设备验收后置。

## 决策

- 视觉准备和状态刷新共用组件状态合并规则；取消后的检查不得发布迟到状态。一次准备已完成SDK工作后，完成通知可以提交下一次准备；只允许一个活动请求和一个等待工作线程退栈的后继，不排队SDK调用，不提前释放仍在SDK中的工作。
- 保留默认full及base/opencv/onnx/full四配置，不增加下载器、SDK、模型或独立Runner工作。已加载会话及初始化结果复用；每次启动仍校验精确组件选择，不为减少哈希省略可执行文件校验，读状态仍仅使用缓存。
- 编辑器保存全部脏插件时，冻结清单、全部正式插件基线及全部编辑草稿，组合编译成功后复核；复用既有有界多文件回滚事务一次提交，不再逐插件保存导致部分提交或跨插件候选无法校验。单插件保存同样复核完整正式基线；未提交的后续编辑保留为脏草稿。单插件历史保存接口保持兼容。
- 多插件事务沿用现有日志格式、恢复和备份边界；超过32MiB旧内容回滚预算明确拒绝，不扩大预算，不删除原数据。正式源码与清单冲突拒绝写入，生成物先失效。
- 已开始的有界磁盘事务及其编辑基线回执一起完成，再响应启动取消；取消仍阻止后续编译/运行。不能在磁盘已提交后丢弃回执，导致编辑器继续拿旧基线保存。提交前取消不开始写入，失败不标成已保存。
- 页面和运行控件必须保留明确的无选中状态，不能把空选择强制显示成第一项；设计器预览保留原数据并反映容器裁剪边界。脚本界面继续共用传统View渲染，不额外建立一套运行模型。
- 设备回归发现Android Spinner在layout后仍会将-1强制变为第一项；下拉框使用仅展示的不可选空行承载无选中，弹出选项不显示该行。正式选项、脚本索引/数量、值与项目数据不包含空行，程序设置不制造用户事件；列表仍使用真实无勾选状态。
- 插件草稿恢复提供保留并关闭，不强迫恢复或删除才能继续编辑；保留期间暂停自动检查点，避免覆盖未处理记录，明确提示重新打开项目继续处理。正式保存和已有陈旧基线拒绝规则不变。

## 验收边界

编译回归源码不等于测试已执行；不由静态审计声称四配置APK、系统浮窗、SDK准确率或设备性能通过。编辑运行保留窗口、最小化状态及单步/高亮身份约束不变。
