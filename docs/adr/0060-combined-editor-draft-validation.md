# ADR 0060：恢复草稿的组合校验

状态：接受，2026-10-10。

## 决定

恢复插件时，把已有未保存插件和本次候选作为同一只读覆盖集交给 Studio 编译器。其余插件仍从正式工程读取；不修改正式文件、生成物或项目能力声明。恢复记录按 ADR 0059 保留用户确认与清单/源码摘要复核，校验返回后再次检查正式项目和全部编辑草稿。

新增末尾 Binder 方法及窄 JNI 方法传输覆盖集，不重排既有 Binder 方法。传输复用私有缓存文件的只读 PFD，结束删除临时文件，不使用 Binder 大 ByteArray。协议为 ZGDS、版本1、大端计数及长度前缀；最多16插件、每源码1MiB、整体20MiB。拒绝重复/未知身份、无效UTF-8、截断、未知版本、尾随数据及超限输入；解析不执行源码。

Runner 不依赖 Studio 编译模块；缺少编译器时明确拒绝请求。组合校验成功仅应用本次确认插件的一次可撤销编辑，不自动保存或运行，不恢复未确认参数文本。失败保留恢复记录。

## 验证

覆盖跨插件递归组合（单独无冲突、组合冲突）、传输边界、原稿和生成目录不被写入、编辑上下文及正式项目变更后拒绝应用。设备安装与测试继续暂停。
