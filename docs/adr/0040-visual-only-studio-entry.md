## 决策

Studio 新建、编辑、启动、界面设计和打包入口仅接受可视化项目；源码编辑为 ADR 0039 定义的插件受限 Lua 视图。独立 Lua 编辑器及专属状态和测试断开生产入口后曾归档，2026-10-10经用户确认删除退休副本（见[清理记录](../verification/repository-cleanup-2026-10-10.md)）。共享截图、函数契约、Lua 运行引擎、旧清单编解码与备份能力继续保留。

旧 Lua 项目不删除、不重写、不隐式转积木。在工作台单独列为“旧源码项目”，只提供完整工程备份导出；备份导入仍接受历史项目，导入后归入该列表。任意 Lua 不属于可逆描述语言，不以空操作替代未知语义。截图交接转接正式可视化图像工具，保持单一 Bitmap 所有权与退出清理。
