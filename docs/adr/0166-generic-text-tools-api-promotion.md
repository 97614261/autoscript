# ADR 0166 通用文本处理及新增工具版本提升补修

日期：2026-10-26。状态：接受，用户反馈新增工具 runtimeApi 1.8 报错及取数入口过于专用。

- 修复两处遗漏：Studio JNI 草稿校验的临时版本提升，以及 ProjectStore 单插件/批次保存的持久版本提升。
  补齐 `text.numberat` 与 `ocr.alphanumeric/includeSymbols=true`；JNI 同时补齐已有区域截图积木。
  草稿校验只改变内存清单，不写正式源码、清单或生成物；保存仍走原事务，不修改节点身份和参数。
  编译器对明确旧版清单的最低版本限制保留，旧 OCR 未开启符号时不额外提升版本。
- 已由旧包保存、清单仍低于 1.8 的上述两类积木，在正式打开项目时沿原回滚事务修复清单，
  保留原清单备份并使旧生成物失效；不重写插件源码、节点身份或参数。修复可重复打开而不再次写盘，
  普通 OCR 和较高版本不改变；只读快照复核不触发迁移，JNI 正式编译的版本门禁仍保留。
- 图像中文字页的专用“读取第几个数字”入口换为通用文本处理菜单，复用已有首项/全部正则提取、
  两侧标记取文、分隔、替换及兼容按序取数。函数库的文本分类提供相同底层积木，不增加重复运行 API。
  来源由用户选择任意文本变量或固定文本，不按 `ocrText` 名称推断绑定，不要求重新截图或识别。
- 首项/全部提取增加数字、连续数字、字母、字母数字、中文、空白分词等明确可选规则。
  选择规则只更新 pattern 并解除旧 patternVariable 绑定，保留文本来源、输出变量和其他草稿。
  自定义正则及变量规则继续支持；首次打开或重开既有积木不自动改写规则。
  全部结果为 JSON 文本列表、首项为原始文本，未找到分别为 [] / 空文本，不返回数值零。
  复用现有 4KiB 文本、128 字节正则、64 项预算及正则引擎限制，超限整次拒绝。
- 通用文本加入沿已有冻结上下文、全项目校验、身份分配及一次撤销规则；兼容旧 `text.numberat` 参数。
  数字仍只是十进制原文，不引入表达式计算、千分位、科学计数或百分比换算。
- 同批定向检查发现运行日志前缀被误写为乱码，恢复“脚本”及对应旧断言，保留等级与内容。
  不修改提示生命周期、项目数据、服务器配置或测试备份密钥。本批仅必要主机检查和编译，不自动升版、
  打包安装或发布；线上仍 0.1.19，实际检查结果另记。
