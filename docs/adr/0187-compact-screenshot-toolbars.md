# ADR 0187: 紧凑截图工具栏

日期：2026-10-29

用户要求触控移除悬浮准星入口，触控与图像工具栏降低行高、上下居中，宽度自适应且超宽可滚动，左侧类型菜单改为紧凑小图标。

- 触控统一进入截图选点，移除 Studio 悬浮准星入口、启动回调及其独立请求状态；录制与原输入能力校验保留。运行服务已有协议和兼容后端不删除。
- 两类工具共用单行工具栏，最低高度 34dp、动作按钮最低 26dp，文字与图标垂直居中；宽度按内容收缩并受当前视口约束，动作区横向滚动，确定与关闭固定可见。
- 左侧类型菜单最多四列，小图标保留短名称，窄窗与大字号减少列数并允许纵向滚动；保持原类型可用性检查。工具栏拖动、位置记忆和屏幕边界约束保留。
- 不改截图原像素、画布选点、坐标生成、积木加入事务、Root 会话或输入执行语义。

仅必要触控能力及图像模式/几何定向检查和原 x86_64 优化构建，保数据更新 MuMu0 查看工具栏；不提交积木、运行项目脚本、连接真机、升版或发布。实际结果另记。

实际结果：触控能力 5 项、图像模式 12 项、视口几何 29 项共 46 项定向检查通过，Release 生产/测试编译、原优化构建、packageRelease 压实与必要包检查通过。候选保持 0.1.30/versionCode31，51818590 字节，SHA256 `73187760614749f2b82557b5c5dd32dc3249a6c8421ad6180d2014412922ecd0`。原函数保数据覆盖 MuMu0，首次安装时间保留，冷启动 Status ok/653ms，进程 3314。

设备当前为 720×1280 竖屏，未旋转。实际确认触控无悬浮准星入口，单击直接进入截图选点；常用单击工具栏约 516×68px，裁剪工具栏约 536×68px；展开工具限宽 704px，横向滑动可见末尾多边形/制字，存模板与关闭固定。类型菜单约 360×336px，四列小图标与全部 14 项完整，最终收起工具并留开菜单。未确认选点、加入或运行积木，不将有限竖屏查看冒充横屏/键盘/全部设备验收。日志与截图留在忽略的 `build/adr0187-*`，未升版或发布。
