# ADR 0016：变量维护与受限计算

状态：接受，2026-09-29；主机验证完成，设备验收待用户执行。

## 源码核对

- 旧一键玩 `config/variable.java`、`script/fun/varName.java`、`varFuZhi.java`、`maths.java`、`ifsList.getSS`：工程/插件作用域，整/浮/字/寻；维护变量后选择变量赋值，通过表达式编辑和 native 校验再加入插件；运算有 + - * / %。
- 新易编 `x/r72.java` 是声明编辑，`x/w72.java` 是带类型过滤的局部/全局选择与新增，`x/t72.java` 是赋值编辑，`x/y72.java` 是六种标量转换。`wt.y` 是重复密钥 XOR，核对解密后的常量：+ - * / ..，整数/浮点/字符/图像。布局来自 `service_tk_var_layout/assignment/type_conversion` 与 `service_var_select`，不凭截图猜行为。
- 旧“寻”是识别结果集合，不等同于新“图”或本项目的任务级帧句柄；不伪造其属性接口。

## 决定

1. 主改可视化，保留现有全局/插件局部声明和四种类型，以及持久化 flow 语义。不自动修改用户旧节点。
2. 新增 `variable.calculate` v1，参数 name、expression；旧 `variable.set/copy` 不变。不提高既有 API 的权限要求。
3. Rust 解析白名单表达式：有限数值、JSON 双引号字符串、声明变量、括号、一元 +/-、+ - * / // % ..、int/float/text 单参数转换。1024 字节、最多128个表达式节点、解析嵌套16层；不允许任意 Lua、成员访问、下标、shell 或动态函数。
4. 算术只接受整数/浮点，连接只接受字符；类型转换必须显式。整型除法用 //，浮点转整向零截断；结果有限且整数运算不允许溢出，除零明确报错。连接结果限4096字节。
5. 新计算的目标/来源必须有当前作用域的声明或插件参数。图像不参与标量计算/转换，图像复制继续使用既有租约语义。
6. 维护声明与插入运行时赋值分开。共享计算弹窗用于函数库、页面编辑器、悬浮编辑器及变量管理入口，快速新增仍经变量表冲突检查持久化，不从 UI 执行表达式。

## 变量维护页布局调整（同日补充）

维护页由常驻添加表单改为作用域分段导航、搜索/类型筛选、带类型标识的紧凑卡片；宽屏两列，窄屏单列。新增/编辑在独立短表单完成，不挤占列表。底栏固定居中，正文随屏幕/键盘高度滚动；取消未保存草稿需确认。只改展示与交互，不改变声明格式、作用域、执行语义或旧节点引用。

循环本次仅源码审查，差异见 `docs/variable-page-loop-audit.md`；不把已有循环编译路径等同于参考弹窗全功能对齐。

## 边界

主机检查与 Debug 构建不能替代设备弹窗/键盘验收。中文变量名、多组寻图对象、字符分组和图像属性计算不在本批伪造实现；现有协议变量标识继续兼容 ASCII。
