# ADR 0073：清理后重启、脚本录制与音频基础

2026-10-11，用户要求补完已确认函数库计划，暂不安装MuMu。

Task.restart结束整个本次执行，等待现有认证触点清理及任务资源清理成功后，重新创建Lua VM/调度器并使用本次已冻结源码、能力、声明图片/字库和已确认界面初值。不得重新读取或执行变更后的私人项目，不绕过Root就绪。每个外部启动最多重启10次；用户停止、会话变化、清理失败、录制未结束均撤销重启。重启期间不通知编辑器假终止，不重新弹配置页面。日志分成独立运行，记录restarted与序号，不记录源码或参数。

脚本录制采用单个有界等待Input.record，而非遗留可丢失的全局开始句柄。1000至60000ms，128至512原始事件预算；复用真实Root录制和独立结束按钮。期间禁止普通脚本触摸/设备键，已有触点则拒绝开始。取消/停止走优先清理，不依赖业务队列；完成返回有界JSON动作及原屏尺寸，异常不返回半成动作。回放完整校验全部数据后才执行，屏幕尺寸变化拒绝，不随机录制内部等待或坐标。

脚本录制定时完成使用单独协商的INPUT_RECORDING_TIMED能力，固定32字节配置末尾只允许bit0表示到期正常完成；旧录制保持超时失败语义，未协商该能力不得发送或接收新模式。到期丢弃尚未抬起的触摸，不返回不完整动作。回放先取得坐标快照、再检查整批原屏尺寸和方向，后续原像素动作携带该快照，显示变化明确拒绝。

音频仅提供单播放器、播放/停止和音量读写。播放来源限定项目私有data音频文件，不接受URL、任意路径或系统文件；文件最大20MiB，播放最长60秒，结束/停止释放播放器。音量0至100是Android音乐流相对值，显式设置才改变，不自动调大。无需麦克风，不录音，不增加网络能力。

音频配置页提供明确的系统文档选择与有界导入，保存到本机项目私有data/audio，使用独立随机名称且不覆盖。音频是运行数据，不自动加入项目资源清单、备份或独立Runner包，配置页明确说明跨设备须重新导入。二进制文件总量64MiB/256条目，音频与PNG共用跨进程即时配额锁；普通文本写入拒绝二进制头，不以扩展名放宽512KiB文本预算。停止、重启和服务销毁释放播放器；播放准备异步且有界。

宿主工具复用已有固定JNI有界字符串与独立等待工作线程，但使用独立runtime-tools目标和固定opcode/operation白名单，不经过UI控件命令解析，不要求ui.control。调用会话、取消与迟到回调分别校验；脚本录制等待不得占住Root工作线程。轻量命名浮窗/绘图仍为原计划单独评估项，不扩大为任意窗口/绘图兼容。
