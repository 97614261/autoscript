# ADR 0116：用户提供Logo与共享轻量品牌动效

2026-10-15，已接受。

## 决定

用户最新要求用上传的`zhigou_logo.svg`替换App、编辑/配置吸附球、运行球、录制与首页品牌图，并提供统一尺寸、背景、单色/线性及idle/running/success资源。该决定替代原蓝紫灵动环造型，不改变窗口行为、首页无功能入口、包名和项目数据。

- 原SVG原样保存在`android/branding/source`。实际内容为嵌入RGBA位图而非矢量路径，不能宣称重建了矢量Logo。
- 生成脚本从原嵌入位图派生，仅抑制低彩度半透明白色背景残留，保持主体色彩、像素坐标、比例、折叠及左右速度线；不以生成展示图充当资源源文件，不描摹重设计。
- 新增真实可构建、无第三方运行依赖的`brand-ui` Android库，集中唯一PNG母版、单色遮罩及传统View品牌组件；Studio与runtime-service共用。库不依赖Compose/引擎/Root，Runner仅通过runtime-service获得通用运行标志，不带Studio页面。
- 运行时用ValueAnimator和有界Canvas外部光效：待机呼吸、执行流光、运行外环、完成一次性亮起；Logo本体不旋转、拉伸或变形。不可见/分离时取消动画，系统禁用动画时静态显示，不为效果增加运行延时或保留本应销毁的窗口。
- 正常停止、失败、暂停不冒充成功；完成效果仅用于明确正常完成的展示上下文。停止与结束清理仍优先，不为播放动画延迟清理。
- 所有导出PNG/GIF/展示板放`android/branding/exports`；App仅打包共用母版及遮罩，不将尺寸全集或GIF预览装入APK。自适应图标保留安全区及API24/25兼容图标，深浅色及Android13单色复用同一轮廓。

## 验证

生成校验锁定原SVG/嵌入PNG摘要、尺寸、alpha、同源缩放、遮罩及GIF帧；单元回归验证动效状态/单次完成/隐藏清理及所有入口接线。编译/Lint和包检查不代替设备视觉验收。更新安装保留数据，不运行私人脚本。

## 同日视觉修订

用户指出悬浮球与原展示板有差距。桌面彩色图标改为日夜均默认浅色底；系统形状遮罩、用户主动启用的主题单色保留，不能把形状自适应承诺为所有启动器自动换背景色。参考[Android官方自适应图标说明](https://developer.android.com/develop/ui/compose/system/icon_design_adaptive)。

悬浮球仅对母版RGB做同一线性提亮，alpha和几何不变；非悬浮展示继续使用原色。把径向柔光峰值移到球体外沿，避免被不透明底色盖住。运行光效改为平滑变速、方向相反的双彗星轨道与掠光，Logo不动；轨道一周期位置/速度连续，30fps有界刷新，隐藏/分离及系统关闭动画的处理保留。导出浅色Logo、球体及GIF由同源母版生成，GIF更新为50ms/帧的更平滑预览。

## 2026年10月16日首页互动修订

用户确认将首页改为“智构空间”，允许简短品牌和交互说明，保留无业务入口、不读项目及实际运行状态的边界。首页复用brand-ui唯一Logo母版，Logo只做整体位移，不旋转、缩放变形或改动速度线；背景提供极光、星轨、粒子三种本地主题。拖动Logo带动光场并回弹，背景水平滑动或主题按钮仅改变本地视觉状态，轻触重播演示。

用户随后要求增加可视化积木运行到某行的动画：首页固定公开五行积木提供层级缩进、当前行移动高亮、行内流光和经过轨迹，紧凑横屏只跟随显示三行。该动画按本地时钟循环展示并标注“不执行脚本”，不是编辑器真实执行定位，也不获取真实积木或变量。

新增显示仅在Studio导航目录内，不进入Runner或修改共享运行球行为。时钟约30fps、粒子和涟漪数量有界，离开页面销毁，暂停停止推进；省电广播立即停动画，恢复前台复查动画开关，静态模式仍允许主题选择和演示结果反馈。横屏顶部和底部预留独立布局空间，不用系统旋转或字号修改来适配。
