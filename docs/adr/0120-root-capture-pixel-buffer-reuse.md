# ADR 0120：Root 截图像素缓冲复用

状态：接受（2026-10-17，识图性能第四阶段）。

## 决定

Root 截图桥在一次完整的 `ReleaseCapture` 后，将已经不再对外可寻址的像素
`Vec<u8>` 放回一个单槽复用缓冲。下一次桥截图把像素读回到这个缓冲，只有完整
读完并通过固定计时尾部校验后才把所有权移动到新的 `StagedCapture`。

复用槽不保存可用截图，也不参与缓存命中；活动帧仍独占自己的 `Vec`，直到收到
匹配的释放命令。读回失败、取消、格式错误或超时只留下不可见的有界容量，不会把
半帧发布给客户端。现有 BGRA 字节序、64 MiB 上限、认证传输、请求代次和降级
到 `screencap` 的行为均保持不变。

## 原因

Root bridge 路径原先每一帧都重新申请一块完整像素 `Vec`。在 720×1280 设备上这
是约 3.5 MiB 的重复分配；复用可降低连续找图时的分配抖动，但不能缩短系统
`SurfaceControl` 捕获或跨进程传输本身，因此不把它宣称为端到端延迟保证。

## 限制

- 复用槽最多持有一块最后释放的像素分配，仍受既有 64 MiB 检查约束。
- 不改变连续帧系列、Studio 预览或旧 `Capture/CaptureChunk` 线格式。
- 设备收益必须按同一设备、分辨率、模板和至少 100 次样本重新测量。
