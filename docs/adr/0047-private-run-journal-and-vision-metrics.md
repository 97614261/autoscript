# ADR 0047：私有运行日志与识图观测

状态：接受（2026-10-05，用户要求实现运行文件日志并分析识图效率）。

## 决定

Runtime 在自身私有 files/runtime-logs/<随机运行 ID>/ 保存 UTF-8 script.log、diagnostic.log、events.jsonl 和 metadata.properties。Studio 通过 runtime-api 的只读文件格式适配器查看本 UID 历史，Runner 不依赖 Studio。导出仅在用户主动选择系统保存位置后进行；不自动上传，不将脚本、变量快照、模板路径或截图写入观测日志。

基础文件日志始终开启；项目支持可关闭的识图指标（默认开启）和积木进入追踪（默认关闭）。设置进入项目清单、编译摘要和冻结 Lua。追踪只记录插件/节点身份，不记录源码和参数。编译器内部上下文标记不新增脚本宿主权限，原有单步检查点仍独立。

引擎使用单独有界事件队列经 JNI 排空，不与用户 Log 文本混用。识图计时使用单调真实时间；Rust 匹配计时不含截图，异步截图/适配器耗时包含宿主往返，不能冒充纯算法时间。记录算法、ROI、帧/模板尺寸、阈值、数量、结果状态。取消、超时、预算失败分别计数。仅按相同几何和配置聚合 P50/P95/P99，注明样本量；实际设备基准仍需用户运行采样。

写盘由专用单线程执行器按需合并，不阻塞停止。最多 256 条待写记录、单条 8 KiB、每运行每通道 1 MiB、最多 16 次历史；超过预算保留已有记录并在元数据注明丢弃/截断。结束元数据独立于普通记录队列。进程崩溃未结束的运行显示为未完整结束，而非成功。所有读写验证随机 UUID 子目录，禁止符号链接逃出私有根目录。

## 验证

2026-10-09：事件文件的精简编码、分段预算、轮转及累计/窗口口径由 [ADR 0051](0051-compact-bounded-run-event-journal.md) 进一步规定，取代本决策最初的事件单文件1MiB停止写入规则；脚本/诊断原上限与旧文件读取保留。

覆盖轮转、结束与队列上限、路径边界、观测设置迁移、事件不含模板路径、统计分组与百分位、开关和单步兼容。性能数据是观测，不承诺已完成实际设备基准。
