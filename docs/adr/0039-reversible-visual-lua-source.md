# 0039 可逆的可视化 Lua 源码视图

2026-10-04，用户确认执行源码统一计划 1–5；替代 0038 的 JSONL 用户编辑入口。旧 Lua 项目清理不属于此批。

## 决策

插件 JSONL 和项目变量声明仍是唯一真相。Studio 工具链提供不执行代码的、有界递归下降解析器，将可视化积木导出为 Lua 5.4 语法的受限描述语言，再解析回相同节点。它不是任意 Lua 反编译器，也不是最终运行 Lua。Runner 继续使用原 Flow 编译器。

所有目录契约自动映射到 `Input.Tap({x=10,y=20})` 等命名调用；参数用具名 Lua 表表达。条件使用 `if Condition({...}) then ... elseif ... else ... end`，限次使用 `for _ = 1, Repeat({...}) do ... end`，条件循环使用 `while Condition({...}) do ... end`。其他容器的子区使用具名、无参 `function() ... end`，仅作为结构描述，绝不执行。固定赋值、复制、计算支持受限赋值语法，计算沿用现有 Rust 表达式语义，不改变除法、字符或变量作用域。新局部声明仍在变量维护页建立。

`--@node` 身份标记用于保留节点 ID、版本、禁用状态与原有结构身份；禁止外来/重复身份。普通注释回写为注释积木。JSON null 和空数组通过 `Json.Null`、`Json.Array({...})` 区分，避免 Lua nil 删除键导致损失。

解析仅允许已注册构造器、字面量与规定结构；未知函数、模块加载、任意闭包、shell、未映射控制流和动态参数表达式报行列错误。源文本 1 MiB、节点 4096、递归 32、词法项 200000，取消检查和后台执行；不增加依赖或 Lua VM。

应用路径：解析 → 契约/结构检查 → 现有 Rust 全项目编译校验（类型/资源/能力/跳转）→ 复核原草稿及运行状态 → 一次可撤销变更 → 现有保存路径。错误、取消、切换插件不得写入。源码行区间与节点双向映射用于定位编译错误。两种视图共享一个草稿，关闭未提交文本需确认。

## 后果

所有现有积木都有无损形式，包括复杂参数与输出变量。手写任意 Lua 不保证可转积木，界面必须说明边界，不能丢弃未知语句、插入空操作或静默创建变量/授权。源码不是另一份独立运行脚本；未来清理旧入口需单独审查生产入口和历史数据。
