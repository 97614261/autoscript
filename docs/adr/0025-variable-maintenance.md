# ADR 0025：有作用域的变量维护与受限常用操作

状态：采纳，2026-10-02。

## 决定

变量继续使用现有 integer/number/string/image 声明和插件局部优先规则。本批不把任意 Lua 表伪装成有类型的项目变量，不改变已保存的节点 kind。

可视化变量改名必须显式携带旧声明和新名称，一次提交声明、相关插件引用、界面绑定和提示过滤配置。只改写结构化变量字段及计算表达式的标识符，不替换常量、说明、资源路径、插件参数名和字符串内容。全局改名跳过被同名局部/参数遮蔽的插件，并拒绝新名称导致的捕获。保存前校验全部文件及预期版本；提交失败恢复原文件。编辑器已有草稿一起提交并刷新，不能随后把旧引用写回。

计算扩展使用可审计的白名单表达式语法，提供 Unicode 字符长度、截取、查找、替换、大小写、去空白；不拼接执行用户源码，不支持正则/Lua pattern 注入。字符串结果最多4096字节，参数和表达式有边界。

集合/对象使用明确的JSON文本契约，保存在现有字符变量中，不新增可执行Lua表类型；Data API在Rust解析、校验、计算并返回新值。仅支持JSON标量取值/赋值/追加、删除、长度、键列表与字符串解码，最多64KiB、16层、1024项；数组索引从1开始，不接受Lua表达式或元方法。字符来源变量和结果类型在Flow编译期检查，动态数据仍在运行时验证。

持久文件由独立Files宿主契约提供，只访问应用私有存储中按projectId隔离的data目录，不属于插件源码或图片资源。必须在project.json显式声明storage.data能力；不自动补权。路径不能绝对化、越界、含符号链接或隐藏控制目录；单文件64KiB、有项目配额，写入原子提交，删除进入受限私有回收区。宿主请求具备取消、3秒超时、会话失效和背压，脚本不能获得任意路径、文件句柄或shell。

## 验证

作用域遮蔽、改名冲突、表达式字符串保护、界面绑定、写入失败/过期草稿，以及字符多字节、参数类型、越界和运行结果都须有测试。
