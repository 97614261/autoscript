# ADR0109：Studio 识别流程完整性

2026-10-14，用户授权识图1–6批，先完成代码，测试/安装后置。目标是智构功能闭环，不机械复制参考产品。

- 图像入口暴露现有找色/连通块/逐字OCR/文字查询和帧处理；配置仍复用生成契约。图像来源明确为自动截图或已有帧；前者平衡创建/释放，后者不释放用户帧，读取结果不截图。
- 等待出现/消失、限次重试和连续未命中计时只构造既有计时、循环、判断、等待和像素/灰度识别积木，不增加运行API、隐藏变量或全局计时状态。所有工作变量由用户明确选择已声明整数，识别频次为1且不带输入动作，轮询等待使用exactTiming而不受普通等待随机化影响；成功/失败子区由用户编辑。连续未命中从第一次实际未命中开始计时，命中后重置。总期限在每次识别前后复核，停止/识别异常中止，不转成未找到；运行中SDK调用受其原有取消/5秒期限约束，不宣称硬实时抢占。
- 组合插入先在独立候选生成精确身份，复用完整项目/全部草稿编译与陈旧上下文复核，一次可撤销加入；位置取消返回原配置。原始节点和受限源码都是可见既有结构，不保存不可逆的额外工作流状态。
- 组件状态仅后台读取既有有界缓存，导入/已校验不等于识别成功。预览错误仅传递固定白名单代码，不泄露异常原文、路径或源码；保持Parcelable布局及运行协议不变，未知代码仍明确失败。
- OCR保持字库及单行字母数字；增加字库结果/位置/置信度的便利读取，不扩大字符集、不替换混淆字符或自动加载新模型。界面和参数关闭保护统一，已有项目/协议/Runner不迁移。
- 不实现下载器、多指、通用中文、多尺度/自动旋转/特征匹配。编译与回归源码不冒充设备和模型精度验收。
