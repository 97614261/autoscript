# ADR 0031：可取消循环及插件状态分支

状态：采纳。日期：2026-10-03。

继续补齐通用能力，并在智构原生提供加入、修改和函数库入口，不引入转换器运行依赖。旧一键玩configCycle/configJump的Java记录确认无限/限时循环和显式返回成功/失败；缺失的Native自然结束状态、检测标记及视觉算法不得猜测等价。

新增 `control.cycle` v1，循环体body，强制1..1000ms宿主可取消让步，默认1ms。无次数上限，可用break/停止/会话配额退出；可选1..86400000ms时长或整/浮变量及毫秒/秒/分单位。限时在让步后再次检查截止。既有control.while保留原次数保护，不能静默解除旧限制。复用最近循环指标和检查、continue上下文，整体运行超时、取消和VM资源配额继续生效；不是保证永久运行的后台服务。

新增 `flow.status.return` v1(success布尔)，返回参数与运行成功/失败状态分离；`flow.call.branch` v1复用强类型调用参数，包含success/failure两个互斥子区。智构自然结束/旧返回上层视为成功，显式失败进入failure；宿主异常、取消、类型错误继续中止，不冒充业务失败。独立调用帧保留自己的返回参数与状态。仅冻结Lua内部返回表增加保留键，旧节点、参数槽及协议不改。旧项目自然结束的Native状态未确认前，其活跃结果分支仍不自动迁移。

界面v2控件上限从128统一扩大到256，传统View、设计器、Rust与Schema保持一致；v1保持32。页数16、父子深度8、字段及事件白名单仍受限，无新控件类型或任意事件代码。旧167控件界面仅消除了数量阻断，样式/页签/加载事件仍待语义核对，不能宣称布局已完整迁移。

无新依赖、权限、宿主能力接口。新增节点旧编译器拒绝；生成器版本升级，防止把不同语义的编译记录当作同一版本。所有已确认功能先以合成测试验证，不执行私人脚本。

新增 `control.continue` v1，仅允许位于循环体，定位最近的循环。Lua生成器以独立内层作用域和节点身份派生的保留标签实现，避免跳入后声明的局部变量作用域；循环仍从下一轮让步开始。旧明确的“结束本次循环”和显式成功／失败返回可以迁移；未知旧检测标记仍不映射。
