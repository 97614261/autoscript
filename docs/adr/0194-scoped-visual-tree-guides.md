# ADR 0194: 嵌套积木按真实范围分组

日期：2026-10-29

用户反馈多层嵌套后归属不明显，要求继续优化。

- 从既有展示投影计算每个可见父行的起止范围，循环及满足/否则、成功/失败分支各自收口，末行加短端线；空分支保留可选标题而不生成假子范围。
- 每层采用浅蓝、浅绿、浅金轮换底色，分段绘制避免深层叠色；选中或执行行的祖先路径加强，其余路径淡化，继承禁用仍灰显。
- 主树与多选编辑窗复用范围及绘制，不增加结束行、行高或缩进。逐行绘制适配懒加载，折叠和聚焦后重算可见范围，导线维持原32层绘制预算。
- 不改变实际节点、标识、顺序、源码、运行/输入、选中/折叠、撤销或保存语义。

仅必要定向检查、原x86_64优化本地候选及MuMu0保数据有限查看，不运行脚本、不连接真机、不升版或上线；实际结果另记。

45项定向检查及Release生产/测试编译通过，覆盖分支起止、空分支、折叠恢复、祖先路径、聚焦投影、禁用/重复只读身份和32层绘制预算，并复查既有分支/折叠/浏览/连续编辑/紧凑行行为。首轮44项通过，异常负层级用例发现范围未随根行关闭，统一按已有非负显示几何归一化后同组45项通过；原失败日志保留，未重跑全套验收。

原x86_64优化构建、packageRelease压实及必要包检查通过。0.1.31/versionCode32本地候选51836214字节、SHA256 1c0b1ec98e5087b7ce96c7d1e595531e147e3ac349dc307dd040262b183fccaa；原函数保数据更新MuMu0，首次安装时间2026-10-12 19:43:43保留，冷启动Status ok/628ms、进程7994。当前720×1280竖屏对照原插件，查看普通/空分支收口、深层滚动、选中祖先加强及多选复选框对齐，最后关闭多选窗留主编辑器。未修改参数/源码、运行脚本、旋转设备、改输入法、连真机或上线；执行行路径共用已检查模型，本轮未做设备脚本运行验收，不将本地同版本候选冒充线上原字节。

用户随后反馈层级线太乱，本批显示方案改为：取消多层贯穿线、彩色线、末端横线和分支长连接；只用最近分组的中性浅底色及原缩进区分层级，选中/执行路径只画最近一层的单条细线。范围模型及交互不变，复用45项结果，仅原优化构建及MuMu有限查看，不重复逻辑测试。最终候选结果另记。
