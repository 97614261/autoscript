# ADR0110：专用识别结果读取与逐字预览

2026-10-14，用户授权继续识图完善1–6，代码先行、测试安装后置。

- 新增Screen.recognitionValue固定白名单API及vision.readresult积木，按明确结果类型、1起序号和字段读取JSON标量编码。独立64KiB/2048结果/固定浅层结构预算，不能通过通用Data预算读取大对象；不改变Data的64KiB/16层/1024累计项语义。拒绝形状、字段、类型、越界和缺失，不返回旧坐标；recognized输出整数1/0。用户源码和函数库接同一契约。
- 图像扩展参数复用生成契约，多点颜色增加结构化点表；范围与颜色输入保留非法草稿，不静默截断。自动截图需明确专用暂存变量，已有帧由用户管理。
- 等待仍展开为真实可见的普通积木，补颜色/文字条件适配，所有工作及输出变量明确声明；可一次选择已有工作变量，不偷偷创建变量。所有加入继续组合校验、陈旧复核、一次撤销。
- 字库测试新增固定GLYPH_DETAILS操作，沿既有reply.text传最多64KiB真实逐字JSON，不新增Parcelable字段，不返回图片。JNI复用现有字库算法输出真实位置/分数；文本模式兼容。客户端严格校验，结果视图绑定同一图片、配置和服务身份，编辑参数立即失效，不把处理图当屏幕坐标。
- 预览从请求入口共享单调期限，传剩余预算给可合作SDK适配层，取消/到期拒绝后续阶段和迟到结果；不能宣称第三方不可取消调用可被强制抢占。普通脚本等待组合继续识别前后检查总期限，错误不转成未找到。
- 不改变旧工程、不实现下载器/独立Runner功能/新模型/通用中文，不把源码编译当运行或设备验收。
