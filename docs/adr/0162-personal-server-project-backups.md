# ADR 0162：个人服务器项目备份

日期：2026-10-26。状态：接受，用户要求先实现自己使用的简版上传和恢复。

- Studio 的备份管理增加服务器备份页，仅手动上传已保存项目、列出快照、明确确认后恢复为新项目。
  不自动同步、不覆盖本机工程、不上传编辑草稿、运行数据或日志；复用 ProjectStore 的完整备份与严格导入。
- 独立 Python 标准库服务仅监听 127.0.0.1:8766，Nginx 仅代理固定 /api/project-backup/v1/。
  不修改现有 APK 发布服务、下载目录或密钥。部署由用户在服务器一次执行，不将本地实现称作服务上线。
- 个人备份使用独立随机256位密钥，通常由用户在 App 配置一次；默认不嵌入 APK、不使用发布密钥、不发送密钥。
  复用已有双向HMAC签名协议的实现及挑战边界，但路径、进程、挑战表、数据目录和密钥独立。
  App 使用AES-256-GCM加密项目及名称，按256KiB分块独立认证、顺序/末尾绑定；恢复必须完整验签、
  摘要与结束认证通过才导入。HTTP仍泄露大小/时间且可被阻断，不冒充HTTPS；可信服务器持有备份密钥。
- 配置仅保存在禁系统备份的 App 私有设置，密钥字段遮蔽，不记录异常原文/项目名/内容/密钥。
  用户必须另存密钥；清数据或丢失密钥不能恢复备份。不增加账号或通用云控。
- 每份原始ZIP最多128MiB、32份快照/总2GiB；服务串行处理，15秒无进展及300秒总期限。
  暂存所属事务提交为不可变快照，不覆盖同ID、扫描删除未知文件或自动轮转。容量满明确拒绝，
  选定快照删除需确认且绑定精确摘要；服务及App失败只清理本次明确持有的暂存。
- UI所有任务可取消并有界，离开页面取消网络；正式本地导入开始后不可取消其原子提交。
  恢复不执行脚本，运行或编辑会话存在时拒绝导入/上传，避免误以为未保存草稿已经备份。

改变持续提示生命周期或把空识别结果伪装成成功。

## 信封 v1

文件头为 ASCII `ZGBK0001` 加随机8字节nonce前缀；每条记录为大端32位明文长度、密文及16字节GCM标签。
明文块最多256KiB，nonce为前缀加大端32位序号，从0开始；必须有经过认证的0长度末尾记录，禁止尾随数据。
AES键由64位小写十六进制主密钥的ASCII字节执行HMAC-SHA256派生，输入为
`zhigou-backup-aes-v1\n{purpose}\n{id}\n`；AAD为`ZGBK0001\n{purpose}\n{id}\n{index}\n{size}\n`。
项目文件purpose为archive；名称purpose为name、index为0、size为-1，使用独立随机12字节nonce，
Base64编码nonce+密文+标签。名称最多1024 UTF-8字节，不使用Android API26的java.util.Base64。
文件最大129MiB，明文ZIP最大128MiB；每个块独立验证，全部签名/摘要及末尾通过后才调用原有严格导入。
