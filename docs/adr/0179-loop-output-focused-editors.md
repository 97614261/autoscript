# ADR 0179: 循环与输出重新组织

日期：2026-10-28

用户查看0178后要求再次设计循环和输出。本轮围绕类型、主要参数及内容来源整理，保留紧凑窗口和现有蓝灰白样式。

## 决定与实现

- 循环在宽短窗口左侧列出三种常用循环，读取、等待、退出等五项保留在其他操作选择中，右侧仅显示当前参数；窄窗或大字号改为完整类型选择。八项全部保留，用途直接说明，宽屏最大520dp。
- 固定值和变量与参数标题同排；时长和单位有空间时并排，小数输入及全部原有预设保留。序号、耗时和让步等收进更多选项，编辑包含这些值的旧节点自动展开。预设采用网格，变量选择支持范围和搜索，保留变量管理。
- 输出导航改为输出内容、对话框、弹窗样式；已有输出编辑不显示冗余的单页导航。四个输出去向在横屏使用左侧列表，窄窗使用紧凑分段。
- 内容来源明确区分文字、变量和表达式。变量直接选择后读取运行时值，编辑器说明可收起；表达式常用插入前置，其他运算折叠，保留原光标及选区处理。
- 从表达式切换为直接变量，仅在选择成功后改变模式；取消保持原稿。回执复核作用域，保留原有积木类型锁定、参数校验、单位、草稿、关闭确认和样式保存状态。
- 输出页按内容收缩，不再为简单内容强占大块高度；窗口较矮时正文可滚动，确认取消固定。

不修改执行模型、运行时API、图像算法、Root或输入安全；不升版本或发布线上。完成必要定向检查后沿原x86_64优化构建安装MuMu 0供查看，不运行项目脚本，不连接真机。
