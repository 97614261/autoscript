# 0066 脚本确认框与布局对话框

日期：2026-10-11。状态：接受。

确认框与布局框属于 ui.control，使用既有可取消宿主请求、同一运行窗口管理和传统 View 渲染器，不引入 Studio 依赖到 Runner。确认框不要求设计界面；布局框必须引用已保存页面 ID，控件值仍用 UI.getValue / UI.command 读取。

UI.confirm(title,message,confirmText,cancelText,timeoutMs) 返回 confirm/cancel/dismiss/timeout；返回、窗外、关闭均不得算作确定。UI.showDialogAndWait(pageId,blockOutside,timeoutMs) 返回 close/dismiss/timeout。期限默认60000ms、范围1000～1800000ms，挂起 Lua 协程，不轮询。停止使等待取消并移除窗口，迟到回调不恢复窗口。

同一运行只允许一个交互对话框，重复请求明确失败，不覆盖已有窗口。布局框独立于主窗口但复用其控件状态；关闭布局框不停止脚本、不删除页面或修改正式布局。布局期间主窗口暂时隐藏，结束恢复原显示状态。布局关闭按钮及设计按钮的 close 动作只关闭布局框；插件事件继续使用既有事件队列。UI.closeDialog 使用引擎控制消息而非被等待占用的宿主工作线程，避免关闭请求死锁。

所有文字和 JSON 经过有界 UTF-8/NUL 校验。参数弹窗、变量类型、能力声明、编译器、受限源码往返和函数说明共用契约；运行提示开关不影响交互框。

长交互请求在单独的最多一个宿主等待线程执行，不占用 Root 输入/识图工作线程；线程通过容量1的通道复用，空闲阻塞接收而不轮询，销毁关闭通道并等待清理。真实交互完成后先释放忙标记再通知引擎，连续对话框可在前一通知收尾期间排入；真实重叠交互失败。属性宿主请求在交互占用同一适配器时明确返回队列忙；旧异步控件更新和优先停止仍可执行。不得为每次点击创建无界线程。
