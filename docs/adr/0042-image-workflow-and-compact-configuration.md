# 0042 图像入口与紧凑识别流程

2026-10-04，用户要求重新设计图像 UI 和流程，并核对项目整体进度。

图像入口使用找图、颜色、文字分类，不同时铺开全部功能；截图取材、图片库、识别测试始终可达。共用识别配置保留常用配置、结果变量、更多参数三页，常用配置直接显示基础输出；高级说明按需展开。顶底栏固定，内容按可用屏高滚动；短按钮与数值输入用实际容器居中、去字体内边距。

模板来源明确区分单张、多张、文件夹，切换时互斥并同步必需的主模板路径，不偷偷切换像素/灰度算法或节点 kind。取消模板选择保留原草稿；保存截图保留阈值、输出及其他参数，列表按原顺序追加且超过64张明确拒绝。设计范围不是设备全屏；屏幕框选回填原始像素，手动固定范围清除旧变量边界覆盖。ONNX单行区域不提供设计全屏捷径。

读取匹配结果不插入截图/释放，不要求无关截图能力；像素/灰度多模板及ONNX识别仍由节点自己截图，颜色/字库OCR沿用截图、识别、释放组合。函数库引用已有帧的插入语义不变。全部加入、修改仍使用现有参数、声明类型、资源及能力校验，不自动授予权限。

多点采样使用有界独立文本编辑，避免单行输入的128字符截断；格式与64点限制不变。识别测试共用紧凑控件和搜索选择器，预览限高且保持原图比例，标记在同一比例容器内绘制；没有声称新版页面或真实识别准确率已经设备验收。

没有新增依赖、后端、运行API或持久化版本。Rust执行语义及历史节点保持兼容。
