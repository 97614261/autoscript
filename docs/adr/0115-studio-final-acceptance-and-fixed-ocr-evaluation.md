# ADR0115: Studio首版最后六项收口

2026-10-15。用户授权按已列六项继续：OCR候选实测、图像完整流程、编辑数据、设计器弹窗、异常稳定性、交付。真机/API24单列；Runner、下载器、免Root和云功能不扩展。模型或生产识别策略替换仍须明确确认。

## 决策

- 六项用同一总账记录，不再把新增夹具当新增开发阶段。区分代码修复、主机回归、真实Android集成、视觉人工验收；未执行不填通过。
- OCR候选仅采用官方登记固定URL/版本及SHA-256的英文移动ONNX，在忽略build目录保存；只读校验后通过显式Gradle开关加入androidTest资产，不进入main/Runner/provider，不实现产品下载器或任意模型入口。
- 使用现有ORT1.19.2及同一BGR/48高/归一化预处理。候选字典形状在测试内显式校验，ASCII筛选和500‰门槛不改变；不能放宽生产decodeAlphanumeric预算。分别报告完整精确结果、首次/热耗时和内存；候选更好不等于用户已批准替换。
- 流程验收只创建自有QA工程、资源和表面；已有用户会话立即拒绝。仅保留数据更新和经授权的App重启，不重启设备、清数据、自动授权或运行私人脚本。清理仅限本次明确创建对象。
- 故障注入必须局限当前自有测试运行/客户端，不能停止其他项目或破坏全局设备设置。横竖/字体/键盘优先在自建测试配置与窗口内验证，不更改用户全局系统偏好。
- 默认full、项目能力唯一真相、事务/签名/原像素/取消预算和协议兼容不变；严格门禁及包校验通过后安装，未完成真机/全部视觉边界单列。
- 设计器恢复仅规范化宿主传入的可信私有根目录，允许Android系统根路径别名；固定ui-designer-drafts子目录、记录/previous/tmp仍逐个拒绝重定向。不能通过对用户子路径统一canonical化来放宽符号链接检查。
- 客户端解绑清理有界高亮收件箱及已结束序号，连接新服务代次前重置旧序号；监听注册仅回送同代次/运行且仍处于运行中的已发布位置，不重放结束或暂停状态。编辑直接运行/选中单步准备已有设计界面的默认控件状态但不显示配置窗，不复用上次正式运行参数；不改协议或Runner。
