# ADR 0082：选中积木测试与普通运行位置

用户2026-10-12要求对齐老版单步入口及普通运行高亮。底部单步在空闲时测试当前选中积木及其子树，不执行前置兄弟节点。完整正式项目先校验；编译器从结构化节点形成隔离测试流程，并保留声明变量、默认界面参数和真实插件调用。结果写入独立 generated-node-test，不覆盖正式生成物或插件，不以Lua文本裁剪实现隔离。测试产物关联原清单/全部插件摘要及选中身份；启动前复核，不执行陈旧结果。

依赖外层循环/标签的节点不得伪造成功，隔离编译明确拒绝；依赖前置赋值或帧的步骤可能需要选择更大的父节点。已有暂停后的逐步推进保持调试用途，普通运行/暂停/继续/停止不变。

普通运行的位置来自编译器节点检查点，使用独立单槽观测，不依赖日志开关、不保存变量值、不按Lua行号猜测。系统事件驱动的引擎泵读取最新位置，最多20Hz合并发送，窗口绑定项目/服务代次/运行代次并拒绝迟到回调。运行行与编辑选中行分离；运行中跟随插件、展开目标祖先并滚动，暂停使用原下一步标记，终止清除运行标记。高频节点允许合并，不保证每一行都在屏幕绘制一帧；不得为高亮拖慢脚本或阻塞优先停止。

运行协议升级至23，旧Runner明确拒绝不兼容版本；冻结Runner不包含Studio测试编译器。
