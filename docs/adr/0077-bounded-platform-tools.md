# ADR 0077：剪贴板与App工具

2026-10-12用户要求平台工具补齐。增加剪贴板字符读写、可见App信息与启动请求固定契约，分别声明device.clipboard和device.apps，均为显式脚本积木，不自动收集或记录剪贴板、包名或变量值。

剪贴板仅纯字符，4096 UTF-8字节，不读取URI/Intent或以coerceToText隐式访问文件。Android后台限制导致没有可读剪贴板时明确失败，不能当成空内容。空的合法纯字符剪贴板可以返回空字串；写入不在停止后自动撤回。

App查询仅Android包可见性范围，清单只声明启动器MAIN/LAUNCHER查询，不申请QUERY_ALL_PACKAGES。结果visible=true表示当前可查询，并给出版本信息；visible=false表示不可见或不存在，不冒充确定未安装。启动仅使用目标包的系统启动Intent、NEW_TASK，返回请求被系统接受，不保证该App已进入前台；后台限制失败明确返回。

不自动授权、不静默切输入法、不安装/卸载App、不执行任意shell。中文字符可通过剪贴板保存，但不以此宣称目标App中文输入已经完成；新增专用输入法仍待用户确认。调用在独立工具工作线程/主线程宿主执行，不占住Root输入线程；世代、取消和迟到回调复核复用ADR0073。
