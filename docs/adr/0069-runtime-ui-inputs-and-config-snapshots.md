# 0069 运行期控件属性与参数快照

2026-10-11，接受。继续函数库第三批，不修改保存的设计稿及旧布局。

占位提示只用于文本/数值输入；范围为整数边界，步长只用于整数滑块。
更新范围/步长先校验当前值，不静默截断、取整或移动控件；提供range对象一次修改上下界与步长，
避免分次操作留下倒置范围。滑块范围与步长必须整除，当前值必须对齐，最多一百万档。
所有运行属性在隐藏/跨页时保留，读取经宿主确认。

页面参数快照通过UI.command(window,get:config/restoreConfig)导出/恢复，
只包含可输入控件值，不包含密码、非输入控件内容、布局或事件引用。
上限8192 UTF-8字节、256控件，超过预算拒绝、不截断。
结构摘要以当前控件ID、类型、必选、选项、数值范围及步长为准，
不依赖颜色、位置或标题；形状变更必须显式拒绝旧快照。
恢复先全部校验再一次应用，不触发插件事件，不改变显示/隐藏或运行入口。
密码保持本次运行现值，不随快照恢复。

持久保存复用已实现的项目私有Files.write/read：导出到字符变量再写文件，
读文件到字符变量再恢复。UI操作仅ui.control，写文件另需storage.data；
不借UI权限隐式取得存储，不产生隐藏变量、任意路径或自动落盘。
停止/过期会话由既有宿主票据与取消保护拒绝迟到应用。
