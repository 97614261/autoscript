# 0067 有界脚本基础工具

2026-10-11，接受。函数库补强不借助任意源码或Android对象执行。

数值/随机/颜色工具通过固定契约交给Rust执行，参数/结果类型、有限数值和范围严格校验。随机源是会话私有非密码学PRNG，只用于脚本取值，不用于密钥/身份；有界拒绝采样避免取模偏差，字符串最多1024个ASCII字符。有限计算不创建新线程，现有协程预算和停止继续生效。

可视化数值操作接受固定值或已声明的同类型变量；输出必须声明，整/浮/字类型不静默转换。每种工具有紧凑的独立积木及真实函数说明，所有参数参与受限源码和撤销保存，不增加隐藏变量。

四舍五入半值远离零，限幅要求下界不大于上界，角度使用屏幕Y向下坐标、范围[-180,180]，轮盘结果为浮点坐标。随机整数端点包含，取值限于可被双精度准确表示的整数范围；RGB输入限0x000000～0xFFFFFF。不同于旧函数的规则明示，不修改旧变量计算语义。

屏幕尺寸与单调时间复用既有宿主API。Unix时间毫秒使用真实墙钟，不能替代超时/性能单调时钟；绝不修改系统时间。屏幕尺寸使用device.display，时间读取使用core.task，数值工具使用core.math，不添加core.system虚构权限。

没有数据访问、网络或任意路径副作用。文本输入/系统写操作仍须独立设计结构化Root和授权边界，不以基础工具实现冒充完成。
