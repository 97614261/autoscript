# ADR 0076：私有data ZIP事务

2026-10-12用户确认文件工具补齐。ZIP仅处理项目私有data：压缩一个目录到不存在的.zip文件，解压一个.zip到不存在的新目录，不覆盖、合并或删除已有目标。

最大128条目、相对路径16层、压缩文件4MiB、展开总量8MiB；每条目和整体最大100倍压缩比例，比例计算对不足1KiB压缩数据使用1KiB下限。只支持STORED/DEFLATED，不保留链接、权限或可执行属性。所有输出是普通文件/目录；绝对路径、点段、Windows特殊路径、重复路径及目录文件冲突明确失败。

完整解析中央目录并校验CRC/声明大小后才发布。解压在所属私有事务目录构造，取消/失败仅删除本请求创建的有界文件；提交复核会话、目标不存在及数据/条目配额后一次原子移动整个目录。普通数据512KiB和二进制64MiB预算仍保留，ZIP文件头纳入二进制分类。宿主超时仍有界，速度慢可明确失败，不返回部分解压结果冒充完成。

不读取外部存储，不增加任意路径能力，不运行归档内容，不执行用户Shell或安装包。空目录压缩可以输出标准空ZIP。既有Files.read/write继续严格UTF-8。

Files.remove仍为明确命名的可恢复移除：普通数据维持64KiB上限，识别到的媒体/ZIP二进制允许至20MiB，并计入回收区二进制预算。恢复复核同样上限、分类与目标不存在，不读取二进制为UTF-8，不覆盖或驱逐其他回收记录；让新归档可以正常清理而不是产生脚本无法清理的私有文件。
