# ADR 0022: 编辑器专用的有界运行变量检查

## 决定

变量维护检查与运行变量信息使用独立 Compose 弹窗。维护检查读取编辑草稿并调用现有编译器验证；运行信息只通过现有 `getDebugSnapshot` 编辑器通道读取 Lua VM 中的真实值，项目清单的声明值不得作为运行值展示。

复用可视化编译器的节点检查点和既有单步暂停标记，不增加脚本 API、opcode、任意表达式求值或 Lua debug 库。Lua VM 的所属线程以 raw 访问读取最近检查点绑定的局部/全局表；暂停时显示当前检查点执行前的真实值，运行时明确标明仅为读取时刻的最近检查点上下文。声明类型单独展示，nil 与不支持的值类型不得伪装成默认值。

沿 Rust → JNI → runtime-service → runtime-api → runtime-client 返回最多 128 项，每个字符串最多 1024 字节，整个 JSON 最多 192 KiB。超限、非 UTF-8 和不支持的值显式标记，检查不调用 `tostring`/元方法，不将变量值写入日志。Binder/JNI 仍采用既有有界队列与超时，停止控制保持独立优先级。

服务保存独立的运行项目身份与递增运行版本，不能借用截图浮窗的项目身份。读取前后均验证项目、连接 generation、native handle 与运行版本，运行重建时丢弃返回值。返回包含连接/运行身份和 VM 读取时的状态；Studio 在会话或状态事件变化时清空旧结果，并在暂停事件上一次性刷新，不轮询。

运行调试 Parcelable 的新字段属于 RuntimeProtocol 21，同包服务与客户端同步升级；Flow、节点、项目和脚本 API 版本不变。

## 后果

- 单步暂停的变量信息随暂停事件刷新，可看到刚执行步骤改变的值及局部/全局同名遮蔽。
- 可视化变量表用于解释声明类型和维护警告，编译器验证仍是流程/参数合法性的权威。
- 不带可视化检查点的手写 Lua 返回明确的不可用状态；不向脚本开放检查任意局部变量或执行表达式的能力。
- 数据回填继续复用标量快照，截断、不支持和值类型不匹配的内容不得回填。
