# ADR 0182: 按行配置循环

日期：2026-10-28

循环创建和循环内读取/判断属于不同操作，八项平铺在顶部使简单配置产生重复标题与大块导航。本轮改为三行创建选项，参数紧邻选中项；辅助操作独立呈现，保留全部八种功能。

- 无限、限次、限时各一行，只有选中项显示输入；未选项显示当前草稿摘要。窄窗和大字号将选中项参数移到下一行，正文仍有界滚动。
- 次数、时长、单位直接填在对应行。常用数值和变量入口放在输入框中；选择变量成功后才切换来源，取消保留原数值，变量字段可切回数值。
- 读取信息、条件跳出、等待集中在辅助区。前两项各保留两种操作选择，并遵守已有节点类型锁定；选中后在同一窗填写参数，不新增页面或替换节点类型。
- 输出与高级设置保留折叠、已有值自动展开，字段按行排列。确认按钮显示加入的操作名称，取消与加入区分主次。

原参数构建、草稿、变量类型/作用域、预设时间单位、插入及执行语义不变。回执字段映射提取为可检查的纯函数，未知键不改草稿。仅必要循环定向检查与Release编译，沿原x86_64优化流程本地更新MuMu 0供查看；不运行项目脚本、不连接真机、不升版或发布线上，实际结果另记。

首轮10项定向检查及Release生产/测试编译通过，原x86_64候选构建并保数据安装MuMu 0。横屏查看限次、限时及变量取消正常，但辅助原生下拉点击落到了底层高级设置，未实际切换到跳出操作；该轮仅保留有限查看证据，不记为辅助操作通过。循环辅助与时间单位随即改为原窗口内展开选择，避免悬浮宿主原生Popup层级，不修改其他面板的公共选择器；选择当前时间单位也不清空已有输出。最终增量编译、候选及实际查看结果另记。

最终Release编译及原x86_64优化构建、packageRelease压实/必要包检查通过，未重复未改的模型检查。候选仍0.1.30/versionCode31，51831094字节、SHA256 `aa58f332cd523d8341b675a7cafa7c8b8b10a53f462ab1244fe7be3262d3d2ba`；原函数保数据覆盖MuMu 0，首次安装时间保留，冷启动Status ok/423ms、进程6811。1280×720横屏确认三行配置、辅助同窗展开并实际切换到时跳出、单位同窗展开并选中分钟收起；最终恢复限次循环并留窗。证据见忽略的`build/adr0182-final-*.png`及最终构建/安装日志，预览裁剪仅保留弹窗。未提交积木、运行项目脚本、连接真机、升版或上线；有限界面查看不代表全部操作、真实键盘或其他设备验收。
