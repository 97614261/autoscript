# ADR 0163 英文数字 OCR 保留符号与顺序取数

日期：2026-10-26。状态：采纳。

## 决定

- 图像中的字母/数字自动识别新增显式“保留符号”，复用固定摘要的 V4 模型及同一单行 ROI，不新增模型或要求制作字库。保留模型实际输出的 ASCII 可打印字符及空格，包括括号、加减号、小数点、百分号和分隔符；不补造模型没有识别出的空格、符号，不将置信度当正确率。
- 旧 `Ocr.alphanumeric`、V5 及已有积木缺省行为不变。`ocr.alphanumeric` 增加可选 `includeSymbols`，开启时编译为独立 `Ocr.latinText`/6105；新建表单默认开启，读取旧积木默认关闭。不改变项目身份、显式变量、插入位置、冻结复核及一次撤销边界。
- 固定视觉 SPI/组件增加版本 3，模型集合与 V2 相同。符号请求仅由内置实现或 V3 组件处理；旧 V1/V2 组件明确拒绝该请求，旧操作仍可使用，不以过滤符号的旧输出冒充成功。
- 新增 `Text.numberAt(text,index)`/14237 及原生可视化积木：按从左到右、从 1 起读出带紧邻正负号的十进制数字原文，保留 `+`、前导零和小数位。括号、空格及其他非数字字符分隔，不计算表达式，不把括号解释为负数，不处理千分位/科学计数或百分比换算。`100(+100) 180` 的前三项为 `100`、`+100`、`180`。
- 取数输入最多 4096 UTF-8 字节，最多 64 项，序号 1–64；超预算或参数错误拒绝整个调用，无该项返回空文本而非零。结果为文本，需计算时由用户显式转换，不隐式创建变量。图像入口提供读取数字快捷入口，复用工具配置及完整插入校验。
- 只做相关契约/编译和定向主机检查；真实图片识别准确率另验。本批不升版、打包、安装或发布。
