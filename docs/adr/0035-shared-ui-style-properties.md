# ADR 0035：共享脚本界面的可选样式属性

日期：2026-10-03。状态：实施。对应补全计划第5阶段。

在v2 UiPresentation上添加可选的fontBold、textUnderline、borderColor、borderWidthPx、cornerPx。默认false、false、#00000000、0、6；缺失字段按默认读入，既有v1/v2数据不删除、不升级。边框宽0–32、圆角0–512，均为设计像素，颜色严格#AARRGGBB。设计器与传统View按同一画布比例缩放，文本样式覆盖文本控件及单选/下拉/列表子项，不虚构图片字体。

UI.command沿用强类型宿主请求、三秒取消/超时和ui.control能力，增加上述固定属性及get:读取；布尔值只接受true/false。隐藏、未挂载页面仍保存更新；重置恢复清单。Schema、Rust清单/运行/编译白名单、Kotlin模型/命令状态、设计器/共享渲染/函数库同时接通，不使用反射或任意Android方法。

这些是智构原生样式，不证明旧Native/SP单位或扩展事件的等价性。转换器必须保留未确认字段并阻断，不能因为新增同名属性就开放猜测转换。真实设备视觉验收独立记录。
