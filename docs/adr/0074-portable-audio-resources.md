# ADR 0074：可选项目音频资源

2026-10-12，用户确认音频随项目备份与独立Runner包携带。替代ADR0073中新导入音频只进入本机data的决定；既有data音频仍兼容，不自动迁移、删除或改写旧积木。

新增清单资源kind=audio，规范路径assets/audio，单文件20MiB、每项目音频总量64MiB；只接受WAV/MP3/OGG/FLAC/M4A，文件头分类不代表平台解码保证。项目备份、冻结发布与Runner资源校验必须一致支持，不把音频当图片或字库注册。

Audio.play继续接受旧data相对路径；assets/audio路径必须在清单声明，使用audio.control，不隐式要求storage.data。宿主在启动准备阶段从有界只读文件描述符复制到独立私有会话缓存；注册仅允许当前准备会话，复核会话票据以拒绝迟到发布。重启保留冻结缓存，不重新读取项目；下一次准备或服务销毁清理所属缓存。脚本不能取得源文件描述符、任意路径或系统文件。

新导入经过现有项目事务、资源路径陈旧检查、限额及校验提交。编辑页提供已声明音频选择与明确导入入口，旧路径仍可填写；导入变更不得把迟到结果回填其他项目。删除声明先检查积木引用，不静默破坏运行数据。音频管理、试听使用明确用户动作，不自动播放私人资源。

平台中文输入方案需用户决定，不借本次音频授权增加输入法。无新增网络、录音、麦克风或免Root能力。剩余文件与浮窗扩展分别记录边界后实现。
