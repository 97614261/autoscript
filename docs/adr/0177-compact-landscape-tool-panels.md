# ADR 0177: 紧凑横屏工具与参数面板

日期：2026-10-28

## 范围与计划

1. 触控、图像工具入口按实际可用宽高及字体缩放自适应，宽窗口使用三至四列，压缩说明、来源选择和分类栏，保留全部入口。
2. 判断参数改为紧凑比较表单；普通条件直接填写，复合条件按需展开，变量候选使用有界选择器。
3. 悬浮准星参考截图工具栏统一外观，增加拖动、屏内约束及横竖屏独立位置记忆，保留原生像素坐标和方向变化拒绝提交。
4. 检查截图工具栏的位置恢复和边界；不改变选区、缩放或取色语义。
5. 一并检查循环、变量计算、输出及通用选项弹窗，压缩固定区域和空白，确认操作固定，正文在小窗、键盘或大字号下可滚动。
6. 仅做相关几何/参数回归、Kotlin 编译及 Lint，集中记录结果；本轮不升版、生成 Studio 安装包、安装设备或发布。

## 约束

宽度只在确有横向空间的短视口下扩展，不将所有弹窗铺满屏幕。保留保存、取消、草稿、来源策略、功能可用性和输入安全校验。说明按需展开，不通过删除功能减少内容。设备视觉效果与主机检查分别记录。

## 实现

- 触控入口保留七类动作、两种取点方式及录制/环境操作；常用动作宽窗三列、持续触点四列。图像保留四个快捷入口及全部分类功能，宽窗四列，收起默认来源和各功能的详细解释。
- 工具入口有顶部关闭按钮时省去重复底栏。仅这些工具及对应参数表单按窗口实际宽高选择最多600dp，普通弹窗默认宽度不变。
- 判断使用紧凑左右值和比较选择；较窄或大字号改为两行/竖排。变量仍可手动输入，候选改为有界选择器，较长列表支持搜索；复合条件、否则如果和原参数校验保留。
- 原生准星工具条采用截图工具条的深色底、蓝色拖动柄、绿色确认；点击柄切换设置，拖动不误触切换，设置和确认均可直接使用。设置正文可滚动，动作和确认条保持可见。
- 两种工具条分别记住横竖屏位置，按当前尺寸约束在屏内。保留准星原像素点位和方向变化取消规则，不执行触摸。
- 循环八类入口改紧凑网格，仅展开当前类型的输入；固定值/变量、单位、循环序号/耗时输出及旧节点保护均保留。变量计算把表达式提前，压缩固定栏、收起说明；输出收起渠道说明并降低空输入区最小行数。通用选项、变量管理标题及触控参数也做了紧凑调整；复合条件移除常驻横滑变量串，通用文本/数学表单说明按需展开。

## 检查边界

定向主机检查覆盖宽度/列数回退、工具条拖动边界和展开后的约束，以及循环、计算、复合条件、输出和原图选区映射。仅复用既有运行和保存契约，不改识图算法、帧策略或脚本执行。设备视觉效果及真实拖动/键盘交互本轮尚未验收；不将编译和主机几何检查称为手机显示已通过。
