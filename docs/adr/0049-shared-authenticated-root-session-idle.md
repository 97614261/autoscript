# ADR 0049：Root 双通道共享认证会话空闲期限

状态：接受（2026-10-09，用户确认修复持续找图时的采集后端失败）。

## 问题

业务和优先停止连接分别按五分钟无消息关闭。停止线程按事件唤醒，不发送心跳；因此业务持续截图时，安静的停止连接仍可能超时并触发安全栅栏，后续截图返回空的 BackendFailure。期限从连接建立起算，不是从脚本开始起算。

## 决定

同一 RootDaemon 的两条已认证连接共享单调活动时刻，使用同一时钟原点。完整鉴权、序列号和命令形状校验成功的业务/停止消息及认证截图流进度才刷新活动；未完成 Hello 的连接仍使用自己的握手期限。整个会话确实空闲时继续有界退出，不添加周期 Lua 轮询或无条件心跳，不延长配置的空闲期限。

等待下一包首字节时，socket 按当前剩余会话期限阻塞；无字节超时后重新检查共享活动，只有其他认证通道已刷新期限才继续等。收到首字节后，长度头及载荷共用八秒绝对期限；半包超时、EOF、鉴权/重放错误不得重新同步或继续使用连接。包和帧资源上限、逐包认证以及独立优先停止通道保持不变。

停止连接真实失败仍关闭输入安全栅栏，并立即取消已在执行的操作及录制；取消后复用断连清理释放指针和回收输入桥，业务连接退出仍负责完整会话回收。共享活动不是连接存活证明，不能掩盖 EOF 或将连接成功当作 Root 能力就绪。

## 验证

使用可推进时钟和模拟分段读取验证超过旧五分钟的业务活动、长期安静后认证停止、整体空闲、握手独立期限、无效鉴权/重放不续命、首字节前可续期但半包不可续期、绝对包期限、断连取消。不得运行用户私人脚本；最终按 build.cmd -Verify 测试、Lint、构建并保留数据安装到 MuMu。

2026-10-09 验证完成：新增13项回归通过，Root四个crate合计60项通过、1项性能测试按默认忽略；模拟时钟推进30分钟后独立认证Cancel仍能取消活动操作。格式检查及主机/Android x86_64 Clippy完成，保留既有非阻断警告，严格-D warnings因旧录制代码警告未通过，不声称零警告。build.cmd -Verify成功（1分18秒），Android五模块572项中571通过、1跳过、0失败，Lint无错误（34 Warning、16 Hint）；arm64/x86_64及内嵌Runner构建成功，已保留数据安装MuMu 0号实例。设备长时间私人脚本复测由用户完成，不将模拟时钟结果描述成30分钟设备实测。
