# ADR 0164 字库制作快捷标注与补样

日期：2026-10-26。状态：采纳。

## 决定

- 制作窗增加数字、数字符号、大小写、常用符号及自定义采样目标，按当前样本显示缺采字符。点击缺字只明确预填下一次单字取样的标注，不定位图像、不猜字、不要求收齐目标才能保存。
- 待加入批次使用与字形一一对应的可空标注，允许任意顺序逐字填写；应用后跳到下一个未标注项。整行粘贴仅在字符数相同且全部有效时应用；未完成输入及未应用的单字编辑阻止追加、切换和覆盖标注。
- 数字与符号快捷键明确标注当前字形并前进，支持括号、正负号、小数点等。批量快捷填充只在样本数精确对应时显示，全部字母数字仍明确为62字，不因新增符号组改变顺序。
- 可以移除单个误切字形，标注随原字形一起移除；仅保留最近一次移除的恢复入口，后续标注或新批次使恢复失效，避免恢复覆盖新修改。空批次仍可恢复最后一次移除，不更改已加入样本及原图。
- 不改ASGLYPH v1、运行识别/切分算法、颜色预算和资源保存确认；保留已有撤销/重做、测试绑定和原图像素。仅定向主机检查及Kotlin编译，不升版、打包、安装或发布，设备便利性及布局另验。
