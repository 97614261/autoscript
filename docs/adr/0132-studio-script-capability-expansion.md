# ADR 0132 Studio脚本能力扩展

日期：2026-10-19

状态：已采纳，分批实现

## 授权与范围

用户明确要求执行主线六批，并新增HTTP/打开网址、可点击拖动并回调脚本的图片浮窗、特征匹配、新OCR模型、多指输入和生产输入法。OCR范围再次确认为数字与英文字母，优先准确率和速度。新模型作为固定、显式可选候选，不自动替换已有模型或默认算法。独立Runner扩展、下载器、账号市场云功能和免Root仍不在范围内；ARM打包保持暂停。

## 边界

- 文本编码、路径处理、尺寸查询等纯工具继续使用固定契约、显式变量、受限源码及原预算，不执行任意Lua，不开放文件系统外部路径。
- HTTP由独立有界异步工作队列执行，仅http/https，系统TLS证书校验不可关闭。请求、响应、头、重定向、并发及总期限均有限；取消主动关闭连接。默认不记录网址、请求头、正文或响应。打开网址为显式系统ACTION_VIEW，不自动提交或下载文件。
- 设备查询只读，不提升授权。Root连接、实际输入特性和系统授权分别报告。常亮只持有所属运行的资源，停止/失败/重启释放，不改写用户系统休眠设置。
- 交互图片浮窗使用独立能力，不改变现有触摸穿透浮窗。图片只读冻结声明资源；事件有界排队并由脚本等待/分支消费，回调不是任意代码。移动使用设备原像素，停止清理窗口、等待者及迟到事件。
- 特征匹配新增明确算法，不冒充像素多尺度或灰度匹配。通过现有OpenCV窄适配层实现有界ORB描述子、匹配、几何验证与结果坐标；缺组件阻断，不降级换算法。
- 新数字英文OCR候选固定来源、版本、摘要与字典，保留原模型；先比较公开合成集的整行准确率、混淆项、初始化、P50/P95/P99及内存，再允许显式选择。拒绝任意外部模型，不做通用中文OCR。
- 多指输入使用Root结构化命令、完整状态机和同任务触点所有权。取消/停止清理全部触点；没有实测能力的设备明确拒绝，不以单指支持冒充多指。
- 生产输入法提供显式启用/选择入口，不静默切换。只提交脚本明确提供的有限文字，不读取、保存、联网上传用户输入，不自动恢复或更改其他输入法设置。停止和焦点/输入连接代次变化拒绝迟到提交。

## 当前实现选择（2026-10-20）

- HTTP采用系统URLConnection、无自动重定向/重试，独立有界工作线程及异步取消连接。仅GET/POST/PUT/DELETE/HEAD/OPTIONS；不声称支持平台不可靠的PATCH。原始正文16KiB、请求正文8KiB、整体跨JNI JSON32KiB；响应正文以Base64返回，不混淆字符集。平台DNS无法保证可强制抢占，取消未返回的工作继续占用有界槽位，不无限增线程。
- 交互图片窗口与旧穿透窗口分开管理，最多8窗/8M显示像素。每窗只记录完成的点击/拖动，最多64条，丢弃计数显式返回；`Floating.waitImageEvent`使用独立JNI等待槽/工作线程，不阻塞普通关闭、更新及Root。返回固定事件数据后显式判断/调用插件，不执行字符串回调。
- 图片窗口的等待注册、触摸队列及关闭均投递到同一Android主线程；JNI等待不占主线程，快速关闭不借助IO队列。设备验收不得用只测JNI分通道代替真实点击/拖动及窗口移除。
- 视觉预览的可选期限不得改变已有七参数JNI入口，保留JVM重载及反射签名回归；独立事件取消入口也需R8保留。公开像素直接调用后端与实际编译脚本/JNI调用必须分别验收。
- 多指复用既有认证指针命令和任务租约，扩展实际指针编号0–4及ASI2桥接握手。只有成功启动真实多指MotionEvent适配器才发布多指特性，客户端必须协商；没有多指能力的新API连编号0也拒绝。指针ID与MotionEvent的数组下标分离，共用downTime；部分失败、停止或EOF发送完整CANCEL。普通单指命令和旧设备降级仍保留，不用多进程单指拼接冒充多指。
- 固定英文V5 ONNX为7,872,351字节、SHA256 `c3461add59bb4323ecba96a492ab75e06dda42467c9e3d0c18db5d1d21924be8`，438类解码预算独立于原V4的97类/旧256上限。仅输出ASCII数字英文字母；历史同一公开合成集V4整行105/150、V5为80/150，不推荐默认替换。V5只是用户明确要求的可选候选，不宣传为已提高准确率。
- ORB限制512个特征、1M像素ROI、256K像素模板、最多256次RANSAC、至少8个内点，检查凸四边形及0.25–4倍几何范围；黑白/透明掩膜不冒充天然特征。特征与V5目前要求相应内置后端；旧固定签名外置SPI不支持扩展操作，明确拒绝，不给旧组件传未知参数或回退其他算法。新版外置组件发行能力仍独立记账。
- 生产输入法位于运行进程，仅系统BIND_INPUT_METHOD可绑定。脚本提交有4096字节预算和不透明焦点票据，不读取周边文字/剪贴板、不留文本历史。启用与选择均由用户决定；本批MuMu临时选择已获用户同意，测试结束须恢复原输入法并停用智构输入法。
- 用户允许删除旧安装包；本批仅删除明确核对的development目录四份自动APK备份，不扩大到项目、图片、脚本或当前安装包。自动备份可重新构建，删除文件本身不保留恢复副本；ARM候选包仍暂停。
- 设备组合验收发现旧`Screen.release`把已加载项目图片也绑定到截图能力。释放改属`core.task`，兼容仅声明`screen.capture`的旧项目；仍校验当前任务帧租约和所有权，不因此允许截图或借用其他任务句柄。API、积木、可用性和编译器同步，测试明确不声明`screen.capture`，旧截图流程也须保持通过。

## 交付要求

每项必须同时具备API契约、原生积木配置、编译/运行、能力及类型校验、函数库文档和取消测试；不发布空壳入口。主机代码检查、MuMu合成验收、真实ARM/API24及生产设备效果分别记录。执行状态见[扩展计划](../reference/studio-capability-expansion-plan.md)，未验证项目不标已完成。
