# 0068 函数库补强的数据与宿主边界

2026-10-11，接受。用户要求继续补完五批，仍不扩大到云服务、免Root、任意Shell或多指。

文本/JSON和日期扩展为固定Rust函数，保留旧Data.get只读标量的规则；另设子结构、存在性、类型、合法性接口。文本按Unicode标量、索引1起，字节接口另名，不猜测旧索引。文本/结果最多64KiB；JSON沿用16层/1024项；正则限制模式128字节、输入4096字节、最多64结果和1MiB编译预算，不支持回溯扩展。增加regex固定维护版本，双MIT/Apache2许可证，纯Rust不引入Android API/ABI运行依赖；构建后记录实际体积，不猜体积数字。

文件扩展仅访问当前项目私有script-data/<project>/data，复用认证宿主、取消/期限、O_NOFOLLOW、原子提交、回收和总配额。新增固定opcode，参数通过有界JSON数组传递；不接受任意方法名或项目身份。宿主回包为严格JSON标量并由Rust依契约解码，旧四个文件接口不改协议。文本文件仍限64KiB、总512KiB/256项；目录删除只允许空目录，复杂复制/压缩需独立原子暂存和配额测试，不能以无操作表示成功。

新增积木复用类型化工具配置，字符、整数和浮点来源/结果必须声明；路径与参数同样检查，特殊宿主接口不会绕过project.json.capabilities。日期的墙钟/固定时区与单调时钟分开，不改变系统时间。

界面运行属性只能扩展白名单，明确读写和列表索引/选项值差异；不以动态Android反射处理。未显示的页面状态继续保留，不让显示/隐藏影响数据。主窗位置与设计控件位置不同，不能共享单位假装等价。

中文输入如采用项目自带输入法，只能由用户显式启用/选择，输入法服务绑定需系统BIND_INPUT_METHOD，提交仅走当前有效InputConnection；不会静默修改默认输入法或读取密码内容。首次授权入口与状态报告必须能区分“已启用”“已选中”和“有当前输入目标”。Root仍为自动化运行前提，不新增免Root触摸后端。

脚本停止/重启只能通过运行服务的优先控制通道，重启先完成旧会话取消与输入清理，不并行创建第二运行。提示/日志开关只影响对应通道，不自动记录用户变量和文本。是否提供高影响系统写操作仍按原计划另行决定。
