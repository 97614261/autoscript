# ADR 0010：插件语义与冻结运行契约

## 决定

- 用户界面的 Flow 统一称“插件”：独立可视化流程文件，可被其他插件调用；不是 Dex/Android 扩展插件。持久化 flowId、节点 kind、路径和协议不改，旧项目不迁移或删除。
- 编辑器运行当前插件，只替换内存中的入口调用，不修改校验过的生成文件；顶层任务始终返回 nil，插件调用返回独立序号通道。
- 声明的全局变量在一次顶层运行内共享；每次插件调用新建局部变量，局部声明和参数遮蔽同名全局变量。数值初始为 0、文本为空、图像为空；未声明变量仍为调用局部变量，兼容旧积木。声明变量写入检查类型，允许 nil 表示空值；图像是运行时整数句柄。新一轮运行重置全局状态。
- 序号调用参数优先于命名参数。使用序号设置节点的插件可以省略对应必填命名参数，实际调用仍检查必填和类型；条件分支未执行设置时必须报错，不能静默默认。下一次调用前消费并清空发送通道；参数和返回通道只传递非空标量。
- 发布冻结项目弹出提示样式，但不冻结开发用日志过滤或运行延迟。可视化样式进入编译器输出并计入 source map；Lua 项目只打包清单中的模块，局部 require 支持嵌套调用、缓存和循环依赖报错，不开放文件系统。
- 生成摘要包含插件声明、入口、变量和弹出提示样式，避免仅修改这些元数据时误用旧生成物。

## 验证

主机回归覆盖入口尾部契约、跨插件共享与局部遮蔽、序号参数优先/清空/运行时校验、提示样式冻结和模块加载。设备交互由用户验证，本批不宣称设备实测。
