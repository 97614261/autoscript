# ADR 0053: 区分取帧开始前取消与不完整流

日期：2026-10-10

## 原因

设备故障注入发现：优先停止已取消截图，但业务连接把开始前的完整取消响应当作半帧断连，提前关闭停止通道，使已请求的触点清理被标为失败。

## 决定

- 只有发送前的停止门禁取消，或通过鉴权、序号、命令和请求身份校验的首个空 Cancelled 响应，可以保留业务连接。
- 收到成功的流元数据之后，任何错误（包括取消、缺失结束摘要、半包、篡改及关联错误）仍作废整个连接；不能复用残留帧。
- 保留连接不代表停止成功，终态仍必须等待独立认证停止确认；真实清理失败继续报告 failed。
- 文件诊断仅保存白名单结构错误码，不保存原始 Lua 诊断或用户源码。

## 验证

增加开始前取消后再次取新帧与 Ping、流中取消作废连接、非法取消内容拒绝等回归，并重跑设备中途停止测试。
