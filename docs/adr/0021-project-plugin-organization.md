# ADR 0021：项目、插件与可携带组织信息

日期：2026-10-02。用户授权执行项目文件组织计划 1–5。

## 决定

- 项目是完整脚本工程；插件是独立可视化流程文件；主插件是项目启动入口。展示采用这些术语，`flowId`、节点 kind、`.jsonl`、`project.json` 与 Rust/Runner 协议不改名、不迁移。
- 标题点击进入插件选择与维护，不混入图片/变量/界面文件。主插件可显式设置；切换前校验原入口、插件列表及界面参数绑定，不自动解除用户绑定。
- 分组是虚拟分类，仍使用 `.studio/source-groups.json`，但从本批起是可携带项目组织信息，进入备份、导入、恢复；其他 `.studio` 状态与生成产物仍排除。
- 图片目录是真目录。使用 `.studio/image-directories.json` 记录空目录，限制为图片根目录内四层、256 个目录、64 KiB。截图保存的三个入口共享 ProjectStore 创建/读取目录；旧项目已有目录被有界扫描识别。目录元数据可携带，不进入运行能力清单。
- 备份增加上述两个可选、精确白名单文件；无这些文件的旧备份继续导入。拒绝非法版本、路径、重复成员、不存在插件、越界目录及未声明额外文件，不宽泛允许整个 `.studio`。
- 复制插件复制其局部变量定义，保留全局变量和外部调用，生成新的流程/节点/块身份。删除插件同时清理仅属于它的局部变量；有界面事件或变量绑定的插件不得删除，批量删除失败逐项反馈。
- 改名不改变引用身份、变量作用域和界面事件。变量及界面设计继续留在项目清单，避免拆文件造成协议与兼容迁移。

## 验证要求

覆盖主入口切换/冲突/参数绑定、局部变量复制与删除、界面引用保护、改名稳定、分组和空目录备份往返、旧备份、安全拒绝、Lua 文件目录及资源恢复；相关单测、Lint、Debug 打包和 MuMu 0 保留数据安装。设备运行体验由用户验收。
