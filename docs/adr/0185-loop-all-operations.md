# ADR 0185: 同页显示全部循环操作

日期：2026-10-29

用户接受0184的行式样式，但要求取消“更多”，支持上下滚动查看全部，并指出比最开始少功能。

对照最初提交`a40d0d3`中的循环面板与0017的功能范围：原有八种操作未从执行层删除，但等待、到次跳出、到时跳出收进额外选择区，序号/耗时输出与让步或安全次数上限改为隐藏配置，导致入口缩减。草稿读取、类型锁定、变量候选、时长解析和构建五个纯函数与该提交原样一致。

- 保持已接受的单选左列、参数右列、30dp输入及蓝灰白样式；直接遍历八种操作，参数分支穷尽全部枚举。
- 八项均在同一张表单：无限、限次、限时、读取次数、读取耗时、等待/空循环、到次跳出、到时跳出。各自数值/变量、预设及单位保留，不跳转到其他操作页。
- 所选循环的序号输出、耗时输出、每轮让步或旧安全次数上限直接列在下方，不再折叠；可选输出保留清空，单位及作用域保护不变。
- 固定顶部来源切换与底部取消/加入，正文按窗口剩余高度滚动，右缘显示滚动指示；校验错误在确认栏上方固定可见。保留窄窗/大字号的上下字段排列。
- 删除更多/高级状态、选择面板、附加参数页及不用的局部切换按钮。变量管理/搜索、预设次数与时长、毫秒/秒/分钟、数值和变量草稿、类型锁定、连续加入与原事务保留。

不改变原解析、参数构建、运行时API或执行语义。只运行原10项循环定向检查及必要Release编译，沿原x86_64优化构建、压实/必要包检查，保数据安装MuMu 0供查看；不重跑整套验收、不提交积木或运行项目、不连接真机、不升版或发布。实际结果另记。

实际结果：原10项循环检查全部通过，Release生产/测试编译、原优化构建、压实及必要包检查通过。候选保持0.1.30/versionCode31，51827450字节，SHA256 `261f98a3fa6ce2a01d597d3e91ca222c0bf22c196407d3d541ff4ad277418f01`。沿原安装函数保数据覆盖MuMu 0，首次安装时间保留，冷启动Status ok/456ms，进程8680。
