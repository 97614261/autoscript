# ADR 0186: 毫秒与逐行变量选择

日期：2026-10-29

用户要求取消循环的单位切换和顶部固定值/变量切换，在原单位按钮位置直接选择变量。

- 保留0185的八项同页滚动表单、紧凑行式样式及固定底栏；删除顶部来源栏和单位展开控件。
- 新建限时、超时及耗时读取统一默认毫秒；原3秒默认值显示为3000毫秒，时长预设同步使用毫秒。
- 每个参数独立提供选择变量按钮。选中后展示名称，数值入口恢复该行固定输入；切换操作按该行实际绑定恢复来源，不再整页联动。取消变量选择保留原来源及草稿。
- 原固定时长等值显示为毫秒，解析与执行预算不变；旧变量的秒/分钟单位以及旧耗时读取输出单位保持原意并只读显示，不把变量值或输出悄悄改成毫秒。返回固定输入时等值转换。
- 保留变量类型、作用域和输出保护、预设、八类执行契约、草稿及原加入事务。
