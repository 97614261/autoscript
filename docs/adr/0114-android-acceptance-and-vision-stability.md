# ADR0114: Android验收与视觉稳定性收口

2026-10-15。用户要求继续修复OCR准确率、MuMu全流程、视觉组件与稳定性未完成项。用户随后明确允许保存后重启智构App复验，以及OCR策略/模型评估；正式替换须再次确认。本批不更换固定模型、不以字符替换或放宽断言掩盖失败，不把环境阻塞写成成功。

## 决策

- 优先使用Android标准Instrumentation及UiAutomation验证Android App，而非通过Windows鼠标驱动模拟器；不构建替代Windows控制通道。测试入口仅在androidTest APK，正式Studio/Runner没有新增入口或测试接口。
- Studio测试创建明确自有的QA工程；进入前复核无用户编辑/配置/活动运行会话，运行控制只处理自身工程及当前会话身份。未知/其他项目会话立即拒绝，不停止或清理用户工作。
- 只在明确授权的MuMu目标设备使用合成脚本和合成内容，不运行私人脚本。权限仅只读检查，缺悬浮/Root授权时明确阻断，不自动授予、不代点认证弹窗、不重启/清数据。
- 测试任务、UI查询、识别及稳定性循环均有明确上限，报告只含固定用例名、白名单错误码、公开合成结果和测量条件，不保存私人界面文本、项目名称、路径或截图。
- 外部视觉组件仍为固定发行签名的两种SDK，使用真实签名/实际清单/白名单/准备/加载检查；验收仅在独立测试包私有目录中进行，不修改Studio的组件选择或默认full。Native代码钉住及快照租约继续保持到进程退出，不为清理测试而删除活动快照。
- MuMu实测PackageManager会向无权限的已签名组件归档元数据加入QUERY_ALL_PACKAGES。身份、版本、最低SDK及代码标志仍经PackageManager读取并复核；声明权限/组件数改由PackageManager为同一只读已验签APK创建的Resources读取实际二进制AndroidManifest.xml，采用有界解析并复核package/version/minSdk/hasCode，仍要求声明权限及入口均为零。不按权限名做忽略白名单、不信任描述自报身份或降低签名校验。
- 真实PathClassLoader在可写快照目录创建oat目录，会污染只允许固定形状的准备区并阻断后续恢复/准备。Android发布前把明确所属的快照及native目录封为0500，禁止ART在冻结目录写缓存；只有获得所属租约后的精确清理才恢复0700，不删除旧快照中未知的oat内容。JVM校验库通过宿主注入封存/解除封存动作，不直接依赖Android Os。测试改用新的自有沙箱，旧测试证据目录保留。
- OCR诊断保留原始失败用例，比较字形及明确ROI，诊断变体不替换原门禁。性能只报告同条件样本与实际采样内存，采样最大值不冒充进程历史峰值或真机结果。
- OCR策略评估仅在独立androidTest中对公开字母数字、混淆字符和两种字体比较原图、显式紧ROI、白边和双倍缩放。每策略按相同样本报告整行精确率和耗时；完成评估与识别全对分开。候选模型先审查官方来源、许可、体积及导出/Android适配，不下载执行未经验证的外部模型，不把官方异条件指标当本设备结果。
- 编辑窗最大化使用系统栏/刘海之外的工作区，保持真实屏幕虚拟坐标、脚本设计坐标及原小窗几何不变；Android30+读取maximumWindowMetrics的系统栏/刘海Insets，旧系统按显示可用尺寸和系统栏资源保守留白，不隐藏系统栏。实际触摸与无障碍语义动作区分，不能靠语义点击绕过系统栏来宣称按钮可用。
- 编辑窗及吸附球隐藏同时同步原生View的VISIBLE/INVISIBLE、窗口alpha及触摸标志，不仅依赖透明度隐藏。保留已挂载组合/测量和草稿，不detach重建；隐藏控件不得继续出现在可见无障碍树。恢复实际触摸结果单独记录。

## 边界

Android程序断言不替代视觉体验、所有键盘/字体/系统版本验收；MuMu的ARM转译支持不作为ARM真机。新夹具执行结果和未完成项统一写入Studio首版总账，不重复堆叠“已完成”口径。
