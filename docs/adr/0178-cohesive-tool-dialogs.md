# ADR 0178: 工具弹窗视觉统一

日期：2026-10-28

用户反馈0177紧凑改版整体难看，并明确要求统一重做。本轮只调整这一批工具入口和表单的视觉组织，不改主页、项目数据或执行行为。

## 决定

- 沿用现有蓝灰白配色，统一圆角、描边、字号和点击高度；减少连续方框和重复的文字按钮。
- 触控所有动作采用等宽入口，图像快捷入口与功能采用同一视觉组件；横屏继续三至四列。
- 输入与选择使用同一控件外观；变量选择嵌入输入框右侧，保留手输、清空和长列表搜索。
- 判断采用有标签的左右操作数和比较方式；循环用模式选择加参数分区，计算、输出及通用选择同步统一。
- 保留工具条拖动、屏内约束、短窗口滚动、确认取消、草稿及输入安全。工具条采用现有截图样式，不增加状态徽标或更换品牌。
- 先完成源码与必要编译，再集中看实际视觉；本轮不升版或发布线上。

## 实现

- 新增共用的图标入口、轻量操作按钮、分段选择和表单标签；沿用蓝灰白配色，普通输入和选择采用6dp圆角，面板标题改深色，蓝色用于图标和选中状态。
- 触控七种动作和录制采用同一等宽网格，横屏最多四列，窄窗按实际字号减少列数；保留原Root能力门禁、两种取点方式与环境入口。
- 图像四个快捷入口与各类功能统一图标和文字卡片。默认截图策略放入标题右侧选择，分类紧接功能网格；保留全部项目、偏好记忆和每项配置中的显式来源。
- 手动变量输入与候选选择合并为单个输入框，右侧图标打开选择；长列表仍支持搜索和清空，不重复显示当前变量。图像识别和复合条件同步复用输入样式。
- 简单判断分开标注左右值和比较方式，右值的固定值/变量选择明确；横屏并排、较窄回退。复合条件仍保留原JSON标量、变量优先级、输入校验和树预算。
- 循环保留八种模式、所有参数和旧节点保护，预设嵌入数值框，单位采用同一分段选择，序号/耗时输出按宽度并排。计算的辅助键自动换行，输出的内容框提前，说明按需展开。
- 所有加入、保存、草稿和资源事务不变；不修改运行时API、识图算法、帧策略、Root会话或输入安全。截图/准星工具条沿用0177的拖动和屏内位置约束。

## 验收边界

本轮主机定向检查沿用窗口几何、复合条件、循环、计算、输出及原图选区映射用例；不为外观调整重复编写执行模型测试。MuMu 0检查时未启动，未主动启动或安装设备，因此主机检查和构建不能当作实际手机视觉、手势或键盘验收。
