# ADR 0122：增量候选点游标

状态：撤回（2026-10-17，识图性能第六阶段评估）。

## 决定

曾评估让 `pixel-vision` 的四种角点遍历（左上、左下、右上、右下）使用行列
增量游标，避免通过 `emitted / columns` 和 `emitted % columns` 重新计算行列。
中心向外遍历保持原有状态机。

## 原因

虽然增量游标减少了除法和取模，但公平的同进程交错基准显示，额外的游标状态、
换行分支和边界维护在当前编译器/输入下反而更慢。因此不以“理论上少一次除法”
作为合入理由。

## 验证

- 所有搜索方向和步长的唯一性回归继续通过。
- 新增四种角点顺序的固定序列回归，保留为顺序门禁。
- 同进程交错 A/B 基准确认候选不具备稳定收益。
- 生产恢复原有 `emitted / columns` 与 `emitted % columns` 实现。

## 限制

- 不改变识图算法、模板比较或截图链路。
- Windows 主机矩阵受调度噪声影响，必须使用同进程交错 A/B，不能只比较两次独立运行。
- MuMu 当前 ADB 目标为 offline，本阶段没有安装 APK、重启模拟器或运行私人脚本。
