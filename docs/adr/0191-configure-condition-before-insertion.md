# ADR 0191: 先填写判断再加入

日期：2026-10-29

用户要求判断先写好，再加入。

- 右侧条件入口选择如果或否则如果后，先进入现有紧凑条件表单，保留单比较、复合条件及共享变量选择。
- 如果填写完成后再选择位置；取消位置选择返回原表单，保留已填内容。只有实际提交成功才关闭表单，取消不创建占位积木。
- 否则如果填写完成后，将条件和对应子块一次追加到原选中的判断，一次撤销即可恢复。不再创建默认分支后打开编辑窗口。
- 结构化配置严格校验字段、变量名、比较值和复合条件预算，异常配置不回退为默认判断。保留原项目/插件/草稿/完整选择及运行状态核对、分支数限制和保存事务。
- 否则仍直接选择分支内的积木，不增加无意义的位置选择。

仅必要定向主机检查、Release编译和原x86_64优化候选及MuMu0有限查看，不提交或运行私人积木、不连接真机、不升版或上线。实际结果另记。
