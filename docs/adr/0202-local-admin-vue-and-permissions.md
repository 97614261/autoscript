# ADR 0202: 本地正式后台、若依权限与可选账号便利操作

日期：2026-10-31

用户要求直接执行既定1—6：独立Vue工作工程、智构管理菜单、角色/按钮权限、管理员及日志页面、App账号便利操作、集中本地验收并安装MuMu。服务器部署仍稍后，不发布线上或提交Git。

## 实现

- `ruoyi-go/web` 从现有Vue3参考复制为独立工作工程，原参考274个文件摘要未变；保留原框架和接口契约，使用智构品牌与功能入口。
- 正式入口 `/admin/`，Vite子路径构建后随Go内嵌；HTML不缓存、带摘要资源长期缓存、缺资源404，旧 `/studio-admin/` 跳转。构建脚本支持明确npm路径，生成物忽略且按清单清理旧文件。
- 智构账号/云备份复用现有管理API，管理员、角色、菜单、登录及操作日志复用若依页面和权限。手动本地菜单工具事务补缺、重复执行0新增，保留已有状态，不给普通角色自动授权。
- 真实撤权检查发现原Redis pipeline里的 `Script.Run` 在冷脚本缓存时失败，改为等价原子INCR；保留前缀、无TTL、批量与拒绝旧权限语义，不改数据库结构。
- 管理密码不存浏览器缓存，令牌使用独立sessionStorage；401关闭账号操作窗并清空密码。原用户管理不预填默认密码或在成功消息里回显重置密码。
- App记住最后成功账号名和地址，不存密码；登录/注册/改密支持显隐。云备份与本机项目选择新增名称搜索，保留完整名称和原目标。免登录本机编辑/运行、旧个人密钥入口保持可用。
