# ADR 0028：独立旧工程转换工具

日期：2026-10-02。状态：实施。用户明确要求独立工具，并继续转换。

从临时 scripts 脚本提取为 `tools/legacy-converter/` 的独立 Python 包。它不依赖 Android、Studio、MuMu、JNI 或账号；仅使用 Python 3.8+ 标准库。提供 Tkinter Windows GUI、CLI、双击启动脚本和便携ZIP打包器。便携包需要系统 Python/Tk，不宣称无运行时依赖的EXE。

输出目录由用户选择，必须是不存在的新目录；默认工具自身 output 下。库不再绑定仓库的 build 路径。私人输出/output/dist/缓存忽略，原ZIP始终原字节保留，不写日志。仓库验证使用忽略的 build 路径；没有外部插件执行或任意Lua/shell转译。

便携包可以携带已构建的独立Rust编译检查器，来源为当前Flow编译器example，仅做只读编译/语法验证。转换器无检查器也能独立分析/生成审阅草稿，但无完整编译确认不能宣称已验证。正常候选只有检查器通过后才标记 converted；有语义缺口保持 blocked、不提供可运行假工程。

继续支持具有明确树层级的相邻IF/EIF/ELSE链、简单同类型比较、数值 + / - / * 计算。任何分支条件不可迁移时保留整个原结构并阻断，不能只迁移第一分支。不映射C++除法/负数余数、成员访问或函数调用，以免语义发生变化。未完成的旧界面、找图结果、外部函数仍列为后续阶段。

GUI工作在线程中执行；取消和180秒截止通过转换检查点，退出请求先确认当前任务取消。Rust检查器30秒超时；未知项报告包含私人源字段，只在本地文件/GUI显示，终端仅聚合。旧scripts入口保留薄兼容包装，维护实现和测试只在独立包内。
