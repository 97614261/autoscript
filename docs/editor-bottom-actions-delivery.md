# 可视化编辑器底部操作：1–5 批交付

日期：2026-09-30。范围：完整编辑页与项目页悬浮可视化编辑器，共享操作面板。Lua 源码调试器不是本次对齐目标。

## 已实现

1. 底部图标在完整点击区域内居中；更多菜单以按钮实际位置定位并限制在窗口范围。运行、暂停、停止时锁定程序修改，单步单独判断运行状态；只读查找、界面预览与变量查看保留入口。
2. 参数反显是恢复积木参数，不是读取运行变量。可修改原节点，或复用参数在上方、下方、内部、末尾加入；内部存在多分支时明确选择分支。修改保留节点身份及已有子树，复用只复制参数，不复制已有子树。输入、变量、计算、判断、循环、跳转、调试、图像优先使用对应配置页；其他契约使用完整参数表单。拒绝过期参数覆盖和复用重复标签。
3. 删除确认显示包含后代的数量，确认期间程序或选择改变则不能删除。批量删除、复用、禁用与文字替换保持一次撤销。禁用积木保存可选 disabled 标记，不删除数据；禁用容器的子树在编译和执行中排除，恢复后重新校验参数。
4. 单步修订：首次点击从当前插件入口正常运行至所选积木并执行它，停在下一个实际到达的检查点；后续每次单步推进至下一检查点。前置动作和初始化照常执行，不跳过上下文。容器或插件调用会进入实际子节点，最后一步正常结束；目标未到达也正常结束。暂停时底部为继续、单步、停止，黄色“下一步”与蓝色编辑选择独立，自动展开并滚动至暂停行，跨插件调用跟随执行插件。状态事件序号确保快速运行后再次暂停也更新；界面和服务拒绝重复单步，客户端验证项目与会话。禁用节点不能作为启动目标。只修改已验证 Lua 的内存运行副本，生成器升至 plugin-v7，磁盘生成物不被就地改写。
5. 更多菜单提供传统 View 项目界面预览、变量检查、运行变量信息和查找替换。查找可覆盖积木完整参数，替换仅支持提示/日志 message 和字符串 value 的字面文本；不批量改变量名、表达式、资源路径和节点身份。界面预览输入不会写入项目或发送给运行任务。

## 明确限制

- 录制动作缺少 Runtime 的真实输入事件流，标为“未接入”并禁用；现有录制工作区预览不算完成录制功能。
- 参数编辑的输入表单可以修改坐标，重新拾取坐标继续使用现有按键加入向导；本次没有新增编辑表单的悬浮拾取入口。
- 项目界面目前是预览入口，不宣称已经对齐参考软件的全部运行界面能力。
- 不宣称已与参考软件 native 实现逐项等价；单步采用上述明确且可测试的检查点语义。暂停位置必须取得当前项目、当前会话的有效快照，不能推进其他项目的暂停任务。
- disabled 是新增可选字段，旧文档无需迁移或删除；旧严格解析器需与新版 Studio 编译器一起升级，Runner 仍只读取冻结 Lua。
