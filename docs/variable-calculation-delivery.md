# 变量维护与计算（2026-09-29）

## 范围与入口

依据旧一键玩 `script/fun/maths/ifsList/varFuZhi/varName` 与新易编 `x/r72/w72/t72/y72` 源码核对，决策见 ADR0016。只主改可视化，不把源码编辑器当作最终产品。

- 右侧“变量”仍维护声明：局部变量属于当前插件，全局变量在同次运行的插件之间共享；局部/参数优先于同名全局。
- 在变量行点击“赋值/计算”，进入共用紧凑计算弹窗。整数/浮点/字符可操作；图像走截图/识别/释放，不参与标量计算。
- 函数库→变量→变量计算也进入同一个弹窗。已有计算积木的参数修改复用该弹窗，不再落到普通字符串属性表。
- 选择目标→输入常量或选择来源变量→插入运算符/类型转换→加入。目标与来源选择显示类型和局部/全局/参数；图像、外部插件局部以及被遮蔽的全局不误当作可用标量。
- “＋变量/＋维护变量”可在不丢计算草稿的情况下维护变量；确定持久化后回到计算。声明只改变变量表，赋值/计算加入的是执行时积木，不在编辑阶段执行。
- 维护页删除声明有确认；修改声明不自动改写旧节点引用，界面明确说明须修正并编译检查，不冒充已有安全批量重命名。
- 同日变量维护页重排为搜索/类型筛选与紧凑卡片，宽屏两列，新增/编辑独立短表单；草稿取消有放弃确认。循环源码审查与未完成项见 `variable-page-loop-audit.md`，不要将本批变量改版当作循环补齐。

## 计算语义

`variable.calculate` v1 新节点，字段 `name/expression`；旧 `variable.set/copy`、项目、flowId 和脚本API兼容，不新增任意Lua执行或宿主权限。

- +、-、*、/、//、%、..、一元正负号与括号；/ 为浮点除法，// 向下整除，% 遵循Lua地板余数，.. 只接受字符。
- int/float/text 六种整数、浮点、字符之间的显式转换；浮点转整向零截断，字符转数值只接受十进制，不接受NaN/Infinity/十六进制或任意表达式。
- 目标整型不隐式接收浮点运算；需要 `int(...)`。64位整数运算检查溢出，来源与目标均按声明规范化，最小整数生成 `math.mininteger`，不丢精度。
- 表达式1..1024 UTF-8字节，最多128个AST项，嵌套16层；字符输入/结果限4096字节。除零、非有限数值、越界转换、超长连接报错，不静默设零。
- 运算符和变量在光标处插入，可替换选中文字；类型转换包裹选中部分或整个表达式，不产生“旧表达式后拼一个函数”的无效代码。数值目标才启用自增/自减。
- 声明变量默认整数/浮点为0、字符为空、图像为空；需要初值时插入赋值/计算积木。局部值每次插件调用独立，全局值在新一轮脚本运行重置。
