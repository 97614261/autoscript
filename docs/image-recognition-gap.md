## Rust 真实能力与缺口

| 能力 | 当前状态 | 依据/还差什么 |
|---|---|---|
| 缓存屏幕帧、资源模板加载、释放 | 已实现 | `runtime-executor` 的 Screen 调用、`automation-core` FramePool，宿主 Root 截图另走结构化 HostRequest |
| 取色、比色、区域找色、统计/全部找色、多点找色 | 已实现并有 Lua/积木链路 | `pixel-vision`、`runtime-executor`、`flow-compiler` |
| 单模板、ROI、RGB容差、相似度、透明像素跳过 | 已实现并接通 | `pixel-vision::find_template`、`runtime-executor::find_image`；是确定性像素匹配，不是 OpenCV 算法 |
| 搜索方向 | 已接通五方向 | Screen.findImage 尾部可选方向、findImages、节点v2和共享弹窗；旧多点颜色映射独立保持 |
| 字库 OCR | 已实现并接通 | `glyph-ocr` 的 ASGLYPH 字库读取、识别、覆盖率/得分；不是通用 ONNX OCR |
| 多模板/文件夹匹配 | 已接通 | 仅声明资源1–64张，共享比较预算/取消，目录冻结排序、首个匹配，返回模板路径/得分/坐标 |
| 返回“图像数据” | 裁剪完成，参考语义未知 | Screen.crop/匹配区域图像是独立任务帧；参考未反编译方法阻断真实返回结构确认，不能宣称等价 |
| 识别频次 | 已接通 | 1–30 次访问一次、首次识别、每轮运行重置；跳过清空输出、不截图、不输入 |
| 成功后点击/按下/停顿/弹起 | 已接通组合 | 五种动作、有界原始像素偏移/时长、自动帧释放、共用原输入仲裁与任务清理；旧Root降级停止限制见输入文档 |
| OpenCV 灰度/特征/缩放等匹配 | 未实现 | 当前 workspace 无 OpenCV 适配层；不能把像素匹配标成 OpenCV |
| ONNX OCR | 未实现 | 当前 workspace 无 ONNX 推理适配层/模型执行后端 |
| 范围坐标使用变量 | 已接通 | 固定值或显式整数变量引用，禁止源码表达式，别名/声明类型/ROI内核检查 |

这不是“整个 Rust 项目全部完成”的结论。Root 输入、Lua 执行、变量/条件/循环、插件调用与运行调度已有真实实现；本表只核对当前图像弹窗及相关执行链路。账号、在线授权、市场等仍按项目约束不实现。
