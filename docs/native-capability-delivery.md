每项验收链路：模型及边界 → Rust/冻结Lua真实执行 → 可视化配置与修改 → 函数库查阅/加入 → 保存恢复 → 独立转换规则 → 单元测试、Lint、Debug构建与MuMu更新安装。重大契约变化先ADR，不改名称、图标、既有启动行为或旧工程数据。

## 批次

1. 变量计算：原生字节长度/查找/截取、向零整除/余数；保留既有字符语义。首个5项增量已实现，边界见ADR0030；不代表全部旧表达式已迁移。
2. 循环：复用现有限次/限时/指标，补真实可取消的无限循环与旧检测语义，编辑器同样可选。
3. 调用：成功/失败状态与返回参数分开，加入/修改能配置结果分支，冻结后Runner同样执行。
4. 视觉：有界多匹配结果及属性读取、匹配后动作，接入原生图像配置与函数库。
5. 界面：统一有界控件上限、页签/分组、样式和事件，设计器/预览/Studio/Runner共享渲染。
6. 全量转换与验收：只在语义确认且编译通过时生成最终工程；缺原图/插件及入口需原稿确认。设备行为验收单列，不自动执行私人脚本。
7. 动态提示：复用强类型计算DSL，内容拼接与三个输出渠道分开，旧提示节点不静默改类型。

本批使用入口：变量 → 赋值/计算 → 字符处理或整数运算；函数 → 变量 → 变量计算。目标需已声明，integer接收长度、位置、整除/余数，string接收截取文本。保存仍是variable.calculate节点，编辑复用原面板，无新持久化临时状态。

示例：`byteLen("中文") = 6`，`byteFind("中文A","A",0) = 6`，`byteSub("中文A",3,3) = "文"`，`idiv(-7,3) = -2`，`irem(-7,3) = -1`。`byteSub("中",1,1)`拒绝；`len("中文") = 2`、`find("中文A","A") = 3`不变。
