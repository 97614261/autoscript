# 编辑、输入、图像与权限收尾

2026-10-03：用户要求执行后续计划 1–2，重新设计图像页面，增加快速权限入口和软件权限状态页。

## 编辑

- 保留底栏运行、单步、编辑、更多；更多内容不改。
- 编辑操作按参数、历史与剪贴板、排列与管理分组，宽窗三列、窄窗两列，显示实际选择数，无选择也能访问历史、粘贴和多选。
- 整理/多选由全屏改为共享小窗：全选/清除选择、可滚动积木列表、四列操作网格，无横向隐藏按钮；选择上限 256，不向过期节点发送选择命令。参数修改、模板复用、子树编辑与撤销仍走原宿主命令。

## 按键和运行

- 保留正式的点击、滑动、长按、拖动、按下、移动、弹起契约和现有 Root 执行器，不增加免 Root 后端。
- 悬浮选点启动的输入特性读取和 Binder 等待移至 IO，界面可继续响应；读取后和启动后分别校验服务/会话/请求身份。
- 取消或切换插件时取消准备协程；Binder 不能强制中断，返回后在不可取消清理段请求关闭迟到窗口。没有声称同步 Binder 可被强制终止。
- 防止重复选点，选点准备/进行期间阻止运行；成功回调早于启动返回时不再报告伪失败或把应用错误地切到后台。
- 按键面板增加权限/环境和重新读取能力；仍区分读取中、没有基础输入、没有持续单指支持。单步状态、暂停继续、优先停止、任务触点释放沿用现有链路与回归测试，不假定设备实测完成。

## 图像

- 可视化图像主入口改为找图、颜色、文字三个紧凑分组，顶部直接访问截图/取图、图片库、识别测试；没有宿主入口的按钮禁用。
- 识别配置分识别设置、输出结果、高级/动作三页，不删除任何已有配置参数，页签切换保留草稿；帧与自动截图、频次、动作偏移/等待集中在高级，模板、范围和阈值位于主配置。
- 提供屏幕框选和项目全屏快捷动作；坐标仍保存为半开 L/T/R/B，不改变像素协议。结果属性页保留专用配置，不强行套入无关模板页。
- 加入、修改、函数库仍复用同一正式配置和校验；截图保存文件夹与资源登记沿用既有实现。

## 权限

- 我的 → 软件权限、运行环境页、项目设置和按键面板均可打开共享权限状态小窗。
- 快速入口为悬浮窗、通知、应用权限、电池限制、重新检查、声明权限；返回系统设置或重新打开页面时重新读取状态，不固定周期轮询。
- 显示悬浮窗、通知、电池优化、Runner、Root、基础输入、持续单指与 Root 截图准备状态；声明权限读取实际安装包。Root 授权由 Root 管理器处理，页面不会假授权，不将未测试截图标为截图成功，不请求无障碍、系统录屏或全部文件访问。
- 系统设置入口不可用时回退应用详情并明确提示；项目 capabilities 不被此页更改。
