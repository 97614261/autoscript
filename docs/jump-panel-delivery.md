# 跳转面板调整

可视化“跳转”现在按实际执行流程分为六项：流程操作、调用插件、设置调用参数、读取调用参数、设置返回参数、读取返回参数。调用插件可直接选择目标插件；加入后继续打开现有调用积木参数编辑器。调用/返回参数的固定值只接受非空标量，数字与布尔值按原类型传递，数字样式的文字需要双引号；变量来源排除已声明的图像变量，等待毫秒变量只列出数值变量。序号、变量名和固定值在插入前检查。

跳转标记可从当前插件已有的根层级标记中选取；自动标记使用首个未占用的 `mark_N`。完整可视化编辑器与项目页悬浮编辑器共用加入前的标记、根层级和循环体检查，也都保留所选调用目标及该目标的必填参数默认值。旧的管道格式调用/返回参数提示仍可读取，不迁移或删除已有节点。

执行语义保持不变：设置调用参数写入下一次插件调用，目标插件读取调用参数；设置返回参数后返回上层，调用者再读取上一次返回参数。标记和跳转仅限当前插件根层级，`break` 只作用于最近一层循环。完整编辑器的调用节点仍可继续编辑参数。

主机验证：Studio `testDebugUnitTest`、`lintDebug`、`assembleDebug`。设备端交互和不同分辨率下的弹窗布局仍需人工验收。

居中修正：固定值/变量等分段选项、序号/来源标签、选择变量/选择标记按钮统一使用容器水平和垂直居中，去掉按字体估算的顶部留白，并关闭按钮文字的额外字体留白。
