## 用户操作

- 编辑弹窗点标题，进入“项目插件”。点击一行打开插件；长按进入管理；勾选单个插件可“设为主插件”。主插件决定项目启动入口，不等于当前正在编辑的文件。
- “新建”可以创建插件或分组；分组只分类，移入分组不移动真实文件；删除分组只解散分类，不删除成员。
- “另存为”复制结构并生成独立身份，同时复制该插件的局部变量定义和所属分组。不复制运行时变量值，不重新解释外部插件调用。
- 改名只改变显示名与文件路径；已保存的调用、变量作用域、界面事件继续使用原 flowId，不会断开。
- 删除主插件前先设置其他主插件。被调用或被界面引用的插件必须先解除引用。删除成功会清理仅属于该插件的局部变量，并重置指向它的提示变量筛选；全局变量和其他插件局部变量不受影响。
- 图像页面的“文件夹”可选择/创建位置；保存截图或设置中导入图片可选择位置。空文件夹立即落盘，不必先保存图片才能保留。
- 备份/恢复仍使用原本的项目备份入口/三个槽位；恢复创建新项目，保留内部引用身份，不覆盖原工程。

## 数据目录（不改成旧软件专用格式）

逻辑结构如下；实际项目目录可在项目文件信息中查看，仍位于 Studio 私有项目存储目录。

```text
<projectId>/
  project.json                    项目配置、主插件、变量、界面、资源声明、能力真相
  visual/flows/<名称>.jsonl        可视化插件；名称可变，flowId 不变
  lua/...                         Lua 调试项目的源码/辅助模块
  assets/images/<子目录>/...       项目图片，允许四层子目录
  dictionaries/...                字库资源
  .studio/source-groups.json      插件虚拟分组，包含空分组
  .studio/image-directories.json  空图片目录的有界可携带清单
  generated/...                   编译生成文件，不参与工程备份
```

参考旧一键玩的“工程/插件/图片/变量信息/界面”和易编精灵的“源文件/分组配置/图片/变量/界面”职责划分，但不引入 `.cj`、`.sue`、`.pz` 等不兼容格式，也不将内部“插件”混同 Android 扩展 APK。

变量及界面继续在清单保存；这是有意保留协议兼容，不是尚未完成的拆文件工作。

## 兼容与限制

- 两个组织清单是备份中精确允许的可选文件；旧备份没有它们仍可恢复，原有物理图片目录可被扫描识别。
- 仅携带这两个 `.studio` 文件；缓存、日志、编辑器临时状态、生成文件仍排除。新备份不保证可被未升级的旧 App 导入。
- 插件/分组名称共用存储规则，最多 64 字符；最多 256 插件、64 分组、512 变量（旧工程转换需要，见 ADR 0027）。
- 图片目录最多四层、256 个，组织清单各不超过 64 KiB。拒绝越界路径、非法 JSON/版本、重复成员、丢失父目录和未知文件；失败导入清理临时目录，不修改现有项目。
- 切换主插件前检查旧入口/插件集合，拒绝过期快照。新入口与现有界面参数绑定不兼容时拒绝保存，不自动解绑用户界面。
- 文件夹创建失败不会登记不存在的目录；如果真实目录创建成功但元数据写入失败，该目录可在下次读取/备份时扫描找回。

架构决定见 [ADR 0021](adr/0021-project-plugin-organization.md)。
